面试核心考点
1.map 是指针类型 — make(map) 返回 *hmap，传参拷贝指针，函数内修改外面能看到
2.一个 bucket 存 8 个 KV — tophash 存哈希高 8 位做快速过滤，满了挂溢出桶
3.两种扩容 — 负载 >6.5 翻倍扩容（增量搬迁防卡顿）；溢出桶太多等量扩容（整理碎片）
4.三大坑 — 写 nil map panic；并发读写 fatal；delete 不释放内存只标记空
5.遍历随机 — 故意设计，防止依赖顺序

关键说明

Map 底层结构 (hmap)
桶数组 buckets：每个桶存 8 个键值对 + 溢出桶指针
哈希种子 hash0：随机化，防止 hash 攻击
负载因子阈值 = 6.5（平均每个桶 6.5 个元素时扩容）
扩容策略：翻倍扩容（桶数 ×2）或等量扩容（整理溢出桶）
查找流程
1. hash(key) + hash0 计算哈希值
2. 低 B 位定位桶号，高 8 位（tophash）在桶内快速匹配
3. 逐个比较 tophash → 命中后比较完整 key
4. 当前桶未命中 → 查溢出桶链表
并发安全
❌ 并发读写 Map → panic: concurrent map read and map write
❌ 并发写 Map → panic: concurrent map writes
✅ 方案 1：sync.RWMutex 保护，读多写少首选
✅ 方案 2：sync.Map：读多写少场景无锁读，写多场景反而更慢
扩容细节
翻倍扩容：桶数翻倍，元素重新分配到新桶（渐进式，每次操作迁移 1-2 个桶）
等量扩容：桶数不变，整理溢出桶使其更紧凑（大量删除后触发）
扩容期间读写正常：先查旧桶，未完成迁移的桶会触发迁移再查
渐进式迁移避免一次性停顿，但扩容期间性能有轻微下降
