面试核心考点总结

1. map 是指针类型
make(map) 返回的是 *hmap 指针，函数传参时拷贝指针，指向同一个对象，所以函数内修改外面 100% 能看到，和 slice 不一样！
2. 一个 bucket 存 8 个键值对
满了就挂溢出桶，tophash 存哈希高 8 位，用来快速过滤，不用真比较整个 key。
3. 两种扩容策略
  • 负载 > 6.5 → 翻倍扩容（增量搬迁，防止卡顿）
  • 溢出桶太多 → 等量扩容（不翻倍，整理溢出桶，释放内存）
4. 三大坑
  • 写 nil map 直接 panic，读不会
  • 并发读写直接 fatal error
  • delete 不会释放内存，只是标记为空
5. 遍历是随机的
故意设计的，防止用户依赖遍历顺序。
