常见问题

你可能想了解的

OpenHands 与 Cursor / GitHub Copilot 有什么区别？

Cursor 和 Copilot 是代码补全/编辑辅助工具，工作在 IDE 中，需要人来主导。 OpenHands 是一个自主 Agent 平台——它能独立完成从理解需求到交付代码的全过程， 运行在沙箱环境中，可以执行命令、跑测试、调试错误，更像是一个"AI 同事"而非"补全工具"。

支持哪些编程语言？

OpenHands 本身不限定语言——只要沙箱环境中有对应的工具链（Python、Node.js、Java、Go、Rust 等）， Agent 就能编写和运行对应语言的代码。它对 Python、JavaScript/TypeScript 等主流语言支持尤其成熟。

数据安全如何保障？

OpenHands 可完全私有化部署，所有代码和数据都在你的基础设施内。 沙箱环境提供进程/容器级隔离，企业版还支持 SSO、RBAC、审计日志等安全特性。 你也可以选择使用本地模型（如 Ollama），数据完全不出网。

可以自定义 Agent 的行为吗？

完全可以。你可以通过自定义提示词、添加 MCP 工具、编写新的 Agent 类来定制 OpenHands 的行为。 社区已经贡献了面向各种场景的 Agent 实现，你也可以基于 SDK 构建完全自定义的工作流。

沙箱环境会被 Agent 搞坏吗？

不会。每个会话都运行在独立的沙箱中——Docker 模式下每个会话一个容器， K8s 模式下每个会话一个 Pod。会话结束后沙箱即被销毁，不会影响宿主系统或其他会话。 了解更多 →
