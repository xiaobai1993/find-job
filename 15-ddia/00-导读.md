# 《数据密集型应用系统设计》DDIA 导读

> Martin Kleppmann 著，O'Reilly 2017 年出版
> 业界公认分布式系统入门+进阶最佳读物，后端面试高频考点来源

## 全书结构

```
Part I  数据系统基础（Ch1-3）  ← 面试必考，概念打底
Part II 分布式数据（Ch5-9）    ← 重中之重，区分度高
Part III 派生数据（Ch10-12）   ← 架构设计加分项
Ch4 编码与演化                ← 独立章节，跨 Part 适用
```

## 各章面试权重

| 章节 | 主题 | 面试权重 | 说明 |
|------|------|----------|------|
| Ch1 | 可靠/可扩展/可维护 | ★★★☆☆ | 概念框架，理解即可 |
| Ch2 | 数据模型与查询语言 | ★★★☆☆ | 关系 vs 文档，图数据库 |
| Ch3 | 存储与检索 | ★★★★☆ | LSM-Tree vs B-Tree，面试热点 |
| Ch4 | 编码与演化 | ★★☆☆☆ | 向后/向前兼容，了解即可 |
| Ch5 | 复制 | ★★★★★ | 主从复制，复制延迟，面试必问 |
| Ch6 | 分区 | ★★★★☆ | 分区策略，热点问题 |
| Ch7 | 事务 | ★★★★★ | 隔离级别，ACID，面试核心 |
| Ch8 | 分布式系统的麻烦 | ★★★★★ | 故障模型，时钟，知识盲区杀手 |
| Ch9 | 一致性与共识 | ★★★★★ | 线性一致性，Raft，最高频考点 |

## 阅读策略

1. **第一遍**：Ch1 → Ch5 → Ch7 → Ch8 → Ch9 → Ch11（核心链路）
2. **第二遍**：补 Ch2/3/4/6/10/12
3. **面试前**：重点复习 Ch5/7/8/9 的"面试重点"小节
