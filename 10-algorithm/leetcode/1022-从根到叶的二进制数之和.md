# 1022. 从根到叶的二进制数之和

题目链接：`https://leetcode.cn/problems/sum-of-root-to-leaf-binary-numbers/`

---

## 一、题目描述

给定一棵二叉树，每个节点的值只可能是 `0` 或 `1`。

每一条从根节点到叶子节点的路径，都可以表示一个二进制数。

要求返回所有根到叶子路径表示的二进制数之和。

---

## 二、先看例子

比如这棵树：

```text
        1
       / \
      0   1
     / \ / \
    0  1 0  1
```

从根到叶子一共有 4 条路径：

```text
1 -> 0 -> 0  = 二进制 100 = 十进制 4
1 -> 0 -> 1  = 二进制 101 = 十进制 5
1 -> 1 -> 0  = 二进制 110 = 十进制 6
1 -> 1 -> 1  = 二进制 111 = 十进制 7
```

所以答案是：

```text
4 + 5 + 6 + 7 = 22
```

---

## 三、和 1290 二进制链表转整数的关系

这题可以看成：

```text
1290 二进制链表转整数 的树版本。
```

1290 是一条链表：

```text
1 -> 0 -> 1
```

表示二进制：

```text
101 = 5
```

这题是二叉树：

```text
每一条根到叶子的路径，都是一条二进制链表。
```

所以共同公式都是：

```text
cur = cur * 2 + 当前位
```

或者写成位运算：

```text
cur = (cur << 1) | 当前位
```

---

## 四、为什么是 `cur = cur*2 + node.Val`？

二进制从左往右读时，每来一位：

```text
原来的值先左移一位，也就是乘 2
再加上当前这一位
```

比如路径：

```text
1 -> 0 -> 1
```

计算过程：

```text
初始 cur = 0

走到 1：cur = 0 * 2 + 1 = 1
走到 0：cur = 1 * 2 + 0 = 2
走到 1：cur = 2 * 2 + 1 = 5
```

最终 `5` 就是二进制 `101` 对应的十进制。

---

## 五、递归函数怎么定义？

这题适合 DFS 递归。

定义一个函数：

```go
func dfs(node *TreeNode, cur int) int
```

它的含义是：

```text
从 node 开始继续往下走，当前路径前面已经形成的值是 cur，
返回从 node 到所有叶子路径形成的数字之和。
```

这个 `cur` 非常关键。

它表示：

```text
从根节点走到当前节点之前，已经算出来的二进制值。
```

---

## 六、递归过程

对当前节点：

### 1. 空节点

```go
if node == nil {
    return 0
}
```

空节点没有路径，贡献是 `0`。

---

### 2. 更新当前路径值

```go
cur = cur*2 + node.Val
```

或者：

```go
cur = (cur << 1) | node.Val
```

---

### 3. 如果当前节点是叶子节点

叶子节点条件：

```go
node.Left == nil && node.Right == nil
```

说明一条完整路径结束了。

这时直接返回当前路径值：

```go
return cur
```

---

### 4. 不是叶子节点，继续递归左右子树

```go
return dfs(node.Left, cur) + dfs(node.Right, cur)
```

因为最终答案是：

```text
所有根到叶路径对应数字之和。
```

---

## 七、Go 解法：乘 2 写法

```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func sumRootToLeaf(root *TreeNode) int {
    return dfs(root, 0)
}

func dfs(node *TreeNode, cur int) int {
    if node == nil {
        return 0
    }

    cur = cur*2 + node.Val

    if node.Left == nil && node.Right == nil {
        return cur
    }

    return dfs(node.Left, cur) + dfs(node.Right, cur)
}
```

这个版本最直观，推荐先掌握。

---

## 八、Go 解法：位运算写法

```go
func sumRootToLeaf(root *TreeNode) int {
    return dfs(root, 0)
}

func dfs(node *TreeNode, cur int) int {
    if node == nil {
        return 0
    }

    cur = (cur << 1) | node.Val

    if node.Left == nil && node.Right == nil {
        return cur
    }

    return dfs(node.Left, cur) + dfs(node.Right, cur)
}
```

解释：

```text
cur << 1：把原来的二进制数左移一位
| node.Val：把当前节点值补到最低位
```

例如：

```text
cur = 10（二进制）
node.Val = 1

cur << 1 = 100
100 | 1 = 101
```

## 九、Python3 解法

### 写法一：乘 2 写法

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def sumRootToLeaf(self, root: Optional[TreeNode]) -> int:
        def dfs(node, cur):
            if not node:
                return 0

            cur = cur * 2 + node.val

            if not node.left and not node.right:
                return cur

            return dfs(node.left, cur) + dfs(node.right, cur)

        return dfs(root, 0)
```

---

### 写法二：位运算写法

        return dfs(root, 0)

## 十、例子走一遍

树：

```text
        1
       / \
      0   1
```

初始调用：

```text
dfs(root=1, cur=0)
```

走到根节点 `1`：

```text
cur = 0 * 2 + 1 = 1
```

---

### 左路径：1 -> 0

走到左孩子 `0`：

```text
cur = 1 * 2 + 0 = 2
```

这是叶子节点，所以返回：

```text
2
```

它对应二进制：

```text
10
```

---

### 右路径：1 -> 1

走到右孩子 `1`：

```text
cur = 1 * 2 + 1 = 3
```

这是叶子节点，所以返回：

```text
3
```

它对应二进制：

```text
11
```

---

最终结果：

```text
2 + 3 = 5
```

## 十一、为什么不需要保存整条 path？

一种直观写法是：

```text
先把根到叶路径保存到数组 path
到叶子节点时，再把 path 转成二进制数
```

这种写法可以理解，但不够简洁。

更推荐的是：

```text
边往下走，边把当前二进制值算出来。
```

也就是：

```text
cur = cur*2 + node.Val
```

这样到叶子节点时，`cur` 已经是这条路径对应的十进制值了。

不需要再回头遍历路径数组。

## 十二、复杂度分析

时间复杂度：

```text
O(n)
```

每个节点只访问一次。

空间复杂度：

```text
O(h)
```

`h` 是树高，来自递归调用栈。

如果树平衡：

```text
O(log n)
```

如果树退化成链表：

```text
O(n)
```

## 十三、容易错的点

### 1. 不要等到叶子再重新算 path

可以这么做，但更麻烦。

推荐递归过程中直接维护：

```text
cur = cur*2 + node.Val
```

---

### 2. 叶子节点才返回 cur

只有走到叶子节点时，一条完整路径才结束。

叶子条件是：

```go
node.Left == nil && node.Right == nil
```

不能在中间节点就把 `cur` 加到答案里。

---

### 3. 左右子树结果要相加

因为答案是所有根到叶路径之和：

```go
return dfs(node.Left, cur) + dfs(node.Right, cur)
```

不是取最大，也不是只走一边。

---

### 4. 这题节点值只有 0 和 1

因为每个节点表示二进制的一位。

所以才可以用：

```go
cur = (cur << 1) | node.Val
```

---

## 十四、面试表达

可以这样说：

> 这题可以看成二进制链表转整数的树版本。每一条从根到叶子的路径都表示一个二进制数。递归时我会维护一个当前路径值 `cur`，每走到一个节点，就把之前的值左移一位，也就是 `cur = cur * 2 + node.Val`。如果当前节点是叶子节点，说明一条完整路径结束，直接返回 `cur`；否则继续递归左右子树，并把左右子树返回的结果相加。这样每个节点只访问一次，时间复杂度是 O(n)。

if node.Left == nil && node.Right == nil {
