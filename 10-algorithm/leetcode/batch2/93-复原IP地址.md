# 93. 复原 IP 地址

## 题目

给一个只含数字的字符串 `s`，返回所有可能组成合法 IPv4 地址的组合。

合法 IP 地址由 4 个整数（每个整数范围 0~255）以点分隔，且每个整数不能有前导零（`"0"` 本身合法，但 `"01"`、`"001"` 非法）。

**示例：**
```
输入: s = "25525512145"
输出: ["255.255.12.145", "255.255.121.45"]

输入: s = "0000"
输出: ["0.0.0.0"]

输入: s = "1111111111111111"
输出: []  // 太长，无法组成合法IP
```

---

## 思路：回溯（Backtracking）

把字符串切 4 刀，每刀取 1~3 位，每次验证这段是否合法，全部取完且字符串用尽则记录结果。

```
"25525512145"
 └─ 第1段: "2" / "25" / "255"
       └─ 取"255", 第2段: "2" / "25" / "255"
              └─ 取"255", 第3段: "1" / "12" / "121"
                     └─ 取"12",  第4段: "145" ✅ → 255.255.12.145
                     └─ 取"121", 第4段: "45"  ✅ → 255.255.121.45
```

### 剪枝条件

| 规则 | 示例 |
|------|------|
| 每段范围 0~255 | `256` 非法 → break |
| 不能有前导零 | `01`、`001` 非法 → break |
| 4 段切完且字符串用尽 | 记录结果 |
| 4 段切完但字符串未用尽 | 直接返回 |

---

## Go 代码

```go
package main

import (
    "fmt"
    "strconv"
)

func restoreIpAddresses(s string) []string {
    var result []string

    // start: 当前处理到字符串哪个位置
    // parts: 已经切了几段
    // current: 当前拼接的IP字符串
    var backtrack func(start, parts int, current string)

    backtrack = func(start, parts int, current string) {
        // 终止条件：4段切完 且 字符串也用完了
        if parts == 4 && start == len(s) {
            result = append(result, current[:len(current)-1]) // 去掉末尾多余的点
            return
        }
        // 剪枝：段数或字符都超了，直接返回
        if parts == 4 || start == len(s) {
            return
        }

        // 每段尝试取 1、2、3 位
        for length := 1; length <= 3; length++ {
            if start+length > len(s) {
                break
            }

            seg := s[start : start+length]

            // 有前导零（比如"01"、"001"）不合法
            if len(seg) > 1 && seg[0] == '0' {
                break
            }

            // 值超过255不合法
            val, _ := strconv.Atoi(seg)
            if val > 255 {
                break
            }

            // 合法，继续递归下一段
            backtrack(start+length, parts+1, current+seg+".")
        }
    }

    backtrack(0, 0, "")
    return result
}

func main() {
    fmt.Println(restoreIpAddresses("25525512145"))
    // [255.255.12.145 255.255.121.45]

    fmt.Println(restoreIpAddresses("0000"))
    // [0.0.0.0]

    fmt.Println(restoreIpAddresses("1111111111111111"))
    // []
}
```

---

## 复杂度分析

- **时间**：O(3^4) = O(81)，最多 81 种组合，近似 **O(1)**
- **空间**：递归深度固定为 4 层，**O(1)**

---

## 总结

这是**固定层数的回溯**经典题：
1. 每层只枚举 1~3 位（而非全部）
2. 三个剪枝条件（范围、前导零、越界）让搜索空间极小
3. 和普通回溯不同，这里不需要"撤销"状态，因为用的是字符串拼接而非原地修改
