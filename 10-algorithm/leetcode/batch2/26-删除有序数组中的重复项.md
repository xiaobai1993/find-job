# 26. 删除有序数组中的重复项

题目链接：`https://leetcode.cn/problems/remove-duplicates-from-sorted-array/`

---

## 一、题目描述

给你一个**升序排列**的整数数组 `nums`，请你**原地**删除重复出现的元素，使每个元素只出现一次，返回删除后数组的新长度。

不能使用额外的数组空间，必须用 O(1) 额外空间原地修改输入数组。

例如：

```text
输入：nums = [1,1,2]
输出：2，nums = [1,2,_]

输入：nums = [0,0,1,1,1,2,2,3,3,4]
输出：5，nums = [0,1,2,3,4,_,_,_,_,_]
```

---

## 二、突破口

数组已经**升序排列**，所以重复元素一定相邻。

不需要排序，只需要跳过和前一个相同的元素。

---

## 三、双指针思路

用快慢双指针：

```text
k：慢指针，指向已去重部分的末尾（写入位置）
i：快指针，向前扫描寻找新的不重复元素
```

规则：当 `nums[i] != nums[k]` 时，说明找到了新元素，`k++`，写入 `nums[k] = nums[i]`。

---

## 四、走一遍例子

`nums = [1, 1, 2, 3, 3]`：

```text
初始：k=0
         k
[1, 1, 2, 3, 3]

i=1：nums[1]==nums[0]，跳过

i=2：nums[2]!=nums[0]，k=1，写入
[1, 2, 2, 3, 3]
    k

i=3：nums[3]!=nums[1]，k=2，写入
[1, 2, 3, 3, 3]
       k

i=4：nums[4]==nums[2]，跳过

返回 k+1 = 3
```

---

## 五、Go 解法

```go
func removeDuplicates(nums []int) int {
    k := 0
    for i := 1; i < len(nums); i++ {
        if nums[i] != nums[k] {
            k++
            nums[k] = nums[i]
        }
    }
    return k + 1
}
```

---

## 六、代码拆开理解

### 1. 初始化

```go
k := 0
```

```text
k=0 表示第一个元素已经是"去重后的第一个"，不需要处理
```

---

### 2. 从 i=1 开始扫描

```go
for i := 1; i < len(nums); i++ {
```

```text
第一个元素不可能是重复的，直接从第二个开始比
```

---

### 3. 发现新元素时写入

```go
if nums[i] != nums[k] {
    k++
    nums[k] = nums[i]
}
```

```text
nums[i] != nums[k]：当前元素和去重末尾不同，是新元素
k++：腾出下一个写入位置
nums[k] = nums[i]：写入新元素
```

---

### 4. 为什么写入不会覆盖未读数据？

```text
k 始终 <= i，写入位置永远不超过读取位置
所以原地覆盖是安全的
```

---

## 七、复杂度分析

时间复杂度：

```text
O(n)：i 和 k 各走一遍数组
```

空间复杂度：

```text
O(1)：只用了两个指针，没有额外数组
```

---

## 八、面试表达

> 数组已排序，重复元素一定相邻。用快慢双指针：慢指针 k 记录去重末尾，快指针 i 扫描新元素。发现 nums[i] != nums[k] 时，k++ 并写入。因为 k 始终不超过 i，原地覆盖是安全的。时间 O(n)，空间 O(1)。
