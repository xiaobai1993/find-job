# 141. 环形链表

题目链接：`https://leetcode.cn/problems/linked-list-cycle/`

---

## 一、题目描述

给你一个链表的头节点 `head`，判断链表中是否有环。

如果链表中存在环，返回 `true`，否则返回 `false`。

---

## 二、核心思路：快慢指针

设两个指针：

```text
慢指针 slow：每次走 1 步
快指针 fast：每次走 2 步
```

如果链表**有环**，快指针一定会在环里追上慢指针，两者相遇。

如果链表**没有环**，快指针会先走到 `nil`，结束。

---

## 三、为什么有环一定相遇

慢指针进入环之后，快指针每轮比慢指针多走 1 步，差距不断缩小：

```text
差距：n → n-1 → n-2 → ... → 1 → 0
```

差距每轮减少 1，一定会经过 0，即相遇。

不会出现"跳过"的情况，因为每轮只差 1 步。

---

## 四、Go 解法

```go
func hasCycle(head *ListNode) bool {
    slow, fast := head, head
    for fast != nil && fast.Next != nil {
        slow = slow.Next
        fast = fast.Next.Next
        if slow == fast {
            return true
        }
    }
    return false
}
```

循环条件 `fast != nil && fast.Next != nil`：

```text
fast 每次走两步，两步都要能走，所以要同时判断 fast 和 fast.Next 不为 nil。
```

---

## 五、复杂度分析

时间复杂度：

```text
O(n)
```

有环时，快指针在环内最多追一圈就追上慢指针。

空间复杂度：

```text
O(1)
```

只用了两个指针。

---

## 六、快慢指针的其他场景

快慢指针是链表题的通用工具，除了判断环，还有以下常见场景。

---

### 场景一：找链表的中间节点（LeetCode 876）

```text
慢指针走 1 步，快指针走 2 步。
快指针到终点时，慢指针刚好在中间。
```

```go
func middleNode(head *ListNode) *ListNode {
    slow, fast := head, head
    for fast != nil && fast.Next != nil {
        slow = slow.Next
        fast = fast.Next.Next
    }
    return slow
}
```

例子：

```text
1 → 2 → 3 → 4 → 5

fast 走到 5 时，slow 在 3，返回 3。
```

偶数长度：

```text
1 → 2 → 3 → 4

fast 走到 nil 时，slow 在 3，返回第二个中间节点。
```

---

### 场景二：找环的入口节点（LeetCode 142）

先用快慢指针找到相遇点，再用数学推导找入口。

**结论：**

```text
相遇后，把其中一个指针移回 head，
两个指针都每次走 1 步，
再次相遇的地方就是环的入口。
```

```go
func detectCycle(head *ListNode) *ListNode {
    slow, fast := head, head
    for fast != nil && fast.Next != nil {
        slow = slow.Next
        fast = fast.Next.Next
        if slow == fast {
            // 找到相遇点，开始找入口
            slow = head
            for slow != fast {
                slow = slow.Next
                fast = fast.Next
            }
            return slow
        }
    }
    return nil
}
```

**为什么这样能找到入口：**

设：

```text
head 到环入口的距离 = a
环入口到相遇点的距离 = b
环的长度 = L
```

相遇时：

```text
slow 走了：a + b 步
fast 走了：a + b + n×L 步（fast 在环里多转了 n 圈）
```

因为 fast 速度是 slow 的 2 倍：

```text
2(a + b) = a + b + n×L
a + b = n×L
a = n×L - b
```

`n×L - b` 就是从相遇点继续走到入口的距离（绕了 n 圈减去已走的 b）。

所以：

```text
从 head 走 a 步到入口
从相遇点走 a 步也到入口
```

两者同步走，一定在入口相遇。

---

### 场景三：找倒数第 k 个节点（LeetCode 19 辅助思路）

让快指针先走 k 步，然后快慢指针同步走。

快指针到 `nil` 时，慢指针刚好在倒数第 k 个节点。

```go
fast := head
for i := 0; i < k; i++ {
    fast = fast.Next
}
slow := head
for fast != nil {
    slow = slow.Next
    fast = fast.Next
}
return slow
```

例子，找倒数第 2 个（k=2）：

```text
1 → 2 → 3 → 4 → 5

fast 先走 2 步到 3。
然后同步走：
  slow=2, fast=4
  slow=3, fast=5
  slow=4, fast=nil → 返回 4
```

---

## 七、快慢指针场景汇总

| 场景 | fast 步长 | slow 步长 | 结论 |
|------|-----------|-----------|------|
| 判断是否有环 | 2 | 1 | 相遇则有环 |
| 找环入口 | 2 | 1 | 相遇后一个回 head，同步走 1 步再次相遇处为入口 |
| 找链表中点 | 2 | 1 | fast 到终点时 slow 在中点 |
| 找倒数第 k 个 | 1（先走 k 步） | 1 | fast 到终点时 slow 在倒数第 k 个 |

---

## 八、面试表达

> 这题用快慢指针。慢指针每次走 1 步，快指针每次走 2 步。有环的话，快指针每轮比慢指针多追 1 步，差距逐渐缩小到 0，一定相遇。没环的话，快指针先到 nil。时间复杂度 O(n)，空间复杂度 O(1)。
