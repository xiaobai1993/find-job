# 83. 删除排序链表中的重复元素

题目链接：`https://leetcode.cn/problems/remove-duplicates-from-sorted-list/`

---

## 一、题目描述

给定一个已排序的链表的头 `head`，删除所有重复的元素，使每个元素只出现一次。返回已排序的链表。

例如：

```text
输入：head = [1,1,2]
输出：[1,2]

输入：head = [1,1,2,3,3]
输出：[1,2,3]
```

---

## 二、突破口

链表已经**排序**，所以重复元素一定相邻，不需要额外的哈希表。

只需要一个指针 `cur`，遇到 `cur.Val == cur.Next.Val` 时，直接跳过 `cur.Next` 即可。

---

## 三、思路

```text
cur 指向当前节点

如果 cur.Val == cur.Next.Val：
    跳过 cur.Next（cur.Next = cur.Next.Next）
    cur 不动，因为新的 cur.Next 可能还是重复的

如果 cur.Val != cur.Next.Val：
    cur 向前移动一步
```

关键：**发现重复时 cur 不动**，继续比较新的 cur.Next，直到不重复为止。

---

## 四、走一遍例子

`1 → 1 → 1 → 2 → 3`：

```text
cur=1，cur.Next=1，相等 → 跳过，cur.Next 指向第二个 1
1 → 1 → 2 → 3
cur 不动

cur=1，cur.Next=1，相等 → 跳过，cur.Next 指向 2
1 → 2 → 3
cur 不动

cur=1，cur.Next=2，不等 → cur 移动到 2

cur=2，cur.Next=3，不等 → cur 移动到 3

cur=3，cur.Next=nil → 退出循环

结果：1 → 2 → 3
```

---

## 五、Go 解法

```go
func deleteDuplicates(head *ListNode) *ListNode {
    cur := head
    for cur != nil && cur.Next != nil {
        if cur.Val == cur.Next.Val {
            cur.Next = cur.Next.Next
        } else {
            cur = cur.Next
        }
    }
    return head
}
```

---

## 六、代码拆开理解

### 1. 循环条件

```go
for cur != nil && cur.Next != nil {
```

```text
cur != nil：链表没走完
cur.Next != nil：还有下一个节点可以比较
两个都要满足，否则无法访问 cur.Next.Val
```

### 2. 发现重复时跳过

```go
if cur.Val == cur.Next.Val {
    cur.Next = cur.Next.Next
}
```

```text
直接让 cur.Next 指向下下个节点，跳过重复节点。
cur 不动，因为新的 cur.Next 可能还是相同的值。
```

### 3. 不重复时前进

```go
} else {
    cur = cur.Next
}
```

```text
当前节点和下一个节点值不同，cur 才往前走。
```

---

## 七、提交代码的 bug 分析

原始提交：

```go
for p1 != nil {
    for p2 = p1.Next; p2.Val == p1.Val; p2 = p2.Next {
        if p2 == nil {
            break
        }
    }
    ...
}
```

**问题所在**：`for` 循环的结构是 `for init; condition; post`，执行顺序是：

```text
1. init：p2 = p1.Next（p2 可能是 nil）
2. condition：p2.Val == p1.Val  ← 此处如果 p2 是 nil 就直接 panic
3. body：if p2 == nil { break }  ← 永远到不了这里
```

nil 判断写在循环体里完全无效，因为 condition 在 body 之前执行，已经崩了。

正确做法：condition 里必须先判断 nil，或者换一种写法避开这个问题。

---

## 八、复杂度分析

时间复杂度：

```text
O(n)：每个节点最多被访问两次（一次被跳过，一次被 cur 经过）
```

空间复杂度：

```text
O(1)：只用了一个指针
```

## 九、面试表达

> 链表已排序，重复元素一定相邻。用一个指针 cur 遍历，遇到 cur.Val == cur.Next.Val 就跳过 cur.Next。注意发现重复时 cur 不动，因为新的 cur.Next 可能还是重复值。时间 O(n)，空间 O(1)。
