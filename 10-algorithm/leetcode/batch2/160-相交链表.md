# 160. 相交链表

题目链接：`https://leetcode.cn/problems/intersection-of-two-linked-lists/`

---

## 一、题目描述

给你两个单链表的头节点 `headA` 和 `headB`，找出并返回两个单链表相交的起始节点。

如果两个链表没有交点，返回 `null`。

例如：

```text
A:  a1 → a2 ↘
              c1 → c2 → c3
B:  b1 → b2 → b3 ↗
```

返回 `c1`。

注意：

```text
交叉点之后的部分是同一批节点，不只是值相同，是内存地址相同。
```

---

## 二、为什么这题容易没思路

两个链表长度可能不同。

如果直接两个指针同时从头走：

```text
A:  a1 → a2 → c1 → c2 → c3
B:  b1 → b2 → b3 → c1 → c2 → c3
```

走到 `c1` 时，pA 和 pB 所在位置不同，永远错开，对不上。

---

## 三、核心思路：消除长度差

让两个指针各走 `lenA + lenB` 步，步数一样就能对齐。

规则：

```text
pA 走完 A 之后，跳到 headB 继续走
pB 走完 B 之后，跳到 headA 继续走
```

---

## 四、为什么步数相同就能相遇

设：

```text
A 非公共部分长度 = a
B 非公共部分长度 = b
公共部分长度     = c
```

pA 到达交叉点的步数：

```text
走完 A（a + c 步）→ 跳到 headB → 再走 b 步到达交叉点
总步数 = a + c + b
```

pB 到达交叉点的步数：

```text
走完 B（b + c 步）→ 跳到 headA → 再走 a 步到达交叉点
总步数 = b + c + a
```

两者步数相同：

```text
a + b + c
```

所以**同时到达交叉点**，此时 `pA == pB`。

---

## 五、不相交的情况

如果两个链表不相交，公共部分 `c = 0`。

```text
pA 走完 A，再走完 B，共 a + b 步，到达 nil
pB 走完 B，再走完 A，共 b + a 步，到达 nil
```

两者同时走到 `nil`，`pA == pB == nil`，退出循环，返回 `nil`。

---

## 六、Go 解法

```go
func getIntersectionNode(headA, headB *ListNode) *ListNode {
    pA, pB := headA, headB
    for pA != pB {
        if pA == nil {
            pA = headB
        } else {
            pA = pA.Next
        }
        if pB == nil {
            pB = headA
        } else {
            pB = pB.Next
        }
    }
    return pA
}
```

---

## 七、代码拆开理解

### 1. 初始化

```go
pA, pB := headA, headB
```

两个指针分别从各自链表的头部出发。

---

### 2. 循环条件

```go
for pA != pB {
```

退出条件是两个指针指向同一个节点。

有两种退出情况：

```text
pA == pB == nil     → 不相交，返回 nil
pA == pB == 交叉节点 → 相交，返回该节点
```

---

### 3. 走到末尾就跳到另一条链表

```go
if pA == nil {
    pA = headB
} else {
    pA = pA.Next
}
```

注意：**走到 nil 才跳**，不是走到最后一个节点就跳。

如果在最后一个节点就跳，步数会少走一步，对不齐。

---

## 八、例子走一遍

```text
A:  1 → 3 → 5 → 6 → nil
               ↑
B:  2 → 4 → 5 → 6 → nil
```

实际上 5 是同一个节点：

```text
A: [1] → [3] ↘
               [5] → [6]
B: [2] → [4] ↗
```

```text
a = 2，b = 2，c = 2
```

走法：

```text
步数  pA    pB
0     1     2
1     3     4
2     5     5   ← pA == pB，返回 5
```

刚好第 2 步相遇（a + b + c = 2 + 2 + 2 = 6，但因为对称，第 a 步就对上了）。

---

## 九、复杂度分析

时间复杂度：

```text
O(m + n)
```

每个节点最多被访问两次。

空间复杂度：

```text
O(1)
```

只用了两个指针，没有额外空间。

---

## 十、面试表达

> 这题用双指针。两个指针分别从 headA 和 headB 出发，走到末尾后跳到另一条链表的头部继续走。设 A 非公共部分长 a，B 非公共部分长 b，公共部分长 c，pA 到交叉点共走 a+b+c 步，pB 也是 a+b+c 步，所以同时到达交叉点。不相交时两者同时走到 nil。时间复杂度 O(m+n)，空间复杂度 O(1)。

## 十一、一句话记忆

```text
相交链表：两个指针互换起点，走的总路程相同，自然对齐。
```
