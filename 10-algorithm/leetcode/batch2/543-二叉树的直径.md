# 543. 二叉树的直径

题目链接：`https://leetcode.cn/problems/diameter-of-binary-tree/description/`

---

## 一、题目描述

给定一棵二叉树的根节点 `root`，返回这棵树的直径。

二叉树的直径是：

```text
任意两个节点之间最长路径的长度。
```

注意：

```text
路径长度指的是边的数量，不是节点数量。
```

例如：

```text
      1
     / \
    2   3
   / \
  4   5
```

最长路径可以是：

```text
4 -> 2 -> 1 -> 3
```

或者：

```text
5 -> 2 -> 1 -> 3
```

这条路径有 3 条边，所以答案是：

```text
3
```

---

## 二、为什么这个题容易没思路？

因为题目说的是：

```text
任意两个节点之间的最长路径。
```

一看到“任意两个节点”，就容易想复杂：

```text
是不是要枚举所有节点对？
是不是要找两个最远节点？
```

其实不需要。

这题的关键是换个角度：

```text
如果最长路径经过某个节点 node，
那么这条路径长度 = node 左子树最大深度 + node 右子树最大深度。
```

所以我们只需要对每个节点都算一次：

```text
leftDepth + rightDepth
```

然后取最大值。

---

## 三、核心结论

对于任意节点 `node`：

```text
经过 node 的最长路径 = 左子树最大深度 + 右子树最大深度
```

例如：

```text
      node
      /  \
 左边最深  右边最深
```

从左边最深节点走到右边最深节点，一定经过 `node`。

所以这条路径的边数就是：

```text
leftDepth + rightDepth
```

最终答案就是所有节点里的最大值：

```text
max(leftDepth + rightDepth)
```

---

## 四、为什么要用后序递归？

因为要计算当前节点的直径：

```text
leftDepth + rightDepth
```

必须先知道：

```text
左子树最大深度
右子树最大深度
```

所以递归顺序是：

```text
先递归左子树
再递归右子树
最后处理当前节点
```

这就是后序递归。

---

## 五、递归函数怎么定义？

定义一个函数：

```go
depth(node)
```

它的含义是：

```text
返回以 node 为根的树的最大深度。
```

注意：

```text
depth(node) 不是直接返回直径。
```

它返回的是深度。

但在求深度的过程中，顺便更新全局最大直径：

```go
ans = max(ans, leftDepth+rightDepth)
```

这个模式很常见：

```text
递归函数返回一个值，同时用外部变量记录答案。
```

---

## 六、Go 解法

```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func diameterOfBinaryTree(root *TreeNode) int {
    ans := 0

    var depth func(node *TreeNode) int
    depth = func(node *TreeNode) int {
        if node == nil {
            return 0
        }

        leftDepth := depth(node.Left)
        rightDepth := depth(node.Right)

        if leftDepth+rightDepth > ans {
            ans = leftDepth + rightDepth
        }

        if leftDepth > rightDepth {
            return leftDepth + 1
        }
        return rightDepth + 1
    }

    depth(root)
    return ans
}
```

---

## 七、代码拆开理解

### 1. 递归出口

```go
if node == nil {
    return 0
}
```

空树深度是 `0`。

---

### 2. 先算左右子树深度

```go
leftDepth := depth(node.Left)
rightDepth := depth(node.Right)
```

这是后序递归的核心。

必须先知道左右子树深度，才能处理当前节点。

---

### 3. 用当前节点尝试更新直径

```go
if leftDepth+rightDepth > ans {
    ans = leftDepth + rightDepth
}
```

表示：

```text
如果最长路径经过当前 node，
那么长度是 leftDepth + rightDepth。
```

每个节点都试一次，最终 `ans` 就是最大直径。

---

### 4. 返回当前树的最大深度

```go
if leftDepth > rightDepth {
    return leftDepth + 1
}
return rightDepth + 1
```

这表示：

```text
当前节点的最大深度 = 左右子树较大深度 + 当前节点这一层
```

也就是：

```text
max(leftDepth, rightDepth) + 1
```

---

## 八、为什么 `leftDepth + rightDepth` 是边数？

看一个简单例子：

```text
      1
     / \
    2   3
```

对于节点 `1`：

```text
leftDepth = 1
rightDepth = 1
```

路径是：

```text
2 -> 1 -> 3
```

边数是：

```text
2
```

刚好：

```text
leftDepth + rightDepth = 1 + 1 = 2
```

再看单边链：

```text
      1
     /
    2
   /
  4
```

对于节点 `1`：

```text
leftDepth = 2
rightDepth = 0
```

最长路径是：

```text
4 -> 2 -> 1
```

边数是：

```text
2
```

刚好：

```text
leftDepth + rightDepth = 2 + 0 = 2
```

---

## 九、为什么不能只在根节点算一次？

如果只算：

```go
depth(root.Left) + depth(root.Right)
```

会漏掉一种情况：

```text
最长路径不一定经过根节点。
```

例如：

```text
        1
       /
      2
     / \
    3   4
   /     \
  5       6
```

最长路径可能是：

```text
5 -> 3 -> 2 -> 4 -> 6
```

它不经过根节点 `1`。

所以必须在每个节点都计算一次：

```text
leftDepth + rightDepth
```

## 十一、Python3 解法

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def diameterOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        ans = 0

        def depth(node):
            nonlocal ans

            if not node:
                return 0

            left_depth = depth(node.left)
            right_depth = depth(node.right)

            ans = max(ans, left_depth + right_depth)

            return max(left_depth, right_depth) + 1

        depth(root)
        return ans
```

## 十二、复杂度分析

每个节点只会被访问一次。

时间复杂度：

```text
O(n)
```

递归栈空间复杂度：

```text
O(h)
```

其中 `h` 是树高。

如果树比较平衡：

```text
O(log n)
```

如果树退化成链表：

```text
O(n)
```

## 十三、容易错的点

### 1. 直径是边数，不是节点数

最长路径：

```text
4 -> 2 -> 1 -> 3
```

节点数是 `4`，边数是 `3`。

题目要的是：

```text
3
```

---

### 2. `depth` 返回的是深度，不是直径

递归函数：

```go
depth(node)
```

返回的是：

```text
以 node 为根的最大深度。
```

直径用外部变量 `ans` 记录。

---

### 3. 每个节点都要更新一次答案

不能只在根节点算一次。

因为最长路径可能在某个子树内部，不经过根节点。

---

### 4. 更新答案用的是 `leftDepth + rightDepth`

不要写成：

```go
leftDepth + rightDepth + 1
```

因为题目要的是边数。

`leftDepth + rightDepth + 1` 算的是经过当前节点的节点数。

---

### 5. 返回深度时才需要 `+1`

正确：

```go
ans = max(ans, leftDepth+rightDepth)
return max(leftDepth, rightDepth) + 1
```

区别是：

```text
更新直径：不用 +1，因为要边数
返回深度：要 +1，因为要加上当前节点这一层
```

---

## 十四、和最大深度题的关系

这题本质上是在“二叉树最大深度”的基础上加了一步：

```text
每个节点算完左右深度之后，顺便用 leftDepth + rightDepth 更新答案。
```

最大深度题只需要：

```go
return max(depth(root.Left), depth(root.Right)) + 1
```

直径题需要：

```go
left := depth(root.Left)
right := depth(root.Right)
ans = max(ans, left+right)
return max(left, right) + 1
```

---

## 十五、面试表达

可以这样说：

> 这题可以用后序递归。对于任意一个节点，如果最长路径经过它，那么这条路径长度就是左子树最大深度加右子树最大深度。所以递归函数定义为返回当前节点的最大深度，在递归计算左右子树深度之后，用 `leftDepth + rightDepth` 尝试更新全局最大直径。最后递归函数返回 `max(leftDepth, rightDepth) + 1`。因为每个节点只访问一次，所以时间复杂度是 O(n)。

## 十六、一句话记忆

```text
二叉树直径：每个节点都试一次“左深度 + 右深度”。
```

递归函数记成：

```text
depth(node)：返回 node 的最大深度，顺便更新直径。
```

核心代码：

```go
left := depth(node.Left)
right := depth(node.Right)

ans = max(ans, left+right)

return max(left, right) + 1
```
