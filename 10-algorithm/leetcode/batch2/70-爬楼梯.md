# 70. 爬楼梯

题目链接：`https://leetcode.cn/problems/climbing-stairs/`

---

## 一、题目描述

假设你正在爬楼梯，需要 `n` 阶才能到达楼顶。

每次你可以爬 `1` 或 `2` 个台阶。你有多少种不同的方法可以爬到楼顶？

例如：

```text
n=3，答案是 3：
  1+1+1
  1+2
  2+1
```

---

## 二、为什么是斐波那契

要到达第 `n` 级台阶，只有两种可能：

```text
从第 n-1 级跨 1 步上来
从第 n-2 级跨 2 步上来
```

所以：

```text
ways(n) = ways(n-1) + ways(n-2)
```

这就是斐波那契的递推公式。

写出前几项验证：

```text
n=1：1 种
n=2：2 种
n=3：3 种
n=4：5 种
n=5：8 种
```

序列：

```text
1, 2, 3, 5, 8, 13 ...
```

---

## 三、Go 解法

用两个变量滚动，不需要数组：

```go
func climbStairs(n int) int {
    if n <= 2 {
        return n
    }
    a, b := 1, 2
    for i := 3; i <= n; i++ {
        a, b = b, a+b
    }
    return b
}
```

---

## 四、代码拆开理解

### 1. 边界处理

```go
if n <= 2 {
    return n
}
```

```text
n=1 → 1 种
n=2 → 2 种
```

---

### 2. 初始化

```go
a, b := 1, 2
```

```text
a 表示 ways(n-2)，初始为 ways(1) = 1
b 表示 ways(n-1)，初始为 ways(2) = 2
```

---

### 3. 滚动更新

```go
for i := 3; i <= n; i++ {
    a, b = b, a+b
}
```

每轮：

```text
新的 b = 旧的 a + 旧的 b  →  ways(i) = ways(i-2) + ways(i-1)
新的 a = 旧的 b            →  往前滚一位
```

Go 的多重赋值先求右边，所以 `a, b = b, a+b` 不需要临时变量。

---

### 4. 返回

```go
return b
```

循环结束时 `b` 就是 `ways(n)`。

---

## 五、走一遍例子

`n=5`：

```text
初始：a=1, b=2

i=3：a, b = 2, 1+2 = 2, 3
i=4：a, b = 3, 2+3 = 3, 5
i=5：a, b = 5, 3+5 = 5, 8

返回 b = 8
```

---

## 六、复杂度分析

时间复杂度：

```text
O(n)
```

空间复杂度：

```text
O(1)
```

只用了两个变量，没有数组。

---

## 七、面试表达

> 这题本质是斐波那契数列。到达第 n 级台阶只能从 n-1 或 n-2 过来，所以 ways(n) = ways(n-1) + ways(n-2)。用两个变量滚动迭代，时间复杂度 O(n)，空间复杂度 O(1)。
