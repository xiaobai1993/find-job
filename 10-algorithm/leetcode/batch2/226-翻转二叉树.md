# 226. 翻转二叉树

题目链接：`https://leetcode.cn/problems/invert-binary-tree/`

---

## 一、题目描述

给你一棵二叉树的根节点 `root`，翻转这棵二叉树，并返回其根节点。

例如：

```text
输入：
      4
     / \
    2   7
   / \ / \
  1  3 6  9

输出：
      4
     / \
    7   2
   / \ / \
  9  6 3  1
```

---

## 二、核心思路

翻转二叉树 = 对每个节点，交换它的左右子树，然后递归处理两棵子树。

---

## 三、前序 DFS（先交换，再递归）

```go
func invertTree(root *TreeNode) *TreeNode {
    if root == nil {
        return nil
    }
    root.Left, root.Right = root.Right, root.Left
    invertTree(root.Left)
    invertTree(root.Right)
    return root
}
```

顺序是：

```text
1. 交换当前节点的左右子树
2. 递归翻转左子树
3. 递归翻转右子树
```

注意：交换之后 `root.Left` 是原来的 `root.Right`，递归的是交换后的子树。
这没有问题，因为两棵子树都要翻转，顺序无所谓。

---

## 四、后序 DFS（先递归，再交换）

```go
func invertTree(root *TreeNode) *TreeNode {
    if root == nil {
        return nil
    }
    invertTree(root.Left)
    invertTree(root.Right)
    root.Left, root.Right = root.Right, root.Left
    return root
}
```

顺序是：

```text
1. 递归翻转左子树
2. 递归翻转右子树
3. 交换当前节点的左右子树
```

两种写法结果完全一样，只是处理顺序不同。

---

## 五、前序 vs 后序的区别

| 写法 | 交换时机 | 是否正确 |
|------|----------|----------|
| 前序 | 先交换，再递归 | 正确 |
| 后序 | 先递归，再交换 | 正确 |

两种都对，原因是：

```text
翻转操作在哪个时机执行，不影响最终结果。
因为每个节点的左右子树最终都要被翻转。
```

---

## 六、常见错误：交换 value 而不是指针

直觉上可能会这样写：

```go
root.Left.Val, root.Right.Val = root.Right.Val, root.Left.Val
```

这是**错误的**。

---

### 为什么错

交换 `Val` 只改变节点存的数字，**树的结构没有变**（谁是左孩子、谁是右孩子不变）。

看一个不对称的例子：

```text
原始树：
      1
     / \
    2   3
   / \
  4   5
```

期望结果（正确）：

```text
      1
     / \
    3   2
       / \
      5   4
```

如果只交换 value，过程是：

```text
第一步，根节点：swap(2, 3) → 值变了，但子树还挂在左边
      1
     / \
    3   2
   / \
  4   5

第二步，递归左节点（Val=3，它还挂着 4、5）：swap(4, 5)
      1
     / \
    3   2
   / \
  5   4

第三步，递归右节点（Val=2，没有子节点）：什么都不做
```

最终结果：

```text
      1
     / \
    3   2
   / \
  5   4
```

子树挂在了错误的一侧，**结果错误**。

---

### 本质原因

| 操作 | 改变了什么 |
|------|------------|
| `root.Left, root.Right = root.Right, root.Left` | 改变树的**结构**，两棵子树整体换边 |
| `root.Left.Val, root.Right.Val = root.Right.Val, root.Left.Val` | 只改变节点的**数字**，结构不变 |

翻转二叉树要的是**结构翻转**，必须交换指针，不能只交换值。

## 七、复杂度分析

每个节点只访问一次。

时间复杂度：

```text
O(n)
```

递归栈空间复杂度：

```text
O(h)
```

其中 `h` 是树高。

平衡树：

```text
O(log n)
```

退化为链表：

```text
O(n)
```

---

## 八、面试表达

> 这题可以用前序或后序递归。对于每个节点，交换它的左右子树，然后递归翻转两棵子树。前序写法是先交换再递归，后序写法是先递归再交换，两种都正确。因为每个节点只访问一次，时间复杂度是 O(n)，空间复杂度是 O(h)。
