# 144. 二叉树的前序遍历

题目链接：`https://leetcode.cn/problems/binary-tree-preorder-traversal/description/`

---

## 一、题目描述

给定一棵二叉树的根节点 `root`，返回它的前序遍历结果。

前序遍历顺序是：

```text
根 -> 左 -> 右
```

也就是：

```text
先访问当前节点
再遍历左子树
最后遍历右子树
```

---

## 二、例子

给定二叉树：

```text
    1
     \
      2
     /
    3
```

前序遍历结果是：

```text
[1, 2, 3]
```

过程是：

```text
先访问 1
1 的左子树为空
再访问 1 的右子树 2
访问 2
再访问 2 的左子树 3
访问 3
```

---

## 三、你的 Go 提交

你的代码：

```go
func preorderTraversal(root *TreeNode) []int {
    if root == nil {
        return []int{}
    }
    sum := []int{root.Val}
    sum = append(sum,preorderTraversal(root.Left)...)
    sum = append(sum,preorderTraversal(root.Right)...)
    return sum
}
```

这个提交是正确的。

它就是最直观的递归写法。

代码顺序正好对应：

```text
根 -> 左 -> 右
```

---

## 四、递归函数怎么定义？

函数：

```go
func preorderTraversal(root *TreeNode) []int
```

它的含义是：

```text
返回以 root 为根的这棵树的前序遍历结果。
```

那么当前树的前序遍历就是：

```text
当前根节点值 + 左子树前序遍历结果 + 右子树前序遍历结果
```

翻译成 Go：

```go
result := []int{root.Val}
result = append(result, preorderTraversal(root.Left)...)
result = append(result, preorderTraversal(root.Right)...)
return result
```

---

## 五、为什么要用 `...`？

因为：

```go
preorderTraversal(root.Left)
```

返回的是：

```go
[]int
```

也就是一个切片。

而 `append` 如果要把另一个切片里的所有元素追加进去，需要写：

```go
append(result, otherSlice...)
```

所以：

```go
result = append(result, preorderTraversal(root.Left)...)
```

意思是：

```text
把左子树前序遍历结果里的每一个元素，追加到 result 里。
```

如果不写 `...`：

```go
append(result, preorderTraversal(root.Left))
```

类型就不对。

因为 `result` 是 `[]int`，它需要追加的是 `int`，不是 `[]int`。

---

## 六、Go 解法一：返回切片递归版

```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func preorderTraversal(root *TreeNode) []int {
    if root == nil {
        return []int{}
    }

    result := []int{root.Val}
    result = append(result, preorderTraversal(root.Left)...)
    result = append(result, preorderTraversal(root.Right)...)

    return result
}
```

这个版本非常适合理解递归。

---

## 七、Go 解法二：共享 result 递归版

面试里也常见这种写法：

```go
func preorderTraversal(root *TreeNode) []int {
    result := []int{}

    var dfs func(node *TreeNode)
    dfs = func(node *TreeNode) {
        if node == nil {
            return
        }

        result = append(result, node.Val)
        dfs(node.Left)
        dfs(node.Right)
    }

    dfs(root)
    return result
}
```

这个版本不需要每一层都返回切片。

顺序也很直观：

```go
result = append(result, node.Val)
dfs(node.Left)
dfs(node.Right)
```

对应：

```text
根 -> 左 -> 右
```

## 八、Python3 解法

### 写法一：返回列表递归版

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def preorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        if not root:
            return []

        return (
            [root.val]
            + self.preorderTraversal(root.left)
            + self.preorderTraversal(root.right)
        )
```

---

### 写法二：共享 result 递归版

```python
class Solution:
    def preorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        result = []

        def dfs(node):
            if not node:
                return

            result.append(node.val)
            dfs(node.left)
            dfs(node.right)

        dfs(root)
        return result
```

树：

```text
    1
     \
      2
     /
    3
```

调用：

```go
preorderTraversal(1)
```

```text
result = [1]
```

左子树为空：

```text
append []
```

右子树是 `2`，递归。

---

处理节点 `2`：

```text
result = [2]
```

左子树是 `3`，递归。

---

处理节点 `3`：

```text
result = [3]
```

左右都为空，返回：

```text
[3]
```

节点 `2` 的结果：

```text
[2] + [3] + [] = [2, 3]
```

```text
[1] + [] + [2, 3] = [1, 2, 3]
```

## 十、三种遍历顺序对比

```text
前序遍历：根 -> 左 -> 右
中序遍历：左 -> 根 -> 右
后序遍历：左 -> 右 -> 根
```

前序遍历的特点是：

```text
先处理当前节点。
```

所以代码里 `append(root.Val)` 放在最前面。

---

## 十一、复杂度分析

时间复杂度：

```text
O(n)
```

每个节点访问一次。

空间复杂度：

```text
O(h)
```

`h` 是树高，来自递归调用栈。

如果树平衡：

```text
O(log n)
```

如果树退化成链表：

```text
O(n)
```

注意：返回切片递归版会有一些切片拼接开销，但对刷题理解没有影响。

---

## 十二、容易错的点

### 1. 前序顺序不要记错

```text
前序：根 -> 左 -> 右
```

不是：

```text
左 -> 根 -> 右
```

也不是：

```text
左 -> 右 -> 根
```

---

### 2. 空节点返回空切片

```go
if root == nil {
    return []int{}
}
```

这样后面追加空结果时不会出问题。

---

### 3. append 另一个切片要加 `...`

正确：

```go
result = append(result, preorderTraversal(root.Left)...)
```

错误：

```go
result = append(result, preorderTraversal(root.Left))
```

因为后者是把 `[]int` 当成一个元素追加到 `[]int` 中，类型不匹配。

---

### 4. 递归版先掌握即可

这题还有迭代栈写法，但刚开始刷树题时，先掌握递归版就够了。

递归顺序想清楚：

```text
根 -> 左 -> 右
```

代码自然就出来了。

---

## 十三、面试表达

可以这样说：

> 这题是二叉树前序遍历，顺序是根、左、右。递归函数的含义是返回以当前节点为根的子树的前序遍历结果。如果当前节点为空，返回空数组；否则先把当前节点值加入结果，然后追加左子树的前序遍历结果，再追加右子树的前序遍历结果。也可以用一个外部 result，在 DFS 过程中按根、左、右的顺序依次追加节点值。时间复杂度是 O(n)，每个节点访问一次。
