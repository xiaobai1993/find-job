# 590. N 叉树的后序遍历

题目链接：`https://leetcode.cn/problems/n-ary-tree-postorder-traversal/`

---

## 一、题目描述

给定一个 N 叉树的根节点 `root`，返回其节点值的后序遍历。

N 叉树的每个节点可以有多个子节点。

示例树：

```text
        1
      / | \
     3  2  4
    / \
   5   6
```

后序遍历结果：

```text
[5, 6, 3, 2, 4, 1]
```

---

## 二、先理解什么是后序遍历

二叉树的后序遍历是：

```text
左子树 -> 右子树 -> 根节点
```

N 叉树没有固定的左、右子树，而是有一个孩子列表 `children`。

所以 N 叉树的后序遍历是：

```text
先按顺序遍历所有孩子节点
最后访问当前节点
```

也就是：

```text
children[0] -> children[1] -> children[2] -> ... -> root
```

---

## 三、核心思路：递归

这题最自然的写法是递归。

对当前节点 `node` 来说：

```text
1. 如果 node 为空，直接返回
2. 遍历 node.children 中的每一个 child
3. 对每个 child 递归执行后序遍历
4. 所有孩子都遍历完后，再把 node.val 加入结果
```

伪代码：

```text
postorder(node):
    if node == nil:
        return

    for child in node.children:
        postorder(child)

    ans.append(node.val)
```

这就是标准后序遍历：

```text
先孩子，后自己。
```

---

## 四、示例走一遍

树：

```text
        1
      / | \
     3  2  4
    / \
   5   6
```

从根节点 `1` 开始：

```text
1 的孩子是 3、2、4
```

先遍历 `3`：

```text
3 的孩子是 5、6
先访问 5：5 没有孩子，加入结果 [5]
再访问 6：6 没有孩子，加入结果 [5, 6]
3 的孩子都处理完，加入 3：[5, 6, 3]
```

再遍历 `2`：

```text
2 没有孩子，加入结果 [5, 6, 3, 2]
```

再遍历 `4`：

```text
4 没有孩子，加入结果 [5, 6, 3, 2, 4]
```

最后访问根节点 `1`：

```text
[5, 6, 3, 2, 4, 1]
```

## 五、Python3 递归解法

```python
"""
# Definition for a Node.
class Node:
    def __init__(self, val=None, children=None):
        self.val = val
        self.children = children
"""

class Solution:
    def postorder(self, root: 'Node') -> List[int]:
        ans = []

        def dfs(node):
            if not node:
                return

            for child in node.children:
                dfs(child)

            ans.append(node.val)

        dfs(root)
        return ans
```

## 六、Go 递归解法

```go
/**
 * Definition for a Node.
 * type Node struct {
 *     Val int
 *     Children []*Node
 * }
 */
func postorder(root *Node) []int {
    var ans []int

    var dfs func(node *Node)
    dfs = func(node *Node) {
        if node == nil {
            return
        }

        for _, child := range node.Children {
            dfs(child)
        }

        ans = append(ans, node.Val)
    }

    dfs(root)
    return ans
}
```

## 七、你的 Go 提交写法

你的提交：

```go
func postorder(root *Node) []int {
    var result []int
    if root == nil {
        return result
    }
    for _, v := range root.Children {
        result = append(result, postorder(v)...)
    }
    result = append(result, root.Val)
    return result
}
```

这个写法是正确的，而且很符合后序遍历定义。

对应关系是：

```text
1. root == nil，返回空结果
2. 先递归遍历所有 child
3. 把每个 child 的后序结果追加到 result
4. 最后追加 root.Val
```

其中这句很关键：

```go
result = append(result, postorder(v)...)
```

`postorder(v)` 返回的是一个 `[]int`，而 `append` 需要把这个切片里的元素一个个追加到 `result` 里，所以要加 `...`。

不能写成：

```go
result = append(result, postorder(v))
```

因为这样相当于想把一个 `[]int` 当成单个 `int` 追加进去，类型不匹配。

你的写法可以这样理解：

```text
每棵子树先递归拿到自己的后序遍历结果，
然后把这些结果拼到当前 result 中，
最后再把当前节点值放到最后。
```

它和上面的 `dfs + 外部 ans` 写法本质一样。

区别是：

| 写法 | 特点 |
|---|---|
| 你的写法 | 每次递归返回一个新的 `[]int`，再用 `append(... )` 合并 |
| 外部 ans 写法 | 所有递归共享同一个结果切片，直接追加 |

你的写法更直观，特别适合理解后序遍历；外部 `ans` 写法更常见，减少了中间切片的创建和合并。

## 八、为什么递归适合这题？

树本身就是递归结构。

一个 N 叉树节点可以理解成：

```text
当前节点 + 多棵子树
```

后序遍历要求：

```text
先遍历每棵子树
再访问当前节点
```

所以递归天然匹配这个过程。

递归函数只需要负责一件事：

```text
把以 node 为根的这棵树，按照后序遍历加入结果数组。
```

## 九、迭代解法思路

如果不用递归，也可以用栈。

后序遍历是：

```text
孩子 -> 根
```

可以反过来思考。

如果我们先得到：

```text
根 -> 从右到左的孩子
```

最后再反转结果，就能得到后序遍历。

更常用的写法是：

```text
1. 栈里先放 root
2. 每次弹出节点，把节点值加入 ans
3. 把节点的 children 按正常顺序压入栈
4. 最后反转 ans
```

为什么这样可以？

因为栈是后进先出。

对于示例：

```text
1 的孩子是 3、2、4
```

如果按顺序压入：

```text
3, 2, 4
```

那么弹出顺序是：

```text
4, 2, 3
```

临时结果会接近：

```text
根 -> 右边孩子 -> 左边孩子
```

最后整体反转，就变成：

```text
左边孩子 -> 右边孩子 -> 根
```

也就是后序遍历。

## 十、Python3 迭代解法

```python
"""
# Definition for a Node.
class Node:
    def __init__(self, val=None, children=None):
        self.val = val
        self.children = children
"""

class Solution:
    def postorder(self, root: 'Node') -> List[int]:
        if not root:
            return []

        stack = [root]
        ans = []

        while stack:
            node = stack.pop()
            ans.append(node.val)

            for child in node.children:
                stack.append(child)

        return ans[::-1]
```

## 十一、Go 迭代解法

```go
/**
 * Definition for a Node.
 * type Node struct {
 *     Val int
 *     Children []*Node
 * }
 */
func postorder(root *Node) []int {
    if root == nil {
        return []int{}
    }

    stack := []*Node{root}
    var ans []int

    for len(stack) > 0 {
        n := len(stack)
        node := stack[n-1]
        stack = stack[:n-1]

        ans = append(ans, node.Val)

        for _, child := range node.Children {
            stack = append(stack, child)
        }
    }

    for i, j := 0, len(ans)-1; i < j; i, j = i+1, j-1 {
        ans[i], ans[j] = ans[j], ans[i]
    }

    return ans
}
```

## 十二、递归和迭代怎么选？

| 写法 | 优点 | 缺点 |
|---|---|---|
| 递归 | 最符合后序遍历定义，代码短，容易理解 | 树很深时可能有递归栈风险 |
| 迭代 | 不依赖系统递归栈 | 逻辑稍微绕一点，需要最后反转结果 |

刷题和面试时，优先掌握递归写法。

如果面试官追问“能不能不用递归”，再写迭代版本。

## 十三、复杂度分析

时间复杂度：

```text
O(n)
```

每个节点只访问一次。

空间复杂度：

```text
O(n)
```

递归写法的空间来自递归调用栈，最坏情况下树退化成链，递归深度是 `n`。

迭代写法的空间来自栈和结果数组。

## 十四、容易错的点

### 1. 后序遍历是先孩子，后自己

错误顺序：

```text
先加入 node.val，再遍历 children
```

这是前序遍历，不是后序遍历。

正确顺序：

```text
先递归 children，再加入 node.val
```

---

### 2. N 叉树要遍历所有 children

二叉树只有：

```text
left
right
```

N 叉树是：

```text
children 列表
```

所以不能只处理一个或两个孩子，要用循环：

```python
for child in node.children:
    dfs(child)
```

Go：

```go
for _, child := range node.Children {
    dfs(child)
}
```

---

### 3. 空树返回空数组

如果 `root == nil` / `None`，返回：

```text
[]
```

---

## 十五、面试表达

可以这样说：

> N 叉树的后序遍历和二叉树后序遍历本质一样，都是先遍历子树，再访问当前节点。区别是二叉树只有 left 和 right，而 N 叉树有 children 列表，所以递归时需要按顺序遍历所有 children。递归函数的含义是：把以当前节点为根的子树按后序顺序加入结果数组。具体实现就是先对每个 child 调用 dfs，最后再 append 当前节点的值。时间复杂度是 O(n)，每个节点访问一次。
