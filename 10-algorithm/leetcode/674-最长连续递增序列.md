# 674. 最长连续递增序列

题目链接：`https://leetcode.cn/problems/longest-continuous-increasing-subsequence/description/`

---

## 一、题目描述

给定一个未经排序的整数数组 `nums`，找到最长且连续递增的子序列，并返回该序列的长度。

注意关键词：

```text
连续递增
```

也就是说，子序列里的元素必须在原数组中连续相邻。

---

## 二、例子

```text
nums = [1, 3, 5, 4, 7]
```

连续递增片段有：

```text
[1, 3, 5]，长度 3
[4, 7]，长度 2
```

所以答案是：

```text
3
```

注意不能选：

```text
[1, 3, 5, 7]
```

因为 `5` 和 `7` 中间隔了一个 `4`，它们不是连续的。

---

## 三、这题不是 LIS 动态规划

这题容易和“最长递增子序列 LIS”混淆。

LIS 可以不连续，比如：

```text
[1, 3, 5, 4, 7]
```

最长递增子序列可以是：

```text
[1, 3, 5, 7]
```

长度是 `4`。

但是这题要求：

```text
连续
```

所以 `7` 不能跨过 `4` 接到 `5` 后面。

因此这题不需要复杂 DP，只需要比较相邻元素。

---

## 四、核心思路

连续递增只看相邻两个数：

```text
nums[i] 和 nums[i-1]
```

维护两个变量：

```text
cur：当前连续递增段长度
ans：目前见过的最大长度
```

从左到右遍历数组：

如果：

```text
nums[i] > nums[i-1]
```

说明当前数字可以接在前面的连续递增段后面：

```text
cur++
```

否则，递增断了：

```text
cur = 1
```

每一步都更新最大值：

```text
ans = max(ans, cur)
```

---

## 五、为什么断了以后是 cur = 1？

因为即使递增断了，当前元素自己也可以作为一个新的连续递增序列。

比如：

```text
[1, 3, 5, 4, 7]
```

走到 `4` 时：

```text
4 > 5 ? false
```

递增断了。

但是 `4` 自己可以作为新序列开头：

```text
cur = 1
```

然后继续看 `7`：

```text
7 > 4 ? true
cur = 2
```

所以断了不是 `cur = 0`，而是 `cur = 1`。

---

## 六、Go 解法

```go
func findLengthOfLCIS(nums []int) int {
    if len(nums) == 0 {
        return 0
    }

    cur := 1
    ans := 1

    for i := 1; i < len(nums); i++ {
        if nums[i] > nums[i-1] {
            cur++
        } else {
            cur = 1
        }

        if cur > ans {
            ans = cur
        }
    }

    return ans
}
```

---

## 七、Python3 解法

```python
class Solution:
    def findLengthOfLCIS(self, nums: List[int]) -> int:
        if not nums:
            return 0

        cur = 1
        ans = 1

        for i in range(1, len(nums)):
            if nums[i] > nums[i - 1]:
                cur += 1
            else:
                cur = 1

            ans = max(ans, cur)

        return ans
```

## 九、为什么只需要一遍扫描？

因为题目要求连续。

连续意味着当前位置 `nums[i]` 只能和前一个位置 `nums[i-1]` 连接。

所以每一步只需要判断：

```text
nums[i] > nums[i-1]
```

不需要回头看更早的元素，也不需要动态规划数组。

---

## 十、复杂度分析

时间复杂度：

```text
O(n)
```

只遍历数组一次。

空间复杂度：

```text
O(1)
```

只用了 `cur` 和 `ans` 两个变量。

---

## 十一、容易错的点

### 1. 看到“子序列”就以为不连续

这题英文是：

```text
Longest Continuous Increasing Subsequence
```

重点是：

```text
Continuous
```

所以必须连续。

---

### 2. 断了以后不是 cur = 0

错误：

```go
cur = 0
```

正确：

```go
cur = 1
```

因为当前元素自己就是长度为 `1` 的连续递增段。

---

### 3. 循环从 i := 1 开始

因为要比较：

```go
nums[i] > nums[i-1]
```

所以 `i` 从 `1` 开始。

---

### 4. 空数组要特殊处理

如果数组为空：

```go
if len(nums) == 0 {
    return 0
}
```

否则初始化 `cur := 1`、`ans := 1` 会不合理。

---

## 十二、面试表达

可以这样说：

> 这题的关键是“连续递增”，所以它不是普通的最长递增子序列问题，不需要 DP。因为连续，当前位置只能接在前一个位置后面，所以只需要从左到右扫描数组，维护当前连续递增段长度 `cur` 和最大长度 `ans`。如果 `nums[i] > nums[i-1]`，说明递增延续，`cur++`；否则递增断开，当前元素重新作为长度为 1 的新段，令 `cur = 1`。每次更新 `ans` 即可。时间复杂度 O(n)，空间复杂度 O(1)。

## 十三、一句话记忆

```text
连续递增：大就续，断就重开。
```

更完整一点：

```text
只看 nums[i] 和 nums[i-1]，大了 cur++，断了 cur=1，ans 取最大。
```
