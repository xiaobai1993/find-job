# 108. 将有序数组转换为二叉搜索树

题目链接：`https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/description/`

---

## 一、题目描述

给定一个升序排列的整数数组 `nums`，将它转换为一棵高度平衡的二叉搜索树。

题目关键词：

```text
升序数组
二叉搜索树
高度平衡
```

高度平衡的意思是：

```text
每个节点的左右两个子树的高度差不超过 1。
```

---

## 二、你的 Go 提交

你的代码：

```go
func sortedArrayToBST(nums []int) *TreeNode {
    if len(nums) == 0 {
        return nil
    }
    if len(nums) == 1 {
        return &TreeNode{
            Val:nums[0],
        }
    }
    midIndex := len(nums)/2

    root := &TreeNode{
        Val:nums[midIndex],
    }
    root.Left = sortedArrayToBST(nums[0:midIndex])
    root.Right = sortedArrayToBST(nums[midIndex+1:len(nums)])
    return root
}
```

这个提交是正确的。

它就是这题最标准的递归构造写法。

---

## 三、核心思路

因为数组是升序的。

如果要构造二叉搜索树，就要满足：

```text
左子树所有节点值 < 根节点值 < 右子树所有节点值
```

对于升序数组来说：

```text
中点左边的元素都比中点小
中点右边的元素都比中点大
```

所以可以：

```text
每次取数组中点作为根节点
左半部分递归构造左子树
右半部分递归构造右子树
```

---

## 四、为什么取中点？

例如数组：

```text
[-10, -3, 0, 5, 9]
```

中点是：

```text
0
```

那么：

```text
左半部分 [-10, -3] 都比 0 小
右半部分 [5, 9] 都比 0 大
```

这正好符合 BST：

```text
左 < 根 < 右
```

同时，因为每次都取中点，左右两边元素数量尽量接近。

所以树的高度也会尽量平衡。

---

## 五、递归函数怎么定义？

函数：

```go
func sortedArrayToBST(nums []int) *TreeNode
```

含义是：

```text
把 nums 这个有序数组转换成一棵高度平衡 BST，并返回根节点。
```

所以逻辑就是：

```text
1. 如果 nums 为空，返回 nil
2. 找到中点 mid
3. 创建根节点 root，值为 nums[mid]
4. nums[:mid] 递归构造左子树
5. nums[mid+1:] 递归构造右子树
6. 返回 root
```

---

## 六、`len(nums) == 1` 可以省略

你写了：

```go
if len(nums) == 1 {
    return &TreeNode{
        Val: nums[0],
    }
}
```

这没有问题。

但其实只保留空数组判断也够了：

```go
if len(nums) == 0 {
    return nil
}
```

因为当 `len(nums) == 1` 时：

```go
mid := len(nums) / 2
```

得到：

```text
mid = 0
```

然后：

```go
root := &TreeNode{Val: nums[0]}
root.Left = sortedArrayToBST(nums[:0])
root.Right = sortedArrayToBST(nums[1:])
```

左右都是空数组，都会返回 `nil`。

结果自然就是一个叶子节点。

## 七、Go 推荐写法

```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func sortedArrayToBST(nums []int) *TreeNode {
    if len(nums) == 0 {
        return nil
    }

    mid := len(nums) / 2

    root := &TreeNode{
        Val: nums[mid],
    }

    root.Left = sortedArrayToBST(nums[:mid])
    root.Right = sortedArrayToBST(nums[mid+1:])

    return root
}
```

---

## 八、Python3 写法

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:
        if not nums:
            return None

        mid = len(nums) // 2

        root = TreeNode(nums[mid])
        root.left = self.sortedArrayToBST(nums[:mid])
        root.right = self.sortedArrayToBST(nums[mid + 1:])

        return root
```

```text
[-10, -3, 0, 5, 9]
```

第一次取中点：

```text
mid = 2
nums[mid] = 0
```

所以根节点是：

```text
0
```

左边数组：

```text
[-10, -3]
```

右边数组：

```text

```

### 构造左子树

数组：

```text
[-10, -3]
```

取中点：

```text
mid = 1
nums[mid] = -3
```

所以左子树根节点是：

```text
-3
```

它的左边数组是：

```text
[-10]
```

右边数组是：

```text
[]
```

所以得到：

```text
    -3
   /
-10
```

---

### 构造右子树

数组：

```text
[5, 9]
```

取中点：

```text
mid = 1
nums[mid] = 9
```

所以右子树根节点是：

```text
9
```

它的左边数组是：

```text
[5]
```

右边数组是：

```text
[]
```

所以得到：

```text
  9
 /
5
```

最终一种合法结果是：

```text
        0
       / \
     -3   9
     /   /
  -10   5
```


## 十、这题属于什么套路？

这题属于：

```text
有序数组 + 构造平衡 BST
```

固定模板：

```text
中点做根，左边递归，右边递归。
```

它和二分查找有点像，都是不断取中点。

区别是：

```text
二分查找：取中点是为了缩小搜索区间
这题：取中点是为了构造平衡树的根节点
```

---

## 十一、复杂度分析

时间复杂度：

```text
O(n)
```

每个数组元素都会被创建成一个树节点。

空间复杂度：

```text
O(log n)
```

递归调用栈高度。

因为每次取中点，构造出来的树是平衡的，所以树高大约是 `log n`。

注意：Go 里的切片表达式不会复制底层数组，只是创建新的切片视图，所以这里不会因为 `nums[:mid]` 产生完整数组复制。

---

## 十二、容易错的点

### 1. 不要取第一个元素当根

如果每次都取第一个元素：

```text
[-10, -3, 0, 5, 9]
```

会构造成类似链表：

```text
-10
  \
  -3
    \
     0
      \
       5
        \
         9
```

这不是高度平衡。

所以必须取中点。

---

### 2. 左右子数组不要包含 mid

中点已经作为根节点了。

所以左边是：

```go
nums[:mid]
```

右边是：

```go
nums[mid+1:]
```

不能写成：

```go
nums[:mid+1]
```

否则中点会被重复使用，甚至可能无限递归。

---

### 3. 空数组返回 nil

```go
if len(nums) == 0 {
    return nil
}
```

这是递归终止条件。

---

### 4. 答案不唯一

偶数长度数组取左中点或右中点都可能构造出合法答案。

只要满足：

```text
BST + 高度平衡
```

就可以。

---

## 十三、面试表达

可以这样说：

> 这题给的是升序数组，要构造高度平衡的二叉搜索树。因为数组有序，中点左边的元素都小于中点，中点右边的元素都大于中点，所以可以把中点作为当前根节点，左半部分递归构造左子树，右半部分递归构造右子树。由于每次都取中点，左右子树规模尽量接近，所以构造出来的树是高度平衡的。递归终止条件是数组为空时返回 nil。每个元素只会创建一个节点，时间复杂度 O(n)。
