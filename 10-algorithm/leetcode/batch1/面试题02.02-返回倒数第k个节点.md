# 面试题 02.02. 返回倒数第 k 个节点

题目链接：`https://leetcode.cn/problems/kth-node-from-end-of-list-lcci/`

---

## 一、题目描述

实现一种算法，找出单向链表中倒数第 `k` 个节点，返回该节点的值。

题目保证：`k` 是有效的。

示例：

```text
输入：1 -> 2 -> 3 -> 4 -> 5, k = 2
输出：4
```

---

## 二、核心思路：快慢指针

这题最经典的做法是 **双指针 / 快慢指针**。

定义两个指针：

```text
fast：快指针
slow：慢指针
```

步骤：

```text
1. fast 和 slow 都从 head 出发
2. fast 先向后走 k 步
3. fast 和 slow 再一起向后走
4. 当 fast 走到 nil / None 时，slow 正好在倒数第 k 个节点
```

---

## 三、为什么这样可以？

假设链表长度是 `n`。

倒数第 `k` 个节点，其实就是正数第：

```text
n - k + 1
```

如果 `fast` 先走 `k` 步，那么 `fast` 和 `slow` 之间始终相差 `k` 个节点。

当 `fast` 走到链表末尾的 `nil` / `None` 时，说明 `fast` 已经走完了整个链表。

这时 `slow` 正好走了：

```text
n - k
```

步，所以 `slow` 停在倒数第 `k` 个节点。

---

## 四、图解理解

链表：

```text
1 -> 2 -> 3 -> 4 -> 5
```

`k = 2`

先让 `fast` 走 2 步：

```text
slow
 |
 1 -> 2 -> 3 -> 4 -> 5 -> nil
           |
          fast
```

然后一起走：

```text
1 -> 2 -> 3 -> 4 -> 5 -> nil
     |              |
    slow           fast
```

继续一起走：

```text
1 -> 2 -> 3 -> 4 -> 5 -> nil
          |              |
         slow           fast
```

此时 `fast == nil`，`slow` 在节点 `4`，答案就是 `4`。

---

## 五、Go 解法

你的 Go 解法是正确的：

```go
/**
 * Definition for singly-linked list.
 * type ListNode struct {
 *     Val int
 *     Next *ListNode
 * }
 */
func kthToLast(head *ListNode, k int) int {
    var q, s *ListNode = head, head

    for i := 0; i < k; i++ {
        q = q.Next
    }

    for ; q != nil; q = q.Next {
        s = s.Next
    }

    return s.Val
}
```

其中：

```text
q：快指针
s：慢指针
```

逻辑就是：

```text
q 先走 k 步，然后 q 和 s 一起走，q 到 nil 时，s 就是倒数第 k 个节点。
```

## 六、Go 写法优化

面试时可以把变量名写得更语义化：

```go
/**
 * Definition for singly-linked list.
 * type ListNode struct {
 *     Val int
 *     Next *ListNode
 * }
 */
func kthToLast(head *ListNode, k int) int {
    fast, slow := head, head

    for i := 0; i < k; i++ {
        fast = fast.Next
    }

    for fast != nil {
        fast = fast.Next
        slow = slow.Next
    }

    return slow.Val
}
```

本质和原解法完全一样，只是 `fast` / `slow` 更容易说明思路。

## 七、Python3 解法

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def kthToLast(self, head: Optional[ListNode], k: int) -> int:
        fast = head
        slow = head

        for _ in range(k):
            fast = fast.next

        while fast:
            fast = fast.next
            slow = slow.next

        return slow.val
```

---

## 八、复杂度分析

时间复杂度：

```text
O(n)
```

最多遍历链表一次。

空间复杂度：

```text
O(1)
```

只使用了两个指针。

---

## 九、容易错的点

### 1. fast 先走的是 k 步，不是 k - 1 步

因为要让 `fast` 和 `slow` 之间相差 `k` 个节点。

如果只走 `k - 1` 步，最后容易错位。

---

### 2. 第二个循环条件是 fast != nil / fast is not None

Go：

```go
for fast != nil {
    fast = fast.Next
    slow = slow.Next
}
```

Python：

```python
while fast:
    fast = fast.next
    slow = slow.next
```

当 `fast` 到达链表末尾，`slow` 就是答案。

---

### 3. 本题不需要额外处理非法 k

题目说明：

```text
给定的 k 保证是有效的。
```

所以 LeetCode 里不用判断：

```text
head 是否为空
k 是否小于等于 0
k 是否大于链表长度
```

如果是工程代码，需要补充这些边界判断。

## 十、面试表达

可以这样说：

> 这题我用快慢指针。先让快指针从头节点开始走 `k` 步，这样快慢指针之间相差 `k` 个节点。然后两个指针同时向后移动，当快指针走到 `nil` 的时候，慢指针正好停在倒数第 `k` 个节点，返回它的值即可。整个过程只遍历一次链表，时间复杂度是 `O(n)`，空间复杂度是 `O(1)`。
