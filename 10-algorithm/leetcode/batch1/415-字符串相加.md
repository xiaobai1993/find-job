# 415. 字符串相加

题目链接：`https://leetcode.cn/problems/add-strings/`

---

## 一、题目描述

给定两个非负整数 `num1` 和 `num2`，它们都用字符串表示。

要求返回它们的和，也用字符串表示。

题目限制：

```text
不能使用任何内置大整数库。
不能直接把输入字符串整体转换成整数。
```

也就是说，不能写成：

```go
// 不允许
n1, _ := strconv.Atoi(num1)
n2, _ := strconv.Atoi(num2)
return strconv.Itoa(n1 + n2)
```

因为字符串可能非常长，超过普通整数范围。

---

## 二、你的 Go 提交

你的代码：

```go
func addStrings(num1 string, num2 string) string {
    var s1, s2 = 0,0
    for i :=len(num1)-1;i>=0;i-- {
        s1 = s1 * 10 + num1[i] - '0'
    }
    for i :=len(num2)-1;i>=0;i-- {
        s2 = s2 * 10 + num2[i] - '0'
    }
    s3 := s1+s2
    if s3 == 0{
        return "0"
    }
    s4 := ""
    for s3 != 0 {
        s4 += s3 %10 + '0'
        s3 = s3 /10
    }
    i,j :=0,len(s4)-1
    for ;i <j ;{
        s4[i], s4[j] = s4[j],s4[i]
        i=i+1
        j=j-1
    }
    return s4
}
```

这段代码的整体想法是：

```text
1. 把 num1 转成整数 s1
2. 把 num2 转成整数 s2
3. s1 + s2 得到 s3
4. 再把 s3 转回字符串
```

这个方向在普通题里可以，但这题不行。

---

## 三、这段代码的主要问题

### 1. 不能把整个字符串转成整数

题目明确限制：

```text
不能直接把输入字符串整体转换成整数。
```

更重要的是，`num1` 和 `num2` 可能非常长。

比如：

```text
"999999999999999999999999999999999999999999999999"
```

这个数字早就超过 Go 的 `int` 范围。

所以：

```go
s1 := 0
s1 = s1*10 + digit
```

这种整体转整数的思路会溢出。

---

### 2. 你的转换方向还会把数字反过来

看这段：

```go
for i := len(num1)-1; i >= 0; i-- {
    s1 = s1 * 10 + num1[i] - '0'
}
```

如果：

```text
num1 = "123"
```

执行过程是：

```text
i = 2，读到 '3'，s1 = 3
i = 1，读到 '2'，s1 = 3*10 + 2 = 32
i = 0，读到 '1'，s1 = 32*10 + 1 = 321
```

结果变成：

```text
123 -> 321
```

所以即使不考虑溢出，这里逻辑也反了。

---

### 3. Go 里 `byte` 和 `int` 不能直接混着算

`num1[i]` 的类型是：

```go
byte
```

而 `s1` 是：

```go
int
```

所以类似这句：

```go
s1 = s1 * 10 + num1[i] - '0'
```

会有类型问题。

一般要写成：

```go
digit := int(num1[i] - '0')
```

---

### 4. Go 的 string 不能直接修改某一位

你后面写：

```go
s4[i], s4[j] = s4[j], s4[i]
```

这个在 Go 里不行。

因为：

```text
string 是不可变的。
```

不能直接给 `s4[i]` 赋值。

如果要反转，需要先用：

```go
[]byte
```

---

## 四、正确思路：模拟小学竖式加法

这题应该这样想：

```text
不能把整个字符串变成整数。
那就一位一位加。
```

也就是模拟小学竖式加法。

例如：

```text
  456
+  77
-----
  533
```

从右往左加：

```text
6 + 7 = 13，当前位写 3，进位 1
5 + 7 + 1 = 13，当前位写 3，进位 1
4 + 0 + 1 = 5，当前位写 5，进位 0
```

因为我们是从右往左算，所以先得到的是：

```text
3, 3, 5
```

最后反转，得到：

```text
533
```

## 五、核心变量

### 1. `i` 和 `j`

```go
i, j := len(num1)-1, len(num2)-1
```

分别指向两个字符串的最后一位。

比如：

```text
num1 = "456"
```

那么：

```text
i = 2
num1[i] = '6'
```

---

### 2. `carry`

```go
carry := 0
```

表示进位。

比如：

```text
6 + 7 = 13
```

那么：

```text
当前位 digit = 3
进位 carry = 1
```

---

### 3. `sum`

每一轮先从进位开始：

```go
sum := carry
```

然后加上 `num1` 当前位：

```go
if i >= 0 {
    sum += int(num1[i] - '0')
    i--
}
```

再加上 `num2` 当前位：

```go
if j >= 0 {
    sum += int(num2[j] - '0')
    j--
}
```

---

### 4. 当前位和新进位

```go
digit := sum % 10
carry = sum / 10
```

例如：

```text
sum = 13
```

那么：

```text
digit = 3
carry = 1
```

---

## 六、为什么循环条件要带 `carry > 0`？

循环条件是：

```go
for i >= 0 || j >= 0 || carry > 0 {
```

意思是：

```text
只要 num1 还有位，或者 num2 还有位，或者还有进位，就继续算。
```

为什么最后还要判断 `carry > 0`？

看例子：

```text
num1 = "999"
num2 = "1"
```

计算过程：

```text
9 + 1 = 10，写 0，进 1
9 + 0 + 1 = 10，写 0，进 1
9 + 0 + 1 = 10，写 0，进 1
```

这时两个字符串都遍历完了，但是还有：

```text
carry = 1
```

所以还要再补一位 `1`。

最终结果是：

```text
1000
```

所以循环条件必须写：

```go
for i >= 0 || j >= 0 || carry > 0
```

## 七、Go 正确写法

```go
func addStrings(num1 string, num2 string) string {
    i, j := len(num1)-1, len(num2)-1
    carry := 0

    result := []byte{}

    for i >= 0 || j >= 0 || carry > 0 {
        sum := carry

        if i >= 0 {
            sum += int(num1[i] - '0')
            i--
        }

        if j >= 0 {
            sum += int(num2[j] - '0')
            j--
        }

        digit := sum % 10
        carry = sum / 10

        result = append(result, byte(digit+'0'))
    }

    left, right := 0, len(result)-1
    for left < right {
        result[left], result[right] = result[right], result[left]
        left++
        right--
    }

    return string(result)
}
```

---

## 八、Go 写法优化：从前面拼接，避免最后反转吗？

理论上可以每次把新数字拼到前面：

```go
result = string(byte(digit+'0')) + result
```

但不推荐。

因为字符串每次拼接都会产生新字符串。

更推荐：

```text
先 append 到 []byte，最后统一反转。
```

这也是这类题最常见的写法。

---

## 九、Python3 解法

```python
class Solution:
    def addStrings(self, num1: str, num2: str) -> str:
        i, j = len(num1) - 1, len(num2) - 1
        carry = 0
        result = []

        while i >= 0 or j >= 0 or carry > 0:
            total = carry

            if i >= 0:
                total += ord(num1[i]) - ord('0')
                i -= 1

            if j >= 0:
                total += ord(num2[j]) - ord('0')
                j -= 1

            result.append(str(total % 10))
            carry = total // 10

        result.reverse()
        return ''.join(result)
```

## 十二、复杂度分析

设：

```text
n = len(num1)
m = len(num2)
```

时间复杂度：

```text
O(max(n, m))
```

因为最多处理较长字符串的每一位。

```text
O(max(n, m))
```

因为结果字符串最多比最长输入多一位。

## 十三、容易错的点

### 1. 不要整体转 int

错误方向：

```go
s1 := 0
for _, ch := range num1 {
    s1 = s1*10 + int(ch-'0')
}
```

原因：

```text
题目不允许，而且可能溢出。
```

---

### 2. 从右往左加

因为个位在字符串最后一位。

所以初始化：

```go
i := len(num1) - 1
j := len(num2) - 1
```

---

### 3. 记得处理进位

```go
carry = sum / 10
```

最后循环条件也要带：

```go
carry > 0
```

---

### 4. 字符转数字

```go
int(num1[i] - '0')
```

比如：

```text
'7' - '0' = 7
```

---

### 5. 数字转字符

```go
byte(digit + '0')
```

比如：

```text
7 + '0' = '7'
```

---

### 6. Go 的 string 不可变

不能写：

```go
s[i], s[j] = s[j], s[i]
```

要用：

```go
result := []byte{}
```

最后：

```go
return string(result)
```

## 十四、面试表达

可以这样说：

> 这题不能把字符串整体转成整数，因为题目限制不允许，而且字符串长度可能很长，会超过整数范围。所以要模拟竖式加法。用两个指针分别从 `num1` 和 `num2` 的最后一位开始往前走，每一轮把当前两位数字和进位 `carry` 相加，当前位是 `sum % 10`，新的进位是 `sum / 10`。因为结果是从低位到高位生成的，所以先放到 `[]byte` 里，最后反转再转成字符串。循环条件要写成 `i >= 0 || j >= 0 || carry > 0`，这样可以处理最后还有进位的情况。
