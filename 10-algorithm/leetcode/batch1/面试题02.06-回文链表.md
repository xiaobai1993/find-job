# 面试题 02.06. 回文链表

题目链接：`https://leetcode.cn/problems/palindrome-linked-list-lcci/`

---

## 一、题目描述

编写一个函数，检查输入的链表是否是回文的。

示例：

```text
输入：1 -> 2
输出：false
```

```text
输入：1 -> 2 -> 2 -> 1
输出：true
```

---

## 二、数组解法

最容易想到的做法是：

```text
1. 遍历链表，把所有节点值放进数组
2. 用左右双指针判断数组是否回文
```

---

## 三、你的 Python 解法问题

你的写法：

```python
class Solution:
    def isPalindrome(self, head: Optional[ListNode]) -> bool:
        l = []
        while head:
            l.append(head.val)
            head = head.next
        i, j = 0, len(l)-1
        while i < j:
            if l[i] != l[j]:
                return False

        return True
```

核心思路是对的，但是双指针循环里少了指针移动。

你写的是：

```python
while i < j:
    if l[i] != l[j]:
        return False
```

如果两边相等，比如：

```text
1 -> 2 -> 2 -> 1
```

第一次比较：

```text
l[0] == l[3]
```

成立，但 `i` 和 `j` 没有变化，所以会一直比较同一组元素，导致死循环。

应该补上：

```python
i += 1
j -= 1
```

## 四、Python 修复版

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def isPalindrome(self, head: Optional[ListNode]) -> bool:
        vals = []

        while head:
            vals.append(head.val)
            head = head.next

        i, j = 0, len(vals) - 1
        while i < j:
            if vals[i] != vals[j]:
                return False
            i += 1
            j -= 1

        return True
```

更 Pythonic 的写法：

```python
class Solution:
    def isPalindrome(self, head: Optional[ListNode]) -> bool:
        vals = []

        while head:
            vals.append(head.val)
            head = head.next

        return vals == vals[::-1]
```

## 五、进阶解法：O(1) 额外空间

如果面试官要求：

```text
时间复杂度 O(n)
空间复杂度 O(1)
```

就不能用数组保存所有节点值。

可以使用三步：

```text
1. 快慢指针找中点
2. 反转后半段链表
3. 前半段和后半段逐个比较
```

## 六、Go 进阶解法

```go
/**
 * Definition for singly-linked list.
 * type ListNode struct {
 *     Val int
 *     Next *ListNode
 * }
 */
func isPalindrome(head *ListNode) bool {
    if head == nil || head.Next == nil {
        return true
    }

    slow, fast := head, head

    // 1. 快慢指针找中点
    for fast != nil && fast.Next != nil {
        slow = slow.Next
        fast = fast.Next.Next
    }

    // 如果 fast != nil，说明链表长度是奇数
    // slow 当前在中间节点，回文比较时中间节点不用比较
    if fast != nil {
        slow = slow.Next
    }

    // 2. 反转后半段链表
    secondHalf := reverseList(slow)

    // 3. 前半段和后半段逐个比较
    p1 := head
    p2 := secondHalf

    for p2 != nil {
        if p1.Val != p2.Val {
            return false
        }
        p1 = p1.Next
        p2 = p2.Next
    }

    return true
}

func reverseList(head *ListNode) *ListNode {
    var prev *ListNode
    cur := head

    for cur != nil {
        next := cur.Next
        cur.Next = prev
        prev = cur
        cur = next
    }

    return prev
}
```

## 七、快慢指针找中点

代码：

```go
slow, fast := head, head

for fast != nil && fast.Next != nil {
    slow = slow.Next
    fast = fast.Next.Next
}
```

含义：

```text
slow 每次走 1 步
fast 每次走 2 步
```

当 `fast` 到达末尾时，`slow` 正好在中间附近。

---

## 八、奇数长度为什么要跳过中间节点？

比如：

```text
1 -> 2 -> 3 -> 2 -> 1
```

快慢指针结束后：

```text
slow 在 3
fast 不为 nil
```

`3` 是中间节点，不影响回文判断，所以跳过它：

```go
if fast != nil {
    slow = slow.Next
}
```

后半段从第二个 `2` 开始：

```text
2 -> 1
```

反转后：

```text
1 -> 2
```

再和前半段比较：

```text
前半段：1 -> 2
后半段：1 -> 2
```

## 九、反转链表模板

这个模板要记熟：

```go
func reverseList(head *ListNode) *ListNode {
    var prev *ListNode
    cur := head

    for cur != nil {
        next := cur.Next
        cur.Next = prev
        prev = cur
        cur = next
    }

    return prev
}
```

四步：

```text
1. 保存 next
2. cur.Next 指向 prev
3. prev 前进到 cur
4. cur 前进到 next
```

## 十、复杂度分析

数组解法：

```text
时间复杂度：O(n)
空间复杂度：O(n)
```

快慢指针 + 反转后半段：

```text
时间复杂度：O(n)
空间复杂度：O(1)
```

## 十一、容易错的点

### 1. 数组解法里双指针要移动

错误：

```python
while i < j:
    if vals[i] != vals[j]:
        return False
```

正确：

```python
while i < j:
    if vals[i] != vals[j]:
        return False
    i += 1
    j -= 1
```

---

### 2. Go 里判断 fast.Next 不能写错

正确：

```go
for fast != nil && fast.Next != nil {
```

---

### 3. 奇数长度要跳过中间节点

```go
if fast != nil {
    slow = slow.Next
}
```

中间节点不需要参与比较。

## 十二、面试表达

可以这样说：

> 这题简单做法是把链表值放进数组，然后用左右双指针判断数组是否回文，时间复杂度 O(n)，空间复杂度 O(n)。如果要求 O(1) 空间，我会用快慢指针找到链表中点。如果链表长度是奇数，就跳过中间节点。然后反转后半段链表，再从头节点和反转后的后半段开始逐个比较。如果所有值都相等，就说明是回文链表，否则不是。
