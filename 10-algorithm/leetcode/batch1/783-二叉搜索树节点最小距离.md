# 783. 二叉搜索树节点最小距离

题目链接：`https://leetcode.cn/problems/minimum-distance-between-bst-nodes/`

---

## 一、题目描述

给定一个二叉搜索树 `root`，返回树中任意两个不同节点值之间的最小差值。

示例：

```text
输入：root = [4,2,6,1,3]
输出：1
```

对应的树：

```text
      4
     / \
    2   6
   / \
  1   3
```

节点值有：

```text
1, 2, 3, 4, 6
```

最小差值是：

```text
2 - 1 = 1
3 - 2 = 1
```

所以答案是 `1`。

---

## 二、这题的关键：二叉搜索树

这题一看到：

```text
二叉搜索树 BST
```

就要想到一个非常重要的性质：

```text
BST 的中序遍历结果是升序数组。
```

二叉搜索树满足：

```text
左子树所有节点值 < 当前节点值 < 右子树所有节点值
```

所以按照：

```text
左子树 -> 当前节点 -> 右子树
```

这个顺序遍历，就会得到从小到大的节点值。

---

## 三、为什么最小差值只需要看相邻节点？

假设中序遍历后得到升序数组：

```text
[1, 2, 3, 4, 6]
```

要找任意两个节点之间的最小差值。

对于有序数组来说，最小差值一定出现在相邻元素之间。

为什么？

比如：

```text
1 和 4 的差值 = 3
```

但是中间还有：

```text
1, 2, 3, 4
```

相邻差值只会更小或者相等：

```text
2 - 1 = 1
3 - 2 = 1
4 - 3 = 1
```

所以不需要任意两两比较，只需要比较中序数组里相邻两个数的差。

---

## 四、核心思路

分两步：

```text
1. 对 BST 做中序遍历，得到升序数组
2. 遍历升序数组，计算相邻元素差值，取最小值
```

伪代码：

```text
inorder(root):
    inorder(root.left)
    ans.append(root.val)
    inorder(root.right)

arr = inorder(root)
minDiff = 正无穷
for i from 0 to len(arr)-2:
    minDiff = min(minDiff, arr[i+1] - arr[i])

return minDiff
```

这个思路是正确的。

关键点在这里：

```go

```

这就是标准中序遍历：

```text
左 -> 根 -> 右
```

因为 `root` 是 BST，所以 `f(root)` 返回的一定是升序数组。

例如这棵树：

```text
      4
     / \
    2   6
   / \
  1   3
```

调用 `f(root)` 后得到：

```text
[1, 2, 3, 4, 6]
```

然后再比较相邻元素：

```text
2 - 1 = 1
3 - 2 = 1
4 - 3 = 1
6 - 4 = 2
```

最小值就是 `1`。

## 七、Go 推荐写法：中序数组版

```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func minDiffInBST(root *TreeNode) int {
    nums := inorder(root)
    minDiff := 1 << 31 - 1

    for i := 0; i < len(nums)-1; i++ {
        diff := nums[i+1] - nums[i]
        if diff < minDiff {
            minDiff = diff
        }
    }

    return minDiff
}

func inorder(root *TreeNode) []int {
    if root == nil {
        return nil
    }

    var result []int
    result = append(result, inorder(root.Left)...)
    result = append(result, root.Val)
    result = append(result, inorder(root.Right)...)
    return result
}
```

这个版本和你的写法本质一样，只是变量名更清楚。

## 八、Go 更常见写法：一次中序遍历，不额外存数组

因为最小差值只和中序遍历中的前一个节点有关，所以也可以不用数组。

遍历过程中记录：

```text
prev：上一个访问到的节点值
minDiff：当前最小差值
```

代码：

```go
func minDiffInBST(root *TreeNode) int {
    prev := -1
    minDiff := 1 << 31 - 1

    var dfs func(node *TreeNode)
    dfs = func(node *TreeNode) {
        if node == nil {
            return
        }

        dfs(node.Left)

        if prev != -1 {
            diff := node.Val - prev
            if diff < minDiff {
                minDiff = diff
            }
        }
        prev = node.Val

        dfs(node.Right)
    }

    dfs(root)
    return minDiff
}
```

这个写法空间更省：

```text
不需要额外数组，只需要记录上一个值。
```

但是对刚开始刷树题的人来说，中序数组版更好理解。

## 九、Python3 写法

### 写法一：中序数组版

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def minDiffInBST(self, root: Optional[TreeNode]) -> int:
        nums = []

        def inorder(node):
            if not node:
                return
            inorder(node.left)
            nums.append(node.val)
            inorder(node.right)

        inorder(root)

        ans = float('inf')
        for i in range(len(nums) - 1):
            ans = min(ans, nums[i + 1] - nums[i])

        return ans
```

### 写法二：一次中序遍历

```python
class Solution:
    def minDiffInBST(self, root: Optional[TreeNode]) -> int:
        prev = None
        ans = float('inf')

        def inorder(node):
            nonlocal prev, ans
            if not node:
                return

            inorder(node.left)

            if prev is not None:
                ans = min(ans, node.val - prev)
            prev = node.val

            inorder(node.right)

        inorder(root)
        return ans
```

```text
    2   6
```

```text

```

得到数组：

```text
[1, 2, 3, 4, 6]
```

```text
2 - 1 = 1
3 - 2 = 1
4 - 3 = 1
6 - 4 = 2
```

最小值：

```text
1
```

## 十一、复杂度分析

### 中序数组版

时间复杂度：

```text
O(n)
```

每个节点访问一次，数组再遍历一次，整体还是 `O(n)`。

空间复杂度：

```text
O(n)
```

数组保存了所有节点值。

递归调用栈额外是：

```text
O(h)
```

`h` 是树高。

---

### 一次中序遍历版

时间复杂度：

```text
O(n)
```

空间复杂度：

```text
O(h)
```

不需要保存完整数组，只需要递归栈。

## 十二、容易错的点

### 1. 不要忘记 BST 的中序遍历是升序

这题不是普通二叉树。

如果是普通二叉树，中序遍历不一定有序。

但是 BST 有这个性质：

```text
中序遍历 = 升序数组
```

这就是本题的核心。

---

### 2. 最小差值只比较相邻元素

不要两层循环暴力比较所有节点。

有序数组中，最小差值一定出现在相邻元素之间。

---

### 3. Go 里追加递归返回的切片要用 `...`

正确：

```go
result = append(result, inorder(root.Left)...)
```

错误：

```go
result = append(result, inorder(root.Left))
```

因为 `inorder(root.Left)` 是一个 `[]int`，不是单个 `int`。

---

### 4. 循环边界是 `len(nums)-1`

比较的是：

```text
nums[i+1] - nums[i]
```

所以 `i` 最大只能到：

```text
len(nums) - 2
```

Go 里写：

```go
for i := 0; i < len(nums)-1; i++ {
```

## 十三、面试表达

可以这样说：

> 这题的关键是它给的是二叉搜索树。BST 的中序遍历结果是升序数组，所以我先对树做中序遍历，把所有节点值按升序放到数组里。对于一个有序数组，任意两个数的最小差值一定出现在相邻元素之间，所以只需要遍历数组，比较 `nums[i+1] - nums[i]` 的最小值即可。时间复杂度是 O(n)。如果进一步优化空间，可以在中序遍历过程中维护上一个访问的节点值 `prev`，边遍历边更新最小差值，这样不需要保存完整数组。
