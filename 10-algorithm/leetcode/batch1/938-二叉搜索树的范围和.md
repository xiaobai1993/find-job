# 938. 二叉搜索树的范围和

题目链接：`https://leetcode.cn/problems/range-sum-of-bst/`

---

## 一、题目描述

给定二叉搜索树的根节点 `root`，以及两个整数 `low` 和 `high`。

返回树中所有节点值在区间 `[low, high]` 范围内的节点值之和。

示例：

```text
输入：root = [10,5,15,3,7,null,18], low = 7, high = 15
输出：32
```

对应的树：

```text
        10
       /  \
      5    15
     / \     \
    3   7     18
```

区间是：

```text
[7, 15]
```

在这个范围里的节点有：

```text
7, 10, 15
```

所以结果是：

```text
7 + 10 + 15 = 32
```

## 二、你的 Go 代码为什么语法错误？

你的代码：

```go
func rangeSumBST(root *TreeNode, low int, high int) int {
    if root == nil {
        return 0
    }
    var s int = 0;
    s += rangeSumBST(root.Left)
    if root.Val >= low && root.Val <= high
        s = s + root.Val
    }
    s += rangeSumBST(root.Right)
    return s
}
```

LeetCode 报错：

```text
Line 16: Char 11: syntax error: cannot use assignment s = (s + root.Val) as value
```

主要有两个问题。

---

### 1. Go 的 `if` 必须写 `{}`

你写的是：

```go
if root.Val >= low && root.Val <= high
    s = s + root.Val
}
```

Go 不像 Python，不能靠缩进表示代码块。

Go 的 `if` 必须写成：

```go
if root.Val >= low && root.Val <= high {
    s = s + root.Val
}
```

否则 Go 编译器会把后面的语句解析乱，于是出现：

```text
cannot use assignment s = (s + root.Val) as value
```

这个报错看起来很怪，但根因就是 `if` 后面少了 `{`。

---

### 2. 递归调用少传了 `low` 和 `high`

函数定义是：

```go
func rangeSumBST(root *TreeNode, low int, high int) int
```

它需要三个参数。

但是你递归时写成了：

```go
s += rangeSumBST(root.Left)
s += rangeSumBST(root.Right)
```

少传了 `low` 和 `high`。

应该写成：

```go
s += rangeSumBST(root.Left, low, high)
s += rangeSumBST(root.Right, low, high)
```

---

## 三、先写最直观版本：普通 DFS

先不要想优化，最直观的方式就是遍历整棵树。

对每个节点做三件事：

```text
1. 递归计算左子树范围和
2. 如果当前节点值在 [low, high]，就加上当前节点值
3. 递归计算右子树范围和
```

伪代码：

```text
rangeSum(root):
    if root == nil:
        return 0

    sum = 0
    sum += rangeSum(root.left)

    if low <= root.val <= high:
        sum += root.val

    sum += rangeSum(root.right)
    return sum
```

这个写法不用先纠结 BST 的剪枝，先保证能写对。

## 四、Go 修复版：普通 DFS

```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func rangeSumBST(root *TreeNode, low int, high int) int {
    if root == nil {
        return 0
    }

    sum := 0

    sum += rangeSumBST(root.Left, low, high)

    if root.Val >= low && root.Val <= high {
        sum += root.Val
    }

    sum += rangeSumBST(root.Right, low, high)

    return sum
}
```

这个版本已经可以通过。

它的逻辑很简单：

```text
整棵树都遍历一遍，只要节点值在区间里，就加入结果。
```

## 五、这题还能利用 BST 性质剪枝

题目给的是二叉搜索树。

BST 的性质是：

```text
左子树所有节点值 < 当前节点值 < 右子树所有节点值
```

所以可以根据当前节点值和区间 `[low, high]` 的关系，决定哪些子树可以不用看。

---

### 情况一：root.Val < low

如果：

```text
root.Val < low
```

说明当前节点太小。

而且因为左子树的节点都比 `root.Val` 更小，所以左子树也一定都小于 `low`。

因此：

```text
当前节点不用加
左子树不用看
只需要去右子树找
```

代码：

```go
if root.Val < low {
    return rangeSumBST(root.Right, low, high)
}
```

---

### 情况二：root.Val > high

如果：

```text
root.Val > high
```

说明当前节点太大。

而且因为右子树的节点都比 `root.Val` 更大，所以右子树也一定都大于 `high`。

因此：

```text
当前节点不用加
右子树不用看
只需要去左子树找
```

代码：

```go
if root.Val > high {
    return rangeSumBST(root.Left, low, high)
}
```

---

### 情况三：low <= root.Val <= high

如果当前节点在区间里：

```text
low <= root.Val <= high
```

当前节点要加上。

左右子树里也可能还有符合条件的节点，所以左右都要继续递归。

代码：

```go
return root.Val +
    rangeSumBST(root.Left, low, high) +
    rangeSumBST(root.Right, low, high)
```

## 六、Go 推荐写法：BST 剪枝版

```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func rangeSumBST(root *TreeNode, low int, high int) int {
    if root == nil {
        return 0
    }

    if root.Val < low {
        return rangeSumBST(root.Right, low, high)
    }

    if root.Val > high {
        return rangeSumBST(root.Left, low, high)
    }

    return root.Val +
        rangeSumBST(root.Left, low, high) +
        rangeSumBST(root.Right, low, high)
}
```

这个版本更符合二叉搜索树题目的特点。

核心就是：

```text
太小就去右边，太大就去左边，在范围内就左右都看。
```

## 七、Python3 写法

### 写法一：普通 DFS

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def rangeSumBST(self, root: Optional[TreeNode], low: int, high: int) -> int:
        if not root:
            return 0

        total = 0
        total += self.rangeSumBST(root.left, low, high)

        if low <= root.val <= high:
            total += root.val

        total += self.rangeSumBST(root.right, low, high)
        return total
```

---

### 写法二：BST 剪枝版

```python
class Solution:
    def rangeSumBST(self, root: Optional[TreeNode], low: int, high: int) -> int:
        if not root:
            return 0

        if root.val < low:
            return self.rangeSumBST(root.right, low, high)

        if root.val > high:
            return self.rangeSumBST(root.left, low, high)

        return (
            root.val
            + self.rangeSumBST(root.left, low, high)
            + self.rangeSumBST(root.right, low, high)
        )
```

## 八、例子走一遍

树：

```text
        10
       /  \
      5    15
     / \     \
    3   7     18
```

区间：

```text
[7, 15]
```

从根节点 `10` 开始：

```text
10 在 [7, 15]，加上 10，左右都继续看
```

左子树 `5`：

```text
5 < 7，太小
5 的左子树更小，不用看
只去右子树 7
```

节点 `7`：

```text
7 在 [7, 15]，加上 7
```

右子树 `15`：

```text
15 在 [7, 15]，加上 15
```

节点 `18`：

```text
18 > 15，太大，不加
```

最终结果：

```text
10 + 7 + 15 = 32
```

## 九、复杂度分析

### 普通 DFS

时间复杂度：

```text
O(n)
```

因为可能遍历整棵树。

空间复杂度：

```text
O(h)
```

`h` 是树高，来自递归调用栈。

---

### BST 剪枝版

时间复杂度：

```text
最坏 O(n)
```

如果区间覆盖大部分节点，仍然可能遍历很多节点。

但平均情况下会剪掉一些不可能符合条件的子树。

空间复杂度：

```text
O(h)
```

递归调用栈高度。

## 十、容易错的点

### 1. Go 的 `if` 一定要写 `{}`

错误：

```go
if root.Val >= low && root.Val <= high
    sum += root.Val
}
```

正确：

```go
if root.Val >= low && root.Val <= high {
    sum += root.Val
}
```

Go 不靠缩进判断代码块。

---

### 2. 递归调用参数不能少

函数定义是：

```go
func rangeSumBST(root *TreeNode, low int, high int) int
```

递归时也必须传三个参数：

```go
rangeSumBST(root.Left, low, high)
rangeSumBST(root.Right, low, high)
```

不能写成：

```go
rangeSumBST(root.Left)
```

---

### 3. 注意区间是闭区间

题目要求的是：

```text
[low, high]
```

所以判断条件是：

```go
root.Val >= low && root.Val <= high
```

包含等于号。

---

### 4. 剪枝方向不要写反

如果：

```text
root.Val < low
```

说明当前节点和左子树都太小，要去右边。

如果：

```text
root.Val > high
```

说明当前节点和右子树都太大，要去左边。

记住：

```text
太小往右，太大往左。
```

## 十一、面试表达

可以这样说：

> 这题可以先用普通 DFS 遍历整棵树，对每个节点判断它的值是否在 `[low, high]` 区间内，如果在就加入结果，最后返回左右子树和加当前节点值。因为题目给的是二叉搜索树，所以还可以利用 BST 的性质剪枝：如果当前节点值小于 `low`，那么当前节点和左子树都不可能满足条件，只需要递归右子树；如果当前节点值大于 `high`，那么当前节点和右子树都不可能满足条件，只需要递归左子树；否则当前节点在区间内，就加上当前节点，并继续递归左右子树。
