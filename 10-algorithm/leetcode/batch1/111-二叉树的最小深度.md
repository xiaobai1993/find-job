# 111. 二叉树的最小深度

题目链接：`https://leetcode.cn/problems/minimum-depth-of-binary-tree/description/`

---

## 一、题目描述

给定一棵二叉树，找出它的最小深度。

最小深度是指：

```text
从根节点到最近叶子节点的最短路径上的节点数量。
```

注意关键词：

```text
叶子节点
```

叶子节点必须是：

```text
左孩子为空，并且右孩子也为空。
```

也就是：

```go
root.Left == nil && root.Right == nil
```

---

## 二、你的 Go 提交

你的代码：

```go
func minDepth(root *TreeNode) int {
    return getDepth(root)
}

func getDepth(root * TreeNode) int {
    if root == nil {
        return 0
    }
    if root.Left == nil && root.Right == nil {
        return 1
    }
    ld := getDepth(root.Left)
    rd := getDepth(root.Right)

    return min(ld,rd) + 1
}
func min(a, b int) int {
    if a< b {
        return a
    }
    return b
}
```

这段代码的基础递归方向是对的，但最后这句有坑：

```go
return min(ld, rd) + 1
```

它会在某个节点只有一边子树时出错。

---

## 三、为什么 `min(ld, rd) + 1` 会错？

最小深度要求的是：

```text
从根节点到叶子节点的最短路径。
```

如果某个节点只有右子树，没有左子树，那么左边是空的。

但是：

```text
空节点不是叶子节点。
```

所以不能把空的左边当成一条深度为 `0` 的路径。

---

## 四、最经典反例

树：

```text
1
 \
  2
```

这棵树的最小深度是多少？

答案是：

```text
2
```

因为唯一一条从根到叶子的路径是：

```text
1 -> 2
```

但是你的代码会这样算：

```go
ld := getDepth(root.Left)  // root.Left 是 nil，所以 ld = 0
rd := getDepth(root.Right) // root.Right 是 2，所以 rd = 1
return min(ld, rd) + 1
```

也就是：

```text
min(0, 1) + 1 = 1
```

错误地返回了 `1`。

根本原因：

```text
它把空子树当成了一条最短路径。
```

但空边不能算路径。

---

## 五、最大深度和最小深度的区别

最大深度可以直接写：

```go
return max(leftDepth, rightDepth) + 1
```

因为最大深度会自然选择更深的那边。

如果一边为空，深度是 `0`，不会影响最大值。

但是最小深度不能直接写：

```go
return min(leftDepth, rightDepth) + 1
```

因为如果一边为空，`min(0, x)` 会选到空边。

这就是这题最坑的地方。

---

## 六、正确递归逻辑

对当前节点 `root`，分情况：

### 1. 空节点

```go
if root == nil {
    return 0
}
```

空树深度是 `0`。

---

### 2. 叶子节点

```go
if root.Left == nil && root.Right == nil {
    return 1
}
```

叶子节点自己就是一条完整路径，深度是 `1`。

---

### 3. 只有右子树，没有左子树

```go
if root.Left == nil {
    return minDepth(root.Right) + 1
}
```

因为左边为空，不能走左边，只能走右边。

---

### 4. 只有左子树，没有右子树

```go
if root.Right == nil {
    return minDepth(root.Left) + 1
}
```

因为右边为空，不能走右边，只能走左边。

---

### 5. 左右子树都存在

这时才可以取较小值：

```go
return min(minDepth(root.Left), minDepth(root.Right)) + 1
```

## 七、Go 修复版

```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func minDepth(root *TreeNode) int {
    if root == nil {
        return 0
    }

    if root.Left == nil && root.Right == nil {
        return 1
    }

    if root.Left == nil {
        return minDepth(root.Right) + 1
    }

    if root.Right == nil {
        return minDepth(root.Left) + 1
    }

    return min(minDepth(root.Left), minDepth(root.Right)) + 1
}

func min(a, b int) int {
    if a < b {
        return a
    }
    return b
}
```

## 八、保留 getDepth 的写法

```go
func minDepth(root *TreeNode) int {
    return getDepth(root)
}

func getDepth(root *TreeNode) int {
    if root == nil {
        return 0
    }

    if root.Left == nil && root.Right == nil {
        return 1
    }

    if root.Left == nil {
        return getDepth(root.Right) + 1
    }

    if root.Right == nil {
        return getDepth(root.Left) + 1
    }

    leftDepth := getDepth(root.Left)
    rightDepth := getDepth(root.Right)

    return min(leftDepth, rightDepth) + 1
}

func min(a, b int) int {
    if a < b {
        return a
    }
    return b
}
```

这个版本和你的结构最接近，只是补上了“一边为空”的特殊情况。

## 九、Python3 解法

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def minDepth(self, root: Optional[TreeNode]) -> int:
        if not root:
            return 0

        if not root.left and not root.right:
            return 1

        if not root.left:
            return self.minDepth(root.right) + 1

        if not root.right:
            return self.minDepth(root.left) + 1

        return min(
            self.minDepth(root.left),
            self.minDepth(root.right)
        ) + 1
```

## 十、例子走一遍

树：

```text
1
 \
  2
```

调用：

```go
minDepth(1)
```

节点 `1`：

```text
root.Left == nil
root.Right != nil
```

所以不能写：

```go
min(0, 1) + 1
```

而是只能走右边：

```go
return minDepth(root.Right) + 1
```

节点 `2` 是叶子节点：

```go
return 1
```

所以最终结果：

```text
1 + 1 = 2
```

---

再看这棵树：

```text
    1
   / \
  2   3
```

左右子树都存在，而且 `2` 和 `3` 都是叶子。

所以：

```text
leftDepth = 1
rightDepth = 1
minDepth = min(1, 1) + 1 = 2
```

这时取 `min` 是正确的。

## 十一、BFS 写法也很适合这题

最小深度也可以用层序遍历 BFS。

因为 BFS 是一层一层遍历的。

第一个遇到的叶子节点，一定就是最近的叶子节点。

思路：

```text
1. 根节点入队，深度为 1
2. 每次出队一个节点
3. 如果它是叶子节点，直接返回当前深度
4. 否则把左右孩子入队，深度 + 1
```

Go 写法：

```go
func minDepth(root *TreeNode) int {
    if root == nil {
        return 0
    }

    queue := []*TreeNode{root}
    depth := 1

    for len(queue) > 0 {
        size := len(queue)

        for i := 0; i < size; i++ {
            node := queue[0]
            queue = queue[1:]

            if node.Left == nil && node.Right == nil {
                return depth
            }

            if node.Left != nil {
                queue = append(queue, node.Left)
            }
            if node.Right != nil {
                queue = append(queue, node.Right)
            }
        }

        depth++
    }

    return depth
}
```

不过刚开始刷树题，递归版先掌握就可以。

## 十二、复杂度分析

### 递归 DFS

时间复杂度：

```text
O(n)
```

最坏情况下需要访问所有节点。

空间复杂度：

```text
O(h)
```

`h` 是树高，来自递归调用栈。

---

### BFS

时间复杂度：

```text
O(n)
```

最坏情况下也可能访问很多节点。

空间复杂度：

```text
O(n)
```

队列最多可能存一层节点。

## 十三、容易错的点

### 1. 空节点不是叶子节点

叶子节点必须是：

```text
左右孩子都为空的真实节点。
```

空节点 `nil` 不是叶子。

---

### 2. 一边为空时，不能取 min

错误：

```go
return min(getDepth(root.Left), getDepth(root.Right)) + 1
```

如果一边为空，会错误地取到 `0`。

正确：

```go
if root.Left == nil {
    return getDepth(root.Right) + 1
}
if root.Right == nil {
    return getDepth(root.Left) + 1
}
```

---

### 3. 左右都存在时，才取 min

```go
return min(getDepth(root.Left), getDepth(root.Right)) + 1
```

这句只有在左右子树都存在时才安全。

---

### 4. 不要照抄最大深度模板

最大深度是：

```go
max(left, right) + 1
```

最小深度不能简单改成：

```go
min(left, right) + 1
```

因为空边不能算路径。

---

## 十四、面试表达

可以这样说：

> 这题容易和最大深度混淆。最大深度可以直接取左右子树深度最大值再加 1，但最小深度不能直接取最小值，因为如果某个节点只有一边子树，另一边为空，空节点不是叶子节点，不能作为一条路径。递归时需要分情况：如果 root 为空返回 0；如果是叶子节点返回 1；如果左子树为空，只能走右子树；如果右子树为空，只能走左子树；只有左右子树都存在时，才能取左右最小深度再加 1。

---

## 十五、一句话记忆

```text
最小深度：空边不能算路径；只有一边子树时，只能走不空的那边。
```

核心代码：

```go
if root.Left == nil {
    return minDepth(root.Right) + 1
}
if root.Right == nil {
    return minDepth(root.Left) + 1
}
return min(minDepth(root.Left), minDepth(root.Right)) + 1
```
