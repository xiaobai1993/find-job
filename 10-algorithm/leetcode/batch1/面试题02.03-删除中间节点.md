# 面试题 02.03. 删除中间节点

题目链接：`https://leetcode.cn/problems/delete-middle-node-lcci/description/`

---

## 一、题目描述

实现一种算法，删除单向链表中间的某个节点。

注意：

```text
题目只给你要删除的那个节点 node，不给链表头节点 head。
```

示例：

```text
输入：单向链表 a -> b -> c -> d -> e -> f 中的节点 c
输出：不返回任何数据，但链表变为 a -> b -> d -> e -> f
```

---

## 二、这题特殊在哪里？

普通删除链表节点，一般需要知道它的前驱节点。

比如要删除 `c`：

```text
a -> b -> c -> d -> e
     |
   prev
```

正常做法是：

```text
prev.Next = c.Next
```

也就是让 `b` 跳过 `c`，直接指向 `d`。

但是这题没有给 `head`，也没有给 `prev`，只给了当前节点 `c`。

所以不能从头遍历，也不能找到前驱节点。

---

## 三、核心思路：复制下一个节点

既然不能删除当前节点本身，那就换一种思路：

```text
把下一个节点的值复制到当前节点
然后删除下一个节点
```

假设链表是：

```text
a -> b -> c -> d -> e
          |
         node
```

想删除 `c`。

第一步，把 `d` 的值复制到 `c`：

```text
a -> b -> d -> d -> e
          |
         node
```

第二步，让当前节点跳过下一个节点：

```text
a -> b -> d -> e
```

从链表整体看，原来的 `c` 已经消失了。

---

## 四、为什么这样可以？

因为链表节点由两部分组成：

```text
值 Val
指针 Next
```

题目要删除的是“链表中表现出来的这个值对应的节点”。

虽然我们没有办法真正让前驱节点跳过当前节点，但可以让当前节点变成下一个节点的样子，再删除下一个节点。

也就是：

```text
node.Val = node.Next.Val
node.Next = node.Next.Next
```

这样链表表现出来的结果就等价于删除了原来的 `node`。

---

## 五、Go 解法

```go
/**
 * Definition for singly-linked list.
 * type ListNode struct {
 *     Val int
 *     Next *ListNode
 * }
 */
func deleteNode(node *ListNode) {
    node.Val = node.Next.Val
    node.Next = node.Next.Next
}
```

逻辑非常短：

```text
1. 当前节点复制下一个节点的值
2. 当前节点跳过下一个节点
```

---

## 六、Python3 解法

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def deleteNode(self, node):
        node.val = node.next.val
        node.next = node.next.next
```

---

## 七、复杂度分析

时间复杂度：

```text
O(1)
```

只修改了当前节点和下一个节点的指针。

空间复杂度：

```text
O(1)
```

没有使用额外空间。

---

## 八、题目限制很关键

这题默认要删除的节点不是尾节点。

因为如果 `node` 是尾节点：

```text
a -> b -> c
          |
         node
```

它没有 `node.Next`，就没办法把下一个节点复制过来。

所以这种方法只适用于：

```text
要删除的节点不是链表尾节点
```

这也是题目说“中间节点”的原因。

---

## 九、容易错的点

### 1. 不要从 head 开始遍历

这题函数参数里没有 `head`，只有 `node`。

所以不能写：

```text
从 head 找 node 的前驱节点
```

题目考的就是：没有前驱节点时怎么删除。

---

### 2. 不是删除当前节点对象本身

严格来说，这种做法不是把当前节点对象从内存里删除。

而是：

```text
把当前节点改造成下一个节点
再跳过下一个节点
```

从链表结果上看，达到了删除当前节点的效果。

---

### 3. 不能用于尾节点

如果 `node.Next == nil` / `None`，这套逻辑就无法执行。

不过题目保证删除的是中间节点，所以不用额外处理。

---

## 十、面试表达

可以这样说：

> 这题和普通删除链表节点不一样，题目没有给 head，也没有给前驱节点，只给了要删除的 node。所以不能通过前驱节点执行 `prev.Next = node.Next`。解决办法是把 node 的下一个节点的值复制到 node 上，然后让 node.Next 指向 node.Next.Next。这样从链表表现上看，相当于删除了原来的 node。因为只改了两个字段，所以时间复杂度是 O(1)，空间复杂度也是 O(1)。不过这个方法要求 node 不能是尾节点。
