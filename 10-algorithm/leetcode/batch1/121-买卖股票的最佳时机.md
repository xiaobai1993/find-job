# 121. 买卖股票的最佳时机

题目链接：`https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/description/`

---

## 一、题目描述

给定一个数组 `prices`，其中：

```text
prices[i] 表示某只股票第 i 天的价格。
```

你只能选择某一天买入，并且选择之后的某一天卖出。

要求返回可以获得的最大利润。

如果不能获得利润，返回 `0`。

注意关键词：

```text
先买入，再卖出。
只能交易一次。
```

---

## 二、你的 Go 提交

你的代码：

```go
func maxProfit(prices []int) int {
    max := 0
    for i :=0;i< len(prices);i++ {
        for j :=i+1;j<len(prices);j++ {
            if prices[j] - prices[i] > max {
                max = prices[j] - prices[i]
            }
        }
    }
    return max
}
```

这个提交的逻辑是正确的。

你的思路是：

```text
1. 枚举每一天 i 作为买入日
2. 枚举 i 后面的每一天 j 作为卖出日
3. 计算 prices[j] - prices[i]
4. 取最大利润
```

这确实能找到答案。

但是它会超时。

---

## 三、为什么会超时？

你的代码是双层循环：

```go
for i := 0; i < len(prices); i++ {
    for j := i+1; j < len(prices); j++ {
        ...
    }
}
```

时间复杂度是：

```text
O(n^2)
```

如果 `prices` 长度是 `100000`，大概需要比较：

```text
100000 * 100000 = 10000000000
```

也就是百亿级操作，肯定会超时。

所以问题不在正确性，而在复杂度。

---

## 四、怎么从暴力优化？

暴力枚举的核心是：

```text
买入日 i + 卖出日 j
```

但我们可以换个角度。

对于每一天，如果把它当成卖出日，那么最好的买入日一定是：

```text
这一天之前价格最低的那一天。
```

所以当遍历到今天 `prices[i]` 时，只需要知道：

```text
前面出现过的最低价格 minPrice
```

那么今天卖出的利润就是：

```text
prices[i] - minPrice
```

然后用它更新最大利润。

---

## 五、核心思路

只需要维护两个变量：

```text
minPrice：到目前为止见过的最低价格
maxProfit：到目前为止能获得的最大利润
```

遍历每一天价格 `price`：

```text
1. 如果 price 比 minPrice 更低，更新 minPrice
2. 否则计算 price - minPrice，尝试更新 maxProfit
```

这就把双层循环压成了一层循环。

---

## 六、为什么这样不违反“先买后卖”？

因为我们是从左到右遍历。

当遍历到第 `i` 天时：

```text
minPrice 只来自第 i 天之前，或者当前第 i 天。
```

如果今天价格更低，只是更新最低买入价。

如果今天卖出，计算的是：

```text
今天价格 - 之前见过的最低价格
```

所以不会出现：

```text
先卖后买
```

这种非法情况。

---

## 七、Go 正确写法

```go
func maxProfit(prices []int) int {
    if len(prices) == 0 {
        return 0
    }

    minPrice := prices[0]
    maxProfit := 0

    for i := 1; i < len(prices); i++ {
        if prices[i] < minPrice {
            minPrice = prices[i]
        } else if prices[i]-minPrice > maxProfit {
            maxProfit = prices[i] - minPrice
        }
    }

    return maxProfit
}
```

---

## 八、Go 写法二：每轮都计算利润

也可以写成下面这种形式：

```go
func maxProfit(prices []int) int {
    if len(prices) == 0 {
        return 0
    }

    minPrice := prices[0]
    ans := 0

    for _, price := range prices {
        if price < minPrice {
            minPrice = price
        }

        profit := price - minPrice
        if profit > ans {
            ans = profit
        }
    }

    return ans
}
```

这个版本也正确。

如果当前 `price` 正好是新的最低价，那么：

```text
profit = price - minPrice = 0
```

不会影响答案。

## 九、Python3 解法

```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        min_price = prices[0]
        max_profit = 0

        for price in prices[1:]:
            if price < min_price:
                min_price = price
            else:
                max_profit = max(max_profit, price - min_price)

        return max_profit
```

也可以写成：

```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        min_price = prices[0]
        ans = 0

        for price in prices:
            min_price = min(min_price, price)
            ans = max(ans, price - min_price)

        return ans
```

minPrice 不断更新：7 -> 6 -> 4 -> 3 -> 1

## 十二、和你的暴力写法对比

| 写法 | 思路 | 时间复杂度 | 空间复杂度 |
|---|---|---|---|
| 双层循环 | 枚举买入日和卖出日 | O(n^2) | O(1) |
| 一次遍历 | 枚举卖出日，维护前面最低买入价 | O(n) | O(1) |

优化的关键是：

```text
不再枚举所有买入日。
而是在遍历卖出日时，顺手记住前面最低买入价。
```

---

## 十三、复杂度分析

时间复杂度：

```text
O(n)
```

只遍历一次数组。

空间复杂度：

```text
O(1)
```

只用了 `minPrice` 和 `maxProfit` 两个变量。

---

## 十四、容易错的点

### 1. 不要用双层循环

双层循环虽然正确，但会超时。

```go
for i := 0; i < len(prices); i++ {
    for j := i+1; j < len(prices); j++ {
        ...
    }
}
```

这是 `O(n^2)`。

---

### 2. `minPrice` 表示当前天之前见过的最低价格

核心变量是：

```go
minPrice
```

它不是最终最低价，而是：

```text
遍历到当前位置为止的最低价。
```

---

### 3. 当前天应该理解成“卖出日”

不要一直从“哪天买”开始想。

更好的角度是：

```text
如果今天卖出，前面哪天买最便宜？
```

---

### 4. 利润不能是负数

如果价格一直下跌，最大利润应该是：

```text
0
```

所以 `maxProfit` 初始化为：

```go
maxProfit := 0
```

---

### 5. 只能交易一次

这题不是把所有上涨区间都加起来。

比如：

```text
[1, 3, 2, 5]
```

这题答案是：

```text
5 - 1 = 4
```

不是：

```text
(3 - 1) + (5 - 2) = 5
```

后者是另一道题：多次买卖股票。

---

## 十五、面试表达

可以这样说：

> 暴力做法是枚举买入日和卖出日，时间复杂度是 O(n^2)，会超时。优化时可以换个角度，把当前遍历到的每一天都看成卖出日，那么要想利润最大，买入日一定应该是当前天之前价格最低的那一天。所以遍历数组时维护一个 `minPrice`，表示到目前为止见过的最低价格；同时用 `prices[i] - minPrice` 更新最大利润 `maxProfit`。这样只需要遍历一次数组，时间复杂度 O(n)，空间复杂度 O(1)。
