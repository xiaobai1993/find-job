# 1290. 二进制链表转整数

题目链接：`https://leetcode.cn/problems/convert-binary-number-in-a-linked-list-to-integer/`

---

## 一、题目描述

给你一个单链表的引用结点 `head`。链表中每个结点的值不是 `0` 就是 `1`。

已知此链表是一个整数数字的二进制表示形式，请你返回该链表所表示数字的十进制值。

示例：

```text
输入：head = [1,0,1]
输出：5
```

解释：

```text
二进制 101 = 十进制 5
```

---

## 二、你的 Go 解法

你的写法是先把链表值放进数组，再从数组尾部开始计算二进制权重。

```go
/**
 * Definition for singly-linked list.
 * type ListNode struct {
 *     Val int
 *     Next *ListNode
 * }
 */
func getDecimalValue(head *ListNode) int {
    var result int
    var list []int

    for t := head; t != nil; t = t.Next {
        list = append(list, t.Val)
    }

    maxLen := len(list)
    me := 1

    for i := 0; i < maxLen; i++ {
        result += list[maxLen-i-1] * me
        me = me * 2
    }

    return result
}
```

这个思路是正确的。

例如：

```text
链表：1 -> 0 -> 1
数组：[1, 0, 1]
```

从后往前计算：

```text
1 * 1 = 1
0 * 2 = 0
1 * 4 = 4
结果 = 5
```

## 三、核心优化：一次遍历

这题可以不用数组。

二进制从左往右读时，每读一位：

```text
之前的结果先乘 2，再加当前位
```

例如：

```text
1 -> 0 -> 1
```

计算过程：

```text
初始 result = 0

读到 1：result = 0 * 2 + 1 = 1
读到 0：result = 1 * 2 + 0 = 2
读到 1：result = 2 * 2 + 1 = 5
```

所以公式是：

```text
result = result * 2 + 当前节点值
```

## 四、Go 推荐写法

```go
/**
 * Definition for singly-linked list.
 * type ListNode struct {
 *     Val int
 *     Next *ListNode
 * }
 */
func getDecimalValue(head *ListNode) int {
    result := 0

    for head != nil {
        result = result*2 + head.Val
        head = head.Next
    }

    return result
}
```

---

## 五、Go 位运算写法

因为乘 2 等价于左移一位：

```text
result * 2 == result << 1
```

所以可以写成：

```go
func getDecimalValue(head *ListNode) int {
    result := 0

    for head != nil {
        result = (result << 1) + head.Val
        head = head.Next
    }

    return result
}
```

也可以用按位或：

```go
func getDecimalValue(head *ListNode) int {
    result := 0

    for head != nil {
        result = result<<1 | head.Val
        head = head.Next
    }

    return result
}
```

解释：

```text
result << 1：把原来的二进制结果左移一位
| head.Val：把当前这一位补到最低位
```

## 六、Python3 写法

### 写法一：一次遍历，乘 2

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def getDecimalValue(self, head: Optional[ListNode]) -> int:
        result = 0

        while head:
            result = result * 2 + head.val
            head = head.next

        return result
```

### 写法二：位运算

```python
class Solution:
    def getDecimalValue(self, head: Optional[ListNode]) -> int:
        result = 0

        while head:
            result = (result << 1) | head.val
            head = head.next

        return result
```

## 七、三种写法对比

| 写法 | 时间复杂度 | 空间复杂度 | 说明 |
|---|---:|---:|---|
| 数组写法 | O(n) | O(n) | 好理解，先存数组再从低位算 |
| 一次遍历乘 2 | O(n) | O(1) | 推荐，简单直观 |
| 位运算左移 | O(n) | O(1) | 最简洁，体现二进制本质 |

## 八、复杂度分析

推荐写法：

```text
时间复杂度：O(n)
空间复杂度：O(1)
```

原因：

```text
只遍历链表一次，只使用 result 一个变量。
```

## 九、容易错的点

### 1. 不需要从尾部开始算

虽然二进制权重从右往左是：

```text
1, 2, 4, 8...
```

但是从左往右也可以直接递推：

```text
result = result * 2 + 当前位
```

这样不需要数组。

---

### 2. 位运算的优先级最好加括号

推荐写：

```go
result = (result << 1) | head.Val
```

Python：

```python
result = (result << 1) | head.val
```

加括号更清晰，不容易误读。

## 十、面试表达

可以这样说：

> 第一种思路是先把链表里的二进制位放到数组中，然后从数组尾部开始按照 1、2、4、8 的权重累加，得到十进制值。这个方法时间复杂度是 O(n)，空间复杂度是 O(n)。
>
> 更优的做法是一次遍历。因为二进制从左到右读时，每读一位，相当于之前的结果左移一位，也就是乘 2，再加上当前位。所以可以写成 `result = result * 2 + head.Val`，或者用位运算写成 `result = (result << 1) | head.Val`。这样空间复杂度可以降到 O(1)。
