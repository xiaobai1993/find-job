# 面试题 04.04. 检查平衡性

题目链接：`https://leetcode.cn/problems/check-balance-lcci/`

---

## 一、题目描述

实现一个函数，检查二叉树是否平衡。

在这道题里，平衡二叉树的定义是：

```text
任意一个节点，它的左右两个子树的高度差不超过 1。
```

也就是说，不只是根节点要平衡，树里的每一个节点都要平衡。

---

## 二、先理解什么是“高度平衡”

比如这棵树是平衡的：

```text
      3
     / \
    9   20
       /  \
      15   7
```

原因是每个节点的左右子树高度差都不超过 1。

这棵树不是平衡的：

```text
        1
       /
      2
     /
    3
   /
  4
```

根节点左子树很高，右子树为空，高度差大于 1，所以不是平衡二叉树。

---

## 三、这题的关键点

很多人容易误解成：

```text
只判断根节点的左右子树高度差是否 <= 1
```

这是不够的。

真正要判断的是：

```text
每一个节点的左右子树高度差都不能超过 1。
```

所以对每个节点都需要知道：

```text
左子树高度
右子树高度
当前节点是否平衡
```

这很适合用递归。

---

## 四、普通思路：每个节点都算高度

可以写一个函数 `height(root)` 计算树高。

然后对每个节点判断：

```text
abs(height(left) - height(right)) <= 1
```

并且递归判断左右子树也是否平衡。

伪代码：

```text
isBalanced(root):
    if root == nil:
        return true

    leftHeight = height(root.left)
    rightHeight = height(root.right)

    return abs(leftHeight - rightHeight) <= 1
           && isBalanced(root.left)
           && isBalanced(root.right)
```

这个思路好理解，但有重复计算。

比如根节点算高度时，会遍历一遍子树；递归到子节点时，又会重新遍历同一批节点。

最坏情况下时间复杂度可能到：

```text
O(n^2)
```

---

## 五、推荐思路：后序递归，一边算高度一边判断

更好的做法是：

```text
递归函数返回当前子树高度。
如果发现某棵子树已经不平衡，就返回 -1。
```

为什么用 `-1`？

因为正常树高不可能是负数，所以 `-1` 可以作为“不平衡”的标记。

递归函数 `check(node)` 的含义：

```text
如果 node 为根的子树是平衡的，返回它的高度。
如果 node 为根的子树不平衡，返回 -1。
```

---

## 六、递归过程

对每个节点：

```text
1. 先递归检查左子树，拿到 leftHeight
2. 如果 leftHeight == -1，说明左子树已经不平衡，直接返回 -1
3. 再递归检查右子树，拿到 rightHeight
4. 如果 rightHeight == -1，说明右子树已经不平衡，直接返回 -1
5. 判断左右高度差是否超过 1
6. 如果超过 1，返回 -1
7. 否则返回当前树高度 max(leftHeight, rightHeight) + 1
```

这是典型的后序遍历：

```text
左子树 -> 右子树 -> 当前节点
```

因为必须先知道左右子树高度，才能判断当前节点是否平衡。

---

## 七、Python3 解法

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def isBalanced(self, root: Optional[TreeNode]) -> bool:
        def check(node: Optional[TreeNode]) -> int:
            if not node:
                return 0

            left_height = check(node.left)
            if left_height == -1:
                return -1

            right_height = check(node.right)
            if right_height == -1:
                return -1

            if abs(left_height - right_height) > 1:
                return -1

            return max(left_height, right_height) + 1

        return check(root) != -1
```

## 八、Go 解法

```go
/**
 * Definition for a binary tree node.
 * type TreeNode struct {
 *     Val int
 *     Left *TreeNode
 *     Right *TreeNode
 * }
 */
func isBalanced(root *TreeNode) bool {
    return checkHeight(root) != -1
}

func checkHeight(root *TreeNode) int {
    if root == nil {
        return 0
    }

    leftHeight := checkHeight(root.Left)
    if leftHeight == -1 {
        return -1
    }

    rightHeight := checkHeight(root.Right)
    if rightHeight == -1 {
        return -1
    }

    if abs(leftHeight-rightHeight) > 1 {
        return -1
    }

    if leftHeight > rightHeight {
        return leftHeight + 1
    }
    return rightHeight + 1
}

func abs(x int) int {
    if x < 0 {
        return -x
    }
    return x
}
```

## 九、为什么返回高度就够了？

因为判断一个节点是否平衡，只需要两个信息：

```text
左子树高度
右子树高度
```

如果左右子树本身已经不平衡，那当前树也一定不平衡。

所以递归函数可以同时完成两件事：

```text
1. 返回高度
2. 用 -1 表示不平衡
```

这样就避免了重复计算高度。

---

## 十、例子走一遍

树：

```text
      3
     / \
    9   20
       /  \
      15   7
```

从叶子节点开始：

```text
9 的高度 = 1
15 的高度 = 1
7 的高度 = 1
20 的左右高度都是 1，所以 20 高度 = 2
3 的左高度 = 1，右高度 = 2，差值 = 1，所以平衡
```

最终返回 `true`。

---

再看不平衡的树：

```text
        1
       /
      2
     /
    3
   /
  4
```

从底部往上：

```text
4 高度 = 1
3 左高度 = 1，右高度 = 0，差值 = 1，平衡，高度 = 2
2 左高度 = 2，右高度 = 0，差值 = 2，不平衡，返回 -1
1 发现左子树返回 -1，直接返回 -1
```

最终返回 `false`。

## 十一、复杂度分析

时间复杂度：

```text
O(n)
```

每个节点最多访问一次。

空间复杂度：

```text
O(h)
```

`h` 是树的高度，来自递归调用栈。

如果是平衡树：

```text
O(log n)
```

如果退化成链表：

```text
O(n)
```

---

## 十二、容易错的点

### 1. 不能只判断根节点

错误理解：

```text
根节点左右高度差 <= 1 就是平衡
```

正确理解：

```text
每一个节点的左右高度差都要 <= 1
```

---

### 2. 空树是平衡的

如果 `root == nil` / `None`，直接认为平衡。

高度定义为：

```text
空树高度 = 0
```

---

### 3. 递归要用后序遍历

因为当前节点是否平衡，依赖左右子树高度。

所以顺序是：

```text
先左子树
再右子树
最后判断当前节点
```

---

### 4. `-1` 是不平衡标记

正常高度不会是负数，所以可以用 `-1` 表示：

```text
这棵子树已经不平衡，不用继续算高度了
```

---

## 十三、面试表达

可以这样说：

> 这题要判断的是每个节点的左右子树高度差是否都不超过 1。普通做法是对每个节点都单独计算左右子树高度，但会有重复计算。更好的做法是后序递归：递归函数返回当前子树高度，如果发现某棵子树不平衡，就返回 -1 作为标记。当前节点拿到左右子树高度后，如果任意一边是 -1，或者左右高度差大于 1，就继续向上返回 -1；否则返回当前高度 `max(left, right) + 1`。最后只要判断根节点返回值是否为 -1 即可。这样每个节点只访问一次，时间复杂度是 O(n)。
