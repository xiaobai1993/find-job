# 733. 图像渲染

> LeetCode 链接：https://leetcode.cn/problems/flood-fill/

## 题目
给定图像（二维数组）、起始位置 (sr,sc) 和新颜色，对起始格及相同颜色且连通的格子进行颜色填充（洪水填充/BFS）。

## 最易理解的方法：DFS 染色

**核心思路：**
从起始点 DFS，将相同颜色的连通格子改为新颜色。注意起始颜色==新颜色时直接返回。

```
image=[[1,1,1],[1,1,0],[1,0,1]], sr=1,sc=1, color=2

从(1,1)出发，旧颜色=1
DFS将所有连通的1改为2:
[[2,2,2],[2,2,0],[2,0,1]]
```

## Go 实现

```go
func floodFill(image [][]int, sr int, sc int, color int) [][]int {
    oldColor := image[sr][sc]
    if oldColor == color { return image }
    var dfs func(r, c int)
    dfs = func(r, c int) {
        if r < 0 || r >= len(image) || c < 0 || c >= len(image[0]) { return }
        if image[r][c] != oldColor { return }
        image[r][c] = color
        dfs(r+1, c); dfs(r-1, c); dfs(r, c+1); dfs(r, c-1)
    }
    dfs(sr, sc)
    return image
}
```

## 复杂度
- 时间：O(m×n)
- 空间：O(m×n)（递归栈）

## 记忆口诀
> 记录旧颜色；DFS扩散；旧颜色相同则染新色继续扩展；注意旧==新颜色时直接返回。
