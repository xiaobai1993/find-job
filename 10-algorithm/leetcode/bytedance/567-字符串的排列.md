# 567. 字符串的排列

> LeetCode 链接：https://leetcode.cn/problems/permutation-in-string/

## 题目
给定字符串 s1 和 s2，判断 s2 中是否包含 s1 的某个排列（即 s1 的字母异位词）。

## 最易理解的方法：固定窗口滑动

**核心思路：**
在 s2 中维护长度为 len(s1) 的窗口，用频率数组比较是否匹配。

```
s1="ab", s2="eidbaooo"

窗口长度=2:
[ei]: [0..] ≠ s1cnt
[id]: ≠
[db]: ≠
[ba]: a=1,b=1 == s1cnt → true
```

## Go 实现

```go
func checkInclusion(s1 string, s2 string) bool {
    if len(s1) > len(s2) { return false }
    var cnt1, cnt2 [26]int
    for i := 0; i < len(s1); i++ {
        cnt1[s1[i]-'a']++
        cnt2[s2[i]-'a']++
    }
    if cnt1 == cnt2 { return true }
    for i := len(s1); i < len(s2); i++ {
        cnt2[s2[i]-'a']++
        cnt2[s2[i-len(s1)]-'a']--
        if cnt1 == cnt2 { return true }
    }
    return false
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 固定窗口(len=s1)滑动；进右出左更新频率；两数组相等则找到。
