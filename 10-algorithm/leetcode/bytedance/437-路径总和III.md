# 437. 路径总和 III

> LeetCode 链接：https://leetcode.cn/problems/path-sum-iii/

## 题目
给定二叉树和整数 targetSum，返回路径和等于 targetSum 的路径数目（路径可以从任意节点开始，但必须向下）。

## 最易理解的方法：前缀和 + 哈希表

**核心思路：**
类似"和为K的子数组"：DFS 过程中维护前缀和，用哈希表记录每种前缀和出现的次数。
当前前缀和为 `cur`，若 `cur - targetSum` 在哈希表中存在 k 次，则有 k 条路径。

```
      10
     /  \
    5   -3
   / \    \
  3   2   11
 / \   \
3  -2   1

targetSum=8
路径: 5→3, 5→2→1, -3→11
```

## Go 实现

```go
func pathSum(root *TreeNode, targetSum int) int {
    prefixCount := map[int]int{0: 1}
    res := 0
    var dfs func(node *TreeNode, cur int)
    dfs = func(node *TreeNode, cur int) {
        if node == nil {
            return
        }
        cur += node.Val
        res += prefixCount[cur-targetSum]
        prefixCount[cur]++
        dfs(node.Left, cur)
        dfs(node.Right, cur)
        prefixCount[cur]-- // 回溯
    }
    dfs(root, 0)
    return res
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> DFS前缀和+哈希表；res+=count[cur-target]；加入当前节点；递归完后减去（回溯）。
