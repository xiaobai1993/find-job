# 191. 位1的个数

> LeetCode 链接：https://leetcode.cn/problems/number-of-1-bits/

## 题目
编写函数，输入无符号整数，返回其二进制表示中 '1' 的个数（Hamming Weight）。

## 最易理解的方法：n & (n-1) 消去最低位1

**核心思路：**
`n & (n-1)` 每次消去最低位的1，统计操作次数即为1的个数。

```
n=12 = 1100
n&(n-1): 1100 & 1011 = 1000 → count=1
         1000 & 0111 = 0000 → count=2
结果: 2
```

## Go 实现

```go
func hammingWeight(n uint32) int {
    count := 0
    for n != 0 {
        n &= n - 1
        count++
    }
    return count
}
```

## 复杂度
- 时间：O(k)，k 为1的个数
- 空间：O(1)

## 记忆口诀
> n&(n-1) 消去最低位1；循环直到n为0，计数即答案。
