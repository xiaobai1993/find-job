# 633. 平方数之和

> LeetCode 链接：https://leetcode.cn/problems/sum-of-square-numbers/

## 题目
给定非负整数 c，判断是否存在整数 a 和 b 使得 a² + b² = c。

## 最易理解的方法：双指针（左0右sqrt(c)）

**核心思路：**
a 从 0 到 sqrt(c)，b 从 sqrt(c) 到 0，双指针夹逼找目标和。

```
c=5

a=0, b=2: 0+4=4 < 5 → a++
a=1, b=2: 1+4=5 == c → true
```

## Go 实现

```go
import "math"

func judgeSquareSum(c int) bool {
    a, b := 0, int(math.Sqrt(float64(c)))
    for a <= b {
        sum := a*a + b*b
        if sum == c { return true }
        if sum < c { a++ } else { b-- }
    }
    return false
}
```

## 复杂度
- 时间：O(sqrt(c))
- 空间：O(1)

## 记忆口诀
> 双指针a=0,b=sqrt(c)；和小则a++，和大则b--；找到则true。
