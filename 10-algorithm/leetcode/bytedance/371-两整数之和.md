# 371. 两整数之和

> LeetCode 链接：https://leetcode.cn/problems/sum-of-two-integers/

## 题目
不使用运算符 + 和 -，计算两整数之和。

## 最易理解的方法：位运算模拟加法

**核心思路：**
- `a ^ b`：相加但不考虑进位（异或）
- `(a & b) << 1`：进位
- 重复直到没有进位

```
a=1, b=3 (01, 11)

a^b = 10 = 2 (无进位加法)
(a&b)<<1 = 01<<1 = 10 = 2 (进位)
下一轮: a=2, b=2
2^2 = 0, (2&2)<<1 = 4
下一轮: a=0, b=4
0^4=4, 无进位

答案=4
```

## Go 实现

```go
func getSum(a int, b int) int {
    for b != 0 {
        carry := (a & b) << 1
        a = a ^ b
        b = carry
    }
    return a
}
```

## 复杂度
- 时间：O(1)（整数位数固定）
- 空间：O(1)

## 记忆口诀
> a^b=无进位和；(a&b)<<1=进位；循环直到进位为0。
