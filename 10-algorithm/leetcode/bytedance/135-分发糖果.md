# 135. 分发糖果

> LeetCode 链接：https://leetcode.cn/problems/candy/

## 题目
n 个孩子站成一排，每个孩子有评分 ratings。分发糖果，规则：每人至少 1 颗；评分高的孩子比相邻孩子获得更多糖果。求最少需要多少糖果。

## 最易理解的方法：两次遍历（贪心）

**核心思路：**
1. 左→右扫描：如果 ratings[i] > ratings[i-1]，则 candy[i] = candy[i-1]+1
2. 右→左扫描：如果 ratings[i] > ratings[i+1]，则 candy[i] = max(candy[i], candy[i+1]+1)

两次扫描分别保证"比左边高"和"比右边高"的约束。

```
ratings = [1, 0, 2]

初始: candy = [1,1,1]

左→右: ratings[2]=2>ratings[1]=0 → candy[2]=2
  candy = [1,1,2]

右→左: ratings[0]=1>ratings[1]=0 → candy[0]=max(1,2)=2
  candy = [2,1,2]

总和 = 2+1+2 = 5
```

## Go 实现

```go
func candy(ratings []int) int {
    n := len(ratings)
    candy := make([]int, n)
    for i := range candy {
        candy[i] = 1
    }
    // 左→右：比左边评分高则多一颗
    for i := 1; i < n; i++ {
        if ratings[i] > ratings[i-1] {
            candy[i] = candy[i-1] + 1
        }
    }
    // 右→左：比右边评分高则取 max
    for i := n - 2; i >= 0; i-- {
        if ratings[i] > ratings[i+1] {
            if candy[i+1]+1 > candy[i] {
                candy[i] = candy[i+1] + 1
            }
        }
    }
    total := 0
    for _, c := range candy {
        total += c
    }
    return total
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> 两遍贪心：先左→右满足左约束；再右→左取max满足右约束；汇总即答案。
