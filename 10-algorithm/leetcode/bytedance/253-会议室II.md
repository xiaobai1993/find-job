# 253. 会议室 II

> LeetCode 链接：https://leetcode.cn/problems/meeting-rooms-ii/

## 题目
给定会议时间区间数组，求需要的最少会议室数量。

## 最易理解的方法：差分/排序双指针

**核心思路：**
将开始时间和结束时间分别排序，双指针扫描：
- 若当前开始时间 < 最早结束时间：需要新会议室，rooms++
- 否则：有会议室释放，endIdx++

```
[[0,30],[5,10],[15,20]]

开始: [0,5,15]
结束: [10,20,30]

i=0(s=0), endIdx=0(e=10): 0<10 → rooms=1
i=1(s=5), endIdx=0(e=10): 5<10 → rooms=2
i=2(s=15), endIdx=0(e=10): 15≥10 → rooms=2(不增), endIdx=1
  15<20 → rooms仍2

答案=2
```

## Go 实现

```go
import "sort"

func minMeetingRooms(intervals [][]int) int {
    n := len(intervals)
    starts := make([]int, n)
    ends := make([]int, n)
    for i, iv := range intervals {
        starts[i] = iv[0]
        ends[i] = iv[1]
    }
    sort.Ints(starts)
    sort.Ints(ends)
    rooms, endIdx := 0, 0
    for i := 0; i < n; i++ {
        if starts[i] < ends[endIdx] {
            rooms++
        } else {
            endIdx++
        }
    }
    return rooms
}
```

## 复杂度
- 时间：O(n log n)
- 空间：O(n)

## 记忆口诀
> 开始结束时间分别排序；开始<最早结束则需新房间；否则有房间释放；记录最大同时会议数。
