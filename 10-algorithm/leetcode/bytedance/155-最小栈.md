# 155. 最小栈

> LeetCode 链接：https://leetcode.cn/problems/min-stack/

## 题目
设计一个支持 push、pop、top 和 getMin 操作的栈，其中 getMin 操作能在常数时间内获取栈中的最小元素。

## 最易理解的方法：辅助栈

**核心思路：**
用两个栈：一个正常栈，一个**最小值栈**（始终维护当前栈中的最小值）。push 时，同步向最小值栈 push `min(新值, 当前最小值)`；pop 时两个栈同步弹出；getMin 返回最小值栈的栈顶。

```
操作序列: push(5),push(3),push(7),pop(),getMin()

主栈:     [5]  [5,3]  [5,3,7]  [5,3]
最小栈:   [5]  [5,3]  [5,3,3]  [5,3]
getMin → 最小栈栈顶 = 3
```

## Go 实现

```go
type MinStack struct {
    stack    []int
    minStack []int
}

func Constructor() MinStack {
    return MinStack{}
}

func (s *MinStack) Push(val int) {
    s.stack = append(s.stack, val)
    if len(s.minStack) == 0 || val <= s.minStack[len(s.minStack)-1] {
        s.minStack = append(s.minStack, val)
    } else {
        s.minStack = append(s.minStack, s.minStack[len(s.minStack)-1])
    }
}

func (s *MinStack) Pop() {
    s.stack = s.stack[:len(s.stack)-1]
    s.minStack = s.minStack[:len(s.minStack)-1]
}

func (s *MinStack) Top() int {
    return s.stack[len(s.stack)-1]
}

func (s *MinStack) GetMin() int {
    return s.minStack[len(s.minStack)-1]
}
```

## 复杂度
- 时间：O(1) 所有操作
- 空间：O(n)

## 记忆口诀
> 辅助最小栈与主栈同步增减；push 时辅助栈取 min(新值, 当前最小)；getMin 直接取辅助栈顶。
