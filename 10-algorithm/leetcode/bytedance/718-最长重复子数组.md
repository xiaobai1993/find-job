# 718. 最长重复子数组

> LeetCode 链接：https://leetcode.cn/problems/maximum-length-of-repeated-subarray/

## 题目
给定两个整数数组，返回两个数组中公共的、长度最长的子数组的长度。（子数组是连续的）

## 最易理解的方法：动态规划

**核心思路：**
`dp[i][j]` = 以 `nums1[i-1]` 和 `nums2[j-1]` 结尾的最长公共子数组长度。
- 若 `nums1[i-1] == nums2[j-1]`：`dp[i][j] = dp[i-1][j-1] + 1`
- 否则：`dp[i][j] = 0`（子数组必须连续）

```
nums1=[1,2,3,2,1], nums2=[3,2,1,4,7]

dp:
  3 2 1 4 7
1 0 0 1 0 0
2 0 1 0 0 0
3 1 0 0 0 0
2 0 2 0 0 0
1 0 0 3 0 0 ← 最大值3

答案=3 (子数组[3,2,1])
```

## Go 实现

```go
func findLength(nums1 []int, nums2 []int) int {
    m, n := len(nums1), len(nums2)
    dp := make([][]int, m+1)
    for i := range dp {
        dp[i] = make([]int, n+1)
    }
    res := 0
    for i := 1; i <= m; i++ {
        for j := 1; j <= n; j++ {
            if nums1[i-1] == nums2[j-1] {
                dp[i][j] = dp[i-1][j-1] + 1
                if dp[i][j] > res {
                    res = dp[i][j]
                }
            }
        }
    }
    return res
}
```

## 复杂度
- 时间：O(m×n)
- 空间：O(m×n)

## 记忆口诀
> dp[i][j]以两数组i,j位置结尾的最长公共子数组；相等则+1，不等为0；记录全局最大。
