# 738. 单调递增的数字

> LeetCode 链接：https://leetcode.cn/problems/monotone-increasing-digits/

## 题目
给定非负整数 n，找最大的不超过 n 且各位数字单调不递减的整数。

## 最易理解的方法：从右向左贪心

**核心思路：**
从右向左扫描，若 `digits[i-1] > digits[i]`，则 `digits[i-1]--`，并将 i 及以后的位全改为 '9'（以最大化）。

```
n = 332

digits: [3,3,2]
i=2: 3>2 → digits[1]=2, mark=2
i=1: 3>2 → digits[0]=2, mark=1
将mark后的位改9: [2,9,9]
结果: 299
```

## Go 实现

```go
import (
    "strconv"
)

func monotoneIncreasingDigits(n int) int {
    s := []byte(strconv.Itoa(n))
    mark := len(s)
    for i := len(s) - 1; i > 0; i-- {
        if s[i-1] > s[i] {
            s[i-1]--
            mark = i
        }
    }
    for i := mark; i < len(s); i++ {
        s[i] = '9'
    }
    res, _ := strconv.Atoi(string(s))
    return res
}
```

## 复杂度
- 时间：O(d)（d为位数）
- 空间：O(d)

## 记忆口诀
> 从右到左找逆序；前位--并记录mark位置；mark后全改9。
