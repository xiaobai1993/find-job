# 69. x 的平方根

> LeetCode 链接：https://leetcode.cn/problems/sqrtx/

## 题目
给定非负整数 `x`，计算并返回 `x` 的算术平方根（向下取整）。不能使用 `sqrt` 函数或运算符。

## 最易理解的方法：二分查找

**核心思路：**
答案在 `[0, x]` 范围内。二分找最大的 `mid` 使得 `mid*mid <= x`。注意用 `mid <= x/mid` 代替 `mid*mid <= x` 以避免整数溢出。

```
x = 8

lo=0, hi=8
mid=4: 4*4=16>8 → hi=3
mid=1: 1*1=1<=8 → lo=2
mid=2: 2*2=4<=8 → lo=3
mid=3: 3*3=9>8  → hi=2
lo>hi, 结束

答案 = hi = 2 (2²=4≤8, 3²=9>8)
```

## Go 实现

```go
func mySqrt(x int) int {
    if x < 2 {
        return x
    }
    lo, hi := 1, x/2
    for lo <= hi {
        mid := (lo + hi) / 2
        if mid <= x/mid { // 等价于 mid*mid <= x，避免溢出
            if mid+1 > x/(mid+1) { // mid+1的平方>x
                return mid
            }
            lo = mid + 1
        } else {
            hi = mid - 1
        }
    }
    return lo
}
```

## 更简洁写法

```go
func mySqrt(x int) int {
    lo, hi := 0, x
    for lo < hi {
        mid := (lo + hi + 1) / 2 // 向上取整防止死循环
        if mid <= x/mid {
            lo = mid
        } else {
            hi = mid - 1
        }
    }
    return lo
}
```

## 复杂度
- 时间：O(log x)
- 空间：O(1)

## 记忆口诀
> 二分找最大的 mid 满足 mid*mid<=x；用 mid<=x/mid 避免溢出；向上取中避免死循环。
