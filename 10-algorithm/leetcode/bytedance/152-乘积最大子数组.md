# 152. 乘积最大子数组

> LeetCode 链接：https://leetcode.cn/problems/maximum-product-subarray/

## 题目
给定整数数组 `nums`，找出数组中乘积最大的连续子数组，返回该乘积。

## 最易理解的方法：同时维护最大值和最小值

**核心思路：**
因为有负数，负数×负数=正数，所以当前的最小值乘以负数可能变成最大值。同时维护：
- `maxVal`：以当前元素结尾的最大乘积
- `minVal`：以当前元素结尾的最小乘积（为负数乘以负数做准备）

每步：新的 maxVal = max(nums[i], maxVal×nums[i], minVal×nums[i])。遇到负数时最大和最小会交换。

```
nums = [2, 3, -2, 4]

i=0: max=2,  min=2
i=1: max=6,  min=3   (max(3,6,6)=6, min(3,6,6)=3)
i=2: max=-2, min=-12 (max(-2,-12,-6)=-2, min(-2,-12,-6)=-12)
i=3: max=4,  min=-48
ans = max历史最大 = 6
```

## Go 实现

```go
func maxProduct(nums []int) int {
    maxVal, minVal, ans := nums[0], nums[0], nums[0]
    for i := 1; i < len(nums); i++ {
        if nums[i] < 0 {
            maxVal, minVal = minVal, maxVal // 负数时交换
        }
        a := maxVal*nums[i]
        if nums[i] > a { a = nums[i] }
        maxVal = a
        b := minVal*nums[i]
        if nums[i] < b { b = nums[i] }
        minVal = b
        if maxVal > ans {
            ans = maxVal
        }
    }
    return ans
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 同时维护最大值和最小值；遇到负数时交换两者（因为负负得正）；每步更新全局最大。
