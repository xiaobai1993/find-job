# 665. 非递减数列

> LeetCode 链接：https://leetcode.cn/problems/non-decreasing-array/

## 题目
给定整数数组，最多改变1个元素，判断是否能让数组变成非递减序列。

## 最易理解的方法：贪心扫描找逆序对

**核心思路：**
找到第一对逆序 `nums[i] > nums[i+1]`，尝试修改 nums[i] 或 nums[i+1]，若还有第二对逆序则返回 false。

```
[4,2,3]:
发现i=0: 4>2 → 修改4→2，[2,2,3] → 之后无逆序 → true

[4,2,1]:
发现i=0: 4>2 → 修改4→2，[2,2,1] → 发现i=1: 2>1 → 第二次逆序 → false
```

## Go 实现

```go
func checkPossibility(nums []int) bool {
    count := 0
    for i := 0; i < len(nums)-1; i++ {
        if nums[i] > nums[i+1] {
            count++
            if count > 1 { return false }
            if i > 0 && nums[i-1] > nums[i+1] {
                nums[i+1] = nums[i] // 修改i+1
            } else {
                nums[i] = nums[i+1] // 修改i
            }
        }
    }
    return true
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 扫描逆序对；超过1次返回false；修改策略：若i-1>i+1则改i+1，否则改i为i+1。
