# 71. 简化路径

> LeetCode 链接：https://leetcode.cn/problems/simplify-path/

## 题目
给定 Unix 风格的绝对路径字符串，将其转化为简化的规范路径（`.` 表示当前目录，`..` 返回上级，多余 `/` 忽略）。

## 最易理解的方法：栈 + 分割

**核心思路：**
按 `/` 分割路径，依次处理每个部分：
- 空字符串或 `.`：忽略
- `..`：弹出栈顶（返回上级）
- 其他：压入栈
最后将栈内容拼接为结果。

```
path = "/home//foo/.."

分割: ["","home","","foo",".."]
处理:
  "": 忽略
  "home": 入栈 → [home]
  "": 忽略
  "foo": 入栈 → [home,foo]
  "..": 弹出 → [home]

结果: "/home"
```

## Go 实现

```go
import "strings"

func simplifyPath(path string) string {
    parts := strings.Split(path, "/")
    stack := []string{}
    for _, p := range parts {
        if p == "" || p == "." {
            continue
        }
        if p == ".." {
            if len(stack) > 0 {
                stack = stack[:len(stack)-1]
            }
        } else {
            stack = append(stack, p)
        }
    }
    return "/" + strings.Join(stack, "/")
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> 按/分割；空或.忽略；..弹栈；其他入栈；最后"/"拼接。
