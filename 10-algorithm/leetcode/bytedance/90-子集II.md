# 90. 子集 II

> LeetCode 链接：https://leetcode.cn/problems/subsets-ii/

## 题目
给定可能含重复元素的整数数组，返回所有不重复的子集。

## 最易理解的方法：排序 + 回溯去重

**核心思路：**
先排序，回溯时跳过同层重复元素（`i > start && nums[i] == nums[i-1]`）。

```
nums=[1,2,2]

排序后:[1,2,2]

[]
start=0:
  [1] → 加入
    [1,2] → 加入
      [1,2,2] → 加入
    [1,2] (第二个2已处理，跳过同层)
  [2] → 加入
    [2,2] → 加入
  [2] (第二个2，i>start=0且重复,跳过)
```

## Go 实现

```go
import "sort"

func subsetsWithDup(nums []int) [][]int {
    sort.Ints(nums)
    var res [][]int
    var backtrack func(start int, path []int)
    backtrack = func(start int, path []int) {
        tmp := make([]int, len(path))
        copy(tmp, path)
        res = append(res, tmp)
        for i := start; i < len(nums); i++ {
            // 同层去重
            if i > start && nums[i] == nums[i-1] {
                continue
            }
            path = append(path, nums[i])
            backtrack(i+1, path)
            path = path[:len(path)-1]
        }
    }
    backtrack(0, nil)
    return res
}
```

## 复杂度
- 时间：O(n × 2^n)
- 空间：O(n)

## 记忆口诀
> 排序；每进入循环先收集当前path；同层去重：i>start且与前相同则跳过。
