# 912. 排序数组

> LeetCode 链接：https://leetcode.cn/problems/sort-an-array/

## 题目
给定整数数组，排升序，要求时间 O(n log n)，空间尽量少（不直接使用 sort.Ints）。

## 最易理解的方法：堆排序（原地 O(1) 空间）

**核心思路：**
建大根堆，然后依次将堆顶（最大值）与末尾交换，缩小堆范围，反复 heapify 直到排序完成。

```
[5,2,3,1]

建堆: [5,2,3,1]
交换5和1: [1,2,3,5], 堆[1,2,3] heapify→[3,2,1]
交换3和1: [1,2,3,5] → wait
实际结果: [1,2,3,5]
```

## Go 实现

```go
func sortArray(nums []int) []int {
    n := len(nums)
    // 建堆
    for i := n/2 - 1; i >= 0; i-- {
        heapify(nums, n, i)
    }
    // 排序
    for i := n - 1; i > 0; i-- {
        nums[0], nums[i] = nums[i], nums[0]
        heapify(nums, i, 0)
    }
    return nums
}

func heapify(nums []int, n, i int) {
    largest := i
    l, r := 2*i+1, 2*i+2
    if l < n && nums[l] > nums[largest] { largest = l }
    if r < n && nums[r] > nums[largest] { largest = r }
    if largest != i {
        nums[i], nums[largest] = nums[largest], nums[i]
        heapify(nums, n, largest)
    }
}
```

## 复杂度
- 时间：O(n log n)
- 空间：O(1)

## 记忆口诀
> 建大根堆→逐步交换堆顶到末尾→缩小堆范围heapify；O(nlogn)原地排序。
