# 58. 最后一个单词的长度

> LeetCode 链接：https://leetcode.cn/problems/length-of-last-word/

## 题目
给定字符串（包含字母和空格），返回最后一个单词的长度。字符串不包含空格时返回 0。

## 最易理解的方法：从末尾向前遍历

**核心思路：**
从字符串末尾向前：先跳过末尾空格，然后计数字母直到遇到空格或到达开头。

```
"Hello World  "

从末尾: 跳空格，然后 d,l,r,o,W → 长度=5
```

## Go 实现

```go
func lengthOfLastWord(s string) int {
    i := len(s) - 1
    // 跳过末尾空格
    for i >= 0 && s[i] == ' ' {
        i--
    }
    // 计数最后一个单词
    length := 0
    for i >= 0 && s[i] != ' ' {
        length++
        i--
    }
    return length
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 从末尾往前：先跳空格，再数字母直到空格；返回计数。
