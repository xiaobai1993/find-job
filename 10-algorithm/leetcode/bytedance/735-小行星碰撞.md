# 735. 小行星碰撞

> LeetCode 链接：https://leetcode.cn/problems/asteroid-collision/

## 题目
整数数组表示小行星（正=向右，负=向左，绝对值为大小），同向不碰撞，碰撞时小的爆炸，相同大小双双爆炸，求最终状态。

## 最易理解的方法：栈模拟

**核心思路：**
遍历小行星，正号直接入栈；负号时与栈顶正号行星比较大小决定谁爆炸，循环处理直到不再碰撞。

```
asteroids = [5,10,-5]

5入栈: [5]
10入栈: [5,10]
-5: 栈顶10>5 → -5爆炸，10留下
结果: [5,10]
```

## Go 实现

```go
func asteroidCollision(asteroids []int) []int {
    stack := []int{}
    for _, a := range asteroids {
        alive := true
        for alive && a < 0 && len(stack) > 0 && stack[len(stack)-1] > 0 {
            top := stack[len(stack)-1]
            if top < -a {
                stack = stack[:len(stack)-1] // 栈顶爆炸
            } else if top == -a {
                stack = stack[:len(stack)-1] // 双双爆炸
                alive = false
            } else {
                alive = false // 当前爆炸
            }
        }
        if alive {
            stack = append(stack, a)
        }
    }
    return stack
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> 栈模拟；正号直接入；负号与栈顶正号比较：栈顶小则爆栈顶，相等则双爆，栈顶大则当前爆。
