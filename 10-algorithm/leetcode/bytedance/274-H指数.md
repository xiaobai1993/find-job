# 274. H 指数

> LeetCode 链接：https://leetcode.cn/problems/h-index/

## 题目
给定论文引用次数数组，计算 H 指数（至少有 h 篇论文各被引用至少 h 次）。

## 最易理解的方法：计数排序

**核心思路：**
用长度 n+1 的桶统计各引用次数的论文数量（超过 n 的算 n），从大到小累加，首次累加 >= h 时返回 h。

```
citations = [3,0,6,1,5], n=5

桶: [1,1,0,1,0,2] (0次1篇,1次1篇,3次1篇,5+次2篇)
从右累加: h=5:2, h=4:2, h=3:3>=3 → 返回3
```

## Go 实现

```go
func hIndex(citations []int) int {
    n := len(citations)
    bucket := make([]int, n+1)
    for _, c := range citations {
        if c >= n {
            bucket[n]++
        } else {
            bucket[c]++
        }
    }
    total := 0
    for h := n; h >= 0; h-- {
        total += bucket[h]
        if total >= h {
            return h
        }
    }
    return 0
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> 计数桶大小n+1；超过n归入n桶；从大到小累加，首次total>=h返回h。
