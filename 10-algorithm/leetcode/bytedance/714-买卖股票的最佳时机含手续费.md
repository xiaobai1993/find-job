# 714. 买卖股票的最佳时机含手续费

> LeetCode 链接：https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-with-transaction-fee/

## 题目
给定股价数组和手续费，每次卖出需支付手续费，可以多次买卖，求最大利润。

## 最易理解的方法：贪心 DP（cash/hold 状态）

**核心思路：**
维护两个状态：`cash`（不持股最大利润）和 `hold`（持股最大利润）。
- `cash = max(cash, hold + price - fee)`（卖出）
- `hold = max(hold, cash - price)`（买入）

```
prices=[1,3,2,8,4,9], fee=2

初始: cash=0, hold=-1
price=1: cash=0, hold=max(-1,0-1)=-1
price=3: cash=max(0,-1+3-2)=0, hold=-1
price=2: cash=0, hold=max(-1,0-2)=-2
price=8: cash=max(0,-2+8-2)=4, hold=-2
price=4: cash=4, hold=max(-2,4-4)=0
price=9: cash=max(4,0+9-2)=7, hold=0

最大利润: 7
```

## Go 实现

```go
func maxProfit(prices []int, fee int) int {
    cash, hold := 0, -prices[0]
    for i := 1; i < len(prices); i++ {
        cash = max2(cash, hold+prices[i]-fee)
        hold = max2(hold, cash-prices[i])
    }
    return cash
}

func max2(a, b int) int {
    if a > b { return a }
    return b
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> cash/hold两状态；卖出时扣手续费；每天更新两状态取最大。
