# 297. 二叉树的序列化与反序列化

> LeetCode 链接：https://leetcode.cn/problems/serialize-and-deserialize-binary-tree/

## 题目
设计一个算法，实现二叉树的序列化（树→字符串）和反序列化（字符串→树）。

## 最易理解的方法：BFS 层序（类 LeetCode 格式）

**核心思路：**
序列化：BFS 层序遍历，节点值用逗号分隔，null 写成 "#"。
反序列化：按层序重建，用队列记录父节点，按位置依次赋左右子节点。

```
树:
    1
   / \
  2   3
     / \
    4   5

序列化: "1,2,3,#,#,4,5"

反序列化:
vals = [1,2,3,#,#,4,5]
根=1；队列=[1]
弹出1: 左=2,右=3；队列=[2,3]
弹出2: 左=#,右=#
弹出3: 左=4,右=5
```

## Go 实现

```go
type Codec struct{}

func Constructor() Codec { return Codec{} }

func (c *Codec) serialize(root *TreeNode) string {
    if root == nil {
        return "#"
    }
    queue := []*TreeNode{root}
    var res []string
    for len(queue) > 0 {
        node := queue[0]
        queue = queue[1:]
        if node == nil {
            res = append(res, "#")
        } else {
            res = append(res, strconv.Itoa(node.Val))
            queue = append(queue, node.Left, node.Right)
        }
    }
    return strings.Join(res, ",")
}

func (c *Codec) deserialize(data string) *TreeNode {
    parts := strings.Split(data, ",")
    if parts[0] == "#" {
        return nil
    }
    val, _ := strconv.Atoi(parts[0])
    root := &TreeNode{Val: val}
    queue := []*TreeNode{root}
    i := 1
    for len(queue) > 0 && i < len(parts) {
        node := queue[0]
        queue = queue[1:]
        if parts[i] != "#" {
            v, _ := strconv.Atoi(parts[i])
            node.Left = &TreeNode{Val: v}
            queue = append(queue, node.Left)
        }
        i++
        if i < len(parts) && parts[i] != "#" {
            v, _ := strconv.Atoi(parts[i])
            node.Right = &TreeNode{Val: v}
            queue = append(queue, node.Right)
        }
        i++
    }
    return root
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> BFS序列化null写"#"；反序列化时用队列记父节点，按顺序赋左右子节点。
