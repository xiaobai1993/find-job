# 143. 重排链表

题目链接：`https://leetcode.cn/problems/reorder-list/`

---

## 一、题目描述

给定一个单链表 L：L0→L1→…→Ln-1→Ln，将其重排为：L0→Ln→L1→Ln-1→L2→Ln-2→…

**要求**：不能只是单纯改变节点内部的值，需要实际进行节点交换。

**示例：**

```
输入: 1→2→3→4
输出: 1→4→2→3

输入: 1→2→3→4→5
输出: 1→5→2→4→3
```

```
func reorderList(head *ListNode) {
	if head == nil || head.Next == nil {
		return
	}
	// 1. 所有节点存入数组
	var arr []*ListNode
	cur := head
	for cur != nil {
		arr = append(arr, cur)
		cur = cur.Next
	}

	// 2. 双指针交替重排，完全不用虚拟节点
	i, j := 0, len(arr)-1
	for i < j {
		arr[i].Next = arr[j]   // 左连右
		i++
		arr[j].Next = arr[i]   // 右连新左
		j--
	}
	// 最后中间节点置空，防止成环
	arr[i].Next = nil
}
```

## 二、核心思路：找中点 → 翻后半 → 交替合并

这题看着复杂，其实就是**三个你已经会的操作拼在一起**：

```
口诀：找中点、翻后半、交替合

1→2→3→4→5

第一步：找中点，切成两半
  左: 1→2→3    右: 4→5

第二步：翻转右半
  左: 1→2→3    右: 5→4

第三步：交替合并
  1→5→2→4→3  ✓
```

每个步骤都是独立的基础操作，没有新东西。记住口诀就能秒写。

---

## 三、第一步：找中点（快慢指针）

```go
slow, fast := head, head
for fast.Next != nil && fast.Next.Next != nil {
    slow = slow.Next
    fast = fast.Next.Next
}
```

为什么用 `fast.Next != nil && fast.Next.Next != nil`？

```
偶数个节点: 1→2→3→4
slow 走到 2，fast 走到 4
左半: 1→2→3（含中点），右半: 4→5（从 slow.Next 开始）

奇数个节点: 1→2→3→4→5
slow 走到 3，fast 走到 5
左半: 1→2→3（含中点），右半: 4→5（从 slow.Next 开始）
```

**中点归左半**，这样左半永远 >= 右半，交替合并时左半多出来的那个节点自然留在末尾，不用特殊处理。

---

## 四、第二步：翻转右半（经典头插法）

```go
func reverseList(head *ListNode) *ListNode {
    var prev *ListNode
    curr := head
    for curr != nil {
        next := curr.Next
        curr.Next = prev
        prev = curr
        curr = next
    }
    return prev
}
```

就是最基础的翻转链表，没有任何变化。

```
4→5  翻转后  5→4
```

---

## 五、第三步：交替合并（双指针穿插）

```go
func mergeList(l1, l2 *ListNode) {
    for l1 != nil && l2 != nil {
        l1Next := l1.Next
        l2Next := l2.Next

        l1.Next = l2
        l1 = l1Next

        l2.Next = l1  // 注意：l1 已经更新了，接的是 l1Next
        l2 = l2Next
    }
}
```

图解交替合并 `1→2→3` 和 `5→4`：

```
初始:
l1: 1→2→3
l2: 5→4

第1轮:
  保存: l1Next=2, l2Next=4
  l1.Next = l2 → 1→5
  l1 = l1Next = 2
  l2.Next = l1 → 5→2
  l2 = l2Next = 4

  现在链表: 1→5→2  ...  4→?

第2轮:
  保存: l1Next=3, l2Next=nil
  l1.Next = l2 → 2→4
  l1 = l1Next = 3
  l2.Next = l1 → 4→3
  l2 = l2Next = nil

  现在链表: 1→5→2→4→3

l2 == nil，循环结束
结果: 1→5→2→4→3  ✓
```

**关键**：`l2.Next = l1` 这行，此时 `l1` 已经是 `l1Next` 了，所以是把右半节点接到左半的下一个，形成穿插。

## 六、完整代码

```go
/**
 * Definition for singly-linked list.
 * type ListNode struct {
 *     Val int
 *     Next *ListNode
 * }
 */
func reorderList(head *ListNode) {
    if head == nil || head.Next == nil {
        return
    }

    // 1. 找中点
    slow, fast := head, head
    for fast.Next != nil && fast.Next.Next != nil {
        slow = slow.Next
        fast = fast.Next.Next
    }

    // 2. 切断 + 翻转右半
    mid := slow.Next
    slow.Next = nil          // 切断左半和右半
    right := reverseList(mid)

    // 3. 交替合并
    mergeList(head, right)
}

func reverseList(head *ListNode) *ListNode {
    var prev *ListNode
    curr := head
    for curr != nil {
        next := curr.Next
        curr.Next = prev
        prev = curr
        curr = next
    }
    return prev
}

func mergeList(l1, l2 *ListNode) {
    for l1 != nil && l2 != nil {
        l1Next := l1.Next
        l2Next := l2.Next

        l1.Next = l2
        l1 = l1Next

        l2.Next = l1
        l2 = l2Next
    }
}
```

## 七、为什么这三步是对的？

直觉上理解：重排的本质是"从两端交替取节点"。

```
原始:  1  2  3  4  5
       ↑              ↑
       头              尾

重排:  1  5  2  4  3
       ↑  ↑  ↑  ↑  ↑
       头 尾 头 尾 中点
```

但单链表只能从头往后走，没法从尾往前。怎么办？

**把后半翻转**，就相当于有了"从尾往前"的能力：

```
后半翻转前: 4→5  （只能从4往后走）
后半翻转后: 5→4  （相当于从尾往前走了！）
```

然后两个方向交替合并，就是重排。

## 九、容易错的点

### 1. 找中点后必须切断

```go
mid := slow.Next
slow.Next = nil  // 必须切断！否则翻转右半时会影响左半
```

不切断的话，右半翻转后 `5→4→3→2→1`，左半的尾还连着右半的头，整个链表乱了。

### 2. 快指针的终止条件

```go
for fast.Next != nil && fast.Next.Next != nil
```

不是 `fast != nil && fast.Next != nil`。区别：

```
fast != nil && fast.Next != nil:
  偶数: slow 到 2，fast 到 4 → slow.Next=3，左半 1→2，右半 3→4
  中点不归左半！交替合并时左半少一个，结果不对

fast.Next != nil && fast.Next.Next != nil:
  偶数: slow 到 2，fast 到 4 → slow.Next=3，左半 1→2→3，右半 4→5
  中点归左半 ✓
```

### 3. mergeList 里 l2.Next = l1 的顺序

```go
l1.Next = l2    // 先接 l2
l1 = l1Next     // l1 前进
l2.Next = l1    // 再接 l1（已经是 l1Next 了）
l2 = l2Next     // l2 前进
```

顺序不能乱。如果先 `l2.Next = l1` 再 `l1 = l1Next`，那 `l2.Next` 接的是旧的 l1，不是 l1Next。

### 4. 原地修改，不需要返回值

题目要求原地修改，所以 `reorderList` 没有 return。`head` 指针没变（头还是头），只是后面的连接关系变了。

## 十、面试表达

> 重排链表三步走：快慢指针找中点，把链表切成两半，中点归左半；翻转右半，这样右半就相当于从尾往前走；然后交替合并左右两半，l1 接 l2，l2 接 l1Next，穿插进行。时间 O(n)，空间 O(1)。
