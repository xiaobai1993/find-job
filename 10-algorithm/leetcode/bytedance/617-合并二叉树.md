# 617. 合并二叉树

> LeetCode 链接：https://leetcode.cn/problems/merge-two-binary-trees/

## 题目
给定两棵二叉树，合并为一棵新树（重叠节点的值相加，缺少的节点用另一棵树的节点填充）。

## 最易理解的方法：递归

**核心思路：**
递归合并：
- 两者都为 nil：返回 nil
- 有一个为 nil：返回另一个
- 两者都不为 nil：创建新节点，值为两者之和，递归合并子树

```
树1:      树2:      合并:
  1         2         3
 / \       / \       / \
3   2     1   3     4   5
/           \         \   \
5            4         5   4
              \
               7
```

## Go 实现

```go
func mergeTrees(root1 *TreeNode, root2 *TreeNode) *TreeNode {
    if root1 == nil {
        return root2
    }
    if root2 == nil {
        return root1
    }
    return &TreeNode{
        Val:   root1.Val + root2.Val,
        Left:  mergeTrees(root1.Left, root2.Left),
        Right: mergeTrees(root1.Right, root2.Right),
    }
}
```

## 复杂度
- 时间：O(min(m,n))
- 空间：O(min(m,n))

## 记忆口诀
> 任一为nil返回另一个；都非nil则新节点值=两者之和，递归合并左右子树。
