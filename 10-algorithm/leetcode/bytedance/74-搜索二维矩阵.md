# 74. 搜索二维矩阵

> LeetCode 链接：https://leetcode.cn/problems/search-a-2d-matrix/

## 题目
m×n 矩阵：每行从左到右递增，每行第一个数大于上一行最后一个数。判断目标值是否在矩阵中。时间复杂度 O(log(m×n))。

## 最易理解的方法：把矩阵当作有序数组做二分

**核心思路：**
整个矩阵展开后是一个有序数组（共 m×n 个元素）。对下标 `mid` 可以通过 `matrix[mid/n][mid%n]` 访问对应元素。直接二分查找。

```
matrix:
1  3  5  7
10 11 16 20
23 30 34 60

视为: [1,3,5,7,10,11,16,20,23,30,34,60]
target=3: 二分找到下标1 → matrix[1/4][1%4]=matrix[0][1]=3 ✓
```

## Go 实现

```go
func searchMatrix(matrix [][]int, target int) bool {
    m, n := len(matrix), len(matrix[0])
    lo, hi := 0, m*n-1
    for lo <= hi {
        mid := (lo + hi) / 2
        val := matrix[mid/n][mid%n]
        if val == target {
            return true
        } else if val < target {
            lo = mid + 1
        } else {
            hi = mid - 1
        }
    }
    return false
}
```

## 复杂度
- 时间：O(log(m × n))
- 空间：O(1)

## 记忆口诀
> 整个矩阵=一个有序数组；下标 mid → matrix[mid/n][mid%n]；直接二分。
