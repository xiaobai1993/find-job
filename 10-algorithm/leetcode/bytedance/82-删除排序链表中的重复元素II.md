# 82. 删除排序链表中的重复元素 II

> LeetCode 链接：https://leetcode.cn/problems/remove-duplicates-from-sorted-list-ii/

## 题目
给定排序链表，删除所有含重复数字的节点，只保留原来没有重复过的数字。

## 最易理解的方法：哑节点 + 跳过重复段

**核心思路：**
用哑节点作为前驱。每次检查 `cur.Next` 和 `cur.Next.Next`，若值相同则记录重复值，跳过所有等于该值的节点；否则 cur 前移。

```
1→2→3→3→4→4→5

dummy→1→2→3→3→4→4→5

cur=dummy:
  1.Next=2, 2.Next.val=3≠2(1.Next.val), cur→1
cur=1:
  2.Next=3, 3.Next.val=3=2.Next.val → 重复val=3
  跳过所有3: cur.Next=4→4→5
cur=1:
  4.Next=4, 4.Next.val=4=4.Next.val → 重复val=4
  跳过所有4: cur.Next=5
cur=1:
  5.Next=nil, cur→5
cur=5: Next=nil，结束

结果: 1→2→5
```

## Go 实现

```go
func deleteDuplicates(head *ListNode) *ListNode {
    dummy := &ListNode{Next: head}
    cur := dummy
    for cur.Next != nil && cur.Next.Next != nil {
        if cur.Next.Val == cur.Next.Next.Val {
            val := cur.Next.Val
            // 跳过所有值为 val 的节点
            for cur.Next != nil && cur.Next.Val == val {
                cur.Next = cur.Next.Next
            }
        } else {
            cur = cur.Next
        }
    }
    return dummy.Next
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 哑节点；发现连续两个值相同时记录该值，内层循环跳过所有该值节点；否则前移cur。
