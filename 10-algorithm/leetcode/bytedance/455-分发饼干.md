# 455. 分发饼干

> LeetCode 链接：https://leetcode.cn/problems/assign-cookies/

## 题目
孩子胃口值为 g[i]，饼干大小为 s[j]，s[j]>=g[i] 才能满足孩子 i。求最多能满足多少孩子。

## 最易理解的方法：排序 + 贪心双指针

**核心思路：**
两者都排序，用最小的够大的饼干满足胃口最小的孩子，双指针向右推进。

```
g=[1,2,3], s=[1,1]

排序后:
g[0]=1 ≤ s[0]=1 → 满足，i++,j++
g[1]=2 > s[1]=1 → 换大饼干，j++
j越界，结束

满足: 1人
```

## Go 实现

```go
import "sort"

func findContentChildren(g []int, s []int) int {
    sort.Ints(g)
    sort.Ints(s)
    i, j := 0, 0
    for i < len(g) && j < len(s) {
        if s[j] >= g[i] {
            i++
        }
        j++
    }
    return i
}
```

## 复杂度
- 时间：O(n log n)
- 空间：O(1)

## 记忆口诀
> 两者排序；双指针：饼干够大则满足孩子(i++)；饼干指针始终右移(j++)。
