# 219. 存在重复元素 II

> LeetCode 链接：https://leetcode.cn/problems/contains-duplicate-ii/

## 题目
给定整数数组和整数 k，判断数组中是否存在两个不同下标 i 和 j，使得 nums[i]==nums[j] 且 abs(i-j)<=k。

## 最易理解的方法：哈希表记录最近下标

**核心思路：**
哈希表存每个值最近出现的下标，遇到相同值时检查距离是否<=k。

```
nums=[1,2,3,1], k=3

map: {1:0}
i=1: {1:0,2:1}
i=2: {1:0,2:1,3:2}
i=3: nums[3]=1, map[1]=0, 3-0=3<=k → true
```

## Go 实现

```go
func containsNearbyDuplicate(nums []int, k int) bool {
    lastIdx := make(map[int]int)
    for i, v := range nums {
        if j, ok := lastIdx[v]; ok && i-j <= k {
            return true
        }
        lastIdx[v] = i
    }
    return false
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> 哈希表记录每值最近下标；找到相同值时检查距离<=k。
