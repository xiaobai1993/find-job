# 326. 3 的幂

> LeetCode 链接：https://leetcode.cn/problems/power-of-three/

## 题目
给定整数 n，判断是否为 3 的幂次方。

## 最易理解的方法：整除判断

**核心思路：**
3 的幂次方只能被 3 整除，不断除以 3 直到余数不为0或等于1。

```
n=27: 27/3=9, 9/3=3, 3/3=1 → true
n=45: 45/3=15, 15/3=5, 5%3=2≠0 → false
```

## Go 实现

```go
func isPowerOfThree(n int) bool {
    if n <= 0 { return false }
    for n%3 == 0 {
        n /= 3
    }
    return n == 1
}
```

## 复杂度
- 时间：O(log n)
- 空间：O(1)

## 记忆口诀
> 不断除以3；最终为1则是3的幂；n<=0直接false。
