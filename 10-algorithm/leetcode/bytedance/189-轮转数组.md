# 189. 轮转数组

> LeetCode 链接：https://leetcode.cn/problems/rotate-array/

## 题目
给定整数数组，将数组向右轮转 k 个位置（原地修改）。

## 最易理解的方法：三次翻转

**核心思路：**
向右旋转 k 位 =
1. 翻转整个数组
2. 翻转前 k 个
3. 翻转后 n-k 个

```
nums=[1,2,3,4,5,6,7], k=3

翻转全部: [7,6,5,4,3,2,1]
翻转前3: [5,6,7,4,3,2,1]
翻转后4: [5,6,7,1,2,3,4]

答案: [5,6,7,1,2,3,4]
```

## Go 实现

```go
func rotate(nums []int, k int) {
    n := len(nums)
    k = k % n // 处理 k > n 的情况
    reverse := func(lo, hi int) {
        for lo < hi {
            nums[lo], nums[hi] = nums[hi], nums[lo]
            lo++
            hi--
        }
    }
    reverse(0, n-1)   // 翻转全部
    reverse(0, k-1)   // 翻转前k个
    reverse(k, n-1)   // 翻转后n-k个
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 三次翻转：全部→前k→后n-k；注意先对k取模防越界。
