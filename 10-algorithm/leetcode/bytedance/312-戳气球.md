# 312. 戳气球

> LeetCode 链接：https://leetcode.cn/problems/burst-balloons/

## 题目
给定 n 个气球，每个有数字 nums[i]。戳破第 i 个气球获得 `nums[left] × nums[i] × nums[right]` 金币（两侧不存在时值为1）。求最多能获得多少金币。

## 最易理解的方法：区间 DP（最后戳破）

**核心思路：**
区间 DP：`dp[i][j]` 表示戳破 (i,j) 开区间内所有气球获得的最大金币。
枚举最后戳破的气球 k（此时 i 和 j 两侧气球还在）：
`dp[i][j] = max(dp[i][k] + nums[i]*nums[k]*nums[j] + dp[k][j])`

在两端各添加1（哨兵）。

```
nums = [3,1,5,8]
→ [1,3,1,5,8,1]

dp[0][5] = 最大金币
```

## Go 实现

```go
func maxCoins(nums []int) int {
    n := len(nums)
    // 添加边界哨兵
    arr := make([]int, n+2)
    arr[0] = 1
    arr[n+1] = 1
    for i, v := range nums {
        arr[i+1] = v
    }
    m := n + 2
    dp := make([][]int, m)
    for i := range dp {
        dp[i] = make([]int, m)
    }
    // 按区间长度枚举
    for length := 2; length < m; length++ {
        for i := 0; i < m-length; i++ {
            j := i + length
            for k := i + 1; k < j; k++ {
                val := dp[i][k] + arr[i]*arr[k]*arr[j] + dp[k][j]
                if val > dp[i][j] {
                    dp[i][j] = val
                }
            }
        }
    }
    return dp[0][m-1]
}
```

## 复杂度
- 时间：O(n³)
- 空间：O(n²)

## 记忆口诀
> 区间DP；枚举最后戳破的气球k；dp[i][j]=max(dp[i][k]+arr[i]*arr[k]*arr[j]+dp[k][j])；两端加哨兵1。
