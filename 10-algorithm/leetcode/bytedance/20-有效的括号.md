# 20. 有效的括号

> LeetCode 链接：https://leetcode.cn/problems/valid-parentheses/

## 题目
给定只包含 `'('`、`')'`、`'{'`、`'}'`、`'['`、`']'` 的字符串，判断字符串是否有效（括号必须以正确的顺序匹配）。

## 最易理解的方法：栈

**核心思路：**
遇到左括号 `(`、`[`、`{` 就入栈；遇到右括号就检查栈顶是否为对应左括号，是则弹出，否则无效。最后栈为空说明全部匹配。

```
s = "()[]{}"

'(' → push    → ['(']
')' → 栈顶'(' 匹配 → pop → []
'[' → push    → ['[']
']' → 栈顶'[' 匹配 → pop → []
'{' → push    → ['{']
'}' → 栈顶'{' 匹配 → pop → []
最终栈空 → true

s = "([)]"
'(' push → ['(']
'[' push → ['(','[']
')' 栈顶'['≠')' → false
```

## Go 实现

```go
func isValid(s string) bool {
    stack := []rune{}
    pair := map[rune]rune{')': '(', ']': '[', '}': '{'}
    for _, ch := range s {
        if ch == '(' || ch == '[' || ch == '{' {
            stack = append(stack, ch)
        } else {
            if len(stack) == 0 || stack[len(stack)-1] != pair[ch] {
                return false
            }
            stack = stack[:len(stack)-1]
        }
    }
    return len(stack) == 0
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> 左括号入栈；右括号查栈顶是否匹配，匹配则出栈；最终栈为空则有效。
