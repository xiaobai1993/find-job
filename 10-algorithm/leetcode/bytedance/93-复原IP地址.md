# 93. 复原 IP 地址

> LeetCode 链接：https://leetcode.cn/problems/restore-ip-addresses/

## 题目
给定一个只包含数字的字符串 `s`，返回所有有效的 IP 地址（由四个 0-255 的整数组成，不含前导零）。

## 最易理解的方法：回溯

**核心思路：**
回溯枚举每一段，每段取 1-3 位，满足以下条件：
1. 数值在 0-255
2. 不能有前导零（"01" 非法）
3. 凑满 4 段且用完所有字符时加入结果

```
s = "25525511135"

取 "2" → 取 "5" → 取 "5" → 取 "25511135"... 最终: 255.255.11.135
取 "255" → 取 "255" → 取 "11" → 取 "135" → 255.255.11.135
```

## Go 实现

```go
func restoreIpAddresses(s string) []string {
    var res []string
    var backtrack func(start, part int, cur string)
    backtrack = func(start, part int, cur string) {
        if part == 4 && start == len(s) {
            res = append(res, cur[:len(cur)-1]) // 去掉最后的"."
            return
        }
        if part == 4 || start == len(s) {
            return
        }
        for length := 1; length <= 3; length++ {
            if start+length > len(s) {
                break
            }
            seg := s[start : start+length]
            // 前导零检查
            if length > 1 && seg[0] == '0' {
                break
            }
            // 数值检查
            val := 0
            for _, c := range seg {
                val = val*10 + int(c-'0')
            }
            if val > 255 {
                break
            }
            backtrack(start+length, part+1, cur+seg+".")
        }
    }
    backtrack(0, 0, "")
    return res
}
```

## 复杂度
- 时间：O(3^4) = O(1)（最多 3 种选择 × 4 段）
- 空间：O(4)（递归深度）

## 记忆口诀
> 回溯4段，每段1-3位；前导零跳出，值>255跳出；4段用完所有字符则收集结果。
