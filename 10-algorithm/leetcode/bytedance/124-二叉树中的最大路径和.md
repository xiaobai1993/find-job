# 124. 二叉树中的最大路径和

> LeetCode 链接：https://leetcode.cn/problems/binary-tree-maximum-path-sum/

## 题目
在二叉树中，**路径**是从某节点出发，向上或向下，经过若干节点的序列（每个节点最多出现一次）。返回所有路径中节点值之和的最大值。

## 最易理解的方法：后序 DFS（关键：区分"贡献值"和"路径和"）

**核心思路：**
对每个节点，定义**向上贡献值** = `max(0, 左贡献 or 右贡献) + 自身值`（只能选一侧，因为要继续向上延伸）。
而**经过该节点的最大路径** = `左贡献 + 右贡献 + 自身值`（可以两侧都选）。
后序遍历时，对每个节点更新全局答案，并返回"向上的贡献值"给父节点。

```
         -10
        /    \
       9      20
             /  \
            15    7

后序遍历到 20：
  左贡献 = max(0, 15) = 15
  右贡献 = max(0, 7)  = 7
  经过20的路径 = 15 + 20 + 7 = 42  ← 全局最大
  向上返回 = max(15, 7) + 20 = 35
```

## Go 实现

```go
func maxPathSum(root *TreeNode) int {
    ans := -1 << 31 // 初始化为极小值（节点可能全负）
    var dfs func(node *TreeNode) int
    dfs = func(node *TreeNode) int {
        if node == nil {
            return 0
        }
        left := max(0, dfs(node.Left))   // 负收益不取
        right := max(0, dfs(node.Right))
        // 经过当前节点的最大路径（两侧都能取）
        if left+right+node.Val > ans {
            ans = left + right + node.Val
        }
        // 只能取一侧向上返回
        if left > right {
            return left + node.Val
        }
        return right + node.Val
    }
    dfs(root)
    return ans
}
```

## 复杂度
- 时间：O(n)
- 空间：O(h)（树高，最坏 O(n)）

## 记忆口诀
> 后序DFS：贡献值 = max(0,左) + max(0,右) + 自身；路径和更新全局，返回父节点只带一侧。
