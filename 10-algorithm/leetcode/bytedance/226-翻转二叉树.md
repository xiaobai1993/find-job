# 226. 翻转二叉树

> LeetCode 链接：https://leetcode.cn/problems/invert-binary-tree/

## 题目
翻转一棵二叉树（将每个节点的左右子树互换）。

## 最易理解的方法：递归

**核心思路：**
对每个节点，交换其左右子节点，然后递归翻转左子树和右子树。

```
    4
   / \
  2   7
 / \ / \
1  3 6  9

翻转后:
    4
   / \
  7   2
 / \ / \
9  6 3  1
```

## Go 实现

```go
func invertTree(root *TreeNode) *TreeNode {
    if root == nil {
        return nil
    }
    root.Left, root.Right = root.Right, root.Left
    invertTree(root.Left)
    invertTree(root.Right)
    return root
}
```

## 复杂度
- 时间：O(n)
- 空间：O(h)

## 记忆口诀
> 先交换当前节点的左右子节点，再递归翻转左右子树；三行代码搞定。
