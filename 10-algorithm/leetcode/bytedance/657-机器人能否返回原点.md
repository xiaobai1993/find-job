# 657. 机器人能否返回原点

> LeetCode 链接：https://leetcode.cn/problems/robot-return-to-origin/

## 题目
机器人执行 UDLR 移动指令，判断最终是否回到原点 (0,0)。

## 最易理解的方法：统计方向抵消

**核心思路：**
统计 U 和 D 的数量，L 和 R 的数量，各自相等则回到原点。

```
moves = "UD"

U=1, D=1, L=0, R=0
U==D && L==R → true

moves = "LL"
L=2, R=0 → false
```

## Go 实现

```go
func judgeCircle(moves string) bool {
    x, y := 0, 0
    for _, c := range moves {
        switch c {
        case 'U': y++
        case 'D': y--
        case 'L': x--
        case 'R': x++
        }
    }
    return x == 0 && y == 0
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 统计x和y偏移；最终x==0且y==0则回到原点。
