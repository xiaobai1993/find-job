# 165. 比较版本号

> LeetCode 链接：https://leetcode.cn/problems/compare-version-numbers/

## 题目
比较两个版本号字符串（如 "1.01" 和 "1.001"），按修订版本号从左到右比较，忽略前导零。返回 -1、1 或 0。

## 最易理解的方法：双指针逐段比较

**核心思路：**
用双指针同时解析两个版本号的每个段（用 "." 分割），比较整数值。短版本号不足的段视为 0。

```
"1.01" vs "1.001"

段1: 1 vs 1 → 相等
段2: 1 vs 1 (忽略前导零)
→ 返回 0
```

## Go 实现

```go
func compareVersion(version1 string, version2 string) int {
    i, j := 0, 0
    for i < len(version1) || j < len(version2) {
        // 解析 version1 当前段
        v1 := 0
        for i < len(version1) && version1[i] != '.' {
            v1 = v1*10 + int(version1[i]-'0')
            i++
        }
        i++ // 跳过 '.'
        // 解析 version2 当前段
        v2 := 0
        for j < len(version2) && version2[j] != '.' {
            v2 = v2*10 + int(version2[j]-'0')
            j++
        }
        j++ // 跳过 '.'
        if v1 > v2 {
            return 1
        }
        if v1 < v2 {
            return -1
        }
    }
    return 0
}
```

## 复杂度
- 时间：O(max(m,n))
- 空间：O(1)

## 记忆口诀
> 双指针逐段解析整数值；遍历直到"."或末尾；短版本缺少的段视为0；比较大小返回结果。
