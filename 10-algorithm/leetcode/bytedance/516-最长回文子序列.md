# 516. 最长回文子序列

> LeetCode 链接：https://leetcode.cn/problems/longest-palindromic-subsequence/

## 题目
给定字符串，找最长回文子序列的长度（子序列不要求连续）。

## 最易理解的方法：区间 DP

**核心思路：**
`dp[i][j]` = s[i..j] 的最长回文子序列长度。
- `s[i]==s[j]`：`dp[i][j] = dp[i+1][j-1] + 2`
- 否则：`dp[i][j] = max(dp[i+1][j], dp[i][j-1])`

```
s = "bbbab"

dp[i][j] (对角线填充):
b  b  b  a  b
1  2  3  3  4
   1  2  2  3
      1  1  2
         1  1
            1

最终: dp[0][4]=4 ("bbbb")
```

## Go 实现

```go
func longestPalindromeSubseq(s string) int {
    n := len(s)
    dp := make([][]int, n)
    for i := range dp {
        dp[i] = make([]int, n)
        dp[i][i] = 1
    }
    for length := 2; length <= n; length++ {
        for i := 0; i <= n-length; i++ {
            j := i + length - 1
            if s[i] == s[j] {
                if length == 2 {
                    dp[i][j] = 2
                } else {
                    dp[i][j] = dp[i+1][j-1] + 2
                }
            } else {
                dp[i][j] = max2(dp[i+1][j], dp[i][j-1])
            }
        }
    }
    return dp[0][n-1]
}

func max2(a, b int) int {
    if a > b { return a }
    return b
}
```

## 复杂度
- 时间：O(n²)
- 空间：O(n²)

## 记忆口诀
> 区间DP；两端相同则+2；不同取两边最大；按长度从小到大填表。
