# 752. 打开转盘锁

> LeetCode 链接：https://leetcode.cn/problems/open-the-lock/

## 题目
四位数字转盘（每位0-9循环），给定死亡组合列表和目标，从"0000"出发，求最少旋转次数达到目标，不可达则返回 -1。

## 最易理解的方法：BFS（最短步数）

**核心思路：**
BFS 枚举所有可能状态（每步每位+1或-1），避开死锁组合，找到目标的最短路径。

```
deadends=["0201","0101","0102","1212","2002"], target="0202"

BFS: 0000→(转动各位)→...
每层扩展8个状态（4位×2方向）
不进入deadends，找到0202的层数
```

## Go 实现

```go
func openLock(deadends []string, target string) int {
    dead := make(map[string]bool)
    for _, d := range deadends { dead[d] = true }
    if dead["0000"] { return -1 }
    queue := []string{"0000"}
    visited := map[string]bool{"0000": true}
    steps := 0
    for len(queue) > 0 {
        n := len(queue)
        for i := 0; i < n; i++ {
            cur := queue[i]
            if cur == target { return steps }
            for j := 0; j < 4; j++ {
                for _, d := range []int{1, -1} {
                    next := []byte(cur)
                    next[j] = byte((int(next[j]-'0')+d+10)%10) + '0'
                    ns := string(next)
                    if !visited[ns] && !dead[ns] {
                        visited[ns] = true
                        queue = append(queue, ns)
                    }
                }
            }
        }
        queue = queue[n:]
        steps++
    }
    return -1
}
```

## 复杂度
- 时间：O(10^4)
- 空间：O(10^4)

## 记忆口诀
> BFS层序；每步枚举4位×2方向共8个状态；跳过死锁和已访问；找到目标返回层数。
