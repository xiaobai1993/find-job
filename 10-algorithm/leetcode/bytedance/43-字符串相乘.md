# 43. 字符串相乘

> LeetCode 链接：https://leetcode.cn/problems/multiply-strings/

## 题目
给定两个非负整数字符串 `num1` 和 `num2`，返回它们的乘积（也用字符串表示）。不能直接转换为整数计算。

## 最易理解的方法：模拟竖式乘法

**核心思路：**
`num1[i]` × `num2[j]` 的结果放在 `pos[i+j]` 和 `pos[i+j+1]` 的位置。
最后从后往前处理进位，转换为字符串。

```
  1 2 3
×   4 5
-------
num1[i]*num2[j] 存到 pos[i+j] 和 pos[i+j+1]:
3*5=15 → pos[3]+=1, pos[4]+=5
2*5=10 → pos[2]+=1, pos[3]+=0
1*5=5  → pos[1]+=0, pos[2]+=5
3*4=12 → pos[2]+=1, pos[3]+=2
...

pos = [0,0,0,0,0,...]
处理进位 → "5535"
```

## Go 实现

```go
func multiply(num1 string, num2 string) string {
    m, n := len(num1), len(num2)
    pos := make([]int, m+n)
    // 逆序相乘
    for i := m - 1; i >= 0; i-- {
        for j := n - 1; j >= 0; j-- {
            mul := int(num1[i]-'0') * int(num2[j]-'0')
            p1, p2 := i+j, i+j+1
            sum := mul + pos[p2]
            pos[p2] = sum % 10
            pos[p1] += sum / 10
        }
    }
    // 构建结果，跳过前导0
    res := []byte{}
    for _, v := range pos {
        if !(len(res) == 0 && v == 0) {
            res = append(res, byte(v)+'0')
        }
    }
    if len(res) == 0 {
        return "0"
    }
    return string(res)
}
```

## 复杂度
- 时间：O(m×n)
- 空间：O(m+n)

## 记忆口诀
> 竖式乘法：pos[i+j+1]+=乘积；pos[i+j]+=进位；最后跳过前导0构建字符串。
