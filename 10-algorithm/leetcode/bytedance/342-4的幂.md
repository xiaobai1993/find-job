# 342. 4 的幂

> LeetCode 链接：https://leetcode.cn/problems/power-of-four/

## 题目
给定整数 n，判断是否为 4 的幂次方。

## 最易理解的方法：位运算

**核心思路：**
4 的幂 = 2 的偶数次幂。条件：
1. n > 0
2. n & (n-1) == 0（是2的幂，只有一个1位）
3. 1 的位置在奇数位（0,2,4,6...）：n & 0x55555555 != 0

```
n=4=100: n&(n-1)=0 ✓, 位于第2位(偶数) ✓
n=8=1000: n&(n-1)=0 ✓, 位于第3位(奇数) ✗
```

## Go 实现

```go
func isPowerOfFour(n int) bool {
    return n > 0 && (n&(n-1)) == 0 && (n&0x55555555) != 0
}
```

## 复杂度
- 时间：O(1)
- 空间：O(1)

## 记忆口诀
> 三条件：n>0；只有一个1位(2的幂)；1在偶数位(与0x55555555非0)。
