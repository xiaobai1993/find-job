# 416. 分割等和子集

> LeetCode 链接：https://leetcode.cn/problems/partition-equal-subset-sum/

## 题目
给定正整数数组，判断是否可以将其分割为两个子集，使得两个子集的元素和相等。

## 最易理解的方法：0-1 背包 DP

**核心思路：**
总和为 sum，若 sum 为奇数则不可能；否则问题转化为：能否从数组中选出一些数，使其和等于 sum/2。

`dp[j]` 表示能否用数组中的数凑出 j：
- 0-1 背包：内层从大到小遍历，避免重复使用同一个数

```
nums=[1,5,11,5], sum=22, target=11

dp[0]=true
加入1: dp[1]=true
加入5: dp[6]=true, dp[5]=true
加入11: dp[11]=true ✓

答案=true
```

## Go 实现

```go
func canPartition(nums []int) bool {
    sum := 0
    for _, n := range nums {
        sum += n
    }
    if sum%2 != 0 {
        return false
    }
    target := sum / 2
    dp := make([]bool, target+1)
    dp[0] = true
    for _, num := range nums {
        // 0-1背包：从大到小
        for j := target; j >= num; j-- {
            dp[j] = dp[j] || dp[j-num]
        }
    }
    return dp[target]
}
```

## 复杂度
- 时间：O(n × sum)
- 空间：O(sum)

## 记忆口诀
> 0-1背包：目标=sum/2；dp[j]=dp[j]||dp[j-num]；内层从大到小（防重复使用）。
