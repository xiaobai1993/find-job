# 188. 买卖股票的最佳时机 IV

> LeetCode 链接：https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-iv/

## 题目
给定股票价格数组和整数 k，最多完成 k 笔交易，求最大利润。

## 最易理解的方法：DP（k 次买卖状态）

**核心思路：**
- 若 k ≥ n/2（交易次数足够多），等价于无限次交易，直接贪心累加正差。
- 否则维护 `buy[i]`（第i次买入后最大余额）和 `sell[i]`（第i次卖出后最大利润），类似123题扩展到k次。

```
prices=[2,4,1], k=2

buy[0]=-2, sell[0]=0
buy[1]=-2, sell[1]=0

p=4:
  buy[0]=max(-2,-4)=-2
  sell[0]=max(0,-2+4)=2
  buy[1]=max(-2,2-4)=-2
  sell[1]=max(0,-2+4)=2

p=1:
  buy[0]=max(-2,-1)=-1
  sell[0]=max(2,-1+1)=2
  buy[1]=max(-2,2-1)=1
  sell[1]=max(2,1+1)=2

答案=sell[k-1]=2
```

## Go 实现

```go
func maxProfit(k int, prices []int) int {
    n := len(prices)
    if n == 0 {
        return 0
    }
    // k足够大，贪心
    if k >= n/2 {
        profit := 0
        for i := 1; i < n; i++ {
            if prices[i] > prices[i-1] {
                profit += prices[i] - prices[i-1]
            }
        }
        return profit
    }
    buy := make([]int, k)
    sell := make([]int, k)
    for i := range buy {
        buy[i] = -prices[0]
    }
    for _, p := range prices[1:] {
        for i := k - 1; i >= 0; i-- {
            if i == 0 {
                buy[i] = max(buy[i], -p)
            } else {
                buy[i] = max(buy[i], sell[i-1]-p)
            }
            sell[i] = max(sell[i], buy[i]+p)
        }
    }
    return sell[k-1]
}

func max(a, b int) int {
    if a > b { return a }
    return b
}
```

## 复杂度
- 时间：O(n×k)
- 空间：O(k)

## 记忆口诀
> k≥n/2贪心；否则buy[]/sell[]数组模拟k次状态；逆序更新防止同一天多次交易。
