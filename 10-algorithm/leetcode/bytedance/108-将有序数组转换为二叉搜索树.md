# 108. 将有序数组转换为二叉搜索树

> LeetCode 链接：https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/

## 题目
给定升序整数数组，将其转换为高度平衡的二叉搜索树（每个节点的左右子树高度差不超过1）。

## 最易理解的方法：二分递归

**核心思路：**
取中间元素作为根（保证高度平衡），左半数组递归构建左子树，右半递归构建右子树。

```
[-10,-3,0,5,9]

mid=0: 根=nums[2]=0
左[-10,-3]: mid=0→根=nums[0]=-10, 右子=-3
右[5,9]: mid=0→根=nums[0]=5, 右子=9

      0
     / \
   -10   5
     \    \
     -3    9
```

## Go 实现

```go
func sortedArrayToBST(nums []int) *TreeNode {
    if len(nums) == 0 {
        return nil
    }
    mid := len(nums) / 2
    return &TreeNode{
        Val:   nums[mid],
        Left:  sortedArrayToBST(nums[:mid]),
        Right: sortedArrayToBST(nums[mid+1:]),
    }
}
```

## 复杂度
- 时间：O(n)
- 空间：O(log n)

## 记忆口诀
> 取中间元素为根；左半递归→左子树；右半递归→右子树；自然保证高度平衡。
