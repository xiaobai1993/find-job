# 57. 插入区间

> LeetCode 链接：https://leetcode.cn/problems/insert-interval/

## 题目
给定无重叠的有序区间列表和一个新区间，插入新区间并合并重叠区间。

## 最易理解的方法：线性扫描三阶段

**核心思路：**
分三个阶段处理：
1. 将所有在新区间左边的区间加入结果（`end < newStart`）
2. 与新区间重叠的区间不断合并（`start <= newEnd`）
3. 将剩余区间加入结果

```
intervals=[[1,2],[3,5],[6,7],[8,10],[12,16]], newInterval=[4,8]

阶段1: [1,2],[3,5] end<4? 2<4✓, 5<4✗
阶段2: [3,5]与[4,8]重叠→merge=[3,8]; [6,7]重叠→merge=[3,8]; [8,10]重叠→merge=[3,10]
阶段3: [12,16]

结果: [[1,2],[3,10],[12,16]]
```

## Go 实现

```go
func insert(intervals [][]int, newInterval []int) [][]int {
    res := [][]int{}
    i, n := 0, len(intervals)
    // 阶段1: 新区间左边的区间
    for i < n && intervals[i][1] < newInterval[0] {
        res = append(res, intervals[i])
        i++
    }
    // 阶段2: 合并重叠区间
    for i < n && intervals[i][0] <= newInterval[1] {
        if intervals[i][0] < newInterval[0] {
            newInterval[0] = intervals[i][0]
        }
        if intervals[i][1] > newInterval[1] {
            newInterval[1] = intervals[i][1]
        }
        i++
    }
    res = append(res, newInterval)
    // 阶段3: 新区间右边的区间
    for i < n {
        res = append(res, intervals[i])
        i++
    }
    return res
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> 三阶段：全在左边直接加→与新区间重叠则合并→全在右边直接加；最后插入合并后的新区间。
