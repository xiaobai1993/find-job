# 581. 最短无序连续子数组

> LeetCode 链接：https://leetcode.cn/problems/shortest-unsorted-continuous-subarray/

## 题目
给定整数数组，找到一个连续子数组，排序后整个数组变为升序，返回该子数组的最短长度。

## 最易理解的方法：一次遍历

**核心思路：**
- 从左到右：找最后一个位置，其值 < 前面的最大值（该位置是右边界）
- 从右到左：找最后一个位置，其值 > 后面的最小值（该位置是左边界）

```
[2, 6, 4, 8, 10, 9, 15]

从左找右边界: maxVal=2
  6: 6>2, max=6
  4: 4<6 → right=2
  8: 8>6, max=8
  10: 10>8, max=10
  9: 9<10 → right=5
  15: 15>10, max=15

右边界=5

从右找左边界: minVal=15
  9: 9<15, min=9
  10: 10>9 → left=4... 继续
  8: 8<9, min=8
  4: 4<8, min=4
  6: 6>4 → left=1
  2: 2<4, min=2

左边界=1

答案=5-1+1=5 (子数组[6,4,8,10,9])
```

## Go 实现

```go
func findUnsortedSubarray(nums []int) int {
    n := len(nums)
    maxVal, right := nums[0], -1
    minVal, left := nums[n-1], -1
    for i := 1; i < n; i++ {
        if nums[i] < maxVal {
            right = i
        } else {
            maxVal = nums[i]
        }
    }
    for i := n - 2; i >= 0; i-- {
        if nums[i] > minVal {
            left = i
        } else {
            minVal = nums[i]
        }
    }
    if right == -1 {
        return 0 // 已有序
    }
    return right - left + 1
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 左→右找最后一个<最大值的位置(右边界)；右→左找最后一个>最小值的位置(左边界)；长度=右-左+1。
