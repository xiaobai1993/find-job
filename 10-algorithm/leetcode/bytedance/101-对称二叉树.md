# 101. 对称二叉树

> LeetCode 链接：https://leetcode.cn/problems/symmetric-tree/

## 题目
给定一棵二叉树的根节点，检查它是否轴对称（镜像对称）。

## 最易理解的方法：递归镜像比较

**核心思路：**
对称 = 左子树和右子树互为镜像。两个树互为镜像的条件：
1. 根节点值相同
2. 左树的左子树 ↔ 右树的右子树 互为镜像
3. 左树的右子树 ↔ 右树的左子树 互为镜像

```
      1
    /   \
   2     2       ← 对称：左2和右2相同
  / \   / \
 3   4 4   3     ← 对称：外侧3=3，内侧4=4
```

## Go 实现

```go
func isSymmetric(root *TreeNode) bool {
    return isMirror(root.Left, root.Right)
}

func isMirror(left, right *TreeNode) bool {
    if left == nil && right == nil {
        return true
    }
    if left == nil || right == nil {
        return false
    }
    return left.Val == right.Val &&
        isMirror(left.Left, right.Right) &&  // 外侧
        isMirror(left.Right, right.Left)     // 内侧
}
```

## 复杂度
- 时间：O(n)
- 空间：O(h)（树高）

## 记忆口诀
> 两树互为镜像：根值相同，左树的左 vs 右树的右，左树的右 vs 右树的左。
