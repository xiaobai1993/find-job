# 409. 最长回文串

> LeetCode 链接：https://leetcode.cn/problems/longest-palindrome/

## 题目
给定字符串，用其中字符构建最长回文串，返回其长度（不需要是原始顺序）。

## 最易理解的方法：统计奇偶频率

**核心思路：**
偶数频率的字符全部可用，奇数频率的字符用 freq-1 个，最后如有任一奇数频率可在中间放1个。

```
s = "abccccdd"

a:1, b:1, c:4, d:2
偶数全用: c(4)+d(2)=6
奇数取偶: a(0)+b(0)=0
有奇数存在: +1
总长度: 7
```

## Go 实现

```go
func longestPalindrome(s string) int {
    cnt := [128]int{}
    for _, c := range s {
        cnt[c]++
    }
    res, hasOdd := 0, false
    for _, v := range cnt {
        if v%2 == 0 {
            res += v
        } else {
            res += v - 1
            hasOdd = true
        }
    }
    if hasOdd { res++ }
    return res
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 偶数频率全加；奇数频率加(v-1)；有任何奇数则最后+1（中心字符）。
