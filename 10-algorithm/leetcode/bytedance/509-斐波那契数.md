# 509. 斐波那契数

> LeetCode 链接：https://leetcode.cn/problems/fibonacci-number/

## 题目
给定 n，返回 F(n)（F(0)=0, F(1)=1, F(n)=F(n-1)+F(n-2)）。

## 最易理解的方法：滚动数组 DP

**核心思路：**
只维护两个变量，滚动更新，空间 O(1)。

```
n=5:

a=0, b=1
b=1, a=1
b=2, a=1
b=3, a=2
b=5

F(5)=5
```

## Go 实现

```go
func fib(n int) int {
    if n <= 1 { return n }
    a, b := 0, 1
    for i := 2; i <= n; i++ {
        a, b = b, a+b
    }
    return b
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 滚动两变量a,b；每步a,b=b,a+b；n次后返回b。
