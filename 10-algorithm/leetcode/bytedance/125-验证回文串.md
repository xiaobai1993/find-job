# 125. 验证回文串

> LeetCode 链接：https://leetcode.cn/problems/valid-palindrome/

## 题目
给定字符串，只考虑字母和数字字符，忽略大小写，判断是否是回文串。

## 最易理解的方法：双指针

**核心思路：**
头尾双指针向中间收缩，跳过非字母数字字符，比较字符（忽略大小写）。

```
"A man, a plan, a canal: Panama"
→ 忽略非字母数字，忽略大小写
→ "amanaplanacanalpanama"
→ 是回文 ✓
```

## Go 实现

```go
func isPalindrome(s string) bool {
    isAlphanumeric := func(c byte) bool {
        return (c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z') || (c >= '0' && c <= '9')
    }
    toLower := func(c byte) byte {
        if c >= 'A' && c <= 'Z' {
            return c + 32
        }
        return c
    }
    lo, hi := 0, len(s)-1
    for lo < hi {
        for lo < hi && !isAlphanumeric(s[lo]) {
            lo++
        }
        for lo < hi && !isAlphanumeric(s[hi]) {
            hi--
        }
        if lo < hi {
            if toLower(s[lo]) != toLower(s[hi]) {
                return false
            }
            lo++
            hi--
        }
    }
    return true
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 双指针；跳过非字母数字；统一转小写比较；不等则false。
