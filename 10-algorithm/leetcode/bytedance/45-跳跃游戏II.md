# 45. 跳跃游戏 II

> LeetCode 链接：https://leetcode.cn/problems/jump-game-ii/

## 题目
给定非负整数数组 `nums`（保证能到达最后），返回到达最后一个下标所需的最少跳跃次数。

## 最易理解的方法：贪心

**核心思路：**
维护当前跳跃能到达的最远位置 `curEnd` 和下一跳能到达的最远位置 `farthest`。遍历时不断更新 `farthest`；当 i 到达 `curEnd` 时，说明必须跳一次了，跳数 +1，`curEnd = farthest`。

```
nums = [2, 3, 1, 1, 4]

初始: curEnd=0, farthest=0, jumps=0

i=0: farthest=max(0,0+2)=2
  i到达curEnd(0) → jumps=1, curEnd=2
i=1: farthest=max(2,1+3)=4
i=2: farthest=max(4,2+1)=4
  i到达curEnd(2) → jumps=2, curEnd=4
i=3: farthest=max(4,3+1)=4
i=4: 已到末尾，退出循环（不在最后一个位置触发跳跃）

答案: 2
```

## Go 实现

```go
func jump(nums []int) int {
    n := len(nums)
    jumps, curEnd, farthest := 0, 0, 0
    for i := 0; i < n-1; i++ { // 不遍历最后一个
        if i+nums[i] > farthest {
            farthest = i + nums[i]
        }
        if i == curEnd { // 必须起跳
            jumps++
            curEnd = farthest
        }
    }
    return jumps
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> curEnd=当前跳覆盖范围；farthest=下一跳可达最远；i到达curEnd时必须跳，jumps++，更新curEnd=farthest。
