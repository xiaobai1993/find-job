# 55. 跳跃游戏

> LeetCode 链接：https://leetcode.cn/problems/jump-game/

## 题目
给定非负整数数组 `nums`，`nums[i]` 表示从 i 位置能跳跃的最大距离，判断是否能从下标 0 跳到最后一个下标。

## 最易理解的方法：贪心（维护最远可达位置）

**核心思路：**
维护当前能到达的最远下标 `maxReach`。遍历时，若当前下标 `i > maxReach`，说明 i 不可达，返回 false。否则更新 `maxReach = max(maxReach, i + nums[i])`。若遍历完毕，返回 true。

```
nums = [2, 3, 1, 1, 4]

i=0: maxReach = max(0, 0+2) = 2
i=1: maxReach = max(2, 1+3) = 4
i=2: maxReach = max(4, 2+1) = 4
i=3: maxReach = max(4, 3+1) = 4
i=4: 4<=4 可达 → return true

nums = [3, 2, 1, 0, 4]
i=3: maxReach=3, i=4 > 3 → return false
```

## Go 实现

```go
func canJump(nums []int) bool {
    maxReach := 0
    for i := 0; i < len(nums); i++ {
        if i > maxReach {
            return false // i 不可达
        }
        if i+nums[i] > maxReach {
            maxReach = i + nums[i]
        }
    }
    return true
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 维护 maxReach；若 i > maxReach 则不可达；否则更新 maxReach=max(maxReach, i+nums[i])。
