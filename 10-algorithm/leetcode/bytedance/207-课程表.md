# 207. 课程表

> LeetCode 链接：https://leetcode.cn/problems/course-schedule/

## 题目
给定 n 门课程和先修关系 `prerequisites[i] = [a, b]`（学 a 之前必须先学 b），判断是否可以完成所有课程（即有无环）。

## 最易理解的方法：拓扑排序（Kahn 算法 BFS）

**核心思路：**
构建有向图和入度数组。将所有入度为 0 的节点加入队列（无前置课程）。BFS 中不断处理队列节点，并将其邻居的入度减 1，若邻居入度变为 0 则加入队列。最终若处理了 n 个节点则无环，否则有环。

```
n=4, prerequisites=[[1,0],[2,0],[3,1],[3,2]]
图：0→1→3, 0→2→3
入度：[0,1,1,2]

队列初始: [0]
处理0 → 1入度→0,2入度→0 → 队列:[1,2]  count=1
处理1 → 3入度→1           → 队列:[2]    count=2
处理2 → 3入度→0           → 队列:[3]    count=3
处理3 →                     队列:[]      count=4
count==n → 可以完成
```

## Go 实现

```go
func canFinish(numCourses int, prerequisites [][]int) bool {
    inDegree := make([]int, numCourses)
    graph := make([][]int, numCourses)
    for _, pre := range prerequisites {
        graph[pre[1]] = append(graph[pre[1]], pre[0])
        inDegree[pre[0]]++
    }
    queue := []int{}
    for i := 0; i < numCourses; i++ {
        if inDegree[i] == 0 {
            queue = append(queue, i)
        }
    }
    count := 0
    for len(queue) > 0 {
        node := queue[0]
        queue = queue[1:]
        count++
        for _, next := range graph[node] {
            inDegree[next]--
            if inDegree[next] == 0 {
                queue = append(queue, next)
            }
        }
    }
    return count == numCourses
}
```

## 复杂度
- 时间：O(V + E)
- 空间：O(V + E)

## 记忆口诀
> 拓扑排序：入度为0的先入队；处理节点时减邻居入度，为0则入队；处理数=总节点数说明无环。
