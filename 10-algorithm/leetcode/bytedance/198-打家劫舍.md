# 198. 打家劫舍

> LeetCode 链接：https://leetcode.cn/problems/house-robber/

## 题目
给定代表每间房屋存放金额的非负整数数组，相邻房屋不能同时被盗，求可以盗取的最大金额。

## 最易理解的方法：动态规划（滚动变量）

**核心思路：**
`dp[i]` = 前 i 间房子能偷到的最大金额。要么偷第 i 间（加上 `dp[i-2]`），要么不偷（等于 `dp[i-1]`）。
- `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`

只需两个变量滚动，不需要数组。

```
nums = [2, 7, 9, 3, 1]

i=0: prev2=0, prev1=2           (只有第0间)
i=1: cur=max(2, 0+7)=7          (选7不选2)
i=2: cur=max(7, 2+9)=11         (选2+9)
i=3: cur=max(11, 7+3)=11
i=4: cur=max(11, 11+1)=12  ← 答案
```

## Go 实现

```go
func rob(nums []int) int {
    if len(nums) == 1 {
        return nums[0]
    }
    prev2, prev1 := 0, nums[0]
    for i := 1; i < len(nums); i++ {
        cur := prev1
        if prev2+nums[i] > cur {
            cur = prev2 + nums[i]
        }
        prev2, prev1 = prev1, cur
    }
    return prev1
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> dp[i] = max(不偷i: dp[i-1], 偷i: dp[i-2]+nums[i])；只需维护前两个值滚动。
