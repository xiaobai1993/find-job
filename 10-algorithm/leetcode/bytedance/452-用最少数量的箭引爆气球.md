# 452. 用最少数量的箭引爆气球

> LeetCode 链接：https://leetcode.cn/problems/minimum-number-of-arrows-to-burst-balloons/

## 题目
给定气球区间列表，每个区间 [start, end] 表示一个气球的水平范围。一支箭能引爆箭穿过的所有气球，求最少需要多少支箭。

## 最易理解的方法：贪心（按右端点排序）

**核心思路：**
按右端点升序排序。用第一个箭射第一个气球的右端点（尽量往右，引爆更多气球）。
后续气球若左端点 > 当前箭的位置，则需要新的一支箭。

```
[[10,16],[2,8],[1,6],[7,12]]

按右端点排序: [[1,6],[2,8],[7,12],[10,16]]

箭1射x=6: 引爆[1,6],[2,8]
箭2射x=12: 引爆[7,12],[10,16]

答案=2
```

## Go 实现

```go
import "sort"

func findMinArrowShots(points [][]int) int {
    sort.Slice(points, func(i, j int) bool {
        return points[i][1] < points[j][1]
    })
    arrows, end := 1, points[0][1]
    for i := 1; i < len(points); i++ {
        if points[i][0] > end {
            arrows++
            end = points[i][1]
        }
    }
    return arrows
}
```

## 复杂度
- 时间：O(n log n)
- 空间：O(1)

## 记忆口诀
> 按右端点排序；贪心：下一个气球左端>当前箭位置才需新箭；箭射在当前气球右端点。
