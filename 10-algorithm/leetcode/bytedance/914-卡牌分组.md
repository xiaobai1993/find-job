# 914. 卡牌分组

> LeetCode 链接：https://leetcode.cn/problems/x-of-a-kind-in-a-deck-of-cards/

## 题目
给定卡牌数组，判断能否将其分成若干组，每组都有相同数量的卡牌且相同面值（每组>=2张）。

## 最易理解的方法：统计频率 + 求最大公约数

**核心思路：**
所有数字频率的最大公约数 GCD >= 2 则可以分组。

```
deck=[1,2,3,4,4,3,2,1]

cnt: 1=2, 2=2, 3=2, 4=2
GCD(2,2,2,2) = 2 >= 2 → true
```

## Go 实现

```go
func hasGroupsSizeX(deck []int) bool {
    cnt := make(map[int]int)
    for _, d := range deck { cnt[d]++ }
    g := 0
    for _, v := range cnt {
        g = gcd(g, v)
    }
    return g >= 2
}

func gcd(a, b int) int {
    for b != 0 { a, b = b, a%b }
    return a
}
```

## 复杂度
- 时间：O(n log C)（C为频率最大值）
- 空间：O(n)

## 记忆口诀
> 统计各值频率；所有频率的GCD>=2则可分组。
