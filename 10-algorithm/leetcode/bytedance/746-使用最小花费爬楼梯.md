# 746. 使用最小花费爬楼梯

> LeetCode 链接：https://leetcode.cn/problems/min-cost-climbing-stairs/

## 题目
每个台阶有花费 cost[i]，支付后可跳1或2步，可从第0或第1步开始，求到达楼顶（n步）的最小花费。

## 最易理解的方法：线性 DP

**核心思路：**
`dp[i]` = 到达第 i 步的最小花费。
`dp[i] = min(dp[i-1]+cost[i-1], dp[i-2]+cost[i-2])`

```
cost = [10,15,20]

dp[0]=0, dp[1]=0
dp[2] = min(0+10, 0+15) = 10
dp[3] = min(10+20, 0+15) = 15

结果: 15
```

## Go 实现

```go
func minCostClimbingStairs(cost []int) int {
    n := len(cost)
    dp := make([]int, n+1)
    for i := 2; i <= n; i++ {
        a := dp[i-1] + cost[i-1]
        b := dp[i-2] + cost[i-2]
        if a < b { dp[i] = a } else { dp[i] = b }
    }
    return dp[n]
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> dp[i]=从i-1或i-2跳来的最小花费；到达楼顶=dp[n]；初始dp[0]=dp[1]=0。
