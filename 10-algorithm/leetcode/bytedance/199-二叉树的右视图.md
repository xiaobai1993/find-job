# 199. 二叉树的右视图

题目链接：`https://leetcode.cn/problems/binary-tree-right-side-view/description/`

---

## 一、题目描述

给定一个二叉树的根节点，想象自己站在它的右侧，按照从顶部到底部的顺序，返回从右侧所能看到的节点值。

**示例：**

```
输入: [1,2,3,null,5,null,4]

    1            ← 看
   / \
  2   3          ← 看
   \   \
    5   4        ← 看

输出: [1,3,4]
```

```
输入: [1,null,3]

  1              ← 看
   \
    3            ← 看

输出: [1,3]
```

---

## 二、核心思路：层序遍历，每层取最后一个

**右视图 = 每层最右边的节点**。所以就是 BFS 层序遍历，每层取最后一个元素。

```
    1           第0层: [1]       → 取 1
   / \
  2   3         第1层: [2,3]     → 取 3
   \   \
    5   4       第2层: [5,4]     → 取 4

右视图: [1,3,4]
```

直觉：站在右边看，每一层只有最靠右的节点能被看到，其他节点被挡住了。

---

## 三、代码

```go
func rightSideView(root *TreeNode) []int {
    res := []int{}
    if root == nil {
        return res
    }

    q := []*TreeNode{root}

    for len(q) > 0 {
        // 收集下一层节点 + 当前层的值
        next := []*TreeNode{}
        for i := 0; i < len(q); i++ {
            if q[i].Left != nil {
                next = append(next, q[i].Left)
            }
            if q[i].Right != nil {
                next = append(next, q[i].Right)
            }
        }
        // 当前层最后一个就是右视图看到的
        res = append(res, q[len(q)-1].Val)
        q = next
    }
    return res
}
```

## 四、精简：不需要 temp 数组

原代码中用了 `temp` 数组存当前层所有值，再取最后一个。但**其实只需要取队列最后一个节点的值**，不需要存整层：

```go
// 原代码：存了整层再取最后
temp := make([]int, 0)
for i := 0; i < len(q); i++ {
    temp = append(temp, q[i].Val)
    // ...
}
res = append(res, temp[len(temp)-1])

// 精简：直接取队列最后一个
res = append(res, q[len(q)-1].Val)
```

`q` 本身就是当前层的所有节点，`q[len(q)-1]` 就是这层最右边的，不需要额外的 `temp`。

## 五、完整流程图解

```
    1
   / \
  2   3
   \   \
    5   4

初始: q = [1]

第0轮:
  遍历 q:
    1: Left=2加入, Right=3加入
  next = [2, 3]
  res = [1]   ← q[0].Val = 1（本层最后一个）
  q = [2, 3]

第1轮:
  遍历 q:
    2: Left=nil, Right=5加入
    3: Left=nil, Right=4加入
  next = [5, 4]
  res = [1, 3]  ← q[1].Val = 3（本层最后一个）
  q = [5, 4]

第2轮:
  遍历 q:
    5: Left=nil, Right=nil
    4: Left=nil, Right=nil
  next = []
  res = [1, 3, 4]  ← q[1].Val = 4（本层最后一个）
  q = []

队列为空，结束

结果: [1, 3, 4] ✓
```

## 六、BFS 层序遍历的两种写法对比

| 写法 | 特点 |
|------|------|
| 逐层展开（本题用） | 每轮创建新切片存下一层，天然分层 |
| 计数分层 | 用 size 记录当前层节点数，逐个出队 |

计数分层的写法（更通用）：

```go
for len(q) > 0 {
    size := len(q)
    for i := 0; i < size; i++ {
        node := q[0]
        q = q[1:]              // 出队
        if i == size-1 {
            res = append(res, node.Val)  // 本层最后一个
        }
        if node.Left != nil {
            q = append(q, node.Left)
        }
        if node.Right != nil {
            q = append(q, node.Right)
        }
    }
}
```

本题两种都行。逐层展开更直观，但每层创建新切片有额外开销；计数分层复用同一个队列，但 Go 切片出队 `q = q[1:]` 也有拷贝开销。面试写哪种都 OK。

## 七、复杂度分析

| 维度 | 值 |
|------|------|
| 时间 | O(n)，每个节点访问一次 |
| 空间 | O(n)，队列最多存一层节点，最宽一层 n/2 |

## 八、容易错的点

### 1. 空树直接返回

```go
if root == nil {
    return res  // 不是 return nil，返回空切片
}
```

### 2. 取最后一个用的是 q 的索引，不是 temp

```go
// ✓ 对：q 本身就是当前层
res = append(res, q[len(q)-1].Val)

// ✗ 错：如果用 temp 且忘记 append，temp 为空时越界
res = append(res, temp[len(temp)-1])
```

### 3. 子节点入队顺序不影响结果

```go
// 先左后右（标准写法）
if q[i].Left != nil { next = append(next, q[i].Left) }
if q[i].Right != nil { next = append(next, q[i].Right) }

// 先右后左也行，因为只取每层最后一个
// 但标准 BFS 习惯先左后右，保持一致
```

### 4. 左子树更深的情况

```
    1
   /
  2
 / \
4   5

右视图: [1,2,5]  ← 不是只有右子树！
```

左子树比右子树深时，左边更深的节点也能被看到。BFS 天然处理了这个情况——每层取最后一个，不管它在左还是右。

---

## 九、面试表达

> 二叉树右视图，用 BFS 层序遍历，每层取最后一个节点。用队列逐层展开，遍历当前层的所有节点，把子节点加入下一层队列，当前层遍历完后取队列最后一个节点的值加入结果。时间 O(n)，空间 O(n)。
