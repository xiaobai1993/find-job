# 64. 最小路径和

> LeetCode 链接：https://leetcode.cn/problems/minimum-path-sum/

## 题目
给定 m×n 网格（非负整数），从左上角到右下角，只能向右或向下移动，找一条路径使数字总和最小。

## 最易理解的方法：原地 DP

**核心思路：**
`dp[i][j]` = 到达 `(i,j)` 的最小路径和 = `grid[i][j] + min(dp[i-1][j], dp[i][j-1])`。
为节省空间，直接在 `grid` 上原地修改。第一行只能从左来，第一列只能从上来。

```
grid:
1 3 1
1 5 1
4 2 1

原地修改后:
1  4  5
2  7  6
6  8  7

答案: grid[2][2] = 7
```

## Go 实现

```go
func minPathSum(grid [][]int) int {
    m, n := len(grid), len(grid[0])
    // 初始化第一行
    for j := 1; j < n; j++ {
        grid[0][j] += grid[0][j-1]
    }
    // 初始化第一列
    for i := 1; i < m; i++ {
        grid[i][0] += grid[i-1][0]
    }
    // 填充其余
    for i := 1; i < m; i++ {
        for j := 1; j < n; j++ {
            up := grid[i-1][j]
            left := grid[i][j-1]
            if up < left {
                grid[i][j] += up
            } else {
                grid[i][j] += left
            }
        }
    }
    return grid[m-1][n-1]
}
```

## 复杂度
- 时间：O(m × n)
- 空间：O(1)（原地修改）

## 记忆口诀
> dp[i][j] = grid[i][j] + min(上方, 左方)；第一行/列单独初始化；右下角为答案。
