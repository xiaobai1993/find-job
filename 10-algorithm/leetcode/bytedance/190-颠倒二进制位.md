# 190. 颠倒二进制位

> LeetCode 链接：https://leetcode.cn/problems/reverse-bits/

## 题目
颠倒给定无符号整数的二进制位。

## 最易理解的方法：逐位颠倒

**核心思路：**
逐位取 n 的最低位加入结果，n 右移，结果左移，重复32次。

```
n = 43261596 = 00000010100101000001111010011100

逐位颠倒:
取最低位放到结果最高位，循环32次
```

## Go 实现

```go
func reverseBits(num uint32) uint32 {
    var res uint32
    for i := 0; i < 32; i++ {
        res = (res << 1) | (num & 1)
        num >>= 1
    }
    return res
}
```

## 复杂度
- 时间：O(1)（固定32次）
- 空间：O(1)

## 记忆口诀
> 循环32次：结果左移1位，加上n的最低位；n右移1位。
