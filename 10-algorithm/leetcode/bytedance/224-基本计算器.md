# 224. 基本计算器

> LeetCode 链接：https://leetcode.cn/problems/basic-calculator/

## 题目
实现计算器，支持 +、-、空格和括号。表达式合法且不含除法和乘法。

## 最易理解的方法：栈处理括号

**核心思路：**
遇到 `(` 时，将当前结果和符号入栈（保存现场），重置结果从0开始计算括号内；
遇到 `)` 时，将括号内结果乘以出栈的符号，再加上出栈的之前结果。

```
"1 + (2 - (3 + 4))"

处理1: res=1
遇+: sign=1
遇(: stack=[1,1], res=0, sign=1
处理2: res=2
遇-: sign=-1
遇(: stack=[1,1,2,-1], res=0, sign=1
处理3: res=3
遇+: sign=1
处理4: res=3+4=7
遇): res = 出栈(-1)*7 + 出栈(2) = -7+2 = -5; sign=出栈(1)
遇): res = 出栈(1)*(-5) + 出栈(1) = -5+1 = -4
答案=-4
```

## Go 实现

```go
func calculate(s string) int {
    stack := []int{}
    res, sign := 0, 1
    i := 0
    for i < len(s) {
        c := s[i]
        if c >= '0' && c <= '9' {
            num := 0
            for i < len(s) && s[i] >= '0' && s[i] <= '9' {
                num = num*10 + int(s[i]-'0')
                i++
            }
            res += sign * num
            continue
        } else if c == '+' {
            sign = 1
        } else if c == '-' {
            sign = -1
        } else if c == '(' {
            stack = append(stack, res)
            stack = append(stack, sign)
            res = 0
            sign = 1
        } else if c == ')' {
            topSign := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            topRes := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            res = topRes + topSign*res
        }
        i++
    }
    return res
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> 遇(入栈保存(res,sign)，重置res=0,sign=1；遇)弹出sign和res，合并：res=topRes+topSign*res。
