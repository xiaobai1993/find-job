# 92. 反转链表 II

> LeetCode 链接：https://leetcode.cn/problems/reverse-linked-list-ii/

## 题目
给定链表和区间 [left, right]，只反转这个区间内的节点，其余部分不动。

## 最易理解的方法：找前驱 + 区间反转

**核心思路：**
用哑节点方便处理边界。找到 left 前驱节点 `pre`，然后通过"头插法"将 left 到 right 区间的节点逐一插到 `pre` 之后，实现反转。

```
dummy -> 1 -> 2 -> 3 -> 4 -> 5, left=2, right=4

找前驱：pre = node(1)，curr = node(2)

头插法（将 curr.Next 插到 pre 之后）：
step1: dummy->1->3->2->4->5  (3插到1后)
step2: dummy->1->4->3->2->5  (4插到1后)

结果：1->4->3->2->5 ✓
```

**算法步骤：**
1. 创建 `dummy -> head`，移动 `pre` 到 left 前驱
2. `curr = pre.Next`
3. 循环 `right - left` 次：`next = curr.Next`，`curr.Next = next.Next`，`next.Next = pre.Next`，`pre.Next = next`（头插）
4. 返回 `dummy.Next`

## Go 实现

```go
func reverseBetween(head *ListNode, left int, right int) *ListNode {
    dummy := &ListNode{Next: head}
    pre := dummy
    // pre 移到 left 前驱
    for i := 1; i < left; i++ {
        pre = pre.Next
    }
    curr := pre.Next
    // 头插法反转 right-left 次
    for i := 0; i < right-left; i++ {
        next := curr.Next
        curr.Next = next.Next
        next.Next = pre.Next
        pre.Next = next
    }
    return dummy.Next
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 找到 left 前驱 pre；头插法：把 curr.Next 插到 pre 正后方；重复 right-left 次。
