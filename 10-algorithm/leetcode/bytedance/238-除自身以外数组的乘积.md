# 238. 除自身以外数组的乘积

> LeetCode 链接：https://leetcode.cn/problems/product-of-array-except-self/

## 题目
给定整数数组，返回数组 `answer`，其中 `answer[i]` 等于 `nums` 中除 `nums[i]` 之外其余各元素的乘积。不使用除法，O(n) 时间。

## 最易理解的方法：左右前缀积

**核心思路：**
- 第一遍（从左）：`left[i]` = `nums[0..i-1]` 的乘积
- 第二遍（从右）：累乘右侧元素更新结果

```
nums = [1, 2, 3, 4]

左前缀积: [1, 1, 2, 6]  (left[0]=1, left[1]=1, left[2]=1*2, left[3]=1*2*3)
右后缀积（在第一步结果上累乘）:
  R=1
  i=3: res[3]=6*1=6, R=R*4=4
  i=2: res[2]=2*4=8, R=R*3=12
  i=1: res[1]=1*12=12, R=R*2=24
  i=0: res[0]=1*24=24

结果: [24, 12, 8, 6]
```

## Go 实现

```go
func productExceptSelf(nums []int) []int {
    n := len(nums)
    res := make([]int, n)
    // 左前缀积
    res[0] = 1
    for i := 1; i < n; i++ {
        res[i] = res[i-1] * nums[i-1]
    }
    // 右后缀积（从右向左累乘）
    R := 1
    for i := n - 1; i >= 0; i-- {
        res[i] *= R
        R *= nums[i]
    }
    return res
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)（输出数组不算额外空间）

## 记忆口诀
> 两遍：先存左侧前缀积；再从右往左乘右侧累积R；结果=左前缀×右后缀。
