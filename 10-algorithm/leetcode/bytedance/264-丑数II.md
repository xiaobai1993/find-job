# 264. 丑数 II

> LeetCode 链接：https://leetcode.cn/problems/ugly-number-ii/

## 题目
给定整数 n，返回第 n 个丑数（只含因子 2、3、5 的正整数，1 是第一个丑数）。

## 最易理解的方法：三指针动态规划（最小堆变体）

**核心思路：**
用三个指针 p2、p3、p5 分别指向下一个应乘 2、3、5 的丑数位置。
每次取三者乘积的最小值作为下一个丑数，并推进相应指针。

```
dp[0]=1

p2=p3=p5=0

dp[1]=min(1*2,1*3,1*5)=2 → p2++
dp[2]=min(2*2,1*3,1*5)=3 → p3++
dp[3]=min(2*2,3,5)=4 → p2++
dp[4]=min(3*2,3,5)=5 → p5++
dp[5]=min(3*2,3,5*2)=6 → p2++,p3++ (去重)
...
```

## Go 实现

```go
func nthUglyNumber(n int) int {
    dp := make([]int, n)
    dp[0] = 1
    p2, p3, p5 := 0, 0, 0
    for i := 1; i < n; i++ {
        next2, next3, next5 := dp[p2]*2, dp[p3]*3, dp[p5]*5
        next := min3(next2, next3, next5)
        dp[i] = next
        if next == next2 {
            p2++
        }
        if next == next3 {
            p3++
        }
        if next == next5 {
            p5++
        }
    }
    return dp[n-1]
}

func min3(a, b, c int) int {
    m := a
    if b < m { m = b }
    if c < m { m = c }
    return m
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> 三指针：p2/p3/p5各指向下一个应乘的位置；每次取三种乘积最小值；相等时同时推进（去重）。
