# 8. 字符串转换整数 (atoi)

> LeetCode 链接：https://leetcode.cn/problems/string-to-integer-atoi/

## 题目
实现 `myAtoi(string s)`：去除前导空格，识别正负号，读取数字，超出 int32 范围则截断。

## 最易理解的方法：模拟

**核心思路：**
按顺序处理：
1. 跳过前导空格
2. 读取正负号
3. 读取数字并检查溢出（每步检查）

```
"  -42abc"
→ 跳空格 → "-42abc"
→ 读符号 sign=-1 → "42abc"
→ 读数字: 4 → 42 → 遇'a'停止
→ 返回 -1 × 42 = -42
```

## Go 实现

```go
import "math"

func myAtoi(s string) int {
    i, n := 0, len(s)
    // 1. 跳空格
    for i < n && s[i] == ' ' {
        i++
    }
    if i == n {
        return 0
    }
    // 2. 读符号
    sign := 1
    if s[i] == '+' {
        i++
    } else if s[i] == '-' {
        sign = -1
        i++
    }
    // 3. 读数字
    res := 0
    for i < n && s[i] >= '0' && s[i] <= '9' {
        digit := int(s[i] - '0')
        // 溢出检查：res > (MaxInt32 - digit) / 10
        if res > (math.MaxInt32-digit)/10 {
            if sign == 1 {
                return math.MaxInt32
            }
            return math.MinInt32
        }
        res = res*10 + digit
        i++
    }
    return sign * res
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 三步：跳空格、读符号、读数字；溢出判断 res>(MaxInt32-digit)/10。
