# 7. 整数反转

> LeetCode 链接：https://leetcode.cn/problems/reverse-integer/

## 题目
给定 32 位有符号整数，反转其各位数字。溢出则返回 0。

## 最易理解的方法：逐位取余

**核心思路：**
每次取末位 `digit = x % 10`，将其加入反转结果，然后 `x /= 10`。
每步检查是否溢出（比较时要避免已经溢出）。

```
x = 123

digit=3, rev=3, x=12
digit=2, rev=32, x=1
digit=1, rev=321, x=0

答案=321
```

## Go 实现

```go
import "math"

func reverse(x int) int {
    rev := 0
    for x != 0 {
        digit := x % 10
        x /= 10
        // 溢出检查：在乘10前检查
        if rev > math.MaxInt32/10 || (rev == math.MaxInt32/10 && digit > 7) {
            return 0
        }
        if rev < math.MinInt32/10 || (rev == math.MinInt32/10 && digit < -8) {
            return 0
        }
        rev = rev*10 + digit
    }
    return rev
}
```

## 复杂度
- 时间：O(log |x|)
- 空间：O(1)

## 记忆口诀
> 逐位取余构建反转数；溢出判断：rev>MaxInt32/10 或 rev==MaxInt32/10且末位>7则溢出。
