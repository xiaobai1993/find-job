# 662. 二叉树最大宽度

> LeetCode 链接：https://leetcode.cn/problems/maximum-width-of-binary-tree/

## 题目
给定一棵二叉树，求该二叉树的最大宽度（每层最左和最右非空节点之间的节点数，包含空节点）。

## 最易理解的方法：BFS + 节点编号

**核心思路：**
给每个节点编号：根节点编号为 1，左孩子为父节点编号 × 2，右孩子为父节点编号 × 2 + 1。每层宽度 = 该层最后节点编号 - 第一个节点编号 + 1。BFS 层序遍历，每层记录第一和最后节点的编号。

**注意溢出：** 编号可能很大（2^depth），需要在每层将编号减去本层第一个节点的编号（归一化），防止溢出。

```
         1(编号1)
        / \
       2   3  (编号2,3)    宽度=3-2+1=2
      / \   \
     4   5   7  (编号4,5,7) 宽度=7-4+1=4
```

## Go 实现

```go
func widthOfBinaryTree(root *TreeNode) int {
    type item struct {
        node *TreeNode
        id   uint // 用uint避免溢出
    }
    queue := []item{{root, 1}}
    ans := 1
    for len(queue) > 0 {
        n := len(queue)
        offset := queue[0].id // 归一化，防止溢出
        for i := 0; i < n; i++ {
            cur := queue[i]
            cur.id -= offset
            if cur.node.Left != nil {
                queue = append(queue, item{cur.node.Left, cur.id*2})
            }
            if cur.node.Right != nil {
                queue = append(queue, item{cur.node.Right, cur.id*2 + 1})
            }
        }
        w := int(queue[n-1].id - queue[0].id + 1)
        if w > ans {
            ans = w
        }
        queue = queue[n:]
    }
    return ans
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> BFS层序 + 节点编号（左孩子=2i，右孩子=2i+1）；每层宽=尾编号-首编号+1；每层归一化防溢出。
