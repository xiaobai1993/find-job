# 119. 杨辉三角 II

> LeetCode 链接：https://leetcode.cn/problems/pascals-triangle-ii/

## 题目
给定行索引 rowIndex（从0开始），返回杨辉三角第 rowIndex 行。

## 最易理解的方法：滚动数组（原地更新）

**核心思路：**
只维护一行，从后往前更新避免覆盖：`row[j] = row[j] + row[j-1]`。

```
rowIndex = 3

row=[1]
row=[1,1]
从后往前: row=[1,2,1]
从后往前: row=[1,3,3,1]
```

## Go 实现

```go
func getRow(rowIndex int) []int {
    row := make([]int, rowIndex+1)
    row[0] = 1
    for i := 1; i <= rowIndex; i++ {
        for j := i; j >= 1; j-- {
            row[j] += row[j-1]
        }
    }
    return row
}
```

## 复杂度
- 时间：O(n²)
- 空间：O(n)

## 记忆口诀
> 从后往前更新row[j]+=row[j-1]（防止覆盖）；首位始终为1。
