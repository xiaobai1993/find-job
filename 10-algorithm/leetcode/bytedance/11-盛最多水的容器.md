# 11. 盛最多水的容器

> LeetCode 链接：https://leetcode.cn/problems/container-with-most-water/

## 题目
给定数组 `height`，每个元素表示一条竖线的高度。找两条线使其与 x 轴构成的容器能盛最多水。

## 最易理解的方法：双指针

**核心思路：**
左右指针从两端向中间夹逼。当前容量 = `min(height[left], height[right]) × (right - left)`。每次将**较矮的那侧**指针向内移动（移动较矮侧才有可能找到更大的水量，移动较高侧宽度减小且高度不可能增加，必然变小）。

```
height = [1, 8, 6, 2, 5, 4, 8, 3, 7]

left=0(h=1), right=8(h=7)
  area = min(1,7) × 8 = 8
  左矮 → left++
left=1(h=8), right=8(h=7)
  area = min(8,7) × 7 = 49
  右矮 → right--
left=1(h=8), right=7(h=3)
  area = min(8,3) × 6 = 18
  右矮 → right--
...最终答案 = 49
```

## Go 实现

```go
func maxArea(height []int) int {
    left, right := 0, len(height)-1
    ans := 0
    for left < right {
        h := height[left]
        if height[right] < h {
            h = height[right]
        }
        area := h * (right - left)
        if area > ans {
            ans = area
        }
        if height[left] < height[right] {
            left++
        } else {
            right--
        }
    }
    return ans
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 双指针从两端夹；每次移动较矮的那侧（移高侧无意义）；记录最大面积。
