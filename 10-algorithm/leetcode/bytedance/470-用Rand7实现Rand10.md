# 470. 用 Rand7() 实现 Rand10()

> LeetCode 链接：https://leetcode.cn/problems/implement-rand10-using-rand7/

## 题目
已有 `rand7()`（等概率返回 1-7），实现 `rand10()`（等概率返回 1-10）。

## 最易理解的方法：拒绝采样

**核心思路：**
1. 用两次 rand7 生成 1-49 的均匀分布：`(rand7()-1)*7 + rand7()`
2. 只取 1-40 的范围（能被10整除），40以外的拒绝重来
3. 对 40 取模 + 1，得到 1-10

```
(rand7()-1)*7 + rand7() 生成 1-49
  → 只要 1-40: (num-1)%10+1 = 1~10 (各占4/40=1/10概率)
  → 41-49: 拒绝，重来

期望调用次数 = 2 × (49/40) ≈ 2.45
```

## Go 实现

```go
func rand10() int {
    for {
        num := (rand7()-1)*7 + rand7() // 1-49 均匀分布
        if num <= 40 {
            return (num-1)%10 + 1
        }
        // 41-49: 拒绝，重试
    }
}
```

## 复杂度
- 期望时间：O(1)（期望约 2.45 次调用）
- 空间：O(1)
