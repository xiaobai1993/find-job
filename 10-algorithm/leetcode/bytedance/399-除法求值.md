# 399. 除法求值

> LeetCode 链接：https://leetcode.cn/problems/evaluate-division/

## 题目
给定变量对和对应的值（a/b=2.0），以及一组查询（c/d=?），返回结果（无法计算返回-1.0）。

## 最易理解的方法：带权图 + BFS/DFS

**核心思路：**
将每个等式构建有向图：a→b 权重 value，b→a 权重 1/value。
对每个查询，从起点出发 BFS/DFS 找终点，路径上的权重乘积就是答案。

```
a/b=2.0, b/c=3.0

图: a→b(2), b→a(0.5), b→c(3), c→b(1/3)

查询 a/c: a→b(2)→c(3) = 6.0
查询 c/a: c→b(1/3)→a(0.5) = 1/6
```

## Go 实现

```go
func calcEquation(equations [][]string, values []float64, queries [][]string) []float64 {
    graph := make(map[string]map[string]float64)
    for i, eq := range equations {
        a, b := eq[0], eq[1]
        if graph[a] == nil {
            graph[a] = make(map[string]float64)
        }
        if graph[b] == nil {
            graph[b] = make(map[string]float64)
        }
        graph[a][b] = values[i]
        graph[b][a] = 1.0 / values[i]
    }
    bfs := func(src, dst string) float64 {
        if graph[src] == nil {
            return -1.0
        }
        if src == dst {
            return 1.0
        }
        visited := map[string]bool{src: true}
        queue := [][2]interface{}{{src, 1.0}}
        for len(queue) > 0 {
            cur := queue[0]
            queue = queue[1:]
            node, prod := cur[0].(string), cur[1].(float64)
            for next, w := range graph[node] {
                if next == dst {
                    return prod * w
                }
                if !visited[next] {
                    visited[next] = true
                    queue = append(queue, [2]interface{}{next, prod * w})
                }
            }
        }
        return -1.0
    }
    res := make([]float64, len(queries))
    for i, q := range queries {
        res[i] = bfs(q[0], q[1])
    }
    return res
}
```

## 复杂度
- 时间：O((E+V) × Q)
- 空间：O(E+V)

## 记忆口诀
> 带权有向图：a→b权重v，b→a权重1/v；BFS查询路径，乘积累乘；不可达返回-1。
