# 766. 托普利茨矩阵

> LeetCode 链接：https://leetcode.cn/problems/toeplitz-matrix/

## 题目
判断矩阵是否是托普利茨矩阵（每条从左上到右下的对角线上的元素都相同）。

## 最易理解的方法：只需验证每个元素等于左上角元素

**核心思路：**
对每个非第一行第一列的元素，验证它与其左上方元素相等即可。

```
矩阵:
1 2 3 4
5 1 2 3
9 5 1 2

每个元素(i>0且j>0)都等于grid[i-1][j-1] → 是托普利茨矩阵
```

## Go 实现

```go
func isToeplitzMatrix(matrix [][]int) bool {
    for i := 1; i < len(matrix); i++ {
        for j := 1; j < len(matrix[0]); j++ {
            if matrix[i][j] != matrix[i-1][j-1] {
                return false
            }
        }
    }
    return true
}
```

## 复杂度
- 时间：O(m×n)
- 空间：O(1)

## 记忆口诀
> 验证每格等于其左上角格；从(1,1)开始遍历即可。
