# 114. 二叉树展开为链表

> LeetCode 链接：https://leetcode.cn/problems/flatten-binary-tree-to-linked-list/

## 题目
给定二叉树根节点，原地将其展开为按前序遍历顺序的单链表（右指针做 next，左指针置 nil）。

## 最易理解的方法：迭代（寻找前序后继）

**核心思路：**
对每个有左子树的节点：
1. 找到左子树**最右节点**（前序遍历中左子树的最后一个节点）
2. 将当前节点的右子树接到最右节点的右指针
3. 将左子树移到右边，左指针置 nil

```
    1
   / \
  2   5
 / \   \
3   4   6

步骤1: 找1的左子树最右节点(4), 把5接到4.right
      1→2→3→4→5→6 (拉平左子树)
      1
       \
        2
       / \
      3   4
           \
            5
             \
              6
步骤2: 对2做同样操作...
最终: 1→2→3→4→5→6
```

## Go 实现

```go
func flatten(root *TreeNode) {
    for root != nil {
        if root.Left != nil {
            // 找左子树最右节点
            rightmost := root.Left
            for rightmost.Right != nil {
                rightmost = rightmost.Right
            }
            // 把右子树接到最右节点
            rightmost.Right = root.Right
            // 左子树移到右边
            root.Right = root.Left
            root.Left = nil
        }
        root = root.Right
    }
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 有左子树时：找左子树最右节点→把右子树接上去→左子树移到右边→左置nil→继续向右。
