# 518. 零钱兑换 II

> LeetCode 链接：https://leetcode.cn/problems/coin-change-ii/

## 题目
给定整数数组 `coins` 和整数 `amount`，计算组成 amount 的组合数（每种面值可用无数次）。

## 最易理解的方法：完全背包 DP（组合数）

**核心思路：**
`dp[i]` 表示凑成金额 `i` 的组合数。与零钱兑换I不同，这里求的是**组合数**（不计顺序）。关键：外层遍历硬币，内层遍历金额（这样每种硬币只被"新增"，不重复计算顺序）。

```
coins = [1, 2, 5], amount = 5

dp[0] = 1 (空集)

用硬币1:
dp = [1,1,1,1,1,1]

用硬币2:
dp[2] += dp[0] = 2
dp[3] += dp[1] = 2
dp[4] += dp[2] = 3
dp[5] += dp[3] = 3

用硬币5:
dp[5] += dp[0] = 4

答案 = dp[5] = 4
```

## Go 实现

```go
func change(amount int, coins []int) int {
    dp := make([]int, amount+1)
    dp[0] = 1
    for _, coin := range coins { // 外层枚举硬币（保证组合不重复）
        for i := coin; i <= amount; i++ {
            dp[i] += dp[i-coin]
        }
    }
    return dp[amount]
}
```

## 复杂度
- 时间：O(amount × len(coins))
- 空间：O(amount)

## 记忆口诀
> 外层枚举硬币，内层枚举金额（完全背包组合数）；与排列数的区别：外枚举物品vs外枚举目标。
