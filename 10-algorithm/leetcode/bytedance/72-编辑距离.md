# 72. 编辑距离

> LeetCode 链接：https://leetcode.cn/problems/edit-distance/

## 题目
给定两个字符串 `word1` 和 `word2`，计算将 `word1` 转换成 `word2` 所用的最少操作数（插入、删除、替换各一步）。

## 最易理解的方法：动态规划

**核心思路：**
`dp[i][j]` 表示 `word1[0:i]` 转换成 `word2[0:j]` 的最少操作数。
- 若 `word1[i-1] == word2[j-1]`：`dp[i][j] = dp[i-1][j-1]`（不操作）
- 否则取三种操作的最小值 + 1：
  - `dp[i-1][j]`：删除 word1[i-1]
  - `dp[i][j-1]`：插入字符到 word1
  - `dp[i-1][j-1]`：替换 word1[i-1]

```
     ""  r  o  s
""    0   1  2  3
h     1   1  2  3
o     2   2  1  2
r     3   2  2  2
s     4   3  3  2   ← dp[4][3]=2

"horse" → "ros" 最少2步
```

## Go 实现

```go
func minDistance(word1 string, word2 string) int {
    m, n := len(word1), len(word2)
    dp := make([][]int, m+1)
    for i := range dp {
        dp[i] = make([]int, n+1)
        dp[i][0] = i // word1 前 i 个字符删完
    }
    for j := 0; j <= n; j++ {
        dp[0][j] = j // word2 前 j 个字符插入
    }
    for i := 1; i <= m; i++ {
        for j := 1; j <= n; j++ {
            if word1[i-1] == word2[j-1] {
                dp[i][j] = dp[i-1][j-1]
            } else {
                dp[i][j] = min(dp[i-1][j-1], min(dp[i-1][j], dp[i][j-1])) + 1
            }
        }
    }
    return dp[m][n]
}
```

## 复杂度
- 时间：O(m × n)
- 空间：O(m × n)，可优化为 O(n)

## 记忆口诀
> dp[i][j]：字符相同=斜上角；不同=三邻居(上,左,斜上)最小+1；边界dp[i][0]=i，dp[0][j]=j。
