# 120. 三角形最小路径和

> LeetCode 链接：https://leetcode.cn/problems/triangle/

## 题目
给定三角形数组，从顶部到底部的最小路径和（每步只能移动到下一行的相邻数字）。

## 最易理解的方法：自底向上 DP

**核心思路：**
从最后一行开始，`dp[j]` 表示从第 i 行第 j 个到底部的最小路径和。
`dp[j] = triangle[i][j] + min(dp[j], dp[j+1])`

```
[2]
[3,4]
[6,5,7]
[4,1,8,3]

从底向上:
dp=[4,1,8,3]
dp=[6+min(4,1), 5+min(1,8), 7+min(8,3)] = [7,6,10]
dp=[3+min(7,6), 4+min(6,10)] = [9,10]
dp=[2+min(9,10)] = [11]

答案=11
```

## Go 实现

```go
func minimumTotal(triangle [][]int) int {
    n := len(triangle)
    dp := make([]int, n)
    copy(dp, triangle[n-1]) // 初始化为最后一行
    for i := n - 2; i >= 0; i-- {
        for j := 0; j <= i; j++ {
            if dp[j] < dp[j+1] {
                dp[j] = triangle[i][j] + dp[j]
            } else {
                dp[j] = triangle[i][j] + dp[j+1]
            }
        }
    }
    return dp[0]
}
```

## 复杂度
- 时间：O(n²)
- 空间：O(n)

## 记忆口诀
> 自底向上；dp初始化为最后一行；每步 dp[j]=triangle[i][j]+min(dp[j],dp[j+1])；最终dp[0]即答案。
