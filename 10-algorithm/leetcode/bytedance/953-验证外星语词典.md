# 953. 验证外星语词典

> LeetCode 链接：https://leetcode.cn/problems/verifying-an-alien-dictionary/

## 题目
给定外星字母表顺序 order 和单词列表 words，判断单词列表是否按外星字典序排列。

## 最易理解的方法：构建映射 + 相邻比较

**核心思路：**
将字母映射到 0-25 的优先级，相邻单词逐字符比较，不满足字典序则返回 false。

```
order="hlabcdefgijkmnopqrstuvwxyz", words=["hello","leetcode"]

映射: h=0,l=1,a=2,b=3,...

比较"hello"和"leetcode":
h(0) vs l(1): 0<1 → 正确顺序
→ true
```

## Go 实现

```go
func isAlienSorted(words []string, order string) bool {
    rank := [26]int{}
    for i, c := range order { rank[c-'a'] = i }
    for i := 0; i < len(words)-1; i++ {
        w1, w2 := words[i], words[i+1]
        found := false
        for j := 0; j < len(w1) && j < len(w2); j++ {
            r1, r2 := rank[w1[j]-'a'], rank[w2[j]-'a']
            if r1 < r2 { found = true; break }
            if r1 > r2 { return false }
        }
        if !found && len(w1) > len(w2) { return false }
    }
    return true
}
```

## 复杂度
- 时间：O(m×n)
- 空间：O(1)

## 记忆口诀
> 建字母优先级映射；相邻单词逐字符比较；前者优先级大则false；前者是后者前缀且更长则false。
