# 530. 二叉搜索树的最小绝对差

> LeetCode 链接：https://leetcode.cn/problems/minimum-absolute-difference-in-bst/

## 题目
给定 BST，求树中任意两节点值之差的绝对值的最小值。

## 最易理解的方法：中序遍历（有序序列相邻差最小）

**核心思路：**
BST 中序遍历得有序序列，相邻元素之差最小，记录前一个节点值。

```
    4
   / \
  2   6
 / \
1   3

中序: 1,2,3,4,6
相邻差: 1,1,1,2 → 最小=1
```

## Go 实现

```go
func getMinimumDifference(root *TreeNode) int {
    minDiff, prev := 1<<31-1, -1
    var inorder func(node *TreeNode)
    inorder = func(node *TreeNode) {
        if node == nil { return }
        inorder(node.Left)
        if prev != -1 && node.Val-prev < minDiff {
            minDiff = node.Val - prev
        }
        prev = node.Val
        inorder(node.Right)
    }
    inorder(root)
    return minDiff
}
```

## 复杂度
- 时间：O(n)
- 空间：O(h)

## 记忆口诀
> BST中序得有序序列；维护prev节点值，更新最小差；相邻元素差最小。
