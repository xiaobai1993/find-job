# 129. 求根节点到叶节点数字之和

> LeetCode 链接：https://leetcode.cn/problems/sum-root-to-leaf-numbers/

## 题目
给定一棵二叉树，每个节点包含 0-9 的数字，每条从根到叶的路径代表一个数。求所有路径代表的数字之和。

## 最易理解的方法：DFS

**核心思路：**
从根往下走，维护当前路径形成的数字 `cur = cur*10 + node.Val`。到叶节点时将 cur 加入总和。

```
    1
   / \
  2   3

路径 1→2 = 12
路径 1→3 = 13
总和 = 12 + 13 = 25
```

## Go 实现

```go
func sumNumbers(root *TreeNode) int {
    var dfs func(node *TreeNode, cur int) int
    dfs = func(node *TreeNode, cur int) int {
        if node == nil {
            return 0
        }
        cur = cur*10 + node.Val
        if node.Left == nil && node.Right == nil {
            return cur // 叶节点返回当前路径数
        }
        return dfs(node.Left, cur) + dfs(node.Right, cur)
    }
    return dfs(root, 0)
}
```

## 复杂度
- 时间：O(n)
- 空间：O(h)

## 记忆口诀
> DFS传当前数值cur；每步 cur=cur*10+val；叶节点返回cur；非叶返回左右之和。
