# 96. 不同的二叉搜索树

> LeetCode 链接：https://leetcode.cn/problems/unique-binary-search-trees/

## 题目
给定整数 n，求恰好有 n 个节点、值为 1 到 n 的不同 BST 的个数（卡特兰数）。

## 最易理解的方法：动态规划

**核心思路：**
`G(n)` = n 个节点能构成的不同 BST 数量。以 i（1≤i≤n）为根时，左子树有 i-1 个节点（G(i-1)种），右子树有 n-i 个节点（G(n-i)种），所以：
- `G(n) = Σ G(i-1) × G(n-i)，i从1到n`
- `G(0) = 1`（空树算一种）

```
G(0)=1, G(1)=1
G(2)=G(0)*G(1) + G(1)*G(0) = 2
G(3)=G(0)*G(2) + G(1)*G(1) + G(2)*G(0) = 2+1+2 = 5
G(4)=14
G(5)=42
```

## Go 实现

```go
func numTrees(n int) int {
    G := make([]int, n+1)
    G[0], G[1] = 1, 1
    for i := 2; i <= n; i++ {
        for j := 1; j <= i; j++ {
            G[i] += G[j-1] * G[i-j]
        }
    }
    return G[n]
}
```

## 复杂度
- 时间：O(n²)
- 空间：O(n)

## 记忆口诀
> G(n) = Σ G(i-1)*G(n-i)，i枚举根节点；G(0)=G(1)=1；这就是卡特兰数。
