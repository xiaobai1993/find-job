# 309. 买卖股票的最佳时机含冷冻期

> LeetCode 链接：https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-with-cooldown/

## 题目
股票买卖，卖出后第二天不能买入（冷冻期1天），求最大利润。

## 最易理解的方法：三状态 DP

**核心思路：**
定义三个状态：
- `hold`：持有股票时的最大收益
- `sold`：刚卖出（今天）的最大收益，明天进入冷冻
- `rest`：冷冻期或空仓（可买入）的最大收益

转移方程：
- `hold = max(hold, rest - price)` （继续持有 or 从rest状态买入）
- `sold = hold + price`（今天卖出）
- `rest = max(rest, sold)`（冷冻过了可以继续rest，或昨天sold进入rest）

```
prices = [1,2,3,0,2]

初始: hold=-∞, sold=0, rest=0

p=1: hold=max(-∞,0-1)=-1, sold=-1+1=0, rest=max(0,0)=0
p=2: hold=max(-1,0-2)=-1, sold=-1+2=1, rest=max(0,0)=0
p=3: hold=max(-1,0-3)=-1, sold=-1+3=2, rest=max(0,1)=1
p=0: hold=max(-1,1-0)=1, sold=-1+0=-1, rest=max(1,2)=2
p=2: hold=max(1,2-2)=1, sold=1+2=3, rest=max(2,-1)=2

答案=max(sold,rest)=max(3,2)=3
```

## Go 实现

```go
func maxProfit(prices []int) int {
    hold, sold, rest := -prices[0], 0, 0
    for _, p := range prices[1:] {
        prevHold, prevSold, prevRest := hold, sold, rest
        hold = max(prevHold, prevRest-p)
        sold = prevHold + p
        rest = max(prevRest, prevSold)
    }
    return max(sold, rest)
}

func max(a, b int) int {
    if a > b { return a }
    return b
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
