# 836. 矩形重叠

> LeetCode 链接：https://leetcode.cn/problems/rectangle-overlap/

## 题目
给定两个矩形（[x1,y1,x2,y2]格式，左下角到右上角），判断是否重叠（边界相触不算重叠）。

## 最易理解的方法：判断不重叠的逆否

**核心思路：**
两矩形不重叠的条件：一个在另一个的左/右/上/下侧。取反即为重叠条件。

```
rec1=[0,0,2,2], rec2=[1,1,3,3]

不重叠条件:
  rec2在rec1右边: rec2.x1 >= rec1.x2 → 1>=2? 否
  rec2在rec1左边: rec1.x1 >= rec2.x2 → 0>=3? 否
  ...
  都不满足 → 重叠
```

## Go 实现

```go
func isRectangleOverlap(rec1 []int, rec2 []int) bool {
    return rec1[0] < rec2[2] && rec2[0] < rec1[2] &&
           rec1[1] < rec2[3] && rec2[1] < rec1[3]
}
```

## 复杂度
- 时间：O(1)
- 空间：O(1)

## 记忆口诀
> 重叠条件：x轴有交叉(rec1.x1<rec2.x2 && rec2.x1<rec1.x2)且y轴有交叉。
