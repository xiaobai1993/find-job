# 144. 二叉树的前序遍历

> LeetCode 链接：https://leetcode.cn/problems/binary-tree-preorder-traversal/

## 题目
给定二叉树根节点，返回它的前序遍历（根→左→右）。要求迭代实现。

## 最易理解的方法：迭代（栈）

**核心思路：**
用栈实现：先访问当前节点，再将右子节点、左子节点依次入栈（右先入保证左先出）。

```
    1
   / \
  2   3

栈: [1]
pop 1, push 3,2 → 结果[1], 栈[3,2]
pop 2, push nil,nil → 结果[1,2], 栈[3]
pop 3 → 结果[1,2,3]
```

## Go 实现

```go
func preorderTraversal(root *TreeNode) []int {
    if root == nil {
        return nil
    }
    var res []int
    stack := []*TreeNode{root}
    for len(stack) > 0 {
        node := stack[len(stack)-1]
        stack = stack[:len(stack)-1]
        res = append(res, node.Val)
        if node.Right != nil {
            stack = append(stack, node.Right)
        }
        if node.Left != nil {
            stack = append(stack, node.Left)
        }
    }
    return res
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> 栈实现：pop并访问当前节点；先push右子再push左子（保证左先被访问）。
