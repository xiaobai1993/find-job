# 292. Nim 游戏

> LeetCode 链接：https://leetcode.cn/problems/nim-game/

## 题目
桌上有 n 块石头，轮流取1-3块，取走最后一块者胜。先手必胜？

## 最易理解的方法：数学规律

**核心思路：**
若 n 是 4 的倍数，无论先手取多少，后手都能补到4，先手必败。否则先手必胜。

```
n=1,2,3: 先手直接取完，必胜
n=4: 先手取1→剩3(后手赢), 取2→剩2(后手赢), 取3→剩1(后手赢) → 先手必败
n=5: 先手取1剩4(后手败) → 先手必胜
...
规律: n%4!=0时先手赢
```

## Go 实现

```go
func canWinNim(n int) bool {
    return n%4 != 0
}
```

## 复杂度
- 时间：O(1)
- 空间：O(1)

## 记忆口诀
> n%4!=0时先手必胜；4的倍数先手必败。
