# 122. 买卖股票的最佳时机 II

> LeetCode 链接：https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-ii/

## 题目
给定每天的股票价格数组，可以多次买卖（同一时刻最多持有一股），求最大利润。

## 最易理解的方法：贪心（累加所有上涨）

**核心思路：**
只要明天比今天贵，就今天买明天卖（等价于累加所有相邻的正差值）。可以理解为：把所有上坡的利润都吃掉。

```
prices = [7, 1, 5, 3, 6, 4]

相邻差: -6, +4, -2, +3, -2
累加正差: 4+3 = 7

或者理解为:
  第2天买(1)，第3天卖(5)：+4
  第4天买(3)，第5天卖(6)：+3
  总利润 = 7
```

## Go 实现

```go
func maxProfit(prices []int) int {
    profit := 0
    for i := 1; i < len(prices); i++ {
        if prices[i] > prices[i-1] {
            profit += prices[i] - prices[i-1]
        }
    }
    return profit
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 累加所有相邻上涨的差值（只收益不亏损）；贪心地把所有上涨都吃掉。
