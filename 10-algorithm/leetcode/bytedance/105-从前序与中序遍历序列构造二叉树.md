# 105. 从前序与中序遍历序列构造二叉树

> LeetCode 链接：https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal/

## 题目
给定一棵树的前序遍历 `preorder` 与中序遍历 `inorder`，构造该二叉树。

## 最易理解的方法：递归

**核心思路：**
前序遍历的**第一个元素**就是根节点。在中序遍历中找到根节点的位置，其左侧是左子树，右侧是右子树。递归地对左右子树做同样的操作。用哈希表快速查找根节点在中序中的位置。

```
preorder = [3,9,20,15,7]
inorder  = [9,3,15,20,7]

根 = 3（preorder[0]）
3 在 inorder 的下标 1：
  左子树 inorder = [9]，        preorder = [9]
  右子树 inorder = [15,20,7]，  preorder = [20,15,7]

递归：
  左根=9，右根=20
  20的左=15，右=7
```

## Go 实现

```go
func buildTree(preorder []int, inorder []int) *TreeNode {
    idxMap := make(map[int]int)
    for i, v := range inorder {
        idxMap[v] = i
    }
    var build func(preL, preR, inL, inR int) *TreeNode
    build = func(preL, preR, inL, inR int) *TreeNode {
        if preL > preR {
            return nil
        }
        rootVal := preorder[preL]
        root := &TreeNode{Val: rootVal}
        mid := idxMap[rootVal] // 根在中序中的位置
        leftSize := mid - inL  // 左子树节点数
        root.Left = build(preL+1, preL+leftSize, inL, mid-1)
        root.Right = build(preL+leftSize+1, preR, mid+1, inR)
        return root
    }
    n := len(preorder)
    return build(0, n-1, 0, n-1)
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)（哈希表 + 递归栈）

## 记忆口诀
> 前序第一个是根；在中序找根位置，左侧是左子树，右侧是右子树；哈希表加速查找。
