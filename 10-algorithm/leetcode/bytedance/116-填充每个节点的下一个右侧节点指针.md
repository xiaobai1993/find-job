# 116. 填充每个节点的下一个右侧节点指针

> LeetCode 链接：https://leetcode.cn/problems/populating-next-right-pointers-in-each-node/

## 题目
给定完美二叉树，将每个节点的 `next` 指针指向同层右侧节点（没有则指向 null）。

## 最易理解的方法：利用已建立的 next 链

**核心思路：**
从根开始，利用上一层已建好的 next 链来串联下一层：
- 左子节点的 next = 父节点的右子节点
- 右子节点的 next = 父节点 next 的左子节点（如果父节点有 next）

```
      1
    /   \
   2     3
  / \   / \
 4   5 6   7

第一层: 1.next=nil
第二层: 2.next=3
第三层: 4.next=5, 5.next=6, 6.next=7
```

## Go 实现

```go
func connect(root *Node) *Node {
    if root == nil {
        return nil
    }
    leftmost := root
    for leftmost.Left != nil {
        cur := leftmost
        for cur != nil {
            // 同一父节点的左右子节点
            cur.Left.Next = cur.Right
            // 跨父节点：右子节点连到父节点next的左子节点
            if cur.Next != nil {
                cur.Right.Next = cur.Next.Left
            }
            cur = cur.Next
        }
        leftmost = leftmost.Left
    }
    return root
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 利用上层已建next链；左子.Next=右子；右子.Next=父.Next.左子；逐层处理。
