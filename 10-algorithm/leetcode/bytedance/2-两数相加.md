# 2. 两数相加

> LeetCode 链接：https://leetcode.cn/problems/add-two-numbers/

## 题目
两个非空链表分别表示两个非负整数（各位数字逆序存储），将两个数相加，返回结果链表（同样逆序存储）。

## 最易理解的方法：模拟进位

**核心思路：**
同时遍历两个链表，逐位相加并处理进位。用 `carry` 记录进位。当两个链表都遍历完且进位为 0 时结束。用哑节点简化边界处理。

```
l1: 2 → 4 → 3  (代表 342)
l2: 5 → 6 → 4  (代表 465)

位0: 2+5+0=7,  carry=0 → 7
位1: 4+6+0=10, carry=1 → 0
位2: 3+4+1=8,  carry=0 → 8
结果: 7 → 0 → 8  (代表 807)
```

## Go 实现

```go
func addTwoNumbers(l1 *ListNode, l2 *ListNode) *ListNode {
    dummy := &ListNode{}
    cur := dummy
    carry := 0
    for l1 != nil || l2 != nil || carry != 0 {
        sum := carry
        if l1 != nil {
            sum += l1.Val
            l1 = l1.Next
        }
        if l2 != nil {
            sum += l2.Val
            l2 = l2.Next
        }
        carry = sum / 10
        cur.Next = &ListNode{Val: sum % 10}
        cur = cur.Next
    }
    return dummy.Next
}
```

## 复杂度
- 时间：O(max(m, n))
- 空间：O(max(m, n))

## 记忆口诀
> 同时遍历两链表，逐位加 carry；sum/10 是新 carry，sum%10 是当前位；三个条件任意一个非空就继续。
