# 179. 最大数

> LeetCode 链接：https://leetcode.cn/problems/largest-number/

## 题目
给定一组非负整数，重新排列它们的顺序，拼接出最大的数。

## 最易理解的方法：自定义排序

**核心思路：**
对于两个数字 a 和 b，比较 `ab`（a拼接b）和 `ba`（b拼接a）的大小，哪个更大就谁在前。

```
[3, 30, 34, 5, 9]
比较: 9>5>34>3>30
排序后: [9,5,34,3,30]
结果: "9534330"
```

## Go 实现

```go
import (
    "sort"
    "strings"
    "strconv"
)

func largestNumber(nums []int) string {
    strs := make([]string, len(nums))
    for i, n := range nums {
        strs[i] = strconv.Itoa(n)
    }
    sort.Slice(strs, func(i, j int) bool {
        return strs[i]+strs[j] > strs[j]+strs[i]
    })
    // 特殊情况：全是0
    if strs[0] == "0" {
        return "0"
    }
    return strings.Join(strs, "")
}
```

## 复杂度
- 时间：O(n log n × k)，k 为数字最大位数
- 空间：O(n)

## 记忆口诀
> 自定义排序：比较 a+b 和 b+a 的字典序，大的在前；注意全0特殊情况。
