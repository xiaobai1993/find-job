# 415. 字符串相加

> LeetCode 链接：https://leetcode.cn/problems/add-strings/

## 题目
给定两个字符串形式的非负整数 `num1` 和 `num2`，计算它们的和并同样以字符串形式返回（不能使用大数库，不能将输入转为整数）。

## 最易理解的方法：从低位到高位模拟

**核心思路：**
从两个字符串末尾（个位）开始，同时向左遍历，逐位相加并处理进位，将每位结果存入 builder。最后翻转结果字符串。

```
num1 = "456"
num2 =  "77"

i=2,j=1: 6+7+0=13, carry=1, 写 '3'
i=1,j=0: 5+7+1=13, carry=1, 写 '3'
i=0,j=-1:4+0+1=5,  carry=0, 写 '5'
i=-1     carry=0  停止

result = "335" → 翻转 → "533"
```

## Go 实现

```go
func addStrings(num1 string, num2 string) string {
    i, j := len(num1)-1, len(num2)-1
    carry := 0
    var res []byte
    for i >= 0 || j >= 0 || carry > 0 {
        sum := carry
        if i >= 0 {
            sum += int(num1[i] - '0')
            i--
        }
        if j >= 0 {
            sum += int(num2[j] - '0')
            j--
        }
        carry = sum / 10
        res = append(res, byte(sum%10)+'0')
    }
    // 翻转
    for l, r := 0, len(res)-1; l < r; l, r = l+1, r-1 {
        res[l], res[r] = res[r], res[l]
    }
    return string(res)
}
```

## 复杂度
- 时间：O(max(m, n))
- 空间：O(max(m, n))

## 记忆口诀
> 从尾到头逐位加 carry；收集结果字节；最后翻转。`'x'-'0'` 转数字，`digit+'0'` 转字符。
