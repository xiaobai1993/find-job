# 424. 替换后的最长重复字符

> LeetCode 链接：https://leetcode.cn/problems/longest-repeating-character-replacement/

## 题目
给定字符串和整数 k，可以将字符串中任意字符替换 k 次，求最长全相同字母子串长度。

## 最易理解的方法：滑动窗口

**核心思路：**
窗口内最多的字符频率为 maxFreq，若 `窗口大小 - maxFreq > k`，则缩小左边界。

```
s="AABABBA", k=1

窗口扩展时维护maxFreq:
[AABA]: maxFreq=3(A), size=4, 4-3=1<=k ✓ len=4
[ABABBA]: size=6, maxFreq=3, 6-3=3>k → 缩左
最终最长: 4
```

## Go 实现

```go
func characterReplacement(s string, k int) int {
    cnt := [26]int{}
    maxFreq, left, res := 0, 0, 0
    for right := 0; right < len(s); right++ {
        cnt[s[right]-'A']++
        if cnt[s[right]-'A'] > maxFreq {
            maxFreq = cnt[s[right]-'A']
        }
        for right-left+1-maxFreq > k {
            cnt[s[left]-'A']--
            left++
        }
        if right-left+1 > res {
            res = right - left + 1
        }
    }
    return res
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 滑动窗口；维护最高频字符数maxFreq；窗口大小-maxFreq>k时缩左边界。
