# 242. 有效的字母异位词

> LeetCode 链接：https://leetcode.cn/problems/valid-anagram/

## 题目
给定两个字符串 s 和 t，判断 t 是否是 s 的字母异位词（字母相同、顺序不同）。

## 最易理解的方法：计数数组

**核心思路：**
用长度26的数组统计 s 中每个字母出现次数，然后遍历 t 时减少计数，若出现负数则不是异位词。

```
s="anagram", t="nagaram"

count(s): a:3, n:1, g:1, r:1, m:1
遍历t: n-1, a-1, g-1, a-1, r-1, a-1, m-1 → 全为0 ✓
```

## Go 实现

```go
func isAnagram(s string, t string) bool {
    if len(s) != len(t) {
        return false
    }
    count := [26]int{}
    for i := 0; i < len(s); i++ {
        count[s[i]-'a']++
        count[t[i]-'a']--
    }
    for _, c := range count {
        if c != 0 {
            return false
        }
    }
    return true
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 长度不同直接false；同时遍历s加计数t减计数；最终所有计数为0则是异位词。
