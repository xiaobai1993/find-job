# 112. 路径总和

> LeetCode 链接：https://leetcode.cn/problems/path-sum/

## 题目
给定二叉树和目标值 `targetSum`，判断从根到叶的路径中是否存在路径和等于 targetSum。

## 最易理解的方法：DFS 递归

**核心思路：**
递归时将 target 减去当前节点值，到叶节点时判断 target 是否变为 0。

```
    5
   / \
  4   8
 /   / \
11  13   4
/ \       \
7   2       1

target=22
5→4→11→7: 5+4+11+7=27 ≠22
5→4→11→2: 5+4+11+2=22 ✓
```

## Go 实现

```go
func hasPathSum(root *TreeNode, targetSum int) bool {
    if root == nil {
        return false
    }
    // 叶节点
    if root.Left == nil && root.Right == nil {
        return root.Val == targetSum
    }
    remain := targetSum - root.Val
    return hasPathSum(root.Left, remain) || hasPathSum(root.Right, remain)
}
```

## 复杂度
- 时间：O(n)
- 空间：O(h)

## 记忆口诀
> 递归减值；叶节点判断剩余是否为0；左或右有一条路径满足即可。
