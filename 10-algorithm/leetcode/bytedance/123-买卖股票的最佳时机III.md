# 123. 买卖股票的最佳时机 III

> LeetCode 链接：https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-iii/

## 题目
给定股票价格数组，最多完成 2 笔交易，求最大利润。（不能同时持有多只股票）

## 最易理解的方法：状态机 DP

**核心思路：**
用 4 个变量分别追踪 4 种状态：
- `buy1`：第一次买入后的最大余额（= -price）
- `sell1`：第一次卖出后的最大利润
- `buy2`：第二次买入后的最大余额（= sell1 - price）
- `sell2`：第二次卖出后的最大利润

```
prices = [3,3,5,0,0,3,1,4]

     buy1  sell1  buy2  sell2
      -3    0      -3    0
      -3    0      -3    0
      -3    2      -3    2
      0     2      2     2
      0     2      2     2
      0     3      2     5
      0     3      2     5
      0     3      2     6  ← 答案
```

## Go 实现

```go
func maxProfit(prices []int) int {
    buy1, sell1 := -prices[0], 0
    buy2, sell2 := -prices[0], 0
    for _, p := range prices[1:] {
        buy1 = max(buy1, -p)
        sell1 = max(sell1, buy1+p)
        buy2 = max(buy2, sell1-p)
        sell2 = max(sell2, buy2+p)
    }
    return sell2
}

func max(a, b int) int {
    if a > b { return a }
    return b
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 4变量状态机：buy1=-p; sell1=buy1+p; buy2=sell1-p; sell2=buy2+p；每步取max。
