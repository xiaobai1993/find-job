# 73. 矩阵置零

> LeetCode 链接：https://leetcode.cn/problems/set-matrix-zeroes/

## 题目
给定 m×n 整数矩阵，如果某元素为 0，则将其所在行和列全部置为 0。原地修改。

## 最易理解的方法：用第一行/列做标记

**核心思路：**
用矩阵第一行和第一列作为标记数组，记录哪些行/列需要置零。
先单独处理第一行/列是否含零，再用标记置零，最后处理第一行/列。

```
原矩阵:
1  1  1
1  0  1
1  1  1

扫描: matrix[1][1]=0 → 标记 row1, col1
  matrix[1][0]=0, matrix[0][1]=0

置零: row1全0, col1全0
结果:
1  0  1
0  0  0
1  0  1
```

## Go 实现

```go
func setZeroes(matrix [][]int) {
    m, n := len(matrix), len(matrix[0])
    firstRowZero := false
    firstColZero := false
    // 检查第一行/列是否有0
    for j := 0; j < n; j++ {
        if matrix[0][j] == 0 {
            firstRowZero = true
        }
    }
    for i := 0; i < m; i++ {
        if matrix[i][0] == 0 {
            firstColZero = true
        }
    }
    // 用第一行/列记录其他行/列是否有0
    for i := 1; i < m; i++ {
        for j := 1; j < n; j++ {
            if matrix[i][j] == 0 {
                matrix[i][0] = 0
                matrix[0][j] = 0
            }
        }
    }
    // 根据标记置零
    for i := 1; i < m; i++ {
        for j := 1; j < n; j++ {
            if matrix[i][0] == 0 || matrix[0][j] == 0 {
                matrix[i][j] = 0
            }
        }
    }
    // 处理第一行/列
    if firstRowZero {
        for j := 0; j < n; j++ {
            matrix[0][j] = 0
        }
    }
    if firstColZero {
        for i := 0; i < m; i++ {
            matrix[i][0] = 0
        }
    }
}
```

## 复杂度
- 时间：O(m×n)
- 空间：O(1)

## 记忆口诀
> 先记录第一行/列是否含零；用第一行/列标记需置零的行/列；置零内部；最后处理第一行/列。
