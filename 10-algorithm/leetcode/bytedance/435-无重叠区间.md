# 435. 无重叠区间

> LeetCode 链接：https://leetcode.cn/problems/non-overlapping-intervals/

## 题目
给定区间数组，找出需要移除的最少区间数，使剩余区间互不重叠。

## 最易理解的方法：贪心（按右端点排序）

**核心思路：**
按右端点升序排序，贪心选择右端点最小的不重叠区间，最大化保留数量，移除数 = 总数 - 保留数。

```
intervals = [[1,2],[2,3],[3,4],[1,3]]
按右端点排: [1,2],[2,3],[1,3],[3,4]

end=2(选[1,2])
[2,3]: 2>=2 不重叠，选，end=3
[1,3]: 1<3 重叠，跳过
[3,4]: 3>=3 不重叠，选，end=4

保留3个，移除1个
```

## Go 实现

```go
import "sort"

func eraseOverlapIntervals(intervals [][]int) int {
    sort.Slice(intervals, func(i, j int) bool {
        return intervals[i][1] < intervals[j][1]
    })
    end := intervals[0][1]
    keep := 1
    for i := 1; i < len(intervals); i++ {
        if intervals[i][0] >= end {
            keep++
            end = intervals[i][1]
        }
    }
    return len(intervals) - keep
}
```

## 复杂度
- 时间：O(n log n)
- 空间：O(1)

## 记忆口诀
> 按右端排序贪心；start>=当前end则选（更新end）；最终总数-保留数=移除数。
