# 234. 回文链表

> LeetCode 链接：https://leetcode.cn/problems/palindrome-linked-list/

## 题目
给定单链表的头节点，判断该链表是否为回文链表。要求 O(n) 时间 O(1) 空间。

## 最易理解的方法：找中点 + 反转后半段

**核心思路：**
1. 快慢指针找到中间节点
2. 反转后半段链表
3. 对比前半段和反转后的后半段
4. （可选）恢复链表

```
1 → 2 → 2 → 1
         ↑
      slow(中间)

后半段反转: 1 → 2 → null
前半段:     1 → 2 → ...
逐一对比: 1==1, 2==2 → 是回文
```

## Go 实现

```go
func isPalindrome(head *ListNode) bool {
    if head == nil || head.Next == nil {
        return true
    }
    // 第一步：找中间节点（slow停在前半段末尾）
    slow, fast := head, head
    for fast.Next != nil && fast.Next.Next != nil {
        slow = slow.Next
        fast = fast.Next.Next
    }
    // 第二步：反转后半段
    secondHalf := reverse(slow.Next)
    // 第三步：对比
    p1, p2 := head, secondHalf
    for p2 != nil {
        if p1.Val != p2.Val {
            return false
        }
        p1 = p1.Next
        p2 = p2.Next
    }
    return true
}

func reverse(head *ListNode) *ListNode {
    var prev *ListNode
    for head != nil {
        next := head.Next
        head.Next = prev
        prev = head
        head = next
    }
    return prev
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 快慢指针找中点；反转后半段；前后两段逐一比较；全匹配则回文。
