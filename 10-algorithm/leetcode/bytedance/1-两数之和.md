# 1. 两数之和

> LeetCode 链接：https://leetcode.cn/problems/two-sum/

## 题目
给定整数数组和目标值 target，返回两个数相加等于 target 的下标。

## 最易理解的方法：哈希表一次遍历

**核心思路：**
遍历数组时，对每个元素检查 `target - nums[i]` 是否已在哈希表中。若在，直接返回两个下标；若不在，把当前 `nums[i] → i` 存入哈希表。

```
nums = [2, 7, 11, 15], target = 9

i=0: 查找 9-2=7，不在map，存 {2:0}
i=1: 查找 9-7=2，在map(下标0)，返回 [0, 1]
```

**算法步骤：**
1. 建空哈希表 `m`
2. 遍历：若 `target - nums[i]` 在 `m` 中，返回 `[m[target-nums[i]], i]`
3. 否则 `m[nums[i]] = i`

## Go 实现

```go
func twoSum(nums []int, target int) []int {
    m := make(map[int]int) // value -> index
    for i, v := range nums {
        if j, ok := m[target-v]; ok {
            return []int{j, i}
        }
        m[v] = i
    }
    return nil
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> 哈希表存已见值；遍历时查 target-nums[i] 是否出现过。
