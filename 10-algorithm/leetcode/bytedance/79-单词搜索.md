# 79. 单词搜索

> LeetCode 链接：https://leetcode.cn/problems/word-search/

## 题目
给定 m×n 字符网格和单词 `word`，判断 word 是否存在于网格中（每个格子只能用一次，可上下左右移动）。

## 最易理解的方法：回溯 DFS

**核心思路：**
从每个格子出发尝试 DFS。递归时检查当前字符是否匹配，匹配则标记为已访问（改为特殊字符），继续向四个方向递归；回溯时恢复字符。若 index 等于 word 长度说明全部匹配。

```
board = [["A","B","C","E"],
         ["S","F","C","S"],
         ["A","D","E","E"]]
word = "ABCCED"

从(0,0)A开始:
A→(0,1)B→(0,2)C→(1,2)C→(2,2)E→(2,1)D ✓
```

## Go 实现

```go
func exist(board [][]byte, word string) bool {
    m, n := len(board), len(board[0])
    var dfs func(i, j, idx int) bool
    dfs = func(i, j, idx int) bool {
        if idx == len(word) {
            return true
        }
        if i < 0 || i >= m || j < 0 || j >= n || board[i][j] != word[idx] {
            return false
        }
        tmp := board[i][j]
        board[i][j] = '#' // 标记已访问
        found := dfs(i+1, j, idx+1) || dfs(i-1, j, idx+1) ||
            dfs(i, j+1, idx+1) || dfs(i, j-1, idx+1)
        board[i][j] = tmp // 回溯恢复
        return found
    }
    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            if dfs(i, j, 0) {
                return true
            }
        }
    }
    return false
}
```

## 复杂度
- 时间：O(m × n × 4^L)，L=word 长度
- 空间：O(L)

## 记忆口诀
> DFS：字符不匹配或越界或已访问则返回false；匹配则标记'#'继续四方向探索；回溯时恢复字符。
