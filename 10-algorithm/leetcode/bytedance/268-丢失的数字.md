# 268. 丢失的数字

> LeetCode 链接：https://leetcode.cn/problems/missing-number/

## 题目
给定含 n 个不同整数的数组（取值范围 0 到 n），找出缺少的那个数字。

## 最易理解的方法：数学（等差数列求和）

**核心思路：**
0 到 n 的和为 `n*(n+1)/2`，减去数组所有元素的和，差就是缺少的数字。

```
nums=[3,0,1]

期望和 = 3*4/2 = 6
实际和 = 3+0+1 = 4
缺少 = 6-4 = 2
```

## Go 实现

```go
func missingNumber(nums []int) int {
    n := len(nums)
    expected := n * (n + 1) / 2
    actual := 0
    for _, v := range nums {
        actual += v
    }
    return expected - actual
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 期望和=n*(n+1)/2；减去实际和即缺少的数。
