# 448. 找到所有数组中消失的数字

> LeetCode 链接：https://leetcode.cn/problems/find-all-numbers-disappeared-in-an-array/

## 题目
给定 n 个整数的数组（元素范围 1-n），找出所有在 1-n 中没有出现的数字，不能使用额外空间。

## 最易理解的方法：原地标记（取负）

**核心思路：**
遍历数组，将 `nums[|nums[i]|-1]` 位置的值取负（作为标记）。
第二遍遍历，值为正的位置 i 对应的数字 i+1 就是缺失的。

```
nums = [4,3,2,7,8,2,3,1]

标记: 位置3取负→[4,3,2,-7,...], 位置2→..., 位置1→..., 位置6→...
最终: [-4,-3,-2,-7,8,2,-3,-1]

位置4(值8>0)和位置5(值2>0) → 5,6是缺失的
```

## Go 实现

```go
func findDisappearedNumbers(nums []int) []int {
    n := len(nums)
    for _, v := range nums {
        idx := v
        if idx < 0 {
            idx = -idx
        }
        idx-- // 转为0-based下标
        if nums[idx] > 0 {
            nums[idx] = -nums[idx]
        }
    }
    var res []int
    for i := 0; i < n; i++ {
        if nums[i] > 0 {
            res = append(res, i+1)
        }
    }
    return res
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 原地标记：将对应位置取负；第二遍找未被取负（仍为正）的位置，i+1即缺失数。
