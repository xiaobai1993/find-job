# 287. 寻找重复数

> LeetCode 链接：https://leetcode.cn/problems/find-the-duplicate-number/

## 题目
给定包含 n+1 个整数的数组（整数范围 1 到 n），其中只有一个整数出现两次或更多次，找出这个重复的整数。要求 O(1) 空间，不修改数组。

## 最易理解的方法：Floyd 判圈（链表找环入口）

**核心思路：**
将数组视为链表：下标 i 的"下一个"是 `nums[i]`。因为有重复数字，这个"链表"一定有环，环入口就是重复的数字（两个位置的 next 指向同一个地方）。用 Floyd 算法找环入口（同 142 题）。

```
nums = [1, 3, 4, 2, 2]
下标:    0  1  2  3  4
链表: 0→1→3→2→4→2→4→2... (从0出发)

环入口=2 (重复数字)
```

## Go 实现

```go
func findDuplicate(nums []int) int {
    slow, fast := nums[0], nums[nums[0]]
    // 第一步：找相遇点
    for slow != fast {
        slow = nums[slow]
        fast = nums[nums[fast]]
    }
    // 第二步：找环入口
    slow = 0
    for slow != fast {
        slow = nums[slow]
        fast = nums[fast]
    }
    return slow
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 把数组当链表（nums[i]→nums[nums[i]]）；Floyd判圈找环入口；环入口即重复数字。
