# 40. 组合总和 II

> LeetCode 链接：https://leetcode.cn/problems/combination-sum-ii/

## 题目
给定候选数组 `candidates`（含重复），找出所有使数字和等于 `target` 的组合，每个数字只能用一次，结果不含重复组合。

## 最易理解的方法：排序 + 回溯去重

**核心思路：**
先排序，回溯时：
- 每次从 `start` 开始枚举
- 跳过同一层的重复元素：`if i > start && candidates[i] == candidates[i-1] → continue`（注意是 `i > start` 不是 `i > 0`，只在同层去重）

```
candidates = [1,1,2,5,6,7,10], target=8

同层跳过重复1: 只取第一个1
    [1] → [1,1] → [1,1,6] ✓
         → [1,2] → [1,2,5] ✓
         → [1,6] → [1,7] ✓
    [2] → [2,6] ✓
    ...
```

## Go 实现

```go
import "sort"

func combinationSum2(candidates []int, target int) [][]int {
    sort.Ints(candidates)
    var res [][]int
    var backtrack func(start, remain int, path []int)
    backtrack = func(start, remain int, path []int) {
        if remain == 0 {
            tmp := make([]int, len(path))
            copy(tmp, path)
            res = append(res, tmp)
            return
        }
        for i := start; i < len(candidates); i++ {
            if candidates[i] > remain {
                break // 已排序，后面更大
            }
            // 同层去重：跳过相同元素（i > start 保证不跳过不同层的相同值）
            if i > start && candidates[i] == candidates[i-1] {
                continue
            }
            path = append(path, candidates[i])
            backtrack(i+1, remain-candidates[i], path)
            path = path[:len(path)-1]
        }
    }
    backtrack(0, target, nil)
    return res
}
```

## 复杂度
- 时间：O(2^n)
- 空间：O(n)

## 记忆口诀
> 排序+回溯；同层去重：i>start且与前一个相同则跳过；每个数用一次：i+1传入。
