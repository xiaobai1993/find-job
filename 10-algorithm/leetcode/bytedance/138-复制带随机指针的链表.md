# 138. 复制带随机指针的链表

> LeetCode 链接：https://leetcode.cn/problems/copy-list-with-random-pointer/

## 题目
给定一个链表，每个节点除了 `next` 还有一个 `random` 指针（可以指向任意节点或 null）。深拷贝这个链表。

## 最易理解的方法：哈希表映射

**核心思路：**
第一遍：遍历原链表，为每个节点创建对应新节点，存入哈希表 `old→new`。
第二遍：再次遍历，用哈希表设置新节点的 next 和 random。

```
原: 1 → 2 → 3
    ↓       ↓
    3       1

哈希: {1→1', 2→2', 3→3'}
第二遍: 1'.next=2', 1'.random=3'
        2'.next=3', 2'.random=nil
        3'.next=nil, 3'.random=1'
```

## Go 实现

```go
func copyRandomList(head *Node) *Node {
    if head == nil {
        return nil
    }
    // 第一遍：建立原节点到新节点的映射
    nodeMap := make(map[*Node]*Node)
    cur := head
    for cur != nil {
        nodeMap[cur] = &Node{Val: cur.Val}
        cur = cur.Next
    }
    // 第二遍：设置 next 和 random
    cur = head
    for cur != nil {
        if cur.Next != nil {
            nodeMap[cur].Next = nodeMap[cur.Next]
        }
        if cur.Random != nil {
            nodeMap[cur].Random = nodeMap[cur.Random]
        }
        cur = cur.Next
    }
    return nodeMap[head]
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> 两遍：第一遍建 old→new 映射；第二遍用映射设 next 和 random。
