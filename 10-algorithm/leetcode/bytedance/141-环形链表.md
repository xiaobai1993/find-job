# 141. 环形链表

> LeetCode 链接：https://leetcode.cn/problems/linked-list-cycle/

## 题目
给定链表，判断链表中是否存在环。

## 最易理解的方法：快慢指针（Floyd 判圈）

**核心思路：**
快指针每次走 2 步，慢指针每次走 1 步。若有环，快指针最终会从后面追上慢指针（在环内相遇）；若无环，快指针会先到达 nil。

```
1 → 2 → 3 → 4 → 5
            ↑___↓  (4→5→4 成环)

slow: 1→2→3→4→5→4→5...
fast: 1→3→5→4→5→4...
在某处 slow==fast → 有环
```

## Go 实现

```go
func hasCycle(head *ListNode) bool {
    slow, fast := head, head
    for fast != nil && fast.Next != nil {
        slow = slow.Next
        fast = fast.Next.Next
        if slow == fast {
            return true
        }
    }
    return false
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 快慢指针；fast走两步，slow走一步；相遇则有环，fast到nil则无环。
