# 380. O(1) 时间插入、删除和获取随机元素

> LeetCode 链接：https://leetcode.cn/problems/insert-delete-getrandom-o1/

## 题目
实现 `RandomizedSet` 类，支持 `insert`、`remove` 和 `getRandom` 操作，平均时间复杂度 O(1)。

## 最易理解的方法：数组 + 哈希表

**核心思路：**
- 数组：存储所有元素，支持 O(1) 随机访问
- 哈希表：key → 数组下标，支持 O(1) 查找
- 删除技巧：将要删除的元素与数组末尾元素交换，然后删除末尾

```
insert(1): arr=[1], map={1:0}
insert(2): arr=[1,2], map={1:0,2:1}
remove(1): 末尾2换到位置0→arr=[2], map={2:0}; 删末尾
getRandom: random arr[0..len-1]
```

## Go 实现

```go
import "math/rand"

type RandomizedSet struct {
    arr []int
    idx map[int]int
}

func Constructor() RandomizedSet {
    return RandomizedSet{idx: make(map[int]int)}
}

func (rs *RandomizedSet) Insert(val int) bool {
    if _, ok := rs.idx[val]; ok {
        return false
    }
    rs.arr = append(rs.arr, val)
    rs.idx[val] = len(rs.arr) - 1
    return true
}

func (rs *RandomizedSet) Remove(val int) bool {
    pos, ok := rs.idx[val]
    if !ok {
        return false
    }
    last := rs.arr[len(rs.arr)-1]
    rs.arr[pos] = last
    rs.idx[last] = pos
    rs.arr = rs.arr[:len(rs.arr)-1]
    delete(rs.idx, val)
    return true
}

func (rs *RandomizedSet) GetRandom() int {
    return rs.arr[rand.Intn(len(rs.arr))]
}
```

## 复杂度
- Insert/Remove/GetRandom：O(1)
- 空间：O(n)

## 记忆口诀
> 数组+哈希表；删除：末尾换到被删位置→更新哈希→删末尾；随机=rand下标。
