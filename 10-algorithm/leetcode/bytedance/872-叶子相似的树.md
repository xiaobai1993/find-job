# 872. 叶子相似的树

> LeetCode 链接：https://leetcode.cn/problems/leaf-similar-trees/

## 题目
给定两棵二叉树，判断它们的叶值序列是否相同（叶值序列=从左到右所有叶子节点的值组成的序列）。

## 最易理解的方法：DFS 收集叶值序列

**核心思路：**
对两棵树分别 DFS 收集叶子节点值序列，比较是否相等。

```
tree1:   3          tree2:   3
        / \                 / \
       5   1               5   1
      / \   \             /   / \
     6   2   9           6   7   4
        / \
       7   4

叶值序列: [6,7,4,9] vs [6,7,4,9] → true
```

## Go 实现

```go
func leafSimilar(root1 *TreeNode, root2 *TreeNode) bool {
    var getLeaves func(node *TreeNode) []int
    getLeaves = func(node *TreeNode) []int {
        if node == nil { return nil }
        if node.Left == nil && node.Right == nil {
            return []int{node.Val}
        }
        return append(getLeaves(node.Left), getLeaves(node.Right)...)
    }
    l1, l2 := getLeaves(root1), getLeaves(root2)
    if len(l1) != len(l2) { return false }
    for i := range l1 {
        if l1[i] != l2[i] { return false }
    }
    return true
}
```

## 复杂度
- 时间：O(m+n)
- 空间：O(m+n)

## 记忆口诀
> DFS收集叶值序列；比较两棵树的叶值序列是否逐位相等。
