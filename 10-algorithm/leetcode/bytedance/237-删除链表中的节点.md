# 237. 删除链表中的节点

> LeetCode 链接：https://leetcode.cn/problems/delete-node-in-a-linked-list/

## 题目
给定单链表中的一个非末尾节点 node，删除该节点（只给了这个节点，没有给链表头）。

## 最易理解的方法：复制下一个节点的值

**核心思路：**
无法访问前驱节点，但可以用下一个节点的值覆盖当前节点，然后跳过下一个节点。

```
4 → 5 → 1 → 9，删除5

将下一节点1的值复制到5的位置：
4 → 1 → 1 → 9
然后跳过第二个1：
4 → 1 → 9
```

## Go 实现

```go
func deleteNode(node *ListNode) {
    node.Val = node.Next.Val
    node.Next = node.Next.Next
}
```

## 复杂度
- 时间：O(1)
- 空间：O(1)

## 记忆口诀
> 复制下一节点的值覆盖当前节点，然后跳过下一节点。
