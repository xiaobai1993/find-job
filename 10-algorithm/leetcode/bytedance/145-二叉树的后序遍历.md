# 145. 二叉树的后序遍历

> LeetCode 链接：https://leetcode.cn/problems/binary-tree-postorder-traversal/

## 题目
给定二叉树根节点，返回它的后序遍历（左→右→根）。要求迭代实现。

## 最易理解的方法：迭代（前序变形 + 翻转）

**核心思路：**
后序 = 左右根。
前序变形：根右左（改前序，先push左再push右），然后翻转结果得到左右根。

```
    1
   / \
  2   3

前序变形(根右左):
pop 1, push 2,3 → [1], 栈[2,3]
pop 3, push nil → [1,3]
pop 2 → [1,3,2]
翻转: [2,3,1]
```

## Go 实现

```go
func postorderTraversal(root *TreeNode) []int {
    if root == nil {
        return nil
    }
    var res []int
    stack := []*TreeNode{root}
    for len(stack) > 0 {
        node := stack[len(stack)-1]
        stack = stack[:len(stack)-1]
        res = append(res, node.Val)
        if node.Left != nil {
            stack = append(stack, node.Left) // 左先入
        }
        if node.Right != nil {
            stack = append(stack, node.Right) // 右后入（右先出）
        }
    }
    // 翻转
    for lo, hi := 0, len(res)-1; lo < hi; lo, hi = lo+1, hi-1 {
        res[lo], res[hi] = res[hi], res[lo]
    }
    return res
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> 前序变形(根右左)：push左再push右；翻转结果得后序(左右根)。
