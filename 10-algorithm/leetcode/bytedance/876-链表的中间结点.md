# 876. 链表的中间结点

> LeetCode 链接：https://leetcode.cn/problems/middle-of-the-linked-list/

## 题目
给定链表，返回中间节点（偶数长度时返回第二个中间节点）。

## 最易理解的方法：快慢指针

**核心思路：**
slow 每次走1步，fast 每次走2步，fast 到末尾时 slow 即为中间节点。

```
1 -> 2 -> 3 -> 4 -> 5

slow=1, fast=1
slow=2, fast=3
slow=3, fast=5 (fast.Next=nil)
返回slow=3
```

## Go 实现

```go
func middleNode(head *ListNode) *ListNode {
    slow, fast := head, head
    for fast != nil && fast.Next != nil {
        slow = slow.Next
        fast = fast.Next.Next
    }
    return slow
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 快慢指针：fast走两步，slow走一步；fast到末尾时slow是中间节点。
