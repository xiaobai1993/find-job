# 228. 汇总区间

> LeetCode 链接：https://leetcode.cn/problems/summary-ranges/

## 题目
给定有序无重复整数数组，将连续范围汇总为 "a->b" 或 "a" 格式。

## 最易理解的方法：双指针扫描

**核心思路：**
用 i 和 j 标记区间起点和终点，j 向后扩展直到不连续为止。

```
nums = [0,1,2,4,5,7]

i=0, j扩展: 0->1->2 (不连续停止) → "0->2"
i=3, j扩展: 4->5 (不连续停止)   → "4->5"
i=5, j扩展: 7 (末尾)            → "7"
```

## Go 实现

```go
import "strconv"

func summaryRanges(nums []int) []string {
    var res []string
    n := len(nums)
    for i := 0; i < n; {
        j := i
        for j+1 < n && nums[j+1] == nums[j]+1 {
            j++
        }
        if i == j {
            res = append(res, strconv.Itoa(nums[i]))
        } else {
            res = append(res, strconv.Itoa(nums[i])+"->"+strconv.Itoa(nums[j]))
        }
        i = j + 1
    }
    return res
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)（不计结果）

## 记忆口诀
> i为区间起点，j向后扩展连续段；单点输出"a"，多点输出"a->b"；i跳到j+1。
