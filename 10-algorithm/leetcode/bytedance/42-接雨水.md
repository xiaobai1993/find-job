# 42. 接雨水

> LeetCode 链接：https://leetcode.cn/problems/trapping-rain-water/

## 题目
给定非负整数数组 `height` 表示柱子高度，计算能接住的雨水总量。

## 最易理解的方法：双指针

**核心思路：**
每个位置能接的雨水 = `min(左边最高, 右边最高) - 自身高度`。用双指针从两端向中间收缩：哪边的 `maxHeight` 小，哪边就可以确定当前位置的雨水（因为另一边的最高值一定不低于当前边的最高值）。

```
height = [0,1,0,2,1,0,1,3,2,1,2,1]

双指针：left=0, right=11
- maxL=0, maxR=1
- left 边 maxL < maxR → left 能接水 = max(0,maxL)-height[left]
- 移动 left

最终累加所有位置的蓄水量
```

**算法步骤：**
1. `left=0`, `right=n-1`, `maxL=0`, `maxR=0`
2. 循环：若 `maxL <= maxR`，处理左指针（`ans += maxL - height[left]` 或更新 `maxL`），left++；否则处理右指针，right--
3. 返回 `ans`

## Go 实现

```go
func trap(height []int) int {
    left, right := 0, len(height)-1
    maxL, maxR := 0, 0
    ans := 0
    for left < right {
        if maxL <= maxR {
            if height[left] >= maxL {
                maxL = height[left] // 更新左侧最大高度
            } else {
                ans += maxL - height[left] // 可以蓄水
            }
            left++
        } else {
            if height[right] >= maxR {
                maxR = height[right]
            } else {
                ans += maxR - height[right]
            }
            right--
        }
    }
    return ans
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 双指针从两端收；哪边矮处理哪边；蓄水 = 当侧最高 - 自身高度。
