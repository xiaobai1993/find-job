# 232. 用栈实现队列

> LeetCode 链接：https://leetcode.cn/problems/implement-queue-using-stacks/

## 题目
仅使用两个栈实现先进先出队列，支持 push、pop、peek、empty 操作。均摊 O(1)。

## 最易理解的方法：输入栈 + 输出栈

**核心思路：**
- `inStack`：所有新元素压入这里
- `outStack`：pop/peek 时从这里取

当 `outStack` 为空时，将 `inStack` 所有元素倒入 `outStack`（顺序翻转，实现先进先出）。每次倒入均摊 O(1)。

```
push(1), push(2), push(3)
inStack:  [1,2,3]
outStack: []

pop() → outStack为空 → 倒入 → outStack:[3,2,1]
      → 弹出 1 → outStack:[3,2]

push(4)
inStack:  [4]
outStack: [3,2]

pop() → outStack非空 → 弹出 2
```

## Go 实现

```go
type MyQueue struct {
    in  []int
    out []int
}

func Constructor() MyQueue { return MyQueue{} }

func (q *MyQueue) Push(x int) {
    q.in = append(q.in, x)
}

func (q *MyQueue) transfer() {
    if len(q.out) == 0 {
        for len(q.in) > 0 {
            n := len(q.in)
            q.out = append(q.out, q.in[n-1])
            q.in = q.in[:n-1]
        }
    }
}

func (q *MyQueue) Pop() int {
    q.transfer()
    val := q.out[len(q.out)-1]
    q.out = q.out[:len(q.out)-1]
    return val
}

func (q *MyQueue) Peek() int {
    q.transfer()
    return q.out[len(q.out)-1]
}

func (q *MyQueue) Empty() bool {
    return len(q.in) == 0 && len(q.out) == 0
}
```

## 复杂度
- 时间：push O(1)，pop/peek 均摊 O(1)
- 空间：O(n)

## 记忆口诀
> 输入栈接收新元素；输出栈为空时才从输入栈批量倒入（翻转顺序）；pop/peek 从输出栈取。
