# 540. 有序数组中的单一元素

> LeetCode 链接：https://leetcode.cn/problems/single-element-in-a-sorted-array/

## 题目
有序数组中每个元素出现两次，只有一个元素出现一次，用 O(log n) 找到它。

## 最易理解的方法：二分查找

**核心思路：**
在单一元素左侧，偶数下标的元素等于其右邻（nums[mid]==nums[mid+1]）；右侧则相反。利用此规律二分。

```
[1,1,2,3,3,4,4,8,8]
 0 1 2 3 4 5 6 7 8

mid=4: nums[4]=3, nums[5]=4 → 不等 → 单一元素在左侧(含mid)
mid=2: nums[2]=2, nums[3]=3 → 不等 → 在左侧
mid=1: nums[1]=1, nums[2]=2 → 不等 → l=r=2 → 返回2
```

## Go 实现

```go
func singleNonDuplicate(nums []int) int {
    lo, hi := 0, len(nums)-1
    for lo < hi {
        mid := lo + (hi-lo)/2
        if mid%2 == 1 { mid-- } // 保证mid为偶数
        if nums[mid] == nums[mid+1] {
            lo = mid + 2 // 单一元素在右侧
        } else {
            hi = mid    // 单一元素在左侧（含mid）
        }
    }
    return nums[lo]
}
```

## 复杂度
- 时间：O(log n)
- 空间：O(1)

## 记忆口诀
> 二分；mid对齐偶数；nums[mid]==nums[mid+1]则单一在右(lo=mid+2)，否则在左(hi=mid)。
