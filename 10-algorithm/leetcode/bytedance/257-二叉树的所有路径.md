# 257. 二叉树的所有路径

> LeetCode 链接：https://leetcode.cn/problems/binary-tree-paths/

## 题目
给定二叉树，返回所有从根到叶的路径（字符串格式，用 "->" 分隔）。

## 最易理解的方法：DFS 回溯

**核心思路：**
DFS 带路径字符串，到达叶节点时将路径加入结果。

```
    1
   / \
  2   3
   \
    5

路径: "1->2->5", "1->3"
```

## Go 实现

```go
import "strconv"

func binaryTreePaths(root *TreeNode) []string {
    var res []string
    var dfs func(node *TreeNode, path string)
    dfs = func(node *TreeNode, path string) {
        if node.Left == nil && node.Right == nil {
            res = append(res, path)
            return
        }
        if node.Left != nil {
            dfs(node.Left, path+"->"+strconv.Itoa(node.Left.Val))
        }
        if node.Right != nil {
            dfs(node.Right, path+"->"+strconv.Itoa(node.Right.Val))
        }
    }
    if root != nil {
        dfs(root, strconv.Itoa(root.Val))
    }
    return res
}
```

## 复杂度
- 时间：O(n²)（字符串拼接）
- 空间：O(n²)

## 记忆口诀
> DFS传路径字符串；叶节点收集结果；非叶节点拼接"->"继续递归。
