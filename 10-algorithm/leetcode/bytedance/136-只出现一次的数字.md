# 136. 只出现一次的数字

> LeetCode 链接：https://leetcode.cn/problems/single-number/

## 题目
给定整数数组，除某个元素只出现一次外，其余每个元素均出现两次。找出那个只出现一次的元素。要求 O(n) 时间，O(1) 空间。

## 最易理解的方法：异或

**核心思路：**
`a ^ a = 0`，`a ^ 0 = a`，异或满足交换律和结合律。
所有元素异或，相同的两两抵消，最终剩下只出现一次的元素。

```
[4, 1, 2, 1, 2]
4 ^ 1 ^ 2 ^ 1 ^ 2
= 4 ^ (1^1) ^ (2^2)
= 4 ^ 0 ^ 0
= 4
```

## Go 实现

```go
func singleNumber(nums []int) int {
    res := 0
    for _, n := range nums {
        res ^= n
    }
    return res
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 全部异或；相同的两两消去；剩下就是只出现一次的数。
