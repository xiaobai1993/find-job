# 85. 最大矩形

> LeetCode 链接：https://leetcode.cn/problems/maximal-rectangle/

## 题目
给定只包含 `'0'` 和 `'1'` 的二维矩阵，找到只包含 `'1'` 的最大矩形，返回其面积。

## 最易理解的方法：逐行转化为柱状图 + 单调栈（84题）

**核心思路：**
对矩阵每一行，把它看成柱状图的底部：`height[j]` = 以当前行为底，向上连续 `'1'` 的数量（遇到 `'0'` 则高度归 0）。然后对每行的柱状图应用 84 题的最大矩形面积算法。

```
matrix:
1 0 1 0 0      height行1: [1,0,1,0,0]  → 最大面积=1
1 0 1 1 1      height行2: [2,0,2,1,1]  → 最大面积=3
1 1 1 1 1      height行3: [3,1,3,2,2]  → 最大面积=6  ← 最大
1 0 0 1 0      height行4: [4,0,0,3,0]  → 最大面积=4
```

## Go 实现

```go
func maximalRectangle(matrix [][]byte) int {
    if len(matrix) == 0 {
        return 0
    }
    n := len(matrix[0])
    heights := make([]int, n)
    ans := 0
    for _, row := range matrix {
        // 更新高度
        for j := 0; j < n; j++ {
            if row[j] == '1' {
                heights[j]++
            } else {
                heights[j] = 0
            }
        }
        // 对当前高度数组求最大矩形
        area := largestInHistogram(heights)
        if area > ans {
            ans = area
        }
    }
    return ans
}

func largestInHistogram(heights []int) int {
    h := make([]int, len(heights)+2)
    copy(h[1:], heights)
    stack := []int{0}
    ans := 0
    for i := 1; i < len(h); i++ {
        for h[i] < h[stack[len(stack)-1]] {
            height := h[stack[len(stack)-1]]
            stack = stack[:len(stack)-1]
            width := i - stack[len(stack)-1] - 1
            if height*width > ans {
                ans = height * width
            }
        }
        stack = append(stack, i)
    }
    return ans
}
```

## 复杂度
- 时间：O(m × n)
- 空间：O(n)

## 记忆口诀
> 逐行维护柱状图高度（遇0归零，遇1+1）；每行用单调栈求最大矩形面积（84题）。
