# 674. 最长连续递增序列

> LeetCode 链接：https://leetcode.cn/problems/longest-continuous-increasing-subsequence/

## 题目
给定整数数组，找最长连续递增子序列的长度。

## 最易理解的方法：线性扫描

**核心思路：**
遍历时比较相邻元素，递增则延伸当前序列长度，否则重置为1。

```
nums = [1,3,5,4,7]

1: cur=1
3>1: cur=2
5>3: cur=3
4<5: cur=1, max=3
7>4: cur=2

最长: 3
```

## Go 实现

```go
func findLengthOfLCIS(nums []int) int {
    if len(nums) == 0 { return 0 }
    res, cur := 1, 1
    for i := 1; i < len(nums); i++ {
        if nums[i] > nums[i-1] {
            cur++
            if cur > res { res = cur }
        } else {
            cur = 1
        }
    }
    return res
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 线性扫描；递增则cur++更新max；否则cur重置为1。
