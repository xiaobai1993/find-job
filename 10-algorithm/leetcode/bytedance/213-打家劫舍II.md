# 213. 打家劫舍 II

> LeetCode 链接：https://leetcode.cn/problems/house-robber-ii/

## 题目
房子排成一圈，相邻房子不能同时偷。求能偷到的最多金额。（和198题相比，首尾相邻）

## 最易理解的方法：两次线性 DP

**核心思路：**
环形约束 = 首尾不能同时取。
拆成两个线性问题：
1. 不取最后一个房子：对 `nums[0..n-2]` 做打家劫舍
2. 不取第一个房子：对 `nums[1..n-1]` 做打家劫舍
两个结果取最大值。

```
nums = [2,3,2]

方案1 (不取末位): [2,3] → 3
方案2 (不取首位): [3,2] → 3
答案 = max(3,3) = 3
```

## Go 实现

```go
func rob(nums []int) int {
    n := len(nums)
    if n == 1 {
        return nums[0]
    }
    // 线性打家劫舍
    robLinear := func(arr []int) int {
        prev2, prev1 := 0, 0
        for _, v := range arr {
            prev2, prev1 = prev1, max(prev1, prev2+v)
        }
        return prev1
    }
    a := robLinear(nums[:n-1]) // 不包含最后一个
    b := robLinear(nums[1:])   // 不包含第一个
    return max(a, b)
}

func max(a, b int) int {
    if a > b {
        return a
    }
    return b
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 环形=拆成两个线性：[0,n-2]和[1,n-1]各做一次打家劫舍，取最大值。
