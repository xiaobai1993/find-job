# 118. 杨辉三角

> LeetCode 链接：https://leetcode.cn/problems/pascals-triangle/

## 题目
给定行数 numRows，生成前 numRows 行杨辉三角。

## 最易理解的方法：逐行生成

**核心思路：**
每行首尾为1，中间元素为上一行相邻两个元素之和。

```
numRows = 5

[1]
[1,1]
[1,2,1]
[1,3,3,1]
[1,4,6,4,1]
```

## Go 实现

```go
func generate(numRows int) [][]int {
    res := [][]int{}
    for i := 0; i < numRows; i++ {
        row := make([]int, i+1)
        row[0], row[i] = 1, 1
        for j := 1; j < i; j++ {
            row[j] = res[i-1][j-1] + res[i-1][j]
        }
        res = append(res, row)
    }
    return res
}
```

## 复杂度
- 时间：O(n²)
- 空间：O(n²)

## 记忆口诀
> 每行首尾为1；中间元素=上一行左+右；逐行构建。
