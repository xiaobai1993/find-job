# 22. 括号生成

> LeetCode 链接：https://leetcode.cn/problems/generate-parentheses/

## 题目
数字 n 代表生成括号的对数，设计函数生成所有可能的并且有效的括号组合。

## 最易理解的方法：回溯 DFS

**核心思路：**
在任意时刻，左括号数 `open` 和右括号数 `close` 满足：
- 只要 `open < n`，就可以加 `(`
- 只要 `close < open`，就可以加 `)`（右括号不能多于左括号）
- 当 `open == close == n` 时，得到一个合法结果

```
n=2 的决策树：
            ""
           /
          "("
         /   \
       "(("  "()"
       /       \
     "(()"    "()(
     /            \
   "(())"       "()()"  ← 结果
```

**算法步骤：**
1. dfs(path, open, close)
2. 若 `open < n`：加 `(`，递归 dfs(path+"(", open+1, close)
3. 若 `close < open`：加 `)`，递归 dfs(path+")", open, close+1)
4. 若 `open == n && close == n`：加入结果集

## Go 实现

```go
func generateParenthesis(n int) []string {
    var res []string
    var dfs func(path string, open, close int)
    dfs = func(path string, open, close int) {
        if open == n && close == n {
            res = append(res, path)
            return
        }
        if open < n {
            dfs(path+"(", open+1, close)
        }
        if close < open {
            dfs(path+")", open, close+1)
        }
    }
    dfs("", 0, 0)
    return res
}
```

## 复杂度
- 时间：O(4^n / √n)（卡特兰数）
- 空间：O(n)（递归深度）

## 记忆口诀
> open < n 加左；close < open 加右；两者都满 n 则入结果。
