# 451. 根据字符出现频率排序

> LeetCode 链接：https://leetcode.cn/problems/sort-characters-by-frequency/

## 题目
给定字符串，按字符出现频率从高到低重新构造字符串。

## 最易理解的方法：频率统计 + 桶排序

**核心思路：**
统计各字符频率，用长度 n+1 的桶（桶下标为频率）存放字符，从高频到低频输出。

```
s = "tree"
cnt: t=1, r=1, e=2

桶[2]=[e], 桶[1]=[t,r]
输出: "eetr"
```

## Go 实现

```go
import "strings"

func frequencySort(s string) string {
    cnt := make(map[byte]int)
    for i := 0; i < len(s); i++ {
        cnt[s[i]]++
    }
    buckets := make([][]byte, len(s)+1)
    for c, freq := range cnt {
        buckets[freq] = append(buckets[freq], c)
    }
    var sb strings.Builder
    for i := len(buckets) - 1; i >= 1; i-- {
        for _, c := range buckets[i] {
            for j := 0; j < i; j++ {
                sb.WriteByte(c)
            }
        }
    }
    return sb.String()
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> 统计频率→桶排序（桶下标=频率）→从大桶到小桶输出。
