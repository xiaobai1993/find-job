# 696. 计数二进制子串

> LeetCode 链接：https://leetcode.cn/problems/count-binary-substrings/

## 题目
给定二进制字符串，统计具有相同数量0和1且所有0和1连续的子串个数。

## 最易理解的方法：统计相邻0/1组长度

**核心思路：**
记录相邻两段连续相同字符的长度 pre 和 cur，`min(pre, cur)` 即为以当前位结尾的满足条件子串数。

```
s = "00110011"

分段: 00 | 11 | 00 | 11
相邻对: (2,2),(2,2),(2,2)
每对贡献: min(2,2)=2 → 总共6

但实际答案=6 ✓
```

## Go 实现

```go
func countBinarySubstrings(s string) int {
    pre, cur, res := 0, 1, 0
    for i := 1; i < len(s); i++ {
        if s[i] == s[i-1] {
            cur++
        } else {
            pre = cur
            cur = 1
        }
        if pre >= cur { res++ }
    }
    return res
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 维护pre(上组长)和cur(当前组长)；字符变化时pre=cur,cur=1；pre>=cur时res++。
