# 739. 每日温度

> LeetCode 链接：https://leetcode.cn/problems/daily-temperatures/

## 题目
给定每日温度数组 `temperatures`，返回一个数组 `answer`，`answer[i]` 为第 i 天后几天才能出现更高温度，若无则为 0。

## 最易理解的方法：单调栈

**核心思路：**
维护一个**单调递减栈**（存下标）。遍历温度数组，当当前温度大于栈顶下标对应的温度时，栈顶出栈，其答案即为 `当前下标 - 栈顶下标`。将当前下标入栈。

```
temperatures = [73, 74, 75, 71, 69, 72, 76, 73]
answer       = [1,   1,  4,  2,  1,  1,  0,  0]

遍历时维护递减栈：
i=0: push 0 → [0]
i=1: 74>73 → pop 0, ans[0]=1-0=1 → push 1 → [1]
i=2: 75>74 → pop 1, ans[1]=2-1=1 → push 2 → [2]
i=3: 71<75 → push 3 → [2,3]
i=4: 69<71 → push 4 → [2,3,4]
i=5: 72>69 → pop 4, ans[4]=5-4=1
         72>71 → pop 3, ans[3]=5-3=2
         72<75 → push 5 → [2,5]
i=6: 76>72 → pop 5, ans[5]=1; 76>75 → pop 2, ans[2]=4 → push 6 → [6]
i=7: 73<76 → push 7 → [6,7]
```

## Go 实现

```go
func dailyTemperatures(temperatures []int) []int {
    n := len(temperatures)
    ans := make([]int, n)
    stack := []int{} // 存下标，栈底温度大于栈顶
    for i := 0; i < n; i++ {
        for len(stack) > 0 && temperatures[i] > temperatures[stack[len(stack)-1]] {
            top := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            ans[top] = i - top
        }
        stack = append(stack, i)
    }
    return ans
}
```

## 复杂度
- 时间：O(n)（每个元素最多入栈出栈一次）
- 空间：O(n)

## 记忆口诀
> 单调递减栈存下标；当前温度比栈顶大时出栈并记录答案（下标差）；最后剩余元素答案为0。
