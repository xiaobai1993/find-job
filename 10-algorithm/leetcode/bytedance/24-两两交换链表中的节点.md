# 24. 两两交换链表中的节点

> LeetCode 链接：https://leetcode.cn/problems/swap-nodes-in-pairs/

## 题目
给定链表，两两交换其中相邻的节点并返回交换后的头节点（不能修改节点值，只能改指针）。

## 最易理解的方法：迭代 + 哑节点

**核心思路：**
用哑节点简化头节点处理。每次处理 `prev → a → b → rest`，交换后变为 `prev → b → a → rest`，然后 `prev` 移到 `a`（交换后的第二个节点）继续。

```
dummy → 1 → 2 → 3 → 4

cur=dummy, a=1, b=2:
  dummy → 2 → 1 → 3 → 4
  cur = 1

cur=1, a=3, b=4:
  1 → 4 → 3 → nil
  cur = 3

结果: dummy → 2 → 1 → 4 → 3
```

## Go 实现

```go
func swapPairs(head *ListNode) *ListNode {
    dummy := &ListNode{Next: head}
    prev := dummy
    for prev.Next != nil && prev.Next.Next != nil {
        a := prev.Next
        b := prev.Next.Next
        // 交换
        prev.Next = b
        a.Next = b.Next
        b.Next = a
        // prev 移到 a（现在 a 在后面）
        prev = a
    }
    return dummy.Next
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> dummy哑节点；每次操作3个指针：prev→b→a→rest；prev前进到a继续。
