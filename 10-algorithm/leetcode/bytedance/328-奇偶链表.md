# 328. 奇偶链表

> LeetCode 链接：https://leetcode.cn/problems/odd-even-linked-list/

## 题目
给定单链表，将奇数位节点放前面，偶数位节点放后面（按索引奇偶，从1开始）。要求 O(1) 空间。

## 最易理解的方法：双指针分离奇偶链

**核心思路：**
用两个指针分别维护奇链和偶链，交替连接，最后将偶链拼接到奇链末尾。

```
1 → 2 → 3 → 4 → 5

odd: 1 → 3 → 5
even: 2 → 4

odd尾接even头: 1→3→5→2→4
```

## Go 实现

```go
func oddEvenList(head *ListNode) *ListNode {
    if head == nil {
        return nil
    }
    odd := head           // 奇链头
    even := head.Next     // 偶链头
    evenHead := even      // 保存偶链头，最后拼接用
    for even != nil && even.Next != nil {
        odd.Next = even.Next  // 奇指针跳过偶节点
        odd = odd.Next
        even.Next = odd.Next  // 偶指针跳过奇节点
        even = even.Next
    }
    odd.Next = evenHead       // 奇链末尾接偶链头
    return head
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 奇偶双指针交替前进；循环条件 even!=nil && even.Next!=nil；最后奇尾接偶头。
