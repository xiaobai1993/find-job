# 27. 移除元素

> LeetCode 链接：https://leetcode.cn/problems/remove-element/

## 题目
给定数组和值 val，原地移除所有等于 val 的元素，返回不等于 val 的元素个数。

## 最易理解的方法：双指针

**核心思路：**
快指针遍历所有元素，遇到不等于 val 的元素就写入慢指针位置。

```
nums=[3,2,2,3], val=3

fast=0(3=val): 跳过
fast=1(2≠val): nums[slow=0]=2, slow=1
fast=2(2≠val): nums[slow=1]=2, slow=2
fast=3(3=val): 跳过

结果: [2,2,...], 返回2
```

## Go 实现

```go
func removeElement(nums []int, val int) int {
    slow := 0
    for _, v := range nums {
        if v != val {
            nums[slow] = v
            slow++
        }
    }
    return slow
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 快慢指针；不等于val的写入slow位置；返回slow值。
