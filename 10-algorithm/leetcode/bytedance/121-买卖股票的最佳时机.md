# 121. 买卖股票的最佳时机

> LeetCode 链接：https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/

## 题目
给定股票每天价格，只能买卖一次，求最大利润。

## 最易理解的方法：一次遍历

**核心思路：**
维护历史最低买入价 `minPrice`。遍历每天价格，尝试以当天卖出，利润 = `price - minPrice`，更新最大利润。遇到更低价格则更新 `minPrice`。

```
prices = [7,1,5,3,6,4]

遍历：
 7: minPrice=7, profit=0
 1: minPrice=1, profit=0   ← 更新最低价
 5: minPrice=1, profit=4
 3: minPrice=1, profit=4
 6: minPrice=1, profit=5   ← 最大利润
 4: minPrice=1, profit=5

答案：5
```

**算法步骤：**
1. `minPrice = 无穷大`，`maxProfit = 0`
2. 遍历每个价格：`maxProfit = max(maxProfit, price - minPrice)`，`minPrice = min(minPrice, price)`
3. 返回 `maxProfit`

## Go 实现

```go
func maxProfit(prices []int) int {
    minPrice := math.MaxInt64
    maxProfit := 0
    for _, price := range prices {
        if price < minPrice {
            minPrice = price          // 更新最低买入价
        } else if price-minPrice > maxProfit {
            maxProfit = price - minPrice // 更新最大利润
        }
    }
    return maxProfit
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 一遍扫：记最低价，每天算利润取最大。
