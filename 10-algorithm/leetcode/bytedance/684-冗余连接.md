# 684. 冗余连接

> LeetCode 链接：https://leetcode.cn/problems/redundant-connection/

## 题目
给定 n 个节点的树加上一条附加边的图，找到并删除的那条附加边（使图仍是树，有多个答案时返回最后出现的那条）。

## 最易理解的方法：并查集

**核心思路：**
依次处理每条边，用并查集检测是否形成环：
- 若两个端点已在同一集合：这条边就是冗余边
- 否则合并两个端点

```
edges = [[1,2],[1,3],[2,3]]

处理[1,2]: find(1)≠find(2)，合并
处理[1,3]: find(1)≠find(3)，合并
处理[2,3]: find(2)==find(3)，冗余！返回[2,3]
```

## Go 实现

```go
func findRedundantConnection(edges [][]int) []int {
    n := len(edges)
    parent := make([]int, n+1)
    for i := range parent {
        parent[i] = i
    }
    var find func(x int) int
    find = func(x int) int {
        if parent[x] != x {
            parent[x] = find(parent[x])
        }
        return parent[x]
    }
    for _, edge := range edges {
        u, v := edge[0], edge[1]
        pu, pv := find(u), find(v)
        if pu == pv {
            return edge
        }
        parent[pu] = pv
    }
    return nil
}
```

## 复杂度
- 时间：O(n × α(n))
- 空间：O(n)

## 记忆口诀
> 并查集：依次处理边；两端点同一集合则是冗余边；否则合并。
