# 338. 比特位计数

> LeetCode 链接：https://leetcode.cn/problems/counting-bits/

## 题目
给定整数 n，返回数组 `ans`，其中 `ans[i]` 是 i 在二进制中 1 的个数。要求 O(n) 时间，O(n) 空间。

## 最易理解的方法：动态规划（最低有效位）

**核心思路：**
- 若 i 为偶数：二进制末位为0，`dp[i] = dp[i/2]`（右移一位1的个数不变）
- 若 i 为奇数：二进制末位为1，`dp[i] = dp[i/2] + 1`

统一写法：`dp[i] = dp[i>>1] + (i&1)`

```
i:   0  1  2  3  4  5  6  7
dp:  0  1  1  2  1  2  2  3

dp[4]=dp[2]+0=1 (4=100, 2=10)
dp[5]=dp[2]+1=2 (5=101)
dp[6]=dp[3]+0=2 (6=110)
dp[7]=dp[3]+1=3 (7=111)
```

## Go 实现

```go
func countBits(n int) []int {
    dp := make([]int, n+1)
    for i := 1; i <= n; i++ {
        dp[i] = dp[i>>1] + (i & 1)
    }
    return dp
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> dp[i] = dp[i>>1] + (i&1)；右移一位的1的个数 + 末位是否为1。
