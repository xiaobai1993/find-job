# 14. 最长公共前缀

> LeetCode 链接：https://leetcode.cn/problems/longest-common-prefix/

## 题目
编写函数求字符串数组中所有字符串的最长公共前缀。若不存在则返回 ""。

## 最易理解的方法：纵向扫描

**核心思路：**
以第一个字符串为基准，逐个字符对比所有字符串的同位置字符，遇到不匹配或越界就停止。

```
["flower","flow","flight"]

位置0: f=f=f ✓
位置1: l=l=l ✓
位置2: o=o=i ✗ → 停止

公共前缀="fl"
```

## Go 实现

```go
func longestCommonPrefix(strs []string) string {
    if len(strs) == 0 {
        return ""
    }
    for i := 0; i < len(strs[0]); i++ {
        c := strs[0][i]
        for _, s := range strs[1:] {
            if i >= len(s) || s[i] != c {
                return strs[0][:i]
            }
        }
    }
    return strs[0]
}
```

## 复杂度
- 时间：O(m × n)，m 为最短字符串长度，n 为字符串数量
- 空间：O(1)

## 记忆口诀
> 以第一个字符串为基准纵向扫描；某个字符串越界或字符不匹配则截断返回。
