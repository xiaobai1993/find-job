# 316. 去除重复字母

> LeetCode 链接：https://leetcode.cn/problems/remove-duplicate-letters/

## 题目
给定字符串，去除重复字母使每个字母只出现一次，且返回字典序最小的结果（需保持字符顺序）。

## 最易理解的方法：单调栈 + 计数

**核心思路：**
用单调递增栈维护结果。遍历每个字符：
- 若字符已在栈中，跳过
- 否则：只要栈顶字母 > 当前字母 且 栈顶字母在后面还有（count>0），则弹出栈顶
- 将当前字母压栈

```
s = "bcabc"

count: {b:2, c:2, a:1}
inStack: {}

b: stack=[b], inStack={b}
c: stack=[b,c], inStack={b,c}
a: c>a且count[c]=1>0→弹c; b>a且count[b]=1>0→弹b; push a → stack=[a]
b: b不在栈中, push b → stack=[a,b]
c: c不在栈中, push c → stack=[a,b,c]

答案="abc"
```

## Go 实现

```go
func removeDuplicateLetters(s string) string {
    count := [26]int{}
    for _, c := range s {
        count[c-'a']++
    }
    inStack := [26]bool{}
    stack := []byte{}
    for i := 0; i < len(s); i++ {
        c := s[i]
        count[c-'a']--
        if inStack[c-'a'] {
            continue
        }
        for len(stack) > 0 && stack[len(stack)-1] > c && count[stack[len(stack)-1]-'a'] > 0 {
            inStack[stack[len(stack)-1]-'a'] = false
            stack = stack[:len(stack)-1]
        }
        stack = append(stack, c)
        inStack[c-'a'] = true
    }
    return string(stack)
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)（26字母）

## 记忆口诀
> 单调递增栈；已在栈中跳过；栈顶>当前且后面还有则弹出；确保字典序最小。
