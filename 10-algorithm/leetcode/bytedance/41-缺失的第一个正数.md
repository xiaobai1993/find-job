# 41. 缺失的第一个正数

> LeetCode 链接：https://leetcode.cn/problems/first-missing-positive/

## 题目
给定未排序整数数组，找出未出现的最小正整数。要求 O(n) 时间、O(1) 空间。

## 最易理解的方法：原地哈希（数组当哈希表）

**核心思路：**
答案必在 `[1, n+1]` 范围内（n 个数最多覆盖 1..n）。将 `nums[i]` 放到对应的"正确位置" `nums[nums[i]-1]`，相当于用数组本身当哈希表。最后扫描，第一个 `nums[i] != i+1` 的位置，`i+1` 就是答案。

```
nums = [3, 4, -1, 1]

整理后（把1放到[0]，3放到[2]，4放到[3]）：
nums = [1, -1, 3, 4]

扫描：
  nums[0]=1 == 0+1 ✓
  nums[1]=-1 != 1+1  → 答案 = 2
```

**算法步骤：**
1. 遍历数组，若 `1 <= nums[i] <= n` 且 `nums[i] != nums[nums[i]-1]`，交换到正确位置
2. 再次扫描，找第一个 `nums[i] != i+1` 的位置，返回 `i+1`
3. 否则返回 `n+1`

## Go 实现

```go
func firstMissingPositive(nums []int) int {
    n := len(nums)
    // 将每个数放到"应该在"的位置
    for i := 0; i < n; i++ {
        for nums[i] > 0 && nums[i] <= n && nums[nums[i]-1] != nums[i] {
            nums[i], nums[nums[i]-1] = nums[nums[i]-1], nums[i]
        }
    }
    // 找第一个不在正确位置的
    for i := 0; i < n; i++ {
        if nums[i] != i+1 {
            return i + 1
        }
    }
    return n + 1
}
```

## 复杂度
- 时间：O(n)（每个元素最多交换一次）
- 空间：O(1)
