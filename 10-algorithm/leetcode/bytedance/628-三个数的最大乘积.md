# 628. 三个数的最大乘积

> LeetCode 链接：https://leetcode.cn/problems/maximum-product-of-three-numbers/

## 题目
给定整数数组，找三个数使其乘积最大，返回最大乘积。

## 最易理解的方法：找最大三个和最小两个

**核心思路：**
最大乘积要么是"三个最大值之积"，要么是"两个最小负数 × 最大正数"。

```
nums = [-100,-98,1,2,3]

最大三个: 1,2,3 → 6
最小两个×最大一个: -100×-98×3 = 29400

取max: 29400
```

## Go 实现

```go
import "sort"

func maximumProduct(nums []int) int {
    sort.Ints(nums)
    n := len(nums)
    // 三最大 vs 两最小×最大
    a := nums[n-1] * nums[n-2] * nums[n-3]
    b := nums[0] * nums[1] * nums[n-1]
    if a > b { return a }
    return b
}
```

## 复杂度
- 时间：O(n log n)
- 空间：O(1)

## 记忆口诀
> 排序后取两种情况最大：末三个之积 vs 首两个×末一个。
