# 66. 加一

> LeetCode 链接：https://leetcode.cn/problems/plus-one/

## 题目
给定由整数组成的非空数组（表示一个非负整数），在最后一位加 1 后返回。

## 最易理解的方法：从末位处理进位

**核心思路：**
从最后一位开始，若当前位 < 9 则直接加一返回；若等于 9 则置 0 并继续进位。
若全是 9（如 999），则在最前面加一个 1。

```
[1,2,3] → [1,2,4]
[1,2,9] → [1,3,0]
[9,9,9] → [1,0,0,0]
```

## Go 实现

```go
func plusOne(digits []int) []int {
    for i := len(digits) - 1; i >= 0; i-- {
        if digits[i] < 9 {
            digits[i]++
            return digits
        }
        digits[i] = 0
    }
    // 全是9的情况
    return append([]int{1}, digits...)
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)（全是9时 O(n)）

## 记忆口诀
> 从末位处理进位；不是9则+1返回；是9则置0继续；全是9则前面加1。
