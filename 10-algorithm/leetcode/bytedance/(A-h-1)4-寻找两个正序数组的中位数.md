# 4. 寻找两个正序数组的中位数

> LeetCode 链接：https://leetcode.cn/problems/median-of-two-sorted-arrays/

## 题目
给定两个正序数组 `nums1` 和 `nums2`，找出两个数组合并后的中位数。时间复杂度 O(log(m+n))。

## 方法一：合并后排序（简单易懂，O(m+n)）

```go
func findMedianSortedArrays(nums1 []int, nums2 []int) float64 {
    merged := make([]int, 0, len(nums1)+len(nums2))
    i, j := 0, 0
    for i < len(nums1) && j < len(nums2) {
        if nums1[i] <= nums2[j] {
            merged = append(merged, nums1[i])
            i++
        } else {
            merged = append(merged, nums2[j])
            j++
        }
    }
    merged = append(merged, nums1[i:]...)
    merged = append(merged, nums2[j:]...)
    n := len(merged)
    if n%2 == 1 {
        return float64(merged[n/2])
    }
    return float64(merged[n/2-1]+merged[n/2]) / 2.0
}
```

## 方法二：二分查找（O(log(min(m,n)))）

**核心思路：**
在较小数组上二分找切割点，将两个数组各切成左右两半，保证：
- 左半部分总元素数 = 右半部分总元素数（或左多1个）
- 左半部分最大值 ≤ 右半部分最小值

```go
func findMedianSortedArrays(nums1 []int, nums2 []int) float64 {
    if len(nums1) > len(nums2) {
        return findMedianSortedArrays(nums2, nums1) // 保证 nums1 更短
    }
    m, n := len(nums1), len(nums2)
    lo, hi := 0, m
    for lo <= hi {
        i := (lo + hi) / 2     // nums1 左半取 i 个
        j := (m+n+1)/2 - i     // nums2 左半取 j 个
        maxL1 := math.MinInt64
        if i > 0 { maxL1 = nums1[i-1] }
        minR1 := math.MaxInt64
        if i < m { minR1 = nums1[i] }
        maxL2 := math.MinInt64
        if j > 0 { maxL2 = nums2[j-1] }
        minR2 := math.MaxInt64
        if j < n { minR2 = nums2[j] }

        if maxL1 <= minR2 && maxL2 <= minR1 {
            if (m+n)%2 == 1 {
                if maxL1 > maxL2 { return float64(maxL1) }
                return float64(maxL2)
            }
            left := maxL1
            if maxL2 > left { left = maxL2 }
            right := minR1
            if minR2 < right { right = minR2 }
            return float64(left+right) / 2.0
        } else if maxL1 > minR2 {
            hi = i - 1
        } else {
            lo = i + 1
        }
    }
    return 0
}
```

## 复杂度
- 合并法：O(m+n)
- 二分法：O(log(min(m,n)))
