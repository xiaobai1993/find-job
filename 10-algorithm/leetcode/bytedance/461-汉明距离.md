# 461. 汉明距离

> LeetCode 链接：https://leetcode.cn/problems/hamming-distance/

## 题目
给定两个整数，计算它们二进制表示中不同位的个数（汉明距离）。

## 最易理解的方法：异或 + 统计1的个数

**核心思路：**
`x XOR y` 的结果中，1的个数就是两者不同的位数。用 `n&(n-1)` 统计1。

```
x=1=0001
y=4=0100

x^y=0101 → 两个1 → 汉明距离=2
```

## Go 实现

```go
func hammingDistance(x int, y int) int {
    xor := x ^ y
    count := 0
    for xor != 0 {
        xor &= xor - 1
        count++
    }
    return count
}
```

## 复杂度
- 时间：O(1)（整数位数有限）
- 空间：O(1)

## 记忆口诀
> 异或得不同位；用n&(n-1)统计1的个数即为汉明距离。
