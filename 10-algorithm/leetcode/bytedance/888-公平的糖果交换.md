# 888. 公平的糖果交换

> LeetCode 链接：https://leetcode.cn/problems/fair-candy-swap/

## 题目
Alice 有糖果数组 aliceSizes，Bob 有 bobSizes，两人各交换一个糖果盒后糖果总数相等，找到交换方案。

## 最易理解的方法：数学 + 哈希集合

**核心思路：**
设 Alice 给出 a，Bob 给出 b，则需要 sumA - a + b = sumB - b + a，化简得 b = a + (sumB - sumA)/2。
遍历 Alice 的每个糖果盒，在 Bob 的集合中查找对应值。

```
aliceSizes=[1,1], bobSizes=[2,2]
sumA=2, sumB=4, diff=1

遍历a:
  a=1: b=1+1=2 ∈ bobSet → 返回[1,2]
```

## Go 实现

```go
func fairCandySwap(aliceSizes []int, bobSizes []int) []int {
    sumA, sumB := 0, 0
    for _, s := range aliceSizes { sumA += s }
    bobSet := make(map[int]bool)
    for _, s := range bobSizes { sumB += s; bobSet[s] = true }
    diff := (sumB - sumA) / 2
    for _, a := range aliceSizes {
        if bobSet[a+diff] {
            return []int{a, a + diff}
        }
    }
    return nil
}
```

## 复杂度
- 时间：O(m+n)
- 空间：O(n)

## 记忆口诀
> 数学推导b=a+(sumB-sumA)/2；遍历Alice每个a，在Bob的set里查找b。
