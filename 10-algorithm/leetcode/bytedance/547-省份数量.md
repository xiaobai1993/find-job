# 547. 省份数量

> LeetCode 链接：https://leetcode.cn/problems/number-of-provinces/

## 题目
给定 n 个城市和连通关系矩阵 isConnected，找出省份数量（相互连通的城市构成一个省份）。

## 最易理解的方法：并查集（Union-Find）

**核心思路：**
将每个城市视为节点，相连城市合并到同一集合。最终集合数量就是省份数量。

```
isConnected:
1 1 0
1 1 0
0 0 1

城市0,1相连→合并
城市2独立

省份数=2
```

## Go 实现

```go
func findCircleNum(isConnected [][]int) int {
    n := len(isConnected)
    parent := make([]int, n)
    for i := range parent {
        parent[i] = i
    }
    var find func(x int) int
    find = func(x int) int {
        if parent[x] != x {
            parent[x] = find(parent[x]) // 路径压缩
        }
        return parent[x]
    }
    union := func(x, y int) {
        parent[find(x)] = find(y)
    }
    for i := 0; i < n; i++ {
        for j := i + 1; j < n; j++ {
            if isConnected[i][j] == 1 {
                union(i, j)
            }
        }
    }
    count := 0
    for i := 0; i < n; i++ {
        if find(i) == i {
            count++
        }
    }
    return count
}
```

## 复杂度
- 时间：O(n² × α(n))
- 空间：O(n)

## 记忆口诀
> 并查集：相连城市union合并；最后统计根节点数（find(i)==i）即省份数。
