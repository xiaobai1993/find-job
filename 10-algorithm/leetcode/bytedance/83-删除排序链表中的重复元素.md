# 83. 删除排序链表中的重复元素

> LeetCode 链接：https://leetcode.cn/problems/remove-duplicates-from-sorted-list/

## 题目
给定有序链表，删除所有重复的元素，使每个元素只出现一次。

## 最易理解的方法：原地删除

**核心思路：**
遍历链表，如果当前节点值等于下一个节点值，跳过下一个节点。

```
1→1→2→3→3

cur=1: cur.Val==next.Val → cur.Next=2 → 1→2→3→3
cur=2: 2≠3 → cur=3
cur=3: cur.Val==next.Val → cur.Next=nil → 1→2→3
```

## Go 实现

```go
func deleteDuplicates(head *ListNode) *ListNode {
    cur := head
    for cur != nil && cur.Next != nil {
        if cur.Val == cur.Next.Val {
            cur.Next = cur.Next.Next // 跳过重复节点
        } else {
            cur = cur.Next
        }
    }
    return head
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 遍历：若当前值=下一个值，跳过下一个节点；否则前进；注意不要推进指针（让循环再次检查）。
