# 402. 移掉 K 位数字

> LeetCode 链接：https://leetcode.cn/problems/remove-k-digits/

## 题目
给定表示非负整数的字符串 `num` 和整数 `k`，从数字中删除 k 个数字后，使剩余数字最小，返回结果字符串（去掉前导零）。

## 最易理解的方法：单调递增栈（贪心）

**核心思路：**
用单调递增栈。遍历每个数字，若栈顶数字**大于当前数字**且还有删除次数（k > 0），则弹出栈顶（删除较大的）。这样保证留下的数字尽可能小。最后若 k > 0 则删掉末尾若干位（单调递增时删末尾）。

```
num = "1432219", k = 3

遍历:
'1' → [1]
'4' → [1,4]
'3' → 4>3,弹4(k=2), [1,3]
'2' → 3>2,弹3(k=1), [1,2]
'2' → 2=2,入栈 [1,2,2]
'1' → 2>1,弹2(k=0), [1,2,1]
'9' → [1,2,1,9]
k=0, 结果"1219"
```

## Go 实现

```go
func removeKdigits(num string, k int) string {
    stack := []byte{}
    for i := 0; i < len(num); i++ {
        for k > 0 && len(stack) > 0 && stack[len(stack)-1] > num[i] {
            stack = stack[:len(stack)-1]
            k--
        }
        stack = append(stack, num[i])
    }
    // 若还有剩余删除次数，删末尾
    stack = stack[:len(stack)-k]
    // 去除前导零
    start := 0
    for start < len(stack)-1 && stack[start] == '0' {
        start++
    }
    return string(stack[start:])
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> 单调递增栈；遇到比栈顶小的数字就弹栈（删大数）；k用完后剩余的弹末尾；最后去前导零。
