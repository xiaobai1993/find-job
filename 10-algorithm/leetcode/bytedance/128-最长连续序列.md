# 128. 最长连续序列

> LeetCode 链接：https://leetcode.cn/problems/longest-consecutive-sequence/

## 题目
给定一个未排序的整数数组 `nums`，找出数字连续的最长序列（元素无需在原数组中相邻），要求时间复杂度 O(n)。

## 最易理解的方法：哈希集合

**核心思路：**
将所有数字存入集合。**只从序列的起点开始计数**（即 num-1 不在集合中时），避免重复计算。从起点不断往 num+1 查找，记录最长连续长度。

```
nums = [100,4,200,1,3,2]
set  = {100, 4, 200, 1, 3, 2}

遍历时：
- 100：99不在set → 是起点，100,101... → 长度1
- 4：3在set → 不是起点，跳过
- 200：199不在set → 是起点，200,201... → 长度1
- 1：0不在set → 是起点，1,2,3,4 → 长度4  ← 最长
- 3：2在set → 跳过
- 2：1在set → 跳过
```

## Go 实现

```go
func longestConsecutive(nums []int) int {
    set := make(map[int]bool)
    for _, n := range nums {
        set[n] = true
    }
    ans := 0
    for n := range set {
        if !set[n-1] { // n 是序列起点
            cur := n
            length := 1
            for set[cur+1] {
                cur++
                length++
            }
            if length > ans {
                ans = length
            }
        }
    }
    return ans
}
```

## 复杂度
- 时间：O(n)（虽然内层有 while，但每个数字只被遍历一次）
- 空间：O(n)

## 记忆口诀
> 哈希集合；只从序列起点（num-1不在集合）出发往后数；避免重复统计。
