# 445. 两数相加 II

> LeetCode 链接：https://leetcode.cn/problems/add-two-numbers-ii/

## 题目
给定两个非空链表（高位在前），将它们作为整数相加，返回表示和的链表（高位在前）。

## 最易理解的方法：栈（反转模拟）

**核心思路：**
用两个栈存两个链表的值，从底部（低位）开始相加，处理进位，头插法构建结果链表。

```
7 -> 2 -> 4 -> 3
     5 -> 6 -> 4

stack1: [7,2,4,3]
stack2: [5,6,4]

弹出: 3+4=7, 4+6=10(进1), 2+5+1=8, 7+0=7
结果: 7->8->0->7
```

## Go 实现

```go
func addTwoNumbers(l1 *ListNode, l2 *ListNode) *ListNode {
    var s1, s2 []int
    for l1 != nil { s1 = append(s1, l1.Val); l1 = l1.Next }
    for l2 != nil { s2 = append(s2, l2.Val); l2 = l2.Next }
    carry := 0
    var head *ListNode
    for len(s1) > 0 || len(s2) > 0 || carry > 0 {
        sum := carry
        if len(s1) > 0 { sum += s1[len(s1)-1]; s1 = s1[:len(s1)-1] }
        if len(s2) > 0 { sum += s2[len(s2)-1]; s2 = s2[:len(s2)-1] }
        carry = sum / 10
        node := &ListNode{Val: sum % 10, Next: head}
        head = node
    }
    return head
}
```

## 复杂度
- 时间：O(m+n)
- 空间：O(m+n)

## 记忆口诀
> 两个栈存节点值；从栈顶（低位）弹出相加处理进位；头插法构建结果（高位在前）。
