# 440. 字典序的第K小数字

> LeetCode 链接：https://leetcode.cn/problems/k-th-smallest-in-lexicographical-order/

## 题目
给定整数 n 和 k，找到 1 到 n 中字典序第 k 小的数字。

## 最易理解的方法：前缀树计数

**核心思路：**
把 1-n 的数字排成字典序前缀树。以 cur 为根的子树包含多少个节点，可以快速计算。
- 若子树节点数 ≤ k：跳过整棵子树，cur++，k 减去节点数
- 否则：进入子树，cur×10，k--

```
n=13, k=2

字典序: 1,10,11,12,13,2,3,...

cur=1: 以1为前缀的数: 1,10,11,12,13 = 5个
5 > k=2, 进入子树: cur=10, k=1

cur=10: 以10为前缀的数: 10,100,...但≤13的有10 = 1个
1 = k=1, 进入子树: cur=100>13, 回退: cur=10, k=0, return 10
```

## Go 实现

```go
func findKthNumber(n int, k int) int {
    // 计算以 cur 为前缀的节点数（不超过n）
    countNodes := func(cur, n int) int {
        count := 0
        next := cur + 1
        for cur <= n {
            if next > n+1 {
                count += n - cur + 1
            } else {
                count += next - cur
            }
            cur *= 10
            next *= 10
        }
        return count
    }
    cur := 1
    k-- // 从1开始，当前节点已占1
    for k > 0 {
        cnt := countNodes(cur, n)
        if cnt <= k {
            // 跳过以cur为前缀的所有数
            k -= cnt
            cur++
        } else {
            // 进入子树
            k--
            cur *= 10
        }
    }
    return cur
}
```

## 复杂度
- 时间：O(log²n)
- 空间：O(1)

## 记忆口诀
> 前缀树计数：若子树≤k则跳过（cur++,k-=cnt）；否则进入子树（cur*=10,k--）。
