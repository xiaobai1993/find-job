# 767. 重构字符串

> LeetCode 链接：https://leetcode.cn/problems/reorganize-string/

## 题目
给定字符串，重排字母使得相邻字母不同，不可能则返回 ""。

## 最易理解的方法：最大堆贪心

**核心思路：**
用最大堆（按频率）每次取频率最高的两个字符交替放置，若最高频超过 (n+1)/2 则不可能。

```
s = "aab"

cnt: a=2, b=1
堆: [(a,2),(b,1)]

取a(2)和b(1): 放"ab"，剩(a,1)入堆
取a(1): 放"a"
结果: "aba"
```

## Go 实现

```go
import "container/heap"

type CharHeap [][2]int
func (h CharHeap) Len() int { return len(h) }
func (h CharHeap) Less(i,j int) bool { return h[i][1] > h[j][1] }
func (h CharHeap) Swap(i,j int) { h[i],h[j] = h[j],h[i] }
func (h *CharHeap) Push(x interface{}) { *h = append(*h, x.([2]int)) }
func (h *CharHeap) Pop() interface{} { old:=*h; x:=old[len(old)-1]; *h=old[:len(old)-1]; return x }

func reorganizeString(s string) string {
    cnt := [26]int{}
    for _, c := range s { cnt[c-'a']++ }
    h := &CharHeap{}
    for i, v := range cnt {
        if v > 0 { heap.Push(h, [2]int{i, v}) }
    }
    res := []byte{}
    for h.Len() >= 2 {
        a := heap.Pop(h).([2]int)
        b := heap.Pop(h).([2]int)
        res = append(res, byte(a[0]+'a'), byte(b[0]+'a'))
        if a[1]--; a[1] > 0 { heap.Push(h, a) }
        if b[1]--; b[1] > 0 { heap.Push(h, b) }
    }
    if h.Len() == 1 {
        last := heap.Pop(h).([2]int)
        if last[1] > 1 { return "" }
        res = append(res, byte(last[0]+'a'))
    }
    return string(res)
}
```

## 复杂度
- 时间：O(n log k)（k=26）
- 空间：O(k)

## 记忆口诀
> 最大堆按频率；每次取最高频两个交替放置；最后剩1个且频率>1则返回""。
