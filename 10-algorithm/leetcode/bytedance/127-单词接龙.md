# 127. 单词接龙

> LeetCode 链接：https://leetcode.cn/problems/word-ladder/

## 题目
给定起始词、终止词和词表，每次变换一个字母，每个中间词必须在词表中，求最短转换序列的长度。

## 最易理解的方法：BFS（最短路）

**核心思路：**
BFS 逐层扩展，对当前单词的每个位置枚举替换 a-z，如果新词在词表中则加入队列（同时从词表删除避免重复访问）。
找到终止词时返回当前层数。

```
beginWord="hit", endWord="cog"
wordList=["hot","dot","dog","lot","log","cog"]

层1: "hit"
层2: "hot" (h→h,i→o,t→t)
层3: "dot","lot"
层4: "dog","log"
层5: "cog" ✓ 返回5
```

## Go 实现

```go
func ladderLength(beginWord string, endWord string, wordList []string) int {
    wordSet := make(map[string]bool)
    for _, w := range wordList {
        wordSet[w] = true
    }
    if !wordSet[endWord] {
        return 0
    }
    queue := []string{beginWord}
    steps := 1
    for len(queue) > 0 {
        n := len(queue)
        for i := 0; i < n; i++ {
            word := queue[i]
            bytes := []byte(word)
            for pos := 0; pos < len(bytes); pos++ {
                orig := bytes[pos]
                for c := byte('a'); c <= 'z'; c++ {
                    if c == orig {
                        continue
                    }
                    bytes[pos] = c
                    newWord := string(bytes)
                    if newWord == endWord {
                        return steps + 1
                    }
                    if wordSet[newWord] {
                        queue = append(queue, newWord)
                        delete(wordSet, newWord)
                    }
                    bytes[pos] = orig
                }
            }
        }
        queue = queue[n:]
        steps++
    }
    return 0
}
```

## 复杂度
- 时间：O(n × m × 26)，n 为词表大小，m 为单词长度
- 空间：O(n)

## 记忆口诀
> BFS最短路；对每个位置枚举a-z替换；新词在词表则入队并删除（防重复）；找到终止词返回步数。
