# 227. 基本计算器 II

> LeetCode 链接：https://leetcode.cn/problems/basic-calculator-ii/

## 题目
实现一个基本计算器来计算字符串表达式（含 +、-、*、/，无括号），结果为整数（除法向零截断）。

## 最易理解的方法：栈 + 符号处理

**核心思路：**
用栈保存每段的值：
- `+`/`-`：直接把数字（正负）入栈
- `*`/`/`：弹出栈顶与当前数字运算后再入栈
最后栈内求和。

```
"3+2*2" → 处理: sign=+,num=3→push 3; sign=+,num=2,遇*; sign=*,num=2→pop 2,2*2=4 push 4
栈=[3,4] → 7
```

## Go 实现

```go
func calculate(s string) int {
    stack := []int{}
    num := 0
    sign := byte('+') // 初始符号为+
    for i := 0; i < len(s); i++ {
        c := s[i]
        if c >= '0' && c <= '9' {
            num = num*10 + int(c-'0')
        }
        // 遇到运算符或末尾时，根据上一个符号处理
        if (c == '+' || c == '-' || c == '*' || c == '/') || i == len(s)-1 {
            switch sign {
            case '+':
                stack = append(stack, num)
            case '-':
                stack = append(stack, -num)
            case '*':
                top := stack[len(stack)-1]
                stack[len(stack)-1] = top * num
            case '/':
                top := stack[len(stack)-1]
                stack[len(stack)-1] = top / num
            }
            sign = c
            num = 0
        }
    }
    res := 0
    for _, v := range stack {
        res += v
    }
    return res
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> 栈法：遇符号或末尾时按上一个sign处理num；+/-直接入栈正负值；*/弹顶计算后压回；最后求和。
