# 303. 区域和检索 - 数组不可变

> LeetCode 链接：https://leetcode.cn/problems/range-sum-query-immutable/

## 题目
给定不可变整数数组，多次查询区间 [left, right] 的和。

## 最易理解的方法：前缀和

**核心思路：**
预处理前缀和 `prefix[i]` = nums[0..i-1] 的和，查询 [l,r] = prefix[r+1] - prefix[l]。

```
nums = [-2,0,3,-5,2,-1]
prefix = [0,-2,-2,1,-4,-2,-3]

query(0,2) = prefix[3]-prefix[0] = 1-0 = 1
query(2,5) = prefix[6]-prefix[2] = -3-(-2) = -1
```

## Go 实现

```go
type NumArray struct {
    prefix []int
}

func Constructor(nums []int) NumArray {
    prefix := make([]int, len(nums)+1)
    for i, v := range nums {
        prefix[i+1] = prefix[i] + v
    }
    return NumArray{prefix}
}

func (na *NumArray) SumRange(left int, right int) int {
    return na.prefix[right+1] - na.prefix[left]
}
```

## 复杂度
- 预处理：O(n)
- 查询：O(1)
- 空间：O(n)

## 记忆口诀
> 前缀和：prefix[i+1]=prefix[i]+nums[i]；查询[l,r]=prefix[r+1]-prefix[l]。
