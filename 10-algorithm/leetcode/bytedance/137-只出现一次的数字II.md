# 137. 只出现一次的数字 II

> LeetCode 链接：https://leetcode.cn/problems/single-number-ii/

## 题目
给定整数数组，除某个元素只出现一次外，其余每个元素均出现三次。找出那个只出现一次的元素。要求 O(n) 时间，O(1) 空间。

## 最易理解的方法：位运算（每位统计 mod 3）

**核心思路：**
对每个二进制位，统计所有数字在该位上 1 的出现次数，对 3 取模。
结果的每一位就是只出现一次的数字对应的位。

```
[2,2,3,2] → 只出现一次的是3

二进制:
2 = 010
2 = 010
3 = 011
2 = 010

位0: 0+0+1+0=1, mod3=1 → 结果位0=1
位1: 1+1+1+1=4, mod3=1 → 结果位1=1
→ 结果=011=3 ✓
```

## Go 实现

```go
func singleNumber(nums []int) int {
    res := 0
    for i := 0; i < 64; i++ {
        bitSum := 0
        for _, n := range nums {
            bitSum += (n >> i) & 1
        }
        if bitSum%3 != 0 {
            res |= 1 << i
        }
    }
    return res
}
```

## 复杂度
- 时间：O(64n) = O(n)
- 空间：O(1)

## 记忆口诀
> 逐位统计所有数字的1的总数，对3取模；余1的位即目标数字对应的位。
