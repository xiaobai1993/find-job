# 215. 数组中的第K个最大元素

题目链接：`https://leetcode.cn/problems/kth-largest-element-in-an-array/description/`

---

## 一、题目描述

给一个无序整数数组，找到第 k 大的元素。要求 O(n) 时间复杂度。

**示例：**

```
输入: [3,2,1,5,6,4], k = 2
输出: 5  （第2大是5）

输入: [3,2,3,1,2,4,5,5,6], k = 4
输出: 4  （第4大是4）
```

---

## 二、三种解法对比

| 方法 | 时间 | 空间 | 面试价值 |
|------|------|------|----------|
| 排序 | O(n log n) | O(1) | 太慢，面试不够 |
| 小顶堆 | O(n log k) | O(k) | 好，实际工程最常用 |
| 快速选择 | O(n) 均摊 | O(1) | 最好，面试加分项 |

面试建议：**先讲堆（好写好理解），再讲快速选择（体现算法能力）。**

---

## 三、方法一：小顶堆（维护前 k 大）

### 思路

维护一个大小为 k 的小顶堆：
- 堆里放"目前遇到的前 k 大元素"
- 堆顶是这 k 个里最小的（也就是第 k 大）
- 遍历完所有数后，堆顶就是答案

```
[3,2,1,5,6,4], k=3

前3个入堆后建堆: h = [_, 1, 2, 3]  （h[0]空着，下标从1开始）

i=3, nums[3]=5 > h[1]=1 → 替换堆顶为5，下沉 → h=[_, 2, 5, 3]
i=4, nums[4]=6 > h[1]=2 → 替换堆顶为6，下沉 → h=[_, 3, 5, 6]
i=5, nums[5]=4 > h[1]=3 → 替换堆顶为4，下沉 → h=[_, 4, 5, 6]

堆顶 h[1]=4 → 第3大 = 4 ✓
```

### Go 代码（手写堆）

```go
func findKthLargest(nums []int, k int) int {
    // h[0] 占位，有效元素从下标1开始
    h := make([]int, k+1)
    i := 0

    // 前 k 个直接放入
    for ; i < k && i < len(nums); i++ {
        h[i+1] = nums[i]
    }

    // 建堆：从最后一个非叶子节点下沉
    for j := k / 2; j >= 1; j-- {
        sitDown(h, j, k+1)
    }

    // 剩余元素：比堆顶大就替换并下沉
    for ; i < len(nums); i++ {
        if nums[i] > h[1] {
            h[1] = nums[i]
            sitDown(h, 1, k+1)
        }
    }

    return h[1]
}

// 下沉调整小根堆（和合并K个链表的 down 一模一样）
func sitDown(h []int, cur, max int) {
    if cur >= max {
        return
    }
    t := cur
    if 2*cur >= max {
        return // 叶子节点
    }
    if h[2*cur] < h[cur] {
        t = 2 * cur
    }
    if 2*cur+1 < max && h[2*cur+1] < h[t] {
        t = 2*cur + 1
    }
    if t != cur {
        h[t], h[cur] = h[cur], h[t]
        sitDown(h, t, max)
    }
}
```

### 手写堆 vs container/heap

| | 手写堆 | container/heap |
|--|--------|----------------|
| 代码量 | 少（一个下沉函数） | 多（5个接口方法） |
| 数组下标 | 1 开始，h[0]空着 | 0 开始 |
| 父子计算 | 左子 `2*i`，右子 `2*i+1` | 左子 `2*i+1`，右子 `2*i+2` |
| 替换堆顶 | 直接 `h[1]=val` 再下沉 | Pop + Push 两步 |
| 面试推荐 | 手写更快更简洁 | 工程代码用标准库 |

### sitDown 和合并K个链表的 down 是同一个函数

```go
// 合并K个链表的 down：比较 ListNode.Val
if h[left].Val < h[target].Val { target = left }

// 本题的 sitDown：直接比较 int
if h[2*cur] < h[cur] { t = 2*cur }
```

逻辑完全一样，只是数据类型不同。**学会了合并K个链表的堆操作，这题直接复用。**

### 记忆

```text
小顶堆维护前k大，堆顶就是第k大。
前k个建堆，后面的比堆顶大就替换+下沉。
```

## 四、方法二：快速选择（O(n) 均摊）

### 核心思路

快速排序的 partition 操作能把数组分成两部分：左边 ≤ pivot，右边 > pivot。partition 完 pivot 就到了它排序后的正确位置。

如果我们只关心第 k 大的位置，不需要把整个数组排好——**只需要看 pivot 落在哪个位置，然后只递归包含目标的那一半。**

```
第 k 大 = 排序后下标为 n-k 的元素

partition 返回 pivot 的最终下标 p：
  如果 p == n-k → 找到了，就是 nums[p]
  如果 p < n-k  → 目标在右边，只递归右半
  如果 p > n-k  → 目标在左边，只递归左半
```

### 图解

```
nums = [3,2,1,5,6,4], k=2, 目标下标 = 6-2 = 4

第1轮 partition（选 nums[0]=3 做 pivot）:
  [3, 2, 1, 5, 6, 4]
   ↑pivot

  分区后: [2, 1, 3, 5, 6, 4]
                  ↑p=2

  p=2 < 目标4 → 递归右半 [5, 6, 4]

第2轮 partition（选 5 做 pivot）:
  [5, 6, 4]
   ↑pivot

  分区后: [4, 5, 6]
              ↑p=1（相对下标）

  绝对下标 p = 3+1 = 4 == 目标4 → 找到了！

答案: nums[4] = 5 ✓
```

### Go 代码

```go
func findKthLargest(nums []int, k int) int {
    target := len(nums) - k // 第k大 = 排序后下标 n-k
    left, right := 0, len(nums)-1

    for left < right {
        p := partition(nums, left, right)
        if p == target {
            return nums[p]
        } else if p < target {
            left = p + 1
        } else {
            right = p - 1
        }
    }

    return nums[left]
}

func partition(nums []int, left, right int) int {
    pivot := nums[left]
    i, j := left, right

    for i < j {
        for i < j && nums[j] >= pivot { j-- }
        for i < j && nums[i] <= pivot { i++ }
        if i < j { nums[i], nums[j] = nums[j], nums[i] }
    }

    nums[left], nums[i] = nums[i], nums[left]
    return i
}
```

### 快速选择 vs 快速排序

| | 快速排序 | 快速选择 |
|--|----------|----------|
| 递归范围 | 两半都递归 | 只递归目标所在的那一半 |
| 时间 | O(n log n) | O(n) 均摊 |
| 目标 | 排好整个数组 | 只找一个位置 |

## 五、partition 详解

这是快速选择的核心，也是面试官最爱追问的部分。

```
partition(nums, 0, 5):  nums = [3, 2, 1, 5, 6, 4]
pivot = nums[0] = 3

目标：比3小的放左边，比3大的放右边，3放在正确位置

用左右双指针：
i=0, j=5
从右往左找第一个 < pivot 的: j=2, nums[2]=1
从左往右找第一个 > pivot 的: i=2, nums[2]=1（没找到更大的）

i == j = 2
交换 nums[0] 和 nums[2]: [1, 2, 3, 5, 6, 4]

返回 i=2，pivot(3) 到了最终位置
```

关键点：
- **选最左边做 pivot**：简单，但最坏情况 O(n²)
- **从右往左先扫**：保证相遇点 ≤ pivot
- **交换后 pivot 就位**：左边都 ≤ 它，右边都 ≥ 它

---

## 六、为什么快速选择是 O(n)？

```
第1轮: 遍历 n 个元素，partition 后丢掉一半
第2轮: 遍历 n/2 个元素
第3轮: 遍历 n/4 个元素
...

总工作量: n + n/2 + n/4 + ... ≈ 2n = O(n)
```

但这是**均摊**复杂度。最坏情况（每次 pivot 选到最大或最小值）会退化到 O(n²)。解决方法是用随机 pivot：

```go
func partition(nums []int, left, right int) int {
    // 随机选 pivot，避免最坏情况
    randIdx := left + rand.Intn(right-left+1)
    nums[left], nums[randIdx] = nums[randIdx], nums[left]

    pivot := nums[left]
    // ... 和之前一样
}
```

## 七、完整流程图解

```
nums = [3,2,3,1,2,4,5,5,6], k=4
目标下标 = 9-4 = 5

第1轮: partition [3,2,3,1,2,4,5,5,6], pivot=3
  → [1,2,2,3,3,4,5,5,6]
              ↑p=3

  p=3 < 5 → 递归右半 [4,5,5,6]

第2轮: partition [4,5,5,6], pivot=4
  → [4,5,5,6]
       ↑p=0（相对下标，绝对下标=4）

  p=4 < 5 → 递归右半 [5,5,6]

第3轮: partition [5,5,6], pivot=5
  → [5,5,6]
       ↑p=0（相对下标，绝对下标=5）

  p=5 == 目标5 → 返回 nums[5] = 4 ✓
```

## 八、复杂度分析

| 方法 | 时间 | 空间 |
|------|------|------|
| 小顶堆 | O(n log k) | O(k) |
| 快速选择 | O(n) 均摊，最坏 O(n²) | O(1) |
| 随机快速选择 | O(n) 期望 | O(1) |

## 九、容易错的点

### 1. 第 k 大不是第 k 小

```
第1大 = 最大的 = 下标 n-1
第k大 = 下标 n-k
```

写代码时 `target := len(nums) - k`，不要写成 `k-1`。

### 2. partition 的扫描顺序

```go
// ✓ 从右往左先扫（选左边做 pivot 时）
for i < j && nums[j] >= pivot { j-- }  // 先
for i < j && nums[i] <= pivot { i++ }  // 后

// ✗ 从左往右先扫，相遇点可能 > pivot
```

原因：选左边做 pivot，先从右扫可以保证相遇位置的值 ≤ pivot，这样交换后左边都 ≤ pivot。

### 3. partition 用 >= 和 <= 不是 > 和 <

```go
for i < j && nums[j] >= pivot { j-- }  // 等于也要跳过
for i < j && nums[i] <= pivot { i++ }
```

用 `>` 和 `<` 会导致遇到等于 pivot 的值时死循环。

### 4. 快速选择是 while 不是递归

```go
// ✓ 迭代写法，空间 O(1)
for left < right {
    p := partition(nums, left, right)
    ...
}

// 也可以递归，但空间变成 O(n) 最坏
```

### 5. 替换堆顶是赋值+下沉，不是 Pop+Push

```go
// ✓ 手写堆：直接赋值再下沉
h[1] = nums[i]
sitDown(h, 1, k+1)

// 不要忘了下沉，否则堆性质被破坏
```

### 6. 建堆从 k/2 开始，不是从 k 开始

```go
for j := k / 2; j >= 1; j-- {
    sitDown(h, j, k+1)
}
```

k/2 是最后一个非叶子节点。从它往下到 1，逐个下沉，就能建好堆。

## 十、面试表达

> 找第 k 大元素，两种方法。第一种用小顶堆，维护大小为 k 的堆，堆顶就是第 k 大，遍历时比堆顶大就替换，时间 O(n log k)。第二种快速选择，是快排的变种：partition 把 pivot 放到正确位置，如果位置正好是 n-k 就找到了，否则只递归目标那一半，均摊时间 O(n)。快速选最坏 O(n²)，用随机 pivot 可以避免。实际工程用堆，面试两种都写。
