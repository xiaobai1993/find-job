# 797. 所有可能的路径

> LeetCode 链接：https://leetcode.cn/problems/all-paths-from-source-to-target/

## 题目
给定有向无环图（DAG），找出从节点0到节点n-1的所有可能路径。

## 最易理解的方法：DFS 回溯

**核心思路：**
从节点0出发 DFS，到达 n-1 时将路径加入结果，回溯时移除最后一个节点。

```
graph = [[1,2],[3],[3],[]]

DFS路径:
0→1→3 ✓
0→2→3 ✓

结果: [[0,1,3],[0,2,3]]
```

## Go 实现

```go
func allPathsSourceTarget(graph [][]int) [][]int {
    var res [][]int
    path := []int{0}
    var dfs func(node int)
    dfs = func(node int) {
        if node == len(graph)-1 {
            tmp := make([]int, len(path))
            copy(tmp, path)
            res = append(res, tmp)
            return
        }
        for _, next := range graph[node] {
            path = append(path, next)
            dfs(next)
            path = path[:len(path)-1]
        }
    }
    dfs(0)
    return res
}
```

## 复杂度
- 时间：O(2^n × n)
- 空间：O(n)（路径栈深度）

## 记忆口诀
> DFS从0出发；到达n-1时拷贝路径加入结果；回溯时弹出最后节点。
