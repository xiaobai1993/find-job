# 26. 删除有序数组中的重复项

> LeetCode 链接：https://leetcode.cn/problems/remove-duplicates-from-sorted-array/

## 题目
给定有序数组，原地删除重复元素，返回不重复元素的个数（顺序不变）。

## 最易理解的方法：双指针

**核心思路：**
慢指针 `slow` 指向下一个写入位置，快指针 `fast` 遍历数组。当 `nums[fast] != nums[slow-1]` 时，写入并移动慢指针。

```
[1,1,2]

slow=1, fast=1: nums[1]=1==nums[0]=1 → fast++
slow=1, fast=2: nums[2]=2!=nums[0]=1 → nums[1]=2, slow=2

结果: [1,2], 返回2
```

## Go 实现

```go
func removeDuplicates(nums []int) int {
    if len(nums) == 0 {
        return 0
    }
    slow := 1
    for fast := 1; fast < len(nums); fast++ {
        if nums[fast] != nums[slow-1] {
            nums[slow] = nums[fast]
            slow++
        }
    }
    return slow
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 快慢指针；fast遍历，遇与slow前不同的元素则写入slow位置；返回slow值。
