# 345. 反转字符串中的元音字母

> LeetCode 链接：https://leetcode.cn/problems/reverse-vowels-of-a-string/

## 题目
给定字符串，只反转其中的元音字母（a, e, i, o, u 大小写）。

## 最易理解的方法：双指针交换元音

**核心思路：**
左右双指针向中间移动，跳过非元音字母，遇到两侧均为元音时交换。

```
s = "hello"

l=0(h非元音),l=1(e元音)
r=4(o元音)

swap e,o → "holle"
```

## Go 实现

```go
func reverseVowels(s string) string {
    vowels := map[byte]bool{'a':true,'e':true,'i':true,'o':true,'u':true,'A':true,'E':true,'I':true,'O':true,'U':true}
    bs := []byte(s)
    l, r := 0, len(bs)-1
    for l < r {
        for l < r && !vowels[bs[l]] { l++ }
        for l < r && !vowels[bs[r]] { r-- }
        if l < r {
            bs[l], bs[r] = bs[r], bs[l]
            l++; r--
        }
    }
    return string(bs)
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)（转byte数组）

## 记忆口诀
> 双指针跳过非元音；两端均为元音时交换，然后向内收缩。
