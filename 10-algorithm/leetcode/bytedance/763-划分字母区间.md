# 763. 划分字母区间

> LeetCode 链接：https://leetcode.cn/problems/partition-labels/

## 题目
给你一个字符串 `s`，把字符串分割成尽量多的片段，同一字母最多出现在一个片段中，返回每个片段长度。

## 最易理解的方法：贪心 + 记录最后出现位置

**核心思路：**
先记录每个字母最后出现的下标 `last[c]`。然后用双指针遍历，维护当前区间的末尾 `end = max(end, last[s[i]])`。当 `i == end` 时，说明当前区间内所有字母都不会在后面出现，输出区间长度，开始新区间。

```
s = "ababcbacadefegdehijhklij"

last: a→8, b→5, c→7, d→14, e→15, f→11, g→13, h→19, i→22, j→23, k→20, l→21

i=0(a): end=max(0,8)=8
i=1(b): end=max(8,5)=8
...
i=8(a): end=8, i==end → 输出8-0+1=9, start=9
i=9(d): end=max(0,14)=14
...
i=15(e): end=15, i==end → 输出15-9+1=7
i=16(i): end=max(0,22)=22
...
i=23(j): end=23, i==end → 输出23-16+1=8
结果:[9,7,8]
```

## Go 实现

```go
func partitionLabels(s string) []int {
    last := [26]int{}
    for i, c := range s {
        last[c-'a'] = i
    }
    var res []int
    start, end := 0, 0
    for i, c := range s {
        if last[c-'a'] > end {
            end = last[c-'a']
        }
        if i == end {
            res = append(res, end-start+1)
            start = end + 1
        }
    }
    return res
}
```

## 复杂度
- 时间：O(n)
- 空间：O(26) = O(1)

## 记忆口诀
> 先记每个字母最后出现位置；贪心扩展end=max(end, last[c])；当i==end时切割，输出长度。
