# 77. 组合

> LeetCode 链接：https://leetcode.cn/problems/combinations/

## 题目
给定两个整数 n 和 k，返回范围 [1, n] 中所有可能的 k 个数的组合。

## 最易理解的方法：回溯

**核心思路：**
从 start 开始枚举，path 长度等于 k 时收集结果。
剪枝：若剩余数字不够凑到 k 个，提前终止（`i <= n - (k - len(path)) + 1`）。

```
n=4, k=2

start=1:
  [1]+start=2: [1,2]✓,[1,3]✓,[1,4]✓
start=2: [2,3]✓,[2,4]✓
start=3: [3,4]✓
```

## Go 实现

```go
func combine(n int, k int) [][]int {
    var res [][]int
    var backtrack func(start int, path []int)
    backtrack = func(start int, path []int) {
        if len(path) == k {
            tmp := make([]int, k)
            copy(tmp, path)
            res = append(res, tmp)
            return
        }
        // 剪枝：后面最多有n-i+1个数可选
        for i := start; i <= n-(k-len(path))+1; i++ {
            path = append(path, i)
            backtrack(i+1, path)
            path = path[:len(path)-1]
        }
    }
    backtrack(1, nil)
    return res
}
```

## 复杂度
- 时间：O(C(n,k) × k)
- 空间：O(k)

## 记忆口诀
> 回溯从start枚举；path长度=k时收集；剪枝：i<=n-(k-len(path))+1。
