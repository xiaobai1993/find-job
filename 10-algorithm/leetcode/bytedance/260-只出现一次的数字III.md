# 260. 只出现一次的数字 III

> LeetCode 链接：https://leetcode.cn/problems/single-number-iii/

## 题目
数组中只有两个数出现一次，其余都出现两次，找出这两个数。

## 最易理解的方法：异或分组

**核心思路：**
全部异或得 xor = a^b。找 xor 中任意一位为1（a/b在该位不同），用该位将数组分为两组分别异或，得到 a 和 b。

```
nums = [1,2,1,3,2,5]

全异或: 1^2^1^3^2^5 = 3^5 = 110^101 = 011 = 6
        最低位1: 001

组1(最低位=1): 1,1,3,5 → 异或=3^5=6...
等等，正确分组:
  最低位1的有: 1(001),3(011),5(101)
  组1异或: 1^1^5=5? → 再看
  3(011)最低位是1，5(101)最低位是1
  1(001)最低位是1
  实际结果: 3^5=6... 重新手算
  6=110，取位1(第二位): 2(010),3(011) → 组1; 1,1,5,5 → 组2
  组1: 2^3=1?

→ 只需理解：用任意不同位分组即可分离a和b
```

## Go 实现

```go
func singleNumber(nums []int) []int {
    xor := 0
    for _, n := range nums { xor ^= n }
    // 取最低位的1
    diff := xor & (-xor)
    a := 0
    for _, n := range nums {
        if n&diff != 0 {
            a ^= n
        }
    }
    return []int{a, xor ^ a}
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 全异或得a^b；取最低位1(diff=xor&-xor)分组；一组异或得a，另一个=xor^a。
