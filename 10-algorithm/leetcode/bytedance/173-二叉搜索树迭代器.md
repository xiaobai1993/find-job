# 173. 二叉搜索树迭代器

> LeetCode 链接：https://leetcode.cn/problems/binary-search-tree-iterator/

## 题目
实现 BST 迭代器，支持 `next()`（返回下一个最小值）和 `hasNext()`，O(h) 空间。

## 最易理解的方法：受控中序遍历（栈）

**核心思路：**
用栈模拟中序遍历：初始时将根到最左叶的路径入栈。
每次 `next()` 弹出栈顶节点，若其有右子树，则将右子树到最左叶的路径入栈。

```
    7
   / \
  3  15
     / \
    9  20

初始栈: [7,3] (从根到最左)
next(): pop 3, 3无右子 → 栈=[7] 返回3
next(): pop 7, 7有右子15→push 15,9 → 栈=[15,9] 返回7
next(): pop 9, 9无右子 → 栈=[15] 返回9
next(): pop 15, 15有右子20→push 20 → 栈=[20] 返回15
next(): pop 20 返回20
```

## Go 实现

```go
type BSTIterator struct {
    stack []*TreeNode
}

func Constructor(root *TreeNode) BSTIterator {
    it := BSTIterator{}
    it.pushLeft(root)
    return it
}

func (it *BSTIterator) pushLeft(node *TreeNode) {
    for node != nil {
        it.stack = append(it.stack, node)
        node = node.Left
    }
}

func (it *BSTIterator) Next() int {
    top := it.stack[len(it.stack)-1]
    it.stack = it.stack[:len(it.stack)-1]
    it.pushLeft(top.Right) // 处理右子树
    return top.Val
}

func (it *BSTIterator) HasNext() bool {
    return len(it.stack) > 0
}
```

## 复杂度
- Next/HasNext：均摊 O(1)
- 空间：O(h)

## 记忆口诀
> 栈存从根到最左叶路径；next弹顶并将其右子树路径入栈；均摊O(1)。
