# 503. 下一个更大元素 II

> LeetCode 链接：https://leetcode.cn/problems/next-greater-element-ii/

## 题目
给定循环数组（数组末尾后接数组开头），对每个元素找到下一个更大的数，不存在则返回 -1。

## 最易理解的方法：单调栈 + 两倍数组模拟循环

**核心思路：**
遍历两遍数组（通过 `i % n` 模拟循环），用单调递减栈存下标。
遇到更大的值时弹出栈顶并记录答案。

```
nums = [1,2,1]

遍历0..5:
i=0: push 0 → stack=[0]
i=1: 2>nums[0]=1 → res[0]=2, pop; push 1 → stack=[1]
i=2: 1<2 → push 2 → stack=[1,2]
i=3: 1>1=nums[2] → res[2]=1, pop; 1<nums[1]=2 → push 3 → stack=[1,3]
i=4: 2>=nums[3%3]=1→pop; 2>=nums[1%3]=2 → 停 push 4 → stack=[1,4]
...

res=[2,-1,2]
```

## Go 实现

```go
func nextGreaterElements(nums []int) []int {
    n := len(nums)
    res := make([]int, n)
    for i := range res {
        res[i] = -1
    }
    stack := []int{} // 存下标
    for i := 0; i < 2*n; i++ {
        for len(stack) > 0 && nums[stack[len(stack)-1]] < nums[i%n] {
            top := stack[len(stack)-1]
            stack = stack[:len(stack)-1]
            res[top] = nums[i%n]
        }
        if i < n {
            stack = append(stack, i)
        }
    }
    return res
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> 单调栈遍历两倍（i%n模拟循环）；只在第一遍(i<n)入栈；遇更大值弹出记答案。
