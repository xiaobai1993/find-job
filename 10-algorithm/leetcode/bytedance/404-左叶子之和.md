# 404. 左叶子之和

> LeetCode 链接：https://leetcode.cn/problems/sum-of-left-leaves/

## 题目
计算所有左叶子节点的值之和。

## 最易理解的方法：DFS 传 isLeft 标记

**核心思路：**
DFS 时传入是否为左子节点的标记，到达叶节点且为左叶子时累加。

```
    3
   / \
  9  20
    /  \
   15   7

左叶子: 9, 15
和: 24
```

## Go 实现

```go
func sumOfLeftLeaves(root *TreeNode) int {
    var dfs func(node *TreeNode, isLeft bool) int
    dfs = func(node *TreeNode, isLeft bool) int {
        if node == nil { return 0 }
        if node.Left == nil && node.Right == nil {
            if isLeft { return node.Val }
            return 0
        }
        return dfs(node.Left, true) + dfs(node.Right, false)
    }
    return dfs(root, false)
}
```

## 复杂度
- 时间：O(n)
- 空间：O(h)

## 记忆口诀
> DFS传isLeft标记；叶节点且isLeft为true时累加val。
