# 70. 爬楼梯

> LeetCode 链接：https://leetcode.cn/problems/climbing-stairs/

## 题目
爬 n 阶楼梯，每次可以爬 1 或 2 个台阶，有多少种不同的方法？

## 最易理解的方法：斐波那契数列（滚动变量）

**核心思路：**
到达第 n 阶的方法数 = 从第 n-1 阶跨 1 步 + 从第 n-2 阶跨 2 步，即 `f(n) = f(n-1) + f(n-2)`。和斐波那契数列完全相同（f(1)=1, f(2)=2）。

```
n=1: 1种  (1)
n=2: 2种  (1+1, 2)
n=3: 3种  (1+1+1, 1+2, 2+1)
n=4: 5种
n=5: 8种
```

## Go 实现

```go
func climbStairs(n int) int {
    if n <= 2 {
        return n
    }
    prev2, prev1 := 1, 2
    for i := 3; i <= n; i++ {
        prev2, prev1 = prev1, prev1+prev2
    }
    return prev1
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 斐波那契：f(n)=f(n-1)+f(n-2)，f(1)=1，f(2)=2；只需两个变量滚动。
