# 32. 最长有效括号

> LeetCode 链接：https://leetcode.cn/problems/longest-valid-parentheses/

## 题目
给你一个只含 `'('` 和 `')'` 的字符串，找出最长有效（格式正确且连续）括号子串的长度。

## 最易理解的方法：栈

**核心思路：**
用栈保存字符的**下标**。初始往栈里压入 -1 作为"边界哨兵"。遇到 `(` 就入栈；遇到 `)` 就出栈，若栈空了则把当前 `)` 的下标压入（成为新边界），否则计算 `当前下标 - 栈顶下标` 即为当前有效长度。

```
s = "())(())"    下标: 0123456
栈初始: [-1]

i=0 '(' → push 0  → [-1, 0]
i=1 ')' → pop 0   → [-1]      len = 1-(-1) = 2
i=2 ')' → pop -1  → []  → push 2  → [2]   栈空，压入新边界
i=3 '(' → push 3  → [2, 3]
i=4 '(' → push 4  → [2, 3, 4]
i=5 ')' → pop 4   → [2, 3]    len = 5-3 = 2
i=6 ')' → pop 3   → [2]       len = 6-2 = 4  ← 最长
```

**算法步骤：**
1. stack = [-1]，ans = 0
2. 遍历每个字符：
   - `(` → 压入 i
   - `)` → 弹出栈顶；若栈空，压入 i（新边界）；否则 ans = max(ans, i - stack.top)
3. 返回 ans

## Go 实现

```go
func longestValidParentheses(s string) int {
    stack := []int{-1} // 哨兵
    ans := 0
    for i := 0; i < len(s); i++ {
        if s[i] == '(' {
            stack = append(stack, i)
        } else {
            stack = stack[:len(stack)-1] // pop
            if len(stack) == 0 {
                stack = append(stack, i) // 新边界
            } else {
                l := i - stack[len(stack)-1]
                if l > ans {
                    ans = l
                }
            }
        }
    }
    return ans
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> 栈存下标+哨兵 -1；`)`出栈后若栈空则压 i 为新边界，否则算长度。
