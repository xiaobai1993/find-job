# 169. 多数元素

> LeetCode 链接：https://leetcode.cn/problems/majority-element/

## 题目
给定大小为 n 的数组，找出其中的多数元素（出现次数大于 n/2 的元素）。保证多数元素一定存在。

## 最易理解的方法：Boyer-Moore 投票算法

**核心思路：**
维护候选者 candidate 和计数 count。
- 遇到与 candidate 相同的数：count++
- 遇到不同的数：count--
- count 变为 0：更换候选者

由于多数元素超过半数，最终剩下的候选者就是答案。

```
[2,2,1,1,1,2,2]

candidate=2, count=1
candidate=2, count=2
candidate=2, count=1 (遇1)
count=0 (再遇1)
candidate=1, count=1
candidate=1, count=2 (遇2时+1-1=0...
→ wait, let me recalculate:
2:cnt=1; 2:cnt=2; 1:cnt=1; 1:cnt=0; 1:cand=1,cnt=1; 2:cnt=0; 2:cand=2,cnt=1
→ cand=2

答案=2
```

## Go 实现

```go
func majorityElement(nums []int) int {
    candidate, count := nums[0], 1
    for _, n := range nums[1:] {
        if count == 0 {
            candidate = n
            count = 1
        } else if n == candidate {
            count++
        } else {
            count--
        }
    }
    return candidate
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> Boyer-Moore投票：相同+1，不同-1，归零换候选者；多数元素票数必然存活到最后。
