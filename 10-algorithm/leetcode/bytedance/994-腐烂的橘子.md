# 994. 腐烂的橘子

> LeetCode 链接：https://leetcode.cn/problems/rotting-oranges/

## 题目
0=空格，1=新鲜橘子，2=腐烂橘子，每分钟腐烂橘子向四邻扩散，求所有橘子腐烂需要的最少分钟数，不可能则返回 -1。

## 最易理解的方法：多源 BFS

**核心思路：**
将所有初始腐烂橘子加入队列（BFS起点），统计新鲜橘子数，逐层扩散，直到队列为空。

```
[[2,1,1],[1,1,0],[0,1,1]]

初始腐烂: (0,0)
分钟1: (0,1),(1,0)腐烂 → fresh减少
分钟2: (0,2),(1,1)腐烂
分钟3: (2,1)腐烂
分钟4: (2,2)腐烂

total: 4分钟
```

## Go 实现

```go
func orangesRotting(grid [][]int) int {
    m, n := len(grid), len(grid[0])
    queue := [][2]int{}
    fresh := 0
    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            if grid[i][j] == 2 { queue = append(queue, [2]int{i, j}) }
            if grid[i][j] == 1 { fresh++ }
        }
    }
    if fresh == 0 { return 0 }
    dirs := [][2]int{{0,1},{0,-1},{1,0},{-1,0}}
    minutes := 0
    for len(queue) > 0 && fresh > 0 {
        n := len(queue)
        for i := 0; i < n; i++ {
            cur := queue[i]
            for _, d := range dirs {
                ni, nj := cur[0]+d[0], cur[1]+d[1]
                if ni >= 0 && ni < m && nj >= 0 && nj < len(grid[0]) && grid[ni][nj] == 1 {
                    grid[ni][nj] = 2
                    fresh--
                    queue = append(queue, [2]int{ni, nj})
                }
            }
        }
        queue = queue[n:]
        minutes++
    }
    if fresh > 0 { return -1 }
    return minutes
}
```

## 复杂度
- 时间：O(m×n)
- 空间：O(m×n)

## 记忆口诀
> 多源BFS从所有腐烂橘子出发；逐层扩散消耗fresh计数；fresh>0则返-1。
