# 86. 分隔链表

> LeetCode 链接：https://leetcode.cn/problems/partition-list/

## 题目
给定链表和值 x，将所有小于 x 的节点排在大于等于 x 的节点前面（保持相对顺序）。

## 最易理解的方法：双链表

**核心思路：**
用两个哑节点分别收集小于 x 和大于等于 x 的节点，最后拼接两个链表。

```
head=1→4→3→2→5→2, x=3

small: 1→2→2
large: 4→3→5

拼接: 1→2→2→4→3→5
```

## Go 实现

```go
func partition(head *ListNode, x int) *ListNode {
    smallDummy := &ListNode{}
    largeDummy := &ListNode{}
    small, large := smallDummy, largeDummy
    for head != nil {
        if head.Val < x {
            small.Next = head
            small = small.Next
        } else {
            large.Next = head
            large = large.Next
        }
        head = head.Next
    }
    large.Next = nil      // 防止循环
    small.Next = largeDummy.Next
    return smallDummy.Next
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 双哑节点分别收集小/大节点；最后拼接；注意大链表末尾置nil防循环。
