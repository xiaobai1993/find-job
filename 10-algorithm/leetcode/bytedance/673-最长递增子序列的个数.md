# 673. 最长递增子序列的个数

> LeetCode 链接：https://leetcode.cn/problems/number-of-longest-increasing-subsequence/

## 题目
给定无序整数数组，返回最长递增子序列的个数。

## 最易理解的方法：DP 同时记录长度和个数

**核心思路：**
`dp[i]` = 以 nums[i] 结尾的 LIS 长度，`cnt[i]` = 该长度的方案数。
更新时：若 dp[j]+1 > dp[i] 则更新长度和个数；若相等则累加个数。

```
nums = [1,3,5,4,7]

dp:  [1,2,3,3,4]
cnt: [1,1,1,1,2]  (7前可选5或4，各一种)

最长=4，个数=2
```

## Go 实现

```go
func findNumberOfLIS(nums []int) int {
    n := len(nums)
    dp := make([]int, n)
    cnt := make([]int, n)
    for i := range dp { dp[i], cnt[i] = 1, 1 }
    maxLen := 1
    for i := 1; i < n; i++ {
        for j := 0; j < i; j++ {
            if nums[j] < nums[i] {
                if dp[j]+1 > dp[i] {
                    dp[i] = dp[j] + 1
                    cnt[i] = cnt[j]
                } else if dp[j]+1 == dp[i] {
                    cnt[i] += cnt[j]
                }
            }
        }
        if dp[i] > maxLen { maxLen = dp[i] }
    }
    res := 0
    for i, l := range dp {
        if l == maxLen { res += cnt[i] }
    }
    return res
}
```

## 复杂度
- 时间：O(n²)
- 空间：O(n)

## 记忆口诀
> dp记长度，cnt记方案；更大则更新cnt=cnt[j]；相等则cnt+=cnt[j]；最后统计最长的cnt之和。
