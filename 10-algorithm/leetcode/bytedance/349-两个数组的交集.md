# 349. 两个数组的交集

> LeetCode 链接：https://leetcode.cn/problems/intersection-of-two-arrays/

## 题目
给定两个数组，返回它们的交集（结果中每个元素唯一）。

## 最易理解的方法：哈希集合

**核心思路：**
将 nums1 存入 set，遍历 nums2，存在且未输出的加入结果。

```
nums1 = [1,2,2,1], nums2 = [2,2]

set1 = {1,2}
遍历nums2: 2 ∈ set1 → 输出2，加入结果set
结果: [2]
```

## Go 实现

```go
func intersection(nums1 []int, nums2 []int) []int {
    set := make(map[int]bool)
    for _, n := range nums1 {
        set[n] = true
    }
    res := make(map[int]bool)
    for _, n := range nums2 {
        if set[n] {
            res[n] = true
        }
    }
    var ans []int
    for k := range res {
        ans = append(ans, k)
    }
    return ans
}
```

## 复杂度
- 时间：O(m+n)
- 空间：O(m)

## 记忆口诀
> nums1存set；遍历nums2找交集；用结果set去重；转slice输出。
