# 687. 最长同值路径

> LeetCode 链接：https://leetcode.cn/problems/longest-univalue-path/

## 题目
给定二叉树，找最长的路径，路径上所有节点值相同（路径可以不经过根节点）。

## 最易理解的方法：DFS 后序遍历

**核心思路：**
对每个节点，计算向左和向右延伸的同值路径长度，二者之和更新全局最大值，返回较长的单侧路径给父节点。

```
    5
   / \
  4   5
 / \   \
1   1   5

节点5(根): 左侧路径=0, 右侧路径=2(→5→5)
全局max=2
```

## Go 实现

```go
func longestUnivaluePath(root *TreeNode) int {
    res := 0
    var dfs func(node *TreeNode) int
    dfs = func(node *TreeNode) int {
        if node == nil { return 0 }
        left := dfs(node.Left)
        right := dfs(node.Right)
        leftPath, rightPath := 0, 0
        if node.Left != nil && node.Left.Val == node.Val {
            leftPath = left + 1
        }
        if node.Right != nil && node.Right.Val == node.Val {
            rightPath = right + 1
        }
        if leftPath+rightPath > res {
            res = leftPath + rightPath
        }
        if leftPath > rightPath { return leftPath }
        return rightPath
    }
    dfs(root)
    return res
}
```

## 复杂度
- 时间：O(n)
- 空间：O(h)

## 记忆口诀
> 后序DFS；左右延伸长度：同值+1否则0；两侧之和更新全局最大；返回较长单侧给父节点。
