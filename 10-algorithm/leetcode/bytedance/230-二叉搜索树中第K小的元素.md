# 230. 二叉搜索树中第 K 小的元素

> LeetCode 链接：https://leetcode.cn/problems/kth-smallest-element-in-a-bst/

## 题目
给定二叉搜索树和整数 k，返回其中第 k 小的元素。

## 最易理解的方法：中序遍历（BST 的中序是升序）

**核心思路：**
BST 的中序遍历结果是升序排列的，第 k 个访问的节点就是第 k 小的元素。
用迭代栈实现中序遍历，遇到第 k 个节点直接返回。

```
    3
   / \
  1   4
   \
    2

中序: 1, 2, 3, 4
k=1 → 1
k=2 → 2
```

## Go 实现

```go
func kthSmallest(root *TreeNode, k int) int {
    stack := []*TreeNode{}
    cur := root
    for cur != nil || len(stack) > 0 {
        // 一路向左
        for cur != nil {
            stack = append(stack, cur)
            cur = cur.Left
        }
        cur = stack[len(stack)-1]
        stack = stack[:len(stack)-1]
        k--
        if k == 0 {
            return cur.Val
        }
        cur = cur.Right
    }
    return -1
}
```

## 复杂度
- 时间：O(h + k)
- 空间：O(h)

## 记忆口诀
> BST中序=升序；迭代栈中序遍历，第k次访问的节点即第k小；遇k==0直接返回。
