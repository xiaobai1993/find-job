# 53. 最大子数组和

> LeetCode 链接：https://leetcode.cn/problems/maximum-subarray/

## 题目
找到整数数组中具有最大和的连续子数组，返回其最大和。

## 最易理解的方法：Kadane 算法

**核心思路：**
遍历数组，维护以当前位置结尾的最大子数组和 `curr`。若 `curr + nums[i] < nums[i]`（即当前累积变成负担），就放弃之前的，从 `nums[i]` 重新开始；否则继续累加。同时更新全局最大值。

```
nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]
curr =  -2  1  -2  4   3  5  6   1  5
ans  =  -2  1   1  4   4  5  6   6  6

答案：6 (子数组 [4,-1,2,1])
```

**算法步骤：**
1. `curr = nums[0]`，`ans = nums[0]`
2. 从 `i=1` 遍历：`curr = max(nums[i], curr + nums[i])`，`ans = max(ans, curr)`
3. 返回 `ans`

## Go 实现

```go
func maxSubArray(nums []int) int {
    curr, ans := nums[0], nums[0]
    for i := 1; i < len(nums); i++ {
        if curr < 0 {
            curr = nums[i] // 抛弃之前的负数累积
        } else {
            curr += nums[i]
        }
        if curr > ans {
            ans = curr
        }
    }
    return ans
}
```

## 更简洁写法

```go
func maxSubArray(nums []int) int {
    ans, curr := nums[0], nums[0]
    for _, v := range nums[1:] {
        curr = max(v, curr+v)
        ans = max(ans, curr)
    }
    return ans
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> curr 若变负则丢弃，从当前数重新开始；全程记全局最大。
