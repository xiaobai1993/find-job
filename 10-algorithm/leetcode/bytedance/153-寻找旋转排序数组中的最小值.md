# 153. 寻找旋转排序数组中的最小值

> LeetCode 链接：https://leetcode.cn/problems/find-minimum-in-rotated-sorted-array/

## 题目
给定一个旋转后的不含重复元素的有序数组，找到其中的最小值。时间复杂度 O(log n)。

## 最易理解的方法：二分查找

**核心思路：**
二分时比较 `nums[mid]` 和 `nums[hi]`：
- 若 `nums[mid] > nums[hi]`：最小值在右半部分（mid 不可能是最小），`lo = mid + 1`
- 否则：最小值在左半部分（含 mid），`hi = mid`

最终 lo == hi 时就是最小值。

```
[3, 4, 5, 1, 2]
lo=0, hi=4
mid=2: nums[2]=5 > nums[4]=2 → lo=3
mid=3: nums[3]=1 < nums[4]=2 → hi=3
lo==hi==3 → nums[3]=1 (最小值)
```

## Go 实现

```go
func findMin(nums []int) int {
    lo, hi := 0, len(nums)-1
    for lo < hi {
        mid := (lo + hi) / 2
        if nums[mid] > nums[hi] {
            lo = mid + 1 // 最小值在右侧
        } else {
            hi = mid // 最小值在左侧（含mid）
        }
    }
    return nums[lo]
}
```

## 复杂度
- 时间：O(log n)
- 空间：O(1)

## 记忆口诀
> 二分比较mid和hi：mid>hi则最小值在右（lo=mid+1）；否则在左含mid（hi=mid）。
