# 494. 目标和

> LeetCode 链接：https://leetcode.cn/problems/target-sum/

## 题目
给定整数数组和目标值 target，对每个数字添加 + 或 - 符号，求使表达式结果等于 target 的方案数。

## 最易理解的方法：DP（0-1 背包转化）

**核心思路：**
设正号数之和为 P，负号数之和为 N。
`P + N = sum`，`P - N = target`
⟹ `P = (sum + target) / 2`

转化为：从数组中选若干数，使其和等于 P 的方案数（0-1 背包计数）。

```
nums=[1,1,1,1,1], target=3
sum=5, P=(5+3)/2=4

0-1背包：从[1,1,1,1,1]中选和为4的方案数=5 (选其中4个)
```

## Go 实现

```go
func findTargetSumWays(nums []int, target int) int {
    sum := 0
    for _, n := range nums {
        sum += n
    }
    // 剪枝
    if (sum+target)%2 != 0 || sum+target < 0 {
        return 0
    }
    P := (sum + target) / 2
    dp := make([]int, P+1)
    dp[0] = 1
    for _, num := range nums {
        for j := P; j >= num; j-- {
            dp[j] += dp[j-num]
        }
    }
    return dp[P]
}
```

## 复杂度
- 时间：O(n × P)
- 空间：O(P)

## 记忆口诀
> 转化：选和为(sum+target)/2的子集方案数；0-1背包计数，内层逆序；dp[0]=1。
