# 394. 字符串解码

> LeetCode 链接：https://leetcode.cn/problems/decode-string/

## 题目
给定编码字符串，按规则解码：`k[encoded_string]` 表示方括号内字符串重复 k 次。

## 最易理解的方法：栈

**核心思路：**
遇到数字 → 累积到 `num`；遇到 `[` → 将当前字符串和数字压栈，重置；遇到字母 → 拼接到当前字符串；遇到 `]` → 弹栈，将当前字符串重复 k 次后拼接到上一层字符串。

```
s = "3[a2[c]]"

遇到'3': num=3
遇到'[': push("", 3), cur="", num=0
遇到'a': cur="a"
遇到'2': num=2
遇到'[': push("a", 2), cur="", num=0
遇到'c': cur="c"
遇到']': pop("a", 2) → cur = "a" + "c"*2 = "acc"
遇到']': pop("", 3)  → cur = "" + "acc"*3 = "accaccacc"
```

## Go 实现

```go
func decodeString(s string) string {
    numStack := []int{}
    strStack := []string{}
    cur := ""
    num := 0
    for _, ch := range s {
        switch {
        case ch >= '0' && ch <= '9':
            num = num*10 + int(ch-'0')
        case ch == '[':
            numStack = append(numStack, num)
            strStack = append(strStack, cur)
            num = 0
            cur = ""
        case ch == ']':
            k := numStack[len(numStack)-1]
            numStack = numStack[:len(numStack)-1]
            prev := strStack[len(strStack)-1]
            strStack = strStack[:len(strStack)-1]
            repeated := ""
            for i := 0; i < k; i++ {
                repeated += cur
            }
            cur = prev + repeated
        default:
            cur += string(ch)
        }
    }
    return cur
}
```

## 复杂度
- 时间：O(n × 最大重复次数)
- 空间：O(n)

## 记忆口诀
> 两个栈：数字栈和字符串栈。`[`入栈保存现场；`]`出栈恢复并重复当前串；数字多位数要 `num*10+digit`。
