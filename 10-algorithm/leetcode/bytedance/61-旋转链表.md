# 61. 旋转链表

> LeetCode 链接：https://leetcode.cn/problems/rotate-list/

## 题目
给定链表，向右旋转 k 个位置（把后 k 个节点移到前面）。

## 最易理解的方法：成环 + 找切割点

**核心思路：**
1. 计算链表长度 n，并将链表连成环
2. 找到新的尾节点（第 n-k%n 个节点），断开环

```
1→2→3→4→5, k=2

n=5, k%n=2
新尾=第3个节点(3), 新头=第4个节点(4)

成环: 1→2→3→4→5→1...
在3处断开: 4→5→1→2→3

答案: [4,5,1,2,3]
```

## Go 实现

```go
func rotateRight(head *ListNode, k int) *ListNode {
    if head == nil || head.Next == nil || k == 0 {
        return head
    }
    // 计算长度并找到尾节点
    tail := head
    n := 1
    for tail.Next != nil {
        tail = tail.Next
        n++
    }
    // 成环
    tail.Next = head
    // 找新尾节点（第 n-k%n 个）
    steps := n - k%n
    newTail := head
    for i := 1; i < steps; i++ {
        newTail = newTail.Next
    }
    newHead := newTail.Next
    newTail.Next = nil
    return newHead
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 成环后找新尾（第n-k%n个节点）；新尾之后是新头；断开环返回新头。
