# 692. 前 K 个高频单词

> LeetCode 链接：https://leetcode.cn/problems/top-k-frequent-words/

## 题目
给定单词列表，返回出现频率最高的 k 个单词（频率相同按字母顺序排序）。

## 最易理解的方法：统计频率 + 排序

**核心思路：**
统计频率后，按频率降序、字母升序排序，取前 k 个。

```
words=["i","love","leetcode","i","love","coding"], k=2

cnt: i=2, love=2, leetcode=1, coding=1
排序: 频率降序+字母升序 → i(2), love(2), coding(1), leetcode(1)
前k=2: ["i","love"]
```

## Go 实现

```go
import "sort"

func topKFrequent(words []string, k int) []string {
    cnt := make(map[string]int)
    for _, w := range words { cnt[w]++ }
    unique := make([]string, 0, len(cnt))
    for w := range cnt { unique = append(unique, w) }
    sort.Slice(unique, func(i, j int) bool {
        if cnt[unique[i]] != cnt[unique[j]] {
            return cnt[unique[i]] > cnt[unique[j]]
        }
        return unique[i] < unique[j]
    })
    return unique[:k]
}
```

## 复杂度
- 时间：O(n log n)
- 空间：O(n)

## 记忆口诀
> 统计频率→按频率降序字母升序排序→取前k个。
