# 344. 反转字符串

> LeetCode 链接：https://leetcode.cn/problems/reverse-string/

## 题目
原地反转字符串（字符数组），O(1) 额外空间。

## 最易理解的方法：双指针

```go
func reverseString(s []byte) {
    lo, hi := 0, len(s)-1
    for lo < hi {
        s[lo], s[hi] = s[hi], s[lo]
        lo++
        hi--
    }
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 头尾双指针交换，向中间收缩。
