# 523. 连续的子数组和

> LeetCode 链接：https://leetcode.cn/problems/continuous-subarray-sum/

## 题目
给定整数数组和整数 k，判断是否存在长度至少为 2 的连续子数组，其和为 k 的倍数。

## 最易理解的方法：前缀和取余 + 哈希表

**核心思路：**
若 prefix[j] % k == prefix[i] % k，则 sum(i+1..j) 是 k 的倍数。
哈希表存 {余数: 最早索引}，找到相同余数且距离>=2时返回 true。

```
nums=[23,2,4,6,7], k=6

prefix%k: 0,5,1,5,5,0(初始)
map: {0:-1}

i=0: pre=23%6=5, 无→存{5:0}
i=1: pre=25%6=1, 无→存{1:1}
i=2: pre=29%6=5, 有5在0 → j-i=2>=2 → true
```

## Go 实现

```go
func checkSubarraySum(nums []int, k int) bool {
    // map: remainder -> first occurrence index
    seen := map[int]int{0: -1}
    prefix := 0
    for i, n := range nums {
        prefix = (prefix + n) % k
        if j, ok := seen[prefix]; ok {
            if i-j >= 2 { return true }
        } else {
            seen[prefix] = i
        }
    }
    return false
}
```

## 复杂度
- 时间：O(n)
- 空间：O(k)

## 记忆口诀
> 前缀和取余；map存{余数:首次索引}(初始{0:-1})；找到相同余数且间距>=2返回true。
