# 463. 岛屿的周长

> LeetCode 链接：https://leetcode.cn/problems/island-perimeter/

## 题目
给定只有一个岛屿的网格（1=陆地，0=水），计算岛屿周长。

## 最易理解的方法：统计边

**核心思路：**
每个陆地格贡献4条边，遇到上方或左方也是陆地则各减2（共享边）。

```
1 1
1 0

格(0,0): 4边
格(0,1): 4-2(左)=2边
格(1,0): 4-2(上)=2边
总: 8
```

## Go 实现

```go
func islandPerimeter(grid [][]int) int {
    perimeter := 0
    for i := 0; i < len(grid); i++ {
        for j := 0; j < len(grid[0]); j++ {
            if grid[i][j] == 1 {
                perimeter += 4
                if i > 0 && grid[i-1][j] == 1 { perimeter -= 2 }
                if j > 0 && grid[i][j-1] == 1 { perimeter -= 2 }
            }
        }
    }
    return perimeter
}
```

## 复杂度
- 时间：O(m×n)
- 空间：O(1)

## 记忆口诀
> 每格+4；上方是陆地-2；左方是陆地-2；遍历一遍即可。
