# 160. 相交链表

> LeetCode 链接：https://leetcode.cn/problems/intersection-of-two-linked-lists/

## 题目
找到两个单链表相交的起始节点，不相交则返回 null。

## 最易理解的方法：双指针等路程

**核心思路：**
两个指针各自走完自己的链表后，再走对方的链表。由于 `lenA + lenB = lenB + lenA`，两个指针走的总路程相同，相遇时必然在交点（或同时到 null）。

```
链表A: a1 -> a2 -> c1 -> c2 -> c3
链表B:       b1 -> b2 -> b3 -> c1 -> c2 -> c3

pA: a1 a2 c1 c2 c3 nil b1 b2 b3 [c1] ← 相遇
pB: b1 b2 b3 c1 c2 c3 nil a1 a2 [c1] ← 相遇
```

**算法步骤：**
1. `pA = headA`，`pB = headB`
2. 循环：若 `pA == pB` 返回（包括都为 nil）；否则 `pA` 走到头则跳到 `headB`，否则 `pA = pA.Next`；`pB` 同理
3. 返回 `pA`

## Go 实现

```go
func getIntersectionNode(headA, headB *ListNode) *ListNode {
    pA, pB := headA, headB
    for pA != pB {
        if pA == nil {
            pA = headB // 走完A，换到B的起点
        } else {
            pA = pA.Next
        }
        if pB == nil {
            pB = headA // 走完B，换到A的起点
        } else {
            pB = pB.Next
        }
    }
    return pA // 相交节点或 nil
}
```

## 复杂度
- 时间：O(m+n)
- 空间：O(1)

## 记忆口诀
> 各走自己再走对方，路程相等，相遇即交点。
