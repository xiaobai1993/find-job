# 621. 任务调度器

> LeetCode 链接：https://leetcode.cn/problems/task-scheduler/

## 题目
给定 CPU 任务列表和冷却间隔 n，同类任务需间隔 n 个单位时间。求完成所有任务的最短时间。

## 最易理解的方法：贪心（数学公式）

**核心思路：**
关键思路：最多出现的任务决定框架。
设最高频率为 maxFreq，出现该频率的任务数为 maxCount。
- 至少需要 `(maxFreq-1)*(n+1) + maxCount` 个时间单位
- 但如果任务总数更多，则取任务总数

```
tasks=["A","A","A","B","B","B"], n=2

A,B各3次, maxFreq=3, maxCount=2
框架: A_B A_B AB = (3-1)*(2+1)+2 = 8
实际任务数=6 < 8

答案=max(6,8)=8
```

## Go 实现

```go
func leastInterval(tasks []byte, n int) int {
    count := [26]int{}
    for _, t := range tasks {
        count[t-'A']++
    }
    maxFreq := 0
    for _, c := range count {
        if c > maxFreq {
            maxFreq = c
        }
    }
    maxCount := 0
    for _, c := range count {
        if c == maxFreq {
            maxCount++
        }
    }
    result := (maxFreq-1)*(n+1) + maxCount
    if len(tasks) > result {
        return len(tasks)
    }
    return result
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 公式：(maxFreq-1)*(n+1)+maxCount；与任务总数取max（任务足够多时无需等待）。
