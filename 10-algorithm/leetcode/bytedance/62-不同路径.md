# 62. 不同路径

> LeetCode 链接：https://leetcode.cn/problems/unique-paths/

## 题目
一个机器人位于 m×n 网格左上角，每次只能向下或向右移动，求到达右下角的不同路径数。

## 最易理解的方法：动态规划

**核心思路：**
`dp[i][j]` 表示到达 `(i, j)` 的路径数。只能从上方 `(i-1,j)` 或左方 `(i,j-1)` 来，所以 `dp[i][j] = dp[i-1][j] + dp[i][j-1]`。第一行和第一列全为 1（只有一种走法）。

```
m=3, n=7
dp:
1 1 1 1 1 1 1
1 2 3 4 5 6 7
1 3 6 10 15 21 28

答案 = dp[2][6] = 28
```

## Go 实现

```go
func uniquePaths(m int, n int) int {
    dp := make([][]int, m)
    for i := range dp {
        dp[i] = make([]int, n)
        dp[i][0] = 1 // 第一列
    }
    for j := 0; j < n; j++ {
        dp[0][j] = 1 // 第一行
    }
    for i := 1; i < m; i++ {
        for j := 1; j < n; j++ {
            dp[i][j] = dp[i-1][j] + dp[i][j-1]
        }
    }
    return dp[m-1][n-1]
}
```

## 复杂度
- 时间：O(m × n)
- 空间：O(m × n)，可优化为 O(n)（一维滚动）

## 记忆口诀
> dp[i][j] = 上方 + 左方；第一行第一列全为1；从左上到右下填表。
