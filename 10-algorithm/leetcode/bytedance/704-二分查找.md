# 704. 二分查找

> LeetCode 链接：https://leetcode.cn/problems/binary-search/

## 题目
给定升序整数数组和目标值，返回目标值的下标。不存在则返回 -1。

## 最易理解的方法：二分查找

**核心思路：**
标准二分：每次取中间位置，根据与 target 的大小关系缩小范围。

```
nums=[-1,0,3,5,9,12], target=9

lo=0, hi=5
mid=2: nums[2]=3<9 → lo=3
mid=4: nums[4]=9==9 → 返回4
```

## Go 实现

```go
func search(nums []int, target int) int {
    lo, hi := 0, len(nums)-1
    for lo <= hi {
        mid := lo + (hi-lo)/2
        if nums[mid] == target {
            return mid
        } else if nums[mid] < target {
            lo = mid + 1
        } else {
            hi = mid - 1
        }
    }
    return -1
}
```

## 复杂度
- 时间：O(log n)
- 空间：O(1)

## 记忆口诀
> 标准二分：lo<=hi；找到返回mid；小了lo=mid+1；大了hi=mid-1；未找到返回-1。
