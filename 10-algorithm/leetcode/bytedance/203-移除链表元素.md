# 203. 移除链表元素

> LeetCode 链接：https://leetcode.cn/problems/remove-linked-list-elements/

## 题目
给定链表头节点和整数 val，删除链表中所有值等于 val 的节点，返回新头节点。

## 最易理解的方法：哑节点（dummy head）

**核心思路：**
加哑节点避免处理头节点特殊情况，遍历时跳过值等于 val 的节点。

```
head=1->2->6->3->6, val=6

dummy -> 1 -> 2 -> 6 -> 3 -> 6
              ↑
              cur.Next.Val==6 → cur.Next = cur.Next.Next
dummy -> 1 -> 2 -> 3 -> 6
                   ↑
                   cur.Next.Val==6 → skip
dummy -> 1 -> 2 -> 3
```

## Go 实现

```go
func removeElements(head *ListNode, val int) *ListNode {
    dummy := &ListNode{Next: head}
    cur := dummy
    for cur.Next != nil {
        if cur.Next.Val == val {
            cur.Next = cur.Next.Next
        } else {
            cur = cur.Next
        }
    }
    return dummy.Next
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 哑节点开头；遇到目标值跳过（不移动cur）；否则cur前进。
