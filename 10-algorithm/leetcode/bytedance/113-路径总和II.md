# 113. 路径总和 II

> LeetCode 链接：https://leetcode.cn/problems/path-sum-ii/

## 题目
给定二叉树和目标值 `targetSum`，返回所有从根到叶路径和等于 targetSum 的路径。

## 最易理解的方法：DFS 回溯

**核心思路：**
DFS 带路径记录，到达叶节点且 target==0 时，复制路径加入结果。回溯时弹出当前节点。

```
    5
   / \
  4   8
 /   / \
11  13   4
/ \     / \
7   2   5   1

target=22
路径 5→4→11→2 和=22 ✓
路径 5→8→4→5 和=22 ✓
```

## Go 实现

```go
func pathSum(root *TreeNode, targetSum int) [][]int {
    var res [][]int
    var path []int
    var dfs func(node *TreeNode, remain int)
    dfs = func(node *TreeNode, remain int) {
        if node == nil {
            return
        }
        path = append(path, node.Val)
        remain -= node.Val
        // 叶节点且路径和等于target
        if node.Left == nil && node.Right == nil && remain == 0 {
            tmp := make([]int, len(path))
            copy(tmp, path)
            res = append(res, tmp)
        }
        dfs(node.Left, remain)
        dfs(node.Right, remain)
        path = path[:len(path)-1] // 回溯
    }
    dfs(root, targetSum)
    return res
}
```

## 复杂度
- 时间：O(n)
- 空间：O(h)

## 记忆口诀
> DFS带路径；叶节点且remain=0则复制路径加入结果；返回前弹出节点（回溯）。
