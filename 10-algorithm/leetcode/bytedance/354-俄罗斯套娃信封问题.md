# 354. 俄罗斯套娃信封问题

> LeetCode 链接：https://leetcode.cn/problems/russian-doll-envelopes/

## 题目
给定 `envelopes[i] = [wi, hi]`，当一个信封宽和高都大于另一个时可以套入，求最多能套多少层。

## 最易理解的方法：排序 + LIS（最长上升子序列）

**核心思路：**
1. 按宽度升序排，宽度相同时按高度降序排（防止同宽度的信封被计入 LIS）
2. 对高度求最长上升子序列

```
envelopes = [[5,4],[6,4],[6,7],[2,3]]

排序后: [[2,3],[5,4],[6,7],[6,4]]
（宽度升序，同宽度按高度降序）

高度序列: [3,4,7,4]

LIS: 3→4→7 = 3（4不能接在7后，同宽6只能选一个高度）
```

## Go 实现

```go
import "sort"

func maxEnvelopes(envelopes [][]int) int {
    sort.Slice(envelopes, func(i, j int) bool {
        if envelopes[i][0] == envelopes[j][0] {
            return envelopes[i][1] > envelopes[j][1] // 同宽度高度降序
        }
        return envelopes[i][0] < envelopes[j][0] // 宽度升序
    })
    // 对高度求 LIS（二分法，O(n log n)）
    tails := []int{}
    for _, e := range envelopes {
        h := e[1]
        lo, hi := 0, len(tails)
        for lo < hi {
            mid := (lo + hi) / 2
            if tails[mid] < h {
                lo = mid + 1
            } else {
                hi = mid
            }
        }
        if lo == len(tails) {
            tails = append(tails, h)
        } else {
            tails[lo] = h
        }
    }
    return len(tails)
}
```

## 复杂度
- 时间：O(n log n)
- 空间：O(n)

## 记忆口诀
> 宽升序+同宽高降序；然后对高度求LIS；降序防止同宽信封互相套娃。
