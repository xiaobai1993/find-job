# 3. 无重复字符的最长子串

题目链接：`https://leetcode.cn/problems/longest-substring-without-repeating-characters/`

---

## 一、题目描述

给定一个字符串 `s`，找出其中不含重复字符的**最长子串**的长度。

注意是**子串**（连续），不是子序列。

**示例：**

```
输入: "abcabcbb"
输出: 3
解释: "abc"，长度 3

输入: "bbbbb"
输出: 1
解释: "b"，长度 1

输入: "pwwkew"
输出: 3
解释: "wke"，长度 3（注意不是 "pwke"，子串必须连续）
```

---

## 二、思路：滑动窗口

核心想法：维护一个窗口 `[left, right]`，窗口内的字符都不重复。

- `right` 一步步往右走，把新字符加进窗口
- 如果新字符已经在窗口里了，就把 `left` 往右推，推到重复字符的后面
- 每一步记录窗口长度，取最大值

图解 `"abcabcbb"`：

```
步骤1: [a] b c a b c b b    窗口="a"       长度=1
步骤2: [a b] c a b c b b    窗口="ab"      长度=2
步骤3: [a b c] a b c b b    窗口="abc"     长度=3  ← 最大
步骤4:  a [b c a] b c b b   left跳到1      窗口="bca"  长度=3
步骤5:  a  b [c a b] c b b  left跳到2      窗口="cab"  长度=3
步骤6:  a  b  c [a b c] b b left跳到3      窗口="abc"  长度=3
步骤7:  a  b  c  a  b [c b] b left跳到5   窗口="cb"   长度=2
步骤8:  a  b  c  a  b  c  [b] left跳到7    窗口="b"    长度=1

结果: 3
```

关键操作：`left` 不是一步步挪，而是**直接跳**到重复字符的下一个位置。

---

## 三、用哈希表记录字符位置

需要一个 `map[byte]int` 来记录每个字符最近出现的位置。

这样当遇到重复字符时，`left` 可以直接跳过去：

```
charIndex = {a:0, b:1, c:2}

right走到3，s[3]='a'，'a'上次出现在位置0
left 跳到 max(left, 0+1) = 1
```

为什么要 `max(left, 旧位置+1)`？

因为旧位置可能在 `left` 的左边（已经不在窗口里了），这时 `left` 不应该往回退。

例子 `"abba"`：

```
步骤1: [a] b b a    charIndex={a:0}  长度=1
步骤2: [a b] b a    charIndex={a:0,b:1}  长度=2
步骤3:  a [b b] a   'b'重复在位置1，left=max(0,1+1)=2  charIndex={a:0,b:2}  长度=2
步骤4:  a  b [b a]  'a'重复在位置0，left=max(2,0+1)=2  不回退！ charIndex={a:3,b:2}  长度=2

结果: 2
```

如果不用 `max`，步骤4 会把 `left` 从 2 退回 1，结果变成 3（错误）。

---

## 四、Go 代码

```go
func lengthOfLongestSubstring(s string) int {
    // 记录每个字符最近出现的位置
    charIndex := make(map[byte]int)
    left := 0
    maxLen := 0

    for right := 0; right < len(s); right++ {
        ch := s[right]

        // 如果字符出现过，且位置在窗口内，left 跳过去
        if pos, ok := charIndex[ch]; ok && pos >= left {
            left = pos + 1
        }

        // 更新字符位置
        charIndex[ch] = right

        // 计算窗口长度
        if right-left+1 > maxLen {
            maxLen = right - left + 1
        }
    }

    return maxLen
}
```

## 五、逐行解释

```go
// 1. 哈希表：字符 → 上次出现的下标
charIndex := make(map[byte]int)

// 2. 窗口左边界
left := 0

// 3. right 遍历每个字符
for right := 0; right < len(s); right++ {

    // 4. 检查当前字符是否在窗口内重复
    if pos, ok := charIndex[ch]; ok && pos >= left {
        //    pos >= left 说明上次出现的位置还在窗口内
        //    left 直接跳到 pos+1，跳过重复字符
        left = pos + 1
    }

    // 5. 不管有没有重复，都更新当前位置
    charIndex[ch] = right

    // 6. 窗口长度 = right - left + 1
    maxLen = max(maxLen, right-left+1)
}
```

## 六、例子完整走一遍

`s = "pwwkew"`

```
初始化: charIndex={}, left=0, maxLen=0

right=0, ch='p':
  'p'没出现过
  charIndex={p:0}
  窗口="p", 长度=1, maxLen=1

right=1, ch='w':
  'w'没出现过
  charIndex={p:0, w:1}
  窗口="pw", 长度=2, maxLen=2

right=2, ch='w':
  'w'上次在位置1, 1 >= left(0) ✓
  left = 1 + 1 = 2
  charIndex={p:0, w:2}
  窗口="w", 长度=1, maxLen=2

right=3, ch='k':
  'k'没出现过
  charIndex={p:0, w:2, k:3}
  窗口="wk", 长度=2, maxLen=2

right=4, ch='e':
  'e'没出现过
  charIndex={p:0, w:2, k:3, e:4}
  窗口="wke", 长度=3, maxLen=3

right=5, ch='w':
  'w'上次在位置2, 2 >= left(2) ✓
  left = 2 + 1 = 3
  charIndex={p:0, w:5, k:3, e:4}
  窗口="kew", 长度=3, maxLen=3

结果: 3
```

## 七、复杂度分析

- **时间**：O(n)，right 走一遍，left 最多也走一遍
- **空间**：O(min(m, n))，m 是字符集大小（ASCII 128 / Unicode 更大）

---

## 八、容易错的点

### 1. left 不能回退

```go
// ✗ 错误写法
if pos, ok := charIndex[ch]; ok {
    left = pos + 1  // 旧位置可能在 left 左边，会导致 left 回退
}

// ✓ 正确写法
if pos, ok := charIndex[ch]; ok && pos >= left {
    left = pos + 1
}
```

反例 `"abba"`，不用 `pos >= left` 会让 `left` 从 2 退回 1。

### 2. 窗口长度是 right - left + 1

不是 `right - left`，因为两个端点都包含。

### 3. 先移 left 再更新 map

顺序很重要：

```
1. 判断重复 → 移 left
2. 更新 charIndex[ch] = right
3. 算长度
```

如果先更新 map 再移 left，判断就会用到错误的位置。

### 4. 子串不是子序列

子串 = 连续的
子序列 = 可以不连续

这题求的是子串。

## 九、面试表达

> 这题用滑动窗口。维护一个窗口 `[left, right]`，用哈希表记录每个字符最近出现的位置。`right` 逐个遍历字符，如果当前字符已经在窗口内出现过（位置 >= left），就把 `left` 跳到那个位置的下一个。然后更新字符位置，计算窗口长度取最大值。时间 O(n)，空间 O(字符集大小)。

## 十、一句话记忆

```text
滑动窗口找子串，哈希表记位置，重复了 left 跳过去，长度 = right - left + 1。
```

再短一点：

```text
窗口右扩遇重复，left 跳到旧位后一位；pos >= left 才跳，防回退。
```
