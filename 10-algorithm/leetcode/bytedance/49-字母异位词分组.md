# 49. 字母异位词分组

> LeetCode 链接：https://leetcode.cn/problems/group-anagrams/

## 题目
给定字符串数组，将字母异位词分组（字母相同、顺序不同的单词）。

## 最易理解的方法：哈希表 + 排序键

**核心思路：**
将每个单词的字母排序后作为 key，相同 key 的单词是异位词，存入同一组。

```
["eat","tea","tan","ate","nat","bat"]

sort("eat") = "aet" → [eat, tea, ate]
sort("tan") = "ant" → [tan, nat]
sort("bat") = "abt" → [bat]
```

## Go 实现

```go
import "sort"

func groupAnagrams(strs []string) [][]string {
    groups := make(map[string][]string)
    for _, s := range strs {
        // 排序作为键
        bytes := []byte(s)
        sort.Slice(bytes, func(i, j int) bool {
            return bytes[i] < bytes[j]
        })
        key := string(bytes)
        groups[key] = append(groups[key], s)
    }
    res := make([][]string, 0, len(groups))
    for _, v := range groups {
        res = append(res, v)
    }
    return res
}
```

## 复杂度
- 时间：O(n × k log k)，k 为最长字符串长度
- 空间：O(n × k)

## 记忆口诀
> 排序字母作key，相同key分一组；哈希表收集，最后取values。
