# 134. 加油站

> LeetCode 链接：https://leetcode.cn/problems/gas-station/

## 题目
环形公路上有 n 个加油站，`gas[i]` 是第 i 个站的汽油量，`cost[i]` 是从 i 到下一站的花费。求从哪个站出发能绕圆圈一圈，不存在则返回 -1。

## 最易理解的方法：贪心一次遍历

**核心思路：**
1. 若总 gas < 总 cost，则一定无解（返回 -1）
2. 否则，一定有解。从某个站开始，维护当前剩余油量 tank。当 tank < 0 时，将起点更新为下一个站（当前起点不可行）。

```
gas  = [1,2,3,4,5]
cost = [3,4,5,1,2]

diff = [-2,-2,-2,3,3]

从0: tank=-2<0 → 起点=1
从1: tank=-4<0 → 起点=2
从2: tank=-6<0 → 起点=3
从3: tank=3,从3+3=3+3=6,tank=4 (到0), tank=2 (到1), tank=1 → 绕圈成功

答案=3
```

## Go 实现

```go
func canCompleteCircuit(gas []int, cost []int) int {
    total, tank, start := 0, 0, 0
    for i := range gas {
        diff := gas[i] - cost[i]
        total += diff
        tank += diff
        if tank < 0 {
            start = i + 1
            tank = 0
        }
    }
    if total < 0 {
        return -1
    }
    return start
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 总和<0无解；否则贪心：tank<0时更新起点为i+1，重置tank；最终start即答案。
