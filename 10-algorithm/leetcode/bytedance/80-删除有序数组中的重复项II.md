# 80. 删除有序数组中的重复项 II

> LeetCode 链接：https://leetcode.cn/problems/remove-duplicates-from-sorted-array-ii/

## 题目
给定有序数组，原地删除重复出现 2 次以上的元素，使每个元素最多出现 2 次，返回新长度。

## 最易理解的方法：双指针

**核心思路：**
slow 指针记录写入位置。每个元素最多保留 2 次，当 `nums[fast] != nums[slow-2]` 时才写入（前两个位置总是保留）。

```
nums=[1,1,1,2,2,3]

slow=2(前两个直接保留)
fast=2(1): 1==nums[slow-2=0]=1 → 跳过
fast=3(2): 2!=nums[0]=1 → nums[2]=2, slow=3
fast=4(2): 2==nums[1]=1? 不,2!=1 → nums[3]=2, slow=4
fast=5(3): 3!=nums[2]=2 → nums[4]=3, slow=5

结果: [1,1,2,2,3], 返回5
```

## Go 实现

```go
func removeDuplicates(nums []int) int {
    slow := 0
    for _, v := range nums {
        if slow < 2 || v != nums[slow-2] {
            nums[slow] = v
            slow++
        }
    }
    return slow
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> slow<2直接写入；否则当前值!=nums[slow-2]才写入（确保最多出现2次）。
