# 240. 搜索二维矩阵 II

> LeetCode 链接：https://leetcode.cn/problems/search-a-2d-matrix-ii/

## 题目
m×n 矩阵：每行从左到右递增，每列从上到下递增（不保证每行首元素大于上行末元素）。判断目标值是否在矩阵中。

## 最易理解的方法：从右上角开始搜索

**核心思路：**
从**右上角** `(0, n-1)` 出发：
- 若当前值 == target：找到，返回 true
- 若当前值 > target：说明整列都大于 target，col--（向左移动）
- 若当前值 < target：说明整行都小于 target，row++（向下移动）

每步排除一行或一列，总步数最多 m+n。

```
matrix:
1  4  7  11
2  5  8  12
3  6  9  16
10 13 14 17

target=5, 从(0,3)=11开始:
11>5 → col=2, (0,2)=7
7>5  → col=1, (0,1)=4
4<5  → row=1, (1,1)=5
5==5 → found!
```

## Go 实现

```go
func searchMatrix(matrix [][]int, target int) bool {
    row, col := 0, len(matrix[0])-1
    for row < len(matrix) && col >= 0 {
        val := matrix[row][col]
        if val == target {
            return true
        } else if val > target {
            col-- // 排除当前列
        } else {
            row++ // 排除当前行
        }
    }
    return false
}
```

## 复杂度
- 时间：O(m + n)
- 空间：O(1)

## 记忆口诀
> 从右上角出发；比target大则左移（col--），比target小则下移（row++）；每步排除一行或一列。
