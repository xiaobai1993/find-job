# 239. 滑动窗口最大值

> LeetCode 链接：https://leetcode.cn/problems/sliding-window-maximum/

## 题目
给定数组 `nums` 和整数 `k`，有一个大小为 k 的滑动窗口从左向右移动，返回每个窗口中的最大值。

## 最易理解的方法：单调递减双端队列（Deque）

**核心思路：**
维护一个存**下标**的双端队列（deque），保持队列中的下标对应的值单调递减。每次：
1. 移除队头中超出窗口范围的下标
2. 移除队尾所有比当前值小的下标（它们不可能是最大值了）
3. 将当前下标加入队尾
4. 当窗口大小达到 k 时，队头就是当前窗口最大值

```
nums = [1,3,-1,-3,5,3,6,7], k=3

i=0: deque=[0]                  无输出
i=1: 3>1,弹0, deque=[1]         无输出
i=2: -1<3, deque=[1,2]          输出nums[1]=3
i=3: -3<-1, deque=[1,2,3]       输出nums[1]=3; 1未超窗口
i=4: 5>-3>-1>3弹完, deque=[4]   输出nums[4]=5
i=5: 3<5, deque=[4,5]           输出nums[4]=5
i=6: 6>3弹5,6>5弹4, deque=[6]   输出nums[6]=6
i=7: 7>6弹6, deque=[7]          输出nums[7]=7
```

## Go 实现

```go
func maxSlidingWindow(nums []int, k int) []int {
    deque := []int{} // 存下标，值单调递减
    var ans []int
    for i := 0; i < len(nums); i++ {
        // 移除超出窗口的队头
        for len(deque) > 0 && deque[0] <= i-k {
            deque = deque[1:]
        }
        // 移除队尾所有比当前值小的元素
        for len(deque) > 0 && nums[deque[len(deque)-1]] <= nums[i] {
            deque = deque[:len(deque)-1]
        }
        deque = append(deque, i)
        // 窗口形成后输出最大值（队头）
        if i >= k-1 {
            ans = append(ans, nums[deque[0]])
        }
    }
    return ans
}
```

## 复杂度
- 时间：O(n)（每个元素最多入队出队一次）
- 空间：O(k)

## 记忆口诀
> 单调递减双端队列；队头维护窗口内最大值；入队前清掉队尾更小的；同时清掉队头超范围的。
