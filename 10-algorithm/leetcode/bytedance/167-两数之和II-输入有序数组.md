# 167. 两数之和 II - 输入有序数组

> LeetCode 链接：https://leetcode.cn/problems/two-sum-ii-input-array-is-sorted/

## 题目
给定升序数组和目标值，找到两个数使其和等于目标值，返回它们的下标（1-indexed）。只存在一个答案。

## 最易理解的方法：双指针

**核心思路：**
头尾双指针：
- 两数之和 == target：返回
- 两数之和 < target：左指针右移（增大和）
- 两数之和 > target：右指针左移（减小和）

```
numbers=[2,7,11,15], target=9

lo=0, hi=3: 2+15=17>9 → hi=2
lo=0, hi=2: 2+11=13>9 → hi=1
lo=0, hi=1: 2+7=9==9 → 返回[1,2]
```

## Go 实现

```go
func twoSum(numbers []int, target int) []int {
    lo, hi := 0, len(numbers)-1
    for lo < hi {
        sum := numbers[lo] + numbers[hi]
        if sum == target {
            return []int{lo + 1, hi + 1}
        } else if sum < target {
            lo++
        } else {
            hi--
        }
    }
    return nil
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 头尾双指针；和<target左移，和>target右移；找到则返回(1-indexed)。
