# 162. 寻找峰值

> LeetCode 链接：https://leetcode.cn/problems/find-peak-element/

## 题目
给定整数数组（相邻元素不相等），找到峰值元素（其值大于相邻元素）的下标。数组边界外的值视为 -∞。时间复杂度 O(log n)。

## 最易理解的方法：二分查找

**核心思路：**
比较 `nums[mid]` 和 `nums[mid+1]`：
- 若 `nums[mid] < nums[mid+1]`：右边一定有峰值（值在增加），`left = mid + 1`
- 若 `nums[mid] > nums[mid+1]`：左边（含mid）一定有峰值（值在减少），`right = mid`

最终 `left == right` 就是峰值位置。

```
nums = [1, 2, 3, 1]

lo=0, hi=3
mid=1: nums[1]=2 < nums[2]=3 → lo=2
mid=2: nums[2]=3 > nums[3]=1 → hi=2
lo==hi==2 → 峰值在下标2，值=3
```

## Go 实现

```go
func findPeakElement(nums []int) int {
    lo, hi := 0, len(nums)-1
    for lo < hi {
        mid := (lo + hi) / 2
        if nums[mid] < nums[mid+1] {
            lo = mid + 1 // 峰在右边
        } else {
            hi = mid // 峰在左边（含mid）
        }
    }
    return lo
}
```

## 复杂度
- 时间：O(log n)
- 空间：O(1)

## 记忆口诀
> 二分：若mid<mid+1则峰在右（lo=mid+1），否则峰在左含mid（hi=mid）；lo==hi即峰值位置。
