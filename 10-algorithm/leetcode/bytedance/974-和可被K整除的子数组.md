# 974. 和可被 K 整除的子数组

> LeetCode 链接：https://leetcode.cn/problems/subarray-sums-divisible-by-k/

## 题目
给定整数数组和整数 k，返回和可被 k 整除的子数组个数。

## 最易理解的方法：前缀和取余 + 哈希表

**核心思路：**
若 prefix[j] % k == prefix[i] % k，则 sum(i+1..j) 能被 k 整除。
统计每个余数出现次数，组合数 C(cnt,2) = cnt*(cnt-1)/2。

```
nums=[4,5,0,-2,-3,1], k=5

prefix%k: 0,4,4,4,2,4,0
count: {0:2, 4:4, 2:1}
结果: C(2,2)+C(4,2)+C(1,2) = 1+6+0 = 7
```

## Go 实现

```go
func subarraysDivByK(nums []int, k int) int {
    cnt := map[int]int{0: 1}
    prefix, res := 0, 0
    for _, n := range nums {
        prefix = (prefix + n) % k
        if prefix < 0 { prefix += k } // 处理负数
        res += cnt[prefix]
        cnt[prefix]++
    }
    return res
}
```

## 复杂度
- 时间：O(n)
- 空间：O(k)

## 记忆口诀
> 前缀和取余(负数加k)；哈希表统计余数出现次数；每次res+=cnt[余数]（组合同余对）。
