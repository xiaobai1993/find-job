# 84. 柱状图中最大的矩形

> LeetCode 链接：https://leetcode.cn/problems/largest-rectangle-in-histogram/

## 题目
给定柱状图中各柱子的高度数组，计算能勾勒出的最大矩形面积。

## 最易理解的方法：单调递增栈

**核心思路：**
维护单调递增栈（存下标）。当遇到比栈顶矮的柱子时，弹出栈顶，以弹出的高度为矩形高，宽度为 `当前下标 - 新栈顶下标 - 1`（当前柱子的前一个较矮者到新栈顶之间的宽度），计算面积。在两端各加一个高度为 0 的哨兵。

```
heights = [2, 1, 5, 6, 2, 3]  (加哨兵:[0,2,1,5,6,2,3,0])

遍历遇到更矮时出栈计算：
...
i=5(h=2): 弹6(i=4), 宽=5-3-1=1, 面积=6×1=6
          弹5(i=3), 宽=5-2-1=2, 面积=5×2=10 ← 最大
i=7(h=0): 清空所有...
```

## Go 实现

```go
func largestRectangleArea(heights []int) int {
    // 加哨兵
    h := make([]int, len(heights)+2)
    copy(h[1:], heights)
    stack := []int{0} // 存下标
    ans := 0
    for i := 1; i < len(h); i++ {
        for h[i] < h[stack[len(stack)-1]] {
            height := h[stack[len(stack)-1]]
            stack = stack[:len(stack)-1]
            width := i - stack[len(stack)-1] - 1
            area := height * width
            if area > ans {
                ans = area
            }
        }
        stack = append(stack, i)
    }
    return ans
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> 单调递增栈；遇矮时弹栈，宽=当前下标-新栈顶-1；两端加0哨兵确保全部弹出。
