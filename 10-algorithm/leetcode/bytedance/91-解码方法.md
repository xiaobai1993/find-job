# 91. 解码方法

> LeetCode 链接：https://leetcode.cn/problems/decode-ways/

## 题目
数字编码规则：A=1, B=2, ..., Z=26。给定只包含数字的字符串 `s`，返回可能解码的方法总数。

## 最易理解的方法：动态规划

**核心思路：**
`dp[i]` 表示 `s[0:i]` 有多少种解码方式。
- 单个字符解码：若 `s[i-1] != '0'`，则 `dp[i] += dp[i-1]`
- 两个字符解码：若 `s[i-2:i]` 在 `10~26` 之间，则 `dp[i] += dp[i-2]`

```
s = "226"

dp[0] = 1 (空串)
dp[1] = 1 (s[0]='2', 单字符'B')
dp[2] = 2 (s[0:2]="22"=22→V, 或2,2→BB)
dp[3] = 3 (s[0:3]="226"→BBF/VF/BZ, 三种)
```

## Go 实现

```go
func numDecodings(s string) int {
    n := len(s)
    dp := make([]int, n+1)
    dp[0] = 1 // 空串
    if s[0] != '0' {
        dp[1] = 1
    }
    for i := 2; i <= n; i++ {
        // 单字符
        if s[i-1] != '0' {
            dp[i] += dp[i-1]
        }
        // 两字符
        twoDigit := (int(s[i-2]-'0'))*10 + int(s[i-1]-'0')
        if twoDigit >= 10 && twoDigit <= 26 {
            dp[i] += dp[i-2]
        }
    }
    return dp[n]
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> dp[i]：单字符非'0'则+dp[i-1]；两字符在10~26则+dp[i-2]；dp[0]=1作初始。
