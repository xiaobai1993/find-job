# 406. 根据身高重建队列

> LeetCode 链接：https://leetcode.cn/problems/queue-reconstruction-by-height/

## 题目
给定 `people[i] = [hi, ki]`，表示每个人的身高和前面有多少个身高 ≥ hi 的人。重建队列。

## 最易理解的方法：贪心（从高到矮插入）

**核心思路：**
1. 按身高降序排，身高相同则 k 小的在前
2. 依次按 k 值插入到对应位置（高个子已在正确位置，矮个子插入不影响高个子的计数）

```
people = [[7,0],[4,4],[7,1],[5,0],[6,1],[5,2]]

按高降序: [[7,0],[7,1],[6,1],[5,0],[5,2],[4,4]]

插入:
[7,0] → 位置0: [[7,0]]
[7,1] → 位置1: [[7,0],[7,1]]
[6,1] → 位置1: [[7,0],[6,1],[7,1]]
[5,0] → 位置0: [[5,0],[7,0],[6,1],[7,1]]
[5,2] → 位置2: [[5,0],[7,0],[5,2],[6,1],[7,1]]
[4,4] → 位置4: [[5,0],[7,0],[5,2],[6,1],[4,4],[7,1]]

答案: [[5,0],[7,0],[5,2],[6,1],[4,4],[7,1]]
```

## Go 实现

```go
import "sort"

func reconstructQueue(people [][]int) [][]int {
    sort.Slice(people, func(i, j int) bool {
        if people[i][0] == people[j][0] {
            return people[i][1] < people[j][1] // 相同高度k小的在前
        }
        return people[i][0] > people[j][0] // 身高降序
    })
    res := make([][]int, 0, len(people))
    for _, p := range people {
        // 在位置p[1]插入
        pos := p[1]
        res = append(res, nil)
        copy(res[pos+1:], res[pos:])
        res[pos] = p
    }
    return res
}
```

## 复杂度
- 时间：O(n²)（切片插入）
- 空间：O(n)

## 记忆口诀
> 高降序排（同高k小在前）；逐个按k值插入对应位置；高个子先入不受矮个子影响。
