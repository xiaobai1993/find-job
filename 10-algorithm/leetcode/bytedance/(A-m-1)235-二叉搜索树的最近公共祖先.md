# 235. 二叉搜索树的最近公共祖先

> LeetCode 链接：https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-search-tree/

## 题目
给定二叉搜索树和两个节点 p、q，找到它们的最近公共祖先。

## 最易理解的方法：利用 BST 性质

**核心思路：**
BST 中：
- 若当前节点值 > max(p,q)：两个节点都在左子树，向左走
- 若当前节点值 < min(p,q)：两个节点都在右子树，向右走
- 否则：当前节点就是最近公共祖先（一个在左一个在右，或就是p/q本身）

```
    6
   / \
  2   8
 / \ / \
0  4 7  9
  / \
  3   5

p=2, q=8: 6在[2,8]之间 → LCA=6
p=2, q=4: 6>4向左→2<2?不,2在[2,4]间 → LCA=2
```

## Go 实现

```go
func lowestCommonAncestor(root, p, q *TreeNode) *TreeNode {
    for root != nil {
        if root.Val > p.Val && root.Val > q.Val {
            root = root.Left
        } else if root.Val < p.Val && root.Val < q.Val {
            root = root.Right
        } else {
            return root
        }
    }
    return nil
}
```

## 复杂度
- 时间：O(h)
- 空间：O(1)（迭代版）

## 记忆口诀
> BST性质：比两个都大→左；比两个都小→右；否则当前节点就是LCA。
