# 56. 合并区间

题目链接：`https://leetcode.cn/problems/merge-intervals/`

---

## 一、题目描述

以数组 `intervals` 表示若干个区间的集合，其中单个区间为 `intervals[i] = [starti, endi]`。请你合并所有重叠的区间，并返回一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间。

**示例：**

```
输入: intervals = [[1,3],[2,6],[8,10],[15,18]]
输出: [[1,6],[8,10],[15,18]]
解释: 区间 [1,3] 和 [2,6] 重叠，合并为 [1,6]

输入: intervals = [[1,4],[4,5]]
输出: [[1,5]]
解释: 区间 [1,4] 和 [4,5] 可被视为重叠区间（端点相接也算重叠）
```

---

## 二、思路：排序 + 贪心扫描

核心想法：**先按左端点排序，再逐个判断是否能合并。**

排序后，相邻区间如果能合并，一定是连续排列的，不会出现"跳跃式"重叠。

```
排序前: [[2,6],[1,3],[8,10],[15,18]]
排序后: [[1,3],[2,6],[8,10],[15,18]]

扫描：
当前区间 [1,3]，加入结果 → result=[[1,3]]
下一个 [2,6]：2 <= 3（重叠），合并为 [1,max(3,6)]=[1,6] → result=[[1,6]]
下一个 [8,10]：8 > 6（不重叠），加入结果 → result=[[1,6],[8,10]]
下一个 [15,18]：15 > 10（不重叠），加入结果 → result=[[1,6],[8,10],[15,18]]

结果: [[1,6],[8,10],[15,18]]  ✓
```

判断是否重叠：`下一个区间的左端 <= 当前合并区间的右端`

合并时右端取最大值：`max(当前右端, 下一个右端)`（注意：下一个可能被当前完全包含）

---

## 三、图解

```
排序后: [1,3] [2,6] [8,10] [15,18]
          ↓
        [1,3]              → 初始化 cur=[1,3]

        [1,3] vs [2,6]:   2 <= 3 → 重叠
        cur 右端 = max(3,6) = 6 → cur=[1,6]

        [1,6] vs [8,10]:  8 > 6  → 不重叠
        把 [1,6] 存入结果，cur=[8,10]

        [8,10] vs [15,18]: 15 > 10 → 不重叠
        把 [8,10] 存入结果，cur=[15,18]

        遍历结束，把 cur=[15,18] 存入结果

结果: [[1,6],[8,10],[15,18]]
```

注意处理包含关系：

```
[1,10] vs [2,5]: 2 <= 10 → 重叠
cur 右端 = max(10,5) = 10 → cur=[1,10]（[2,5] 被完全吸收）
```

## 四、Go 代码

```go
func merge(intervals [][]int) [][]int {
    // 1. 按左端点升序排序
    sort.Slice(intervals, func(i, j int) bool {
        return intervals[i][0] < intervals[j][0]
    })

    result := [][]int{}
    cur := intervals[0]

    for i := 1; i < len(intervals); i++ {
        next := intervals[i]
        if next[0] <= cur[1] {
            // 重叠：合并，右端取最大值
            cur[1] = max(cur[1], next[1])
        } else {
            // 不重叠：把当前区间存入结果，切换到下一个
            result = append(result, cur)
            cur = next
        }
    }

    // 最后一个区间别忘了加进去
    result = append(result, cur)

    return result
}
```

## 五、逐行解释

```go
// 1. 排序：保证相邻区间按左端点有序，才能贪心扫描
sort.Slice(intervals, func(i, j int) bool {
    return intervals[i][0] < intervals[j][0]
})

// 2. cur 代表"正在合并的区间"，初始为第一个
cur := intervals[0]

for i := 1; i < len(intervals); i++ {
    next := intervals[i]

    // 3. 判断是否重叠：next 的左端 <= cur 的右端
    if next[0] <= cur[1] {
        // 重叠：扩展 cur 的右端（用 max 防止被包含的情况）
        cur[1] = max(cur[1], next[1])
    } else {
        // 不重叠：cur 已经合并到最大了，存入结果
        result = append(result, cur)
        cur = next  // 切换到新的区间开始合并
    }
}

// 4. 循环结束后 cur 还没存，补上
result = append(result, cur)
```

## 六、例子完整走一遍

`intervals = [[1,4],[0,2],[3,5]]`

```
排序后: [[0,2],[1,4],[3,5]]

初始: cur=[0,2]

i=1, next=[1,4]:
  1 <= 2 → 重叠
  cur[1] = max(2,4) = 4 → cur=[0,4]

i=2, next=[3,5]:
  3 <= 4 → 重叠
  cur[1] = max(4,5) = 5 → cur=[0,5]

循环结束，append cur=[0,5]
result = [[0,5]]

结果: [[0,5]]  ✓
```

## 七、复杂度分析

| 维度 | 值 |
|------|------|
| 时间 | O(n log n)，排序主导；扫描是 O(n) |
| 空间 | O(n)，结果数组最多存 n 个区间 |

## 八、容易错的点

### 1. 忘记处理最后一个区间

```go
// 循环结束时，cur 还没加进 result
// 必须在循环后再 append 一次
result = append(result, cur)
```

### 2. 合并时右端要取 max，不能直接赋值

```go
// ✗ 错误：遇到被包含的情况会缩短区间
cur[1] = next[1]

// ✓ 正确：右端只能扩大，不能缩小
cur[1] = max(cur[1], next[1])
```

反例：`[1,10]` 和 `[2,5]`，合并结果是 `[1,10]` 而不是 `[1,5]`。

### 3. 重叠条件是 <=，不是 <

```go
// next[0] == cur[1] 时，端点相接也算重叠
// 例如 [1,4] 和 [4,5] 应合并为 [1,5]
if next[0] <= cur[1]
```

### 4. 一定要先排序

不排序直接扫描无法保证相邻的是重叠的：

```
未排序: [1,3],[8,10],[2,6]
扫描到 [1,3] 和 [8,10]：不重叠，[1,3] 存入结果
再扫描 [2,6]：和已存的 [1,3] 重叠，但已经存进去了！
```

## 九、面试表达

> 先按左端点排序，然后贪心扫描。维护一个 `cur` 表示当前正在合并的区间。遍历时，如果下一个区间的左端 <= cur 的右端，说明有重叠，把 cur 右端更新为 max；否则把 cur 存入结果，切换到下一个区间继续。遍历结束后把最后的 cur 也存入。时间 O(n log n)，空间 O(n)。

## 十、一句话记忆

```text
先排序，cur 代表当前合并区间；next 左端 <= cur 右端就合并取 max，否则存 cur 换下一个。
```

再短一点：

```text
排序 + 贪心：重叠就扩右端，不重叠就存档换新区间，最后别忘加最后一个。
```
