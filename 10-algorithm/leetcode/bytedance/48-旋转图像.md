# 48. 旋转图像

> LeetCode 链接：https://leetcode.cn/problems/rotate-image/

## 题目
给定 n×n 矩阵，将矩阵**原地**顺时针旋转 90 度。

## 最易理解的方法：转置 + 左右翻转

**核心思路：**
顺时针旋转 90° = **先沿主对角线转置**，再**左右翻转**每行。

```
原矩阵:         转置:           左右翻转:
1 2 3           1 4 7           7 4 1
4 5 6    →     2 5 8    →      8 5 2
7 8 9           3 6 9           9 6 3
```

**为什么这样等价：**
转置将 `matrix[i][j]` 与 `matrix[j][i]` 互换。左右翻转将 `matrix[i][j]` 与 `matrix[i][n-1-j]` 互换。组合后 `(i,j)` → `(j, n-1-i)`，正是顺时针旋转 90° 的变换 `(i,j)→(j, n-1-i)`。

## Go 实现

```go
func rotate(matrix [][]int) {
    n := len(matrix)
    // 第一步：沿主对角线转置
    for i := 0; i < n; i++ {
        for j := i + 1; j < n; j++ {
            matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
        }
    }
    // 第二步：每行左右翻转
    for i := 0; i < n; i++ {
        for l, r := 0, n-1; l < r; l, r = l+1, r-1 {
            matrix[i][l], matrix[i][r] = matrix[i][r], matrix[i][l]
        }
    }
}
```

## 复杂度
- 时间：O(n²)
- 空间：O(1)

## 记忆口诀
> 顺时针旋转 = 转置 + 左右翻转；逆时针旋转 = 转置 + 上下翻转。
