# 21. 合并两个有序链表

> LeetCode 链接：https://leetcode.cn/problems/merge-two-sorted-lists/

## 题目
将两个升序链表合并为一个新的升序链表并返回。

## 最易理解的方法：哑节点 + 双指针

**核心思路：**
用一个哑节点（dummy head）避免处理空链表边界。用两个指针分别指向两个链表，每次取较小的节点接到结果链表末尾，直到某链表遍历完，将另一链表剩余部分直接接上。

```
l1: 1→2→4
l2: 1→3→4

dummy → ?
比较 1,1 → 取l1的1  → dummy→1
比较 2,1 → 取l2的1  → dummy→1→1
比较 2,3 → 取l1的2  → dummy→1→1→2
比较 4,3 → 取l2的3  → dummy→1→1→2→3
比较 4,4 → 取l1的4  → dummy→1→1→2→3→4
l1空     → 接上l2的4 → dummy→1→1→2→3→4→4
```

## Go 实现

```go
func mergeTwoLists(list1 *ListNode, list2 *ListNode) *ListNode {
    dummy := &ListNode{}
    cur := dummy
    for list1 != nil && list2 != nil {
        if list1.Val <= list2.Val {
            cur.Next = list1
            list1 = list1.Next
        } else {
            cur.Next = list2
            list2 = list2.Next
        }
        cur = cur.Next
    }
    if list1 != nil {
        cur.Next = list1
    } else {
        cur.Next = list2
    }
    return dummy.Next
}
```

## 复杂度
- 时间：O(m + n)
- 空间：O(1)

## 记忆口诀
> dummy哑节点开头；两链表谁小接谁；最后把剩余链表直接接上。
