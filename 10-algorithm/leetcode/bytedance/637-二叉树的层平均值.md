# 637. 二叉树的层平均值

> LeetCode 链接：https://leetcode.cn/problems/average-of-levels-in-binary-tree/

## 题目
给定二叉树，返回每层节点的平均值（浮点数数组）。

## 最易理解的方法：BFS 层序遍历

**核心思路：**
BFS 每次处理整层，计算该层所有节点值的平均数。

```
    3
   / \
  9  20
    /  \
   15   7

层0: [3] → 3.0
层1: [9,20] → 14.5
层2: [15,7] → 11.0
```

## Go 实现

```go
func averageOfLevels(root *TreeNode) []float64 {
    var res []float64
    queue := []*TreeNode{root}
    for len(queue) > 0 {
        n := len(queue)
        sum := 0.0
        for i := 0; i < n; i++ {
            node := queue[i]
            sum += float64(node.Val)
            if node.Left != nil { queue = append(queue, node.Left) }
            if node.Right != nil { queue = append(queue, node.Right) }
        }
        res = append(res, sum/float64(n))
        queue = queue[n:]
    }
    return res
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> BFS层序；每次处理整层(n个节点)；求和除n得平均值。
