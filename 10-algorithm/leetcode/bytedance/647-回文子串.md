# 647. 回文子串

> LeetCode 链接：https://leetcode.cn/problems/palindromic-substrings/

## 题目
给定字符串，计算其中回文子串的数目。

## 最易理解的方法：中心扩展

**核心思路：**
枚举每个可能的回文中心（共 2n-1 个：n 个单字符中心 + n-1 个双字符中心），从中心向两侧扩展计数。

```
s = "aaa"

中心a(0): "a"=1
中心aa(0,1): "aa"=1
中心a(1): "a","aaa"=2
中心aa(1,2): "aa"=1
中心a(2): "a"=1

总计=6
```

## Go 实现

```go
func countSubstrings(s string) int {
    count := 0
    n := len(s)
    expand := func(lo, hi int) {
        for lo >= 0 && hi < n && s[lo] == s[hi] {
            count++
            lo--
            hi++
        }
    }
    for i := 0; i < n; i++ {
        expand(i, i)   // 奇数长度回文
        expand(i, i+1) // 偶数长度回文
    }
    return count
}
```

## 复杂度
- 时间：O(n²)
- 空间：O(1)

## 记忆口诀
> 枚举中心（奇+偶），向两侧扩展，满足条件则计数；2n-1个中心。
