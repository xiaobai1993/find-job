# 290. 单词规律

> LeetCode 链接：https://leetcode.cn/problems/word-pattern/

## 题目
给定规律字符串 pattern 和字符串 s（空格分隔），判断 s 是否遵循 pattern（双向一一映射）。

## 最易理解的方法：双向哈希表

**核心思路：**
两个 map 建立 pattern字符↔单词 的双向映射，发现冲突则返回 false。

```
pattern="abba", s="dog cat cat dog"

a→dog, b→cat
第4个: b→dog? 但b已映射cat → false
```

## Go 实现

```go
import "strings"

func wordPattern(pattern string, s string) bool {
    words := strings.Split(s, " ")
    if len(pattern) != len(words) { return false }
    p2w := make(map[byte]string)
    w2p := make(map[string]byte)
    for i := 0; i < len(pattern); i++ {
        p, w := pattern[i], words[i]
        if pw, ok := p2w[p]; ok {
            if pw != w { return false }
        } else {
            if _, ok := w2p[w]; ok { return false }
            p2w[p] = w
            w2p[w] = p
        }
    }
    return true
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> 双向map：pattern字符↔单词；两个方向都要检查已有映射是否一致。
