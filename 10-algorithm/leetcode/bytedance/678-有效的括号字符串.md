# 678. 有效的括号字符串

> LeetCode 链接：https://leetcode.cn/problems/valid-parenthesis-string/

## 题目
字符串仅含 '('、')' 和 '*'（可视为 '('、')'、或空），判断是否是有效括号串。

## 最易理解的方法：贪心（维护未匹配 '(' 的最小/最大可能数）

**核心思路：**
维护未匹配左括号的最小值 lo 和最大值 hi：
- '('：lo++, hi++
- ')'：lo--, hi--
- '*'：lo--, hi++（lo不能<0）
若 hi<0 则失败；最终 lo==0 则成功。

```
s = "(*)"

初始: lo=0, hi=0
'(': lo=1, hi=1
'*': lo=0, hi=2
')': lo=-1→0, hi=1

lo==0 → true
```

## Go 实现

```go
func checkValidString(s string) bool {
    lo, hi := 0, 0
    for _, c := range s {
        switch c {
        case '(':
            lo++; hi++
        case ')':
            lo--; hi--
        case '*':
            lo--; hi++
        }
        if hi < 0 { return false }
        if lo < 0 { lo = 0 }
    }
    return lo == 0
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 维护lo和hi(左括号可能数范围)；hi<0直接false；lo<0归零；最终lo==0成功。
