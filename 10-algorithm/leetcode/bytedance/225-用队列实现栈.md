# 225. 用队列实现栈

> LeetCode 链接：https://leetcode.cn/problems/implement-stack-using-queues/

## 题目
仅使用队列操作，实现先进后出的栈（push、pop、top、empty）。

## 最易理解的方法：单队列（每次 push 后旋转）

**核心思路：**
每次 push 后，将队列前面的元素旋转到队尾（把新元素转到队头位置），使队头始终是栈顶元素。

```
push(1): queue=[1]
push(2): queue=[2,1] (先入2,再把1转到2后面)
push(3): queue=[3,2,1]

pop: 出队3 → 返回3
top: 队头=2
```

## Go 实现

```go
type MyStack struct {
    queue []int
}

func Constructor() MyStack {
    return MyStack{}
}

func (s *MyStack) Push(x int) {
    s.queue = append(s.queue, x)
    // 将前面的元素旋转到后面
    for i := 0; i < len(s.queue)-1; i++ {
        s.queue = append(s.queue, s.queue[0])
        s.queue = s.queue[1:]
    }
}

func (s *MyStack) Pop() int {
    top := s.queue[0]
    s.queue = s.queue[1:]
    return top
}

func (s *MyStack) Top() int {
    return s.queue[0]
}

func (s *MyStack) Empty() bool {
    return len(s.queue) == 0
}
```

## 复杂度
- Push：O(n)
- Pop/Top/Empty：O(1)
- 空间：O(n)

## 记忆口诀
> push后旋转：将队列中前n-1个元素轮流移到队尾，使新元素始终在队头（栈顶）。
