# 19. 删除链表的倒数第 N 个节点

> LeetCode 链接：https://leetcode.cn/problems/remove-nth-node-from-end-of-list/

## 题目
给定链表，删除链表的倒数第 n 个节点，返回链表头节点。

## 最易理解的方法：快慢指针（一趟扫描）

**核心思路：**
用两个指针，先让 fast 走 n+1 步（多走一步是为了让 slow 停在待删节点的前驱），然后 fast 和 slow 同时向后移动，直到 fast 到达链表末尾（nil），此时 slow 就在倒数第 n 个节点的前驱，直接 `slow.Next = slow.Next.Next`。

```
链表: 1→2→3→4→5, n=2  (删除倒数第2个=4)

哑节点: dummy→1→2→3→4→5

fast 先走 n+1=3 步: fast 在 3
然后同步走：
fast: 3→4→5→nil
slow: dummy→1→2→3  (slow停在4的前驱=3)
slow.Next = slow.Next.Next  → 删除4
```

## Go 实现

```go
func removeNthFromEnd(head *ListNode, n int) *ListNode {
    dummy := &ListNode{Next: head}
    fast, slow := dummy, dummy
    // fast 先走 n+1 步
    for i := 0; i <= n; i++ {
        fast = fast.Next
    }
    // 同步移动直到 fast == nil
    for fast != nil {
        fast = fast.Next
        slow = slow.Next
    }
    // slow 在待删节点的前驱
    slow.Next = slow.Next.Next
    return dummy.Next
}
```

## 复杂度
- 时间：O(n)（一趟）
- 空间：O(1)

## 记忆口诀
> dummy哑节点；fast先走n+1步；然后同步走到fast==nil；slow.Next即目标节点，跳过即删除。
