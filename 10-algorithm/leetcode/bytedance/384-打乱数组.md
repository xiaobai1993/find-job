# 384. 打乱数组

> LeetCode 链接：https://leetcode.cn/problems/shuffle-an-array/

## 题目
实现 shuffle，要求等概率地产生数组的任意排列。支持 reset 恢复原数组。

## 最易理解的方法：Fisher-Yates 洗牌算法

**核心思路：**
从后往前，每次将当前元素与它之前（含自身）的随机位置元素交换，保证等概率。

```
[1,2,3]
i=2: 随机j∈[0,2]，swap(2,j)
i=1: 随机j∈[0,1]，swap(1,j)
i=0: j=0，不变

每种排列概率 = 1/3 × 1/2 × 1 = 1/6 = 1/3! ✓
```

## Go 实现

```go
import "math/rand"

type Solution struct {
    original []int
    nums     []int
}

func Constructor(nums []int) Solution {
    orig := make([]int, len(nums))
    copy(orig, nums)
    cp := make([]int, len(nums))
    copy(cp, nums)
    return Solution{orig, cp}
}

func (s *Solution) Reset() []int {
    copy(s.nums, s.original)
    return s.nums
}

func (s *Solution) Shuffle() []int {
    n := len(s.nums)
    for i := n - 1; i > 0; i-- {
        j := rand.Intn(i + 1)
        s.nums[i], s.nums[j] = s.nums[j], s.nums[i]
    }
    return s.nums
}
```

## 复杂度
- Shuffle：O(n)
- Reset：O(n)
- 空间：O(n)

## 记忆口诀
> Fisher-Yates：从后往前，i位置与[0,i]随机位置交换；保存原始数组用于reset。
