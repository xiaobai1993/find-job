# 76. 最小覆盖子串

> LeetCode 链接：https://leetcode.cn/problems/minimum-window-substring/

## 题目
给你字符串 `s` 和 `t`，返回 `s` 中包含 `t` 所有字符的最短子串。若不存在返回 `""`。

## 最易理解的方法：滑动窗口

**核心思路：**
维护窗口 `[left, right]` 和一个 need 映射（记录还需要多少个 t 中各字符）。右指针扩展直到窗口涵盖 t 中所有字符（`valid == len(t)` 下降到 0）；然后左指针收缩寻找更小窗口；如此循环，记录最小窗口。

```
s = "ADOBECODEBANC", t = "ABC"
need = {A:1, B:1, C:1}, missing = 3

right扩展：A→B→O→B→E→C，missing→0，窗口[0,5]="ADOBEC"
left收缩: A用掉，left=1，missing=1，记录最小窗口="ADOBEC"(长6)
right继续：O→D→E→B→A，missing→0，窗口[1,10]
left收缩: D→O→B→E→C→... 找到最小="BANC"(长4)
```

## Go 实现

```go
func minWindow(s string, t string) string {
    need := make(map[byte]int)
    for i := range t {
        need[t[i]]++
    }
    missing := len(t) // 还缺多少字符
    left, start, minLen := 0, 0, len(s)+1

    for right := 0; right < len(s); right++ {
        if need[s[right]] > 0 {
            missing--
        }
        need[s[right]]--

        for missing == 0 { // 窗口已覆盖t的所有字符
            if right-left+1 < minLen {
                minLen = right - left + 1
                start = left
            }
            need[s[left]]++
            if need[s[left]] > 0 {
                missing++
            }
            left++
        }
    }
    if minLen > len(s) {
        return ""
    }
    return s[start : start+minLen]
}
```

## 复杂度
- 时间：O(m + n)，m=len(s)，n=len(t)
- 空间：O(n)

## 记忆口诀
> right扩window直到missing==0；left收缩找更小窗口；missing==0时记录结果。
