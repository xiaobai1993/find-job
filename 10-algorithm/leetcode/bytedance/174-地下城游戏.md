# 174. 地下城游戏

> LeetCode 链接：https://leetcode.cn/problems/dungeon-game/

## 题目
骑士从左上角出发，每步只能向右或向下，到达右下角救公主。每个格子有正/负血量值，求出发时最低初始血量（至少为1）。

## 最易理解的方法：逆向 DP（从右下角往左上角）

**核心思路：**
`dp[i][j]` = 从 (i,j) 出发到终点所需最低血量。
从右下角往左上角推：`dp[i][j] = max(1, min(dp[i+1][j], dp[i][j+1]) - dungeon[i][j])`。

```
dungeon:
-2  -3   3
-5 -10   1
10  30  -5

dp（逆向）:
 7   5   2
 6  11   5
 1   1   6
```

## Go 实现

```go
func calculateMinimumHP(dungeon [][]int) int {
    m, n := len(dungeon), len(dungeon[0])
    dp := make([][]int, m+1)
    for i := range dp {
        dp[i] = make([]int, n+1)
        for j := range dp[i] {
            dp[i][j] = 1<<31 - 1
        }
    }
    dp[m][n-1] = 1
    dp[m-1][n] = 1
    for i := m - 1; i >= 0; i-- {
        for j := n - 1; j >= 0; j-- {
            need := min2(dp[i+1][j], dp[i][j+1]) - dungeon[i][j]
            if need < 1 {
                need = 1
            }
            dp[i][j] = need
        }
    }
    return dp[0][0]
}

func min2(a, b int) int {
    if a < b { return a }
    return b
}
```

## 复杂度
- 时间：O(m×n)
- 空间：O(m×n)

## 记忆口诀
> 逆向DP从右下到左上；每格需求=下一格最小需求-当前值；至少为1。
