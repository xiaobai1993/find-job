# 450. 删除二叉搜索树中的节点

> LeetCode 链接：https://leetcode.cn/problems/delete-node-in-a-bst/

## 题目
给定 BST 根节点和目标值 key，删除值为 key 的节点，返回新根节点。

## 最易理解的方法：递归分三种情况

**核心思路：**
1. 叶节点：直接删除
2. 只有一个子树：返回该子树
3. 两个子树：找右子树最小节点（后继），用其值替换，再删右子树中的后继。

```
    5
   / \
  3   6
 / \   \
2   4   7

删除3:
右子树最小=4，替换3→4，删右子树中4
    5
   / \
  4   6
 /     \
2       7
```

## Go 实现

```go
func deleteNode(root *TreeNode, key int) *TreeNode {
    if root == nil { return nil }
    if key < root.Val {
        root.Left = deleteNode(root.Left, key)
    } else if key > root.Val {
        root.Right = deleteNode(root.Right, key)
    } else {
        if root.Left == nil { return root.Right }
        if root.Right == nil { return root.Left }
        // 找右子树最小节点（后继）
        succ := root.Right
        for succ.Left != nil { succ = succ.Left }
        root.Val = succ.Val
        root.Right = deleteNode(root.Right, succ.Val)
    }
    return root
}
```

## 复杂度
- 时间：O(h)
- 空间：O(h)

## 记忆口诀
> 三种情况：叶→nil；单子→子；双子→用右子树最小替换，再删右子树该值。
