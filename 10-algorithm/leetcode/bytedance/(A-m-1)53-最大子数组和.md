# 53. 最大子数组和

题目链接：`https://leetcode.cn/problems/maximum-subarray/`

---

## 一、题目描述

给你一个整数数组 `nums`，请你找出一个具有最大和的**连续子数组**（子数组最少包含一个元素），返回其最大和。

**示例：**

```
输入: nums = [-2,1,-3,4,-1,2,1,-5,4]
输出: 6
解释: 连续子数组 [4,-1,2,1] 的和最大，为 6

输入: nums = [1]
输出: 1

输入: nums = [5,4,-1,7,8]
输出: 23
```

---

## 二、思路：Kadane 算法（贪心/DP）

核心想法：遍历数组，维护"以当前元素结尾的最大子数组和" `cur`。

- 如果 `cur` 加上当前元素后变小了（即之前的 `cur < 0`），就**抛弃前缀**，从当前元素重新开始
- 每步更新全局最大值 `maxSum`

一句话：**前缀若为负，丢掉重来。**

```
nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4]

i=0: cur = max(-2, 0+(-2)) = -2        maxSum=-2
i=1: cur = max(1,  -2+1)   = 1         maxSum=1
i=2: cur = max(-3, 1+(-3)) = -2        maxSum=1
i=3: cur = max(4,  -2+4)   = 4         maxSum=4
i=4: cur = max(-1, 4+(-1)) = 3         maxSum=4
i=5: cur = max(2,  3+2)    = 5         maxSum=5
i=6: cur = max(1,  5+1)    = 6         maxSum=6  ← 最大
i=7: cur = max(-5, 6+(-5)) = 1         maxSum=6
i=8: cur = max(4,  1+4)    = 5         maxSum=6

结果: 6  ✓ 对应子数组 [4,-1,2,1]
```

---

## 三、DP 视角理解

定义 `dp[i]` = 以 `nums[i]` 结尾的最大子数组和。

状态转移：

```
dp[i] = max(nums[i], dp[i-1] + nums[i])

含义：
- nums[i]         → 不接前面，从当前元素另起炉灶
- dp[i-1] + nums[i] → 接上前面的子数组

如果 dp[i-1] < 0，接了只会更小，不如另起炉灶
```

最终答案 = `max(dp[0], dp[1], ..., dp[n-1])`

由于 `dp[i]` 只依赖 `dp[i-1]`，可以用一个变量滚动，空间 O(1)。

## 四、Go 代码

```go
func maxSubArray(nums []int) int {
    cur := nums[0]
    maxSum := nums[0]

    for i := 1; i < len(nums); i++ {
        if cur < 0 {
            cur = nums[i]   // 前缀为负，抛弃，重新开始
        } else {
            cur += nums[i]  // 前缀为正，接上当前元素
        }
        if cur > maxSum {
            maxSum = cur
        }
    }

    return maxSum
}
```

等价写法（用 max 函数更简洁）：

```go
func maxSubArray(nums []int) int {
    cur := nums[0]
    maxSum := nums[0]

    for i := 1; i < len(nums); i++ {
        cur = max(nums[i], cur+nums[i])
        maxSum = max(maxSum, cur)
    }

    return maxSum
}
```

## 五、逐行解释

```go
// 初始化：从第一个元素开始（不能初始化为0，因为可能全是负数）
cur := nums[0]
maxSum := nums[0]

for i := 1; i < len(nums); i++ {
    // cur < 0 说明前面的子数组是"拖累"，抛掉它
    // cur >= 0 说明前面的子数组有贡献，接上当前元素
    cur = max(nums[i], cur+nums[i])

    // 每步记录全局最大
    maxSum = max(maxSum, cur)
}
```

## 六、例子完整走一遍

`nums = [5, 4, -1, 7, 8]`

```
初始: cur=5, maxSum=5

i=1, nums[1]=4:
  cur = max(4, 5+4) = 9
  maxSum = max(5, 9) = 9

i=2, nums[2]=-1:
  cur = max(-1, 9+(-1)) = 8
  maxSum = max(9, 8) = 9

i=3, nums[3]=7:
  cur = max(7, 8+7) = 15
  maxSum = max(9, 15) = 15

i=4, nums[4]=8:
  cur = max(8, 15+8) = 23
  maxSum = max(15, 23) = 23

结果: 23  ✓ 对应整个数组 [5,4,-1,7,8]
```

## 八、容易错的点

### 1. 初始值不能是 0

```go
// ✗ 错误：全负数数组时，maxSum=0 是错的
maxSum := 0

// ✓ 正确：从 nums[0] 开始，保证至少包含一个元素
maxSum := nums[0]
cur := nums[0]
```

反例：`nums = [-1]`，答案是 `-1`，不是 `0`。

### 2. 是子数组（连续），不是子序列

```
[-2, 1, -3, 4, -1, 2, 1, -5, 4]

子数组 [4,-1,2,1] = 连续的，和=6  ✓
子序列 [1,4,2,1,4] = 不连续，不合法 ✗
```

### 3. cur < 0 才丢弃，不是 cur <= 0

```go
// cur == 0 时，加上正数还是更大，所以不丢
// 只有 cur < 0 才是负担
cur = max(nums[i], cur+nums[i])
// 等价于：if cur < 0 { cur = nums[i] } else { cur += nums[i] }
```

## 九、进阶：如果要返回子数组的起止位置？

```go
func maxSubArray(nums []int) (int, int, int) {
    cur := nums[0]
    maxSum := nums[0]
    start, end := 0, 0
    tempStart := 0

    for i := 1; i < len(nums); i++ {
        if cur < 0 {
            cur = nums[i]
            tempStart = i   // 记录新起点
        } else {
            cur += nums[i]
        }
        if cur > maxSum {
            maxSum = cur
            start = tempStart
            end = i
        }
    }

    return maxSum, start, end
}
```

## 十、面试表达

> 用 Kadane 算法，维护两个变量：`cur` 表示以当前元素结尾的最大子数组和，`maxSum` 是全局最大值。遍历时，如果 `cur` 是负数，说明前面的前缀是拖累，直接从当前元素重新开始；否则接上当前元素。每步更新 `maxSum`。时间 O(n)，空间 O(1)。
