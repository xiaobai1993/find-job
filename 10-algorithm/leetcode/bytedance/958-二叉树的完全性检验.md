# 958. 二叉树的完全性检验

> LeetCode 链接：https://leetcode.cn/problems/check-completeness-of-a-binary-tree/

## 题目
给定一棵二叉树，判断其是否是完全二叉树（除最后一层外都满，最后一层节点从左到右连续填满）。

## 最易理解的方法：BFS + 遇 null 后不应有非 null

**核心思路：**
层序遍历，将 null 也入队。一旦遇到 null，此后所有出队的节点都应该是 null。

```
完全二叉树:       非完全:
    1                 1
   / \               / \
  2   3             2   3
 / \  /            /     \
4   5 6           4       5

BFS: 1,2,3,4,5,6,null,null,null,null,null
遇null后全是null ✓

BFS: 1,2,3,4,null,null,5
遇null后出现非null → false
```

## Go 实现

```go
func isCompleteTree(root *TreeNode) bool {
    queue := []*TreeNode{root}
    foundNull := false
    for len(queue) > 0 {
        node := queue[0]
        queue = queue[1:]
        if node == nil {
            foundNull = true
        } else {
            if foundNull {
                return false // null之后出现非null
            }
            queue = append(queue, node.Left)
            queue = append(queue, node.Right)
        }
    }
    return true
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> BFS将null也入队；一旦遇到null设foundNull=true；之后若遇非null返回false。
