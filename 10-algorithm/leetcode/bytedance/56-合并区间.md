# 56. 合并区间

> LeetCode 链接：https://leetcode.cn/problems/merge-intervals/

## 题目
给出若干区间，合并所有重叠的区间，返回不重叠区间数组。

## 最易理解的方法：排序 + 贪心合并

**核心思路：**
先按区间左端点排序，然后一趟遍历：若当前区间左端点 ≤ 上一个合并区间的右端点，则两区间重叠，更新右端点为较大值；否则将上一个区间加入结果，开始新区间。

```
intervals = [[1,3],[2,6],[8,10],[15,18]]
排序后：    [[1,3],[2,6],[8,10],[15,18]]

cur=[1,3]
→ [2,6]:  2<=3 重叠 → cur=[1,6]
→ [8,10]: 8>6  不重叠 → 输出[1,6]，cur=[8,10]
→ [15,18]:15>10 不重叠 → 输出[8,10]，cur=[15,18]
最后输出[15,18]

结果：[[1,6],[8,10],[15,18]]
```

**算法步骤：**
1. 按左端点排序
2. 初始化 cur = intervals[0]
3. 遍历 i=1 开始：若 intervals[i][0] <= cur[1]，更新 cur[1] = max(cur[1], intervals[i][1])；否则加入结果并更新 cur
4. 最后把 cur 加入结果

## Go 实现

```go
import "sort"

func merge(intervals [][]int) [][]int {
    sort.Slice(intervals, func(i, j int) bool {
        return intervals[i][0] < intervals[j][0]
    })
    res := [][]int{intervals[0]}
    for _, iv := range intervals[1:] {
        last := res[len(res)-1]
        if iv[0] <= last[1] { // 重叠
            if iv[1] > last[1] {
                last[1] = iv[1] // 扩展右端点
            }
        } else {
            res = append(res, iv)
        }
    }
    return res
}
```

## 复杂度
- 时间：O(n log n)（排序主导）
- 空间：O(n)

## 记忆口诀
> 按左端排序，新区间左端 ≤ 当前右端则合并（取更大右端），否则另起一个。
