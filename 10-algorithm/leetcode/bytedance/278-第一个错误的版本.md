# 278. 第一个错误的版本

> LeetCode 链接：https://leetcode.cn/problems/first-bad-version/

## 题目
给定 n 个版本，某个版本后都是错误的。调用 `isBadVersion(version)` API，找到第一个错误版本，尽量减少调用次数。

## 最易理解的方法：二分查找

**核心思路：**
二分查找第一个 `isBadVersion(mid)` 为 true 的位置：
- 若 `isBadVersion(mid)` 为 true：答案在左侧（含 mid），`hi = mid`
- 否则：答案在右侧，`lo = mid + 1`

```
n=5, first bad=4

lo=1, hi=5
mid=3: isBadVersion(3)=false → lo=4
mid=4: isBadVersion(4)=true → hi=4
lo==hi==4 → 答案=4
```

## Go 实现

```go
func firstBadVersion(n int) int {
    lo, hi := 1, n
    for lo < hi {
        mid := lo + (hi-lo)/2 // 防溢出
        if isBadVersion(mid) {
            hi = mid // 可能是第一个
        } else {
            lo = mid + 1
        }
    }
    return lo
}
```

## 复杂度
- 时间：O(log n)
- 空间：O(1)

## 记忆口诀
> 二分找左边界：isBadVersion(mid)为true则hi=mid；否则lo=mid+1；lo==hi即答案。
