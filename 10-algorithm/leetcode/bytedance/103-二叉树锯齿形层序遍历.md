# 103. 二叉树的锯齿形层序遍历

题目链接：`https://leetcode.cn/problems/binary-tree-zigzag-level-order-traversal/`

---

## 一、题目描述

给一棵二叉树，按层序从上到下遍历，但奇数层从左到右、偶数层从右到左（锯齿形）。

**示例：**

```
输入:
    3
   / \
  9  20
    /  \
   15   7

输出: [[3], [20,9], [15,7]]

第1层(奇数): 从左到右 → [3]
第2层(偶数): 从右到左 → [20,9]
第3层(奇数): 从左到右 → [15,7]
```

---

## 二、核心思路：BFS + 交替反转

这题 = **层序遍历（BFS）** + **偶数层反转**。

层序遍历你肯定会，每层从左到右收集节点。锯齿形只是在此基础上，偶数层把结果反转一下。

```
普通层序遍历:
  第1层: [3]
  第2层: [9, 20]
  第3层: [15, 7]

锯齿形: 偶数层反转
  第1层: [3]        → 不变（奇数）
  第2层: [9, 20]    → 反转 → [20, 9]
  第3层: [15, 7]    → 不变（奇数）
```

**一句话：正常 BFS，偶数层 reverse 一下就行。**

---

## 三、Go 完整代码

```go
func zigzagLevelOrder(root *TreeNode) [][]int {
    if root == nil {
        return nil
    }

    var res [][]int
    queue := []*TreeNode{root}
    level := 0

    for len(queue) > 0 {
        n := len(queue)
        vals := make([]int, n)

        for i := 0; i < n; i++ {
            node := queue[i]
            if level%2 == 0 {
                vals[i] = node.Val       // 奇数层：正序放
            } else {
                vals[n-1-i] = node.Val   // 偶数层：倒序放
            }
            if node.Left != nil {
                queue = append(queue, node.Left)
            }
            if node.Right != nil {
                queue = append(queue, node.Right)
            }
        }

        res = append(res, vals)
        queue = queue[n:]
        level++
    }

    return res
}
```

## 四、逐行理解

```go
if root == nil { return nil }      // 空树直接返回

var res [][]int                     // 结果：每层一个切片
queue := []*TreeNode{root}          // BFS 队列，初始放根节点
level := 0                          // 当前层数，从 0 开始

for len(queue) > 0 {               // BFS 标准循环
    n := len(queue)                 // 当前层的节点数
    vals := make([]int, n)          // 存当前层的值

    for i := 0; i < n; i++ {
        node := queue[i]

        // ---- 关键：根据层数决定正放还是倒放 ----
        if level%2 == 0 {
            vals[i] = node.Val      // 偶数 level（第1、3...层）：正序
        } else {
            vals[n-1-i] = node.Val  // 奇数 level（第2、4...层）：倒序
        }
        // ----------------------------------------

        // 子节点入队（永远是先左后右，BFS 不变）
        if node.Left != nil {
            queue = append(queue, node.Left)
        }
        if node.Right != nil {
            queue = append(queue, node.Right)
        }
    }

    res = append(res, vals)         // 收集当前层结果
    queue = queue[n:]               // 弹出当前层，队列只剩下一层
    level++                         // 层数 +1
}
```

## 五、为什么不直接 reverse？

你当然可以先正序收集，再 `reverse(vals)`，但**在写入时直接倒序放更省一次反转操作**：

```go
// 方法1：先正序收集，再反转
vals[i] = node.Val        // 正序放
if level%2 == 1 {
    reverse(vals)          // 事后反转
}

// 方法2：写入时直接决定位置（推荐）
if level%2 == 0 {
    vals[i] = node.Val       // 正序
} else {
    vals[n-1-i] = node.Val  // 倒序
}
```

方法2一次遍历搞定，不需要额外的 reverse。

## 七、层数从0还是1开始？

代码中 `level` 从 0 开始：
- `level=0`（偶数）→ 第1层，从左到右
- `level=1`（奇数）→ 第2层，从右到左
- `level=2`（偶数）→ 第3层，从左到右

和题目描述"奇数层从左到右、偶数层从右到左"对应关系：

| 题目说 | level 值 | level%2 | 方向 |
|--------|----------|---------|------|
| 第1层（奇数） | 0 | 0（偶数） | 从左到右 |
| 第2层（偶数） | 1 | 1（奇数） | 从右到左 |
| 第3层（奇数） | 2 | 0（偶数） | 从左到右 |

所以代码里 `level%2==0` 对应"从左到右"，`level%2==1` 对应"从右到左"。

## 八、复杂度分析

- **时间**：O(n)，每个节点访问一次
- **空间**：O(n)，队列最多存一层的节点

---

## 九、容易错的点

### 1. BFS 永远先左后右入队

```go
// 入队顺序不变，永远是先左后右
if node.Left != nil { queue = append(queue, node.Left) }
if node.Right != nil { queue = append(queue, node.Right) }
```

锯齿效果靠的是**输出时反转**，不是入队时反转。

### 2. 不要在偶数层反过来入队

```go
// ✗ 错误做法：偶数层先右后左入队
if level%2 == 1 {
    if node.Right != nil { ... }
    if node.Left != nil { ... }
}

// ✓ 正确做法：入队顺序不变，输出时倒序放
```

反过来入队会导致下一层的顺序也乱掉，因为子节点的子节点顺序也跟着变了。

### 3. 空树返回 nil 不是 [[]]

```go
if root == nil { return nil }
```

空树没有节点，结果应该是 `nil`（空切片），不是 `[[]]`。

### 4. n 要在循环开始时记录

```go
n := len(queue)  // 先记录当前层的节点数
for i := 0; i < n; i++ {
    // 遍历 queue[0:n]
}
queue = queue[n:]  // 弹出当前层
```

不能在循环里 `len(queue)`，因为入队后 queue 在变长。

## 十、面试表达

> 锯齿形层序遍历，就是普通 BFS 层序遍历加一个方向切换。用队列做 BFS，每层开始时记录当前层节点数 n，遍历这 n 个节点时把子节点入队。关键点：偶数层（从右到左）时，值写入 vals 倒序位置，即 `vals[n-1-i] = node.Val`。入队顺序永远是先左后右，锯齿效果只体现在输出顺序上。时间 O(n)，空间 O(n)。
