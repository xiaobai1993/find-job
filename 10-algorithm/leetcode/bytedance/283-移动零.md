# 283. 移动零

> LeetCode 链接：https://leetcode.cn/problems/move-zeroes/

## 题目
给定数组 `nums`，将所有 0 移动到数组末尾，同时保持非零元素的相对顺序（原地操作）。

## 最易理解的方法：双指针（慢指针记录非零写入位置）

**核心思路：**
`slow` 指针指向下一个非零数应该写入的位置。遍历 `fast` 指针，遇到非零数就将其写入 `slow` 位置，然后 `slow++`。遍历结束后 `slow` 之后的位置全部填 0。

```
nums = [0, 1, 0, 3, 12]

fast=0: 0, skip
fast=1: 1→写入slow=0, slow=1, nums=[1,1,0,3,12]
fast=2: 0, skip
fast=3: 3→写入slow=1, slow=2, nums=[1,3,0,3,12]
fast=4: 12→写入slow=2, slow=3, nums=[1,3,12,3,12]
slow之后填0: nums=[1,3,12,0,0]
```

## Go 实现

```go
func moveZeroes(nums []int) {
    slow := 0
    for fast := 0; fast < len(nums); fast++ {
        if nums[fast] != 0 {
            nums[slow] = nums[fast]
            slow++
        }
    }
    // 剩余位置填0
    for ; slow < len(nums); slow++ {
        nums[slow] = 0
    }
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> slow指向非零写入位；fast遇非零就写入slow并slow++；最后slow之后全置0。
