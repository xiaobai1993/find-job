# 377. 组合总和 IV

> LeetCode 链接：https://leetcode.cn/problems/combination-sum-iv/

## 题目
给定不含重复数字的正整数数组和目标值，找出数字和等于目标值的排列数（顺序不同算不同）。

## 最易理解的方法：DP（排列数）

**核心思路：**
`dp[i]` 表示和为 i 的排列数。
外层枚举目标值，内层枚举每个数字：`dp[i] += dp[i-num]`
（与零钱兑换II相反：外层枚举目标，内层枚举元素 → 排列数）

```
nums=[1,2,3], target=4

dp[0]=1 (空)
dp[1]=dp[0]=1 (1)
dp[2]=dp[1]+dp[0]=2 (1+1, 2)
dp[3]=dp[2]+dp[1]+dp[0]=4 (1+1+1, 1+2, 2+1, 3)
dp[4]=dp[3]+dp[2]+dp[1]=7

答案=7
```

## Go 实现

```go
func combinationSum4(nums []int, target int) int {
    dp := make([]int, target+1)
    dp[0] = 1
    for i := 1; i <= target; i++ { // 外层枚举目标（保证计入顺序）
        for _, num := range nums {
            if i >= num {
                dp[i] += dp[i-num]
            }
        }
    }
    return dp[target]
}
```

## 复杂度
- 时间：O(target × len(nums))
- 空间：O(target)

## 记忆口诀
> 排列数：外层枚举目标，内层枚举元素；与组合数相反（组合数外层枚举元素）。
