# 98. 验证二叉搜索树

> LeetCode 链接：https://leetcode.cn/problems/validate-binary-search-tree/

## 题目
给定二叉树根节点，判断其是否是有效的二叉搜索树（BST：左子树所有节点 < 根，右子树所有节点 > 根，且左右子树也是BST）。

## 最易理解的方法：DFS 传递上下界

**核心思路：**
递归时传递允许的值范围 `[min, max]`。根节点范围为 `(-∞, +∞)`；左子树的上界是父节点值；右子树的下界是父节点值。若某节点的值超出范围则不是 BST。

```
    5
   / \
  1   4
     / \
    3   6

验证4: 4应在(5,+∞)范围内，4<5 → 不合法 → false

    2
   / \
  1   3

验证1: 在(-∞,2)内 ✓
验证3: 在(2,+∞)内 ✓ → true
```

## Go 实现

```go
import "math"

func isValidBST(root *TreeNode) bool {
    return validate(root, math.MinInt64, math.MaxInt64)
}

func validate(node *TreeNode, min, max int) bool {
    if node == nil {
        return true
    }
    if node.Val <= min || node.Val >= max {
        return false
    }
    return validate(node.Left, min, node.Val) &&
        validate(node.Right, node.Val, max)
}
```

## 复杂度
- 时间：O(n)
- 空间：O(h)

## 记忆口诀
> 递归传上下界；左子树上界=父节点值，右子树下界=父节点值；节点值超出范围则失败。
