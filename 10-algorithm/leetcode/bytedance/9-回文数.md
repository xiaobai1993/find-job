# 9. 回文数

> LeetCode 链接：https://leetcode.cn/problems/palindrome-number/

## 题目
给定整数 x，判断其是否是回文数（不能转换为字符串）。

## 最易理解的方法：反转后半部分

**核心思路：**
- 负数和末位为0但不是0的数一定不是回文
- 将后半部分数字反转，与前半部分比较
- 当后半 ≥ 前半时停止

```
x = 1221

步骤: 后半=1, x=122
     后半=12, x=12
     12>=12 停止

偶数位: x == rev → 1221: 12==12 ✓

x = 12321

后半=1, x=1232
后半=12, x=123
后半=123, x=12
123>=12 停止

奇数位: x == rev/10 → 12==12 ✓
```

## Go 实现

```go
func isPalindrome(x int) bool {
    if x < 0 || (x%10 == 0 && x != 0) {
        return false
    }
    rev := 0
    for x > rev {
        rev = rev*10 + x%10
        x /= 10
    }
    return x == rev || x == rev/10 // 偶数位 || 奇数位
}
```

## 复杂度
- 时间：O(log x)
- 空间：O(1)

## 记忆口诀
> 反转后半：循环直到x≤rev；偶数位x==rev，奇数位x==rev/10（去掉中间位）。
