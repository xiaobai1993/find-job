# 560. 和为 K 的子数组

> LeetCode 链接：https://leetcode.cn/problems/subarray-sum-equals-k/

## 题目
给定整数数组 `nums` 和整数 `k`，返回和为 `k` 的连续子数组的数目。

## 最易理解的方法：前缀和 + 哈希表

**核心思路：**
前缀和 `prefixSum[i]` = `nums[0] + ... + nums[i-1]`。子数组 `[j, i]` 的和 = `prefixSum[i] - prefixSum[j]`。若和 = k，则 `prefixSum[j] = prefixSum[i] - k`。用哈希表记录每个前缀和出现的次数，遍历时查表看有多少个满足条件的 j。

```
nums = [1, 1, 1], k = 2

map = {0: 1}  (初始化：空前缀和为0，出现1次)

i=0: prefixSum=1, 查(1-2=-1)不存在, map={0:1, 1:1}
i=1: prefixSum=2, 查(2-2=0)存在1次 → count=1, map={0:1, 1:2}
         等待：... 实际map={0:1, 1:1, 2:1}
i=2: prefixSum=3, 查(3-2=1)存在2次 → count=3...

实际: count=1+1+1=...

答案: 2 (子数组[0:2]和[1:3])
```

## Go 实现

```go
func subarraySum(nums []int, k int) int {
    count := 0
    prefixSum := 0
    freq := map[int]int{0: 1} // 空前缀和出现1次
    for _, num := range nums {
        prefixSum += num
        count += freq[prefixSum-k] // 有多少个前缀和等于 prefixSum-k
        freq[prefixSum]++
    }
    return count
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> 前缀和 + 哈希表；初始化{0:1}；遍历时先查表加count（prefixSum-k的频次），再记录当前prefixSum。
