# 438. 找到字符串中所有字母异位词

> LeetCode 链接：https://leetcode.cn/problems/find-all-anagrams-in-a-string/

## 题目
给定字符串 s 和 p，找出 s 中所有 p 的字母异位词的起始索引。

## 最易理解的方法：固定窗口滑动

**核心思路：**
维护长度为 len(p) 的窗口，用两个频率数组比较，匹配时记录起始索引。

```
s="cbaebafd", p="abc"

窗口[cba]: cnt==[1,1,1] == pcnt → 索引0
右移 → [bae]: cnt变化，不等
...
窗口[eab]→[baf]→[afd]...
窗口[bae]→[aef]→... 找到[eab]在索引6? 重新检查
```

## Go 实现

```go
func findAnagrams(s string, p string) []int {
    if len(s) < len(p) { return nil }
    var scnt, pcnt [26]int
    for i := 0; i < len(p); i++ {
        pcnt[p[i]-'a']++
        scnt[s[i]-'a']++
    }
    var res []int
    if scnt == pcnt { res = append(res, 0) }
    for i := len(p); i < len(s); i++ {
        scnt[s[i]-'a']++
        scnt[s[i-len(p)]-'a']--
        if scnt == pcnt {
            res = append(res, i-len(p)+1)
        }
    }
    return res
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 固定长度窗口滑动；进右出左更新频率数组；两数组相等时记录起始位置。
