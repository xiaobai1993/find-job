# 139. 单词拆分

> LeetCode 链接：https://leetcode.cn/problems/word-break/

## 题目
给定字符串 `s` 和字符串列表 `wordDict`，判断 `s` 是否可以由字典中的单词拼接而成（单词可重复使用）。

## 最易理解的方法：动态规划

**核心思路：**
`dp[i]` 表示 `s[0:i]` 能否被字典中的单词拼接组成。对每个位置 i，枚举所有可能的结尾 j（`j < i`），若 `dp[j] == true` 且 `s[j:i]` 在字典中，则 `dp[i] = true`。

```
s = "leetcode", wordDict = ["leet","code"]

dp[0] = true（空串）
dp[4]：j=0, dp[0]=T, s[0:4]="leet" ∈ dict → dp[4]=true
dp[8]：j=4, dp[4]=T, s[4:8]="code" ∈ dict → dp[8]=true ✓
```

## Go 实现

```go
func wordBreak(s string, wordDict []string) bool {
    wordSet := make(map[string]bool)
    for _, w := range wordDict {
        wordSet[w] = true
    }
    n := len(s)
    dp := make([]bool, n+1)
    dp[0] = true
    for i := 1; i <= n; i++ {
        for j := 0; j < i; j++ {
            if dp[j] && wordSet[s[j:i]] {
                dp[i] = true
                break
            }
        }
    }
    return dp[n]
}
```

## 复杂度
- 时间：O(n²)
- 空间：O(n)

## 记忆口诀
> dp[i]：枚举所有切割点 j；若 dp[j]=true 且 s[j:i] 在字典中，则 dp[i]=true。
