# 78. 子集

> LeetCode 链接：https://leetcode.cn/problems/subsets/

## 题目
给定一个不含重复元素的整数数组 `nums`，返回其所有可能的子集（幂集）。

## 最易理解的方法：回溯

**核心思路：**
从 `start` 开始枚举，将当前路径加入结果集（每个节点都是结果，不只是叶节点），然后递归枚举后续元素。关键：每次从 `start` 开始避免重复。

```
nums = [1,2,3]

dfs(start=0, path=[])  → 加入 []
  选1: dfs(1, [1])     → 加入 [1]
    选2: dfs(2, [1,2]) → 加入 [1,2]
      选3: dfs(3, [1,2,3]) → 加入 [1,2,3]
    选3: dfs(3, [1,3]) → 加入 [1,3]
  选2: dfs(2, [2])     → 加入 [2]
    选3: dfs(3, [2,3]) → 加入 [2,3]
  选3: dfs(3, [3])     → 加入 [3]
```

## Go 实现

```go
func subsets(nums []int) [][]int {
    var res [][]int
    var dfs func(start int, path []int)
    dfs = func(start int, path []int) {
        // 每个状态都是一个子集（包括空集）
        tmp := make([]int, len(path))
        copy(tmp, path)
        res = append(res, tmp)
        for i := start; i < len(nums); i++ {
            dfs(i+1, append(path, nums[i]))
        }
    }
    dfs(0, []int{})
    return res
}
```

## 复杂度
- 时间：O(2^n × n)
- 空间：O(n)（递归深度）

## 记忆口诀
> 回溯：每到一个状态就加入结果；从 start 往后枚举，避免重复选择。
