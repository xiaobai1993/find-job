# 94. 二叉树的中序遍历

> LeetCode 链接：https://leetcode.cn/problems/binary-tree-inorder-traversal/

## 题目
给定二叉树的根节点，返回其节点值的中序遍历（左→根→右）。

## 最易理解的方法：迭代（栈模拟）

**核心思路：**
用栈模拟递归。持续将当前节点的左子链入栈，直到左子为空；然后弹出栈顶（访问），转向右子，继续重复。

```
    1
     \
      2
     /
    3

cur=1: 左链入栈 [1], cur=nil
弹栈: 访问1, cur=1.right=2
cur=2: 左链入栈 [2,3](先push2后push3的左), 实际:cur=3→nil
弹栈: 访问3, cur=nil
弹栈: 访问2, cur=nil
结果: [1, 3, 2]
```

## Go 实现

```go
// 迭代版（面试更能体现理解）
func inorderTraversal(root *TreeNode) []int {
    var res []int
    var stack []*TreeNode
    cur := root
    for cur != nil || len(stack) > 0 {
        // 一路向左入栈
        for cur != nil {
            stack = append(stack, cur)
            cur = cur.Left
        }
        // 弹出访问，转向右子
        cur = stack[len(stack)-1]
        stack = stack[:len(stack)-1]
        res = append(res, cur.Val)
        cur = cur.Right
    }
    return res
}

// 递归版（更简洁）
func inorderTraversalRecur(root *TreeNode) []int {
    var res []int
    var dfs func(*TreeNode)
    dfs = func(node *TreeNode) {
        if node == nil {
            return
        }
        dfs(node.Left)
        res = append(res, node.Val)
        dfs(node.Right)
    }
    dfs(root)
    return res
}
```

## 复杂度
- 时间：O(n)
- 空间：O(h)（树高）

## 记忆口诀
> 迭代：一路向左入栈直到nil；弹栈访问；转向右子重复；`cur != nil || 栈非空` 是循环条件。
