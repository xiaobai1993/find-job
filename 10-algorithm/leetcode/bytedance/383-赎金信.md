# 383. 赎金信

> LeetCode 链接：https://leetcode.cn/problems/ransom-note/

## 题目
给定字符串 ransomNote 和 magazine，判断 ransomNote 中的字母是否能由 magazine 中的字母构成（每个字母只用一次）。

## 最易理解的方法：字母频率统计

**核心思路：**
统计 magazine 中每个字母的频率，遍历 ransomNote 时递减，如果某字母不足则返回 false。

```
ransomNote = "aa", magazine = "aab"

cnt: a=2, b=1
ransomNote: a→cnt[a]=1, a→cnt[a]=0 ✓
```

## Go 实现

```go
func canConstruct(ransomNote string, magazine string) bool {
    cnt := [26]int{}
    for _, c := range magazine {
        cnt[c-'a']++
    }
    for _, c := range ransomNote {
        cnt[c-'a']--
        if cnt[c-'a'] < 0 {
            return false
        }
    }
    return true
}
```

## 复杂度
- 时间：O(m+n)
- 空间：O(1)（固定26个字母）

## 记忆口诀
> 统计magazine字母频率；遍历ransomNote时递减；为负立即返回false。
