# 322. 零钱兑换

> LeetCode 链接：https://leetcode.cn/problems/coin-change/

## 题目
给定硬币面额数组 `coins` 和总金额 `amount`，计算凑成总金额所需的最少硬币数。若无法凑成返回 -1。

## 最易理解的方法：动态规划（完全背包）

**核心思路：**
`dp[i]` 表示凑成金额 `i` 所需的最少硬币数。转移：对每个硬币 `c`，`dp[i] = min(dp[i], dp[i-c] + 1)`。初始 `dp[0]=0`，其余初始化为 `amount+1`（表示不可达）。

```
coins = [1, 2, 5], amount = 11

dp[0] = 0
dp[1] = min(dp[1-1]+1) = 1       (用1)
dp[2] = min(dp[1]+1, dp[0]+1) = 1  (用2)
dp[3] = 2  (2+1)
dp[5] = 1  (用5)
dp[6] = 2  (5+1)
dp[11]= 3  (5+5+1)
```

## Go 实现

```go
func coinChange(coins []int, amount int) int {
    dp := make([]int, amount+1)
    for i := 1; i <= amount; i++ {
        dp[i] = amount + 1 // 初始化为不可达
    }
    for i := 1; i <= amount; i++ {
        for _, c := range coins {
            if c <= i && dp[i-c]+1 < dp[i] {
                dp[i] = dp[i-c] + 1
            }
        }
    }
    if dp[amount] > amount {
        return -1
    }
    return dp[amount]
}
```

## 复杂度
- 时间：O(amount × len(coins))
- 空间：O(amount)

## 记忆口诀
> dp[i] 初始化为 amount+1（无穷大）；对每个金额枚举每种硬币：dp[i]=min(dp[i], dp[i-c]+1)。
