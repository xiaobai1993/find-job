# 1049. 最后一块石头的重量 II

> LeetCode 链接：https://leetcode.cn/problems/last-stone-weight-ii/

## 题目
每次选两块石头相撞（若重量不同，差值保留），最终剩最少重量（可能为0）。

## 最易理解的方法：转化为 0-1 背包（尽量分成相等两组）

**核心思路：**
问题等价于将石头分成两组，最小化两组之差。即背包容量为 sum/2，求最大能装多少。

```
stones = [2,7,4,1,8,1], sum=23

dp(容量11的0-1背包):
最大能装: 11
另一组: 23-11=12

差: 12-11=1
```

## Go 实现

```go
func lastStoneWeightII(stones []int) int {
    sum := 0
    for _, s := range stones { sum += s }
    target := sum / 2
    dp := make([]int, target+1)
    for _, s := range stones {
        for j := target; j >= s; j-- {
            if dp[j-s]+s > dp[j] { dp[j] = dp[j-s] + s }
        }
    }
    return sum - 2*dp[target]
}
```

## 复杂度
- 时间：O(n × sum)
- 空间：O(sum)

## 记忆口诀
> 等价分两组最小化差；0-1背包求sum/2内最大装载量；答案=sum-2×dp[sum/2]。
