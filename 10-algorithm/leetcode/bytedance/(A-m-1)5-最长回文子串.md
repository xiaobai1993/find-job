# 5. 最长回文子串

题目链接：`https://leetcode.cn/problems/longest-palindromic-substring/description/`

---

## 一、题目描述

给定一个字符串 `s`，找到 `s` 中最长的回文子串。

**示例：**

```
输入: "babad"   → 输出: "bab"（"aba" 也是正确答案）
输入: "cbbd"    → 输出: "bb"
输入: "a"       → 输出: "a"
```

---

## 二、核心思路：中心扩展

**回文是对称的**——从中心往两边扩展，两边字符相同就继续，不同就停。

每个字符（和每对相邻字符）都是一个可能的回文中心，向外扩展找最长回文。

```
以 "babad" 为例:

中心 = b (i=0):  b → 停（左边没了）         长度 1
中心 = a (i=1):  a → ba? ✗ → 停             长度 1
中心 = ba(i=0,1): b≠a → 停                  长度 0
中心 = b (i=2):  b → ab? ✗ → 停             长度 1
中心 = ab(i=1,2): a=b? a≠b → 停             长度 0
中心 = a (i=1):  a → bab ✓ → abab? ✗ → 停   长度 3 ← 最长
...
```

---

## 三、为什么中心有两种？

回文长度分两种：

```
奇数长: 以单个字符为中心
  b a b
    ↑
  中心是 a，左右对称

偶数长: 以两个相邻字符的间隙为中心
  b b
  ↑↑
  中心是两个 b 之间，左右对称
```

所以每个位置 `i` 要尝试两种扩展：
1. `extend(i, i)` —— 奇数长度回文，中心是 `s[i]`
2. `extend(i, i+1)` —— 偶数长度回文，中心是 `s[i]` 和 `s[i+1]` 之间

---

## 四、代码

```go
func longestPalindrome(s string) string {
    minLeft, maxRight := 0, 0

    // 从中心向外扩展，返回能到达的最远边界
    var extend = func(s string, left, right int) (int, int) {
        for left >= 0 && right < len(s) {
            if s[left] != s[right] {
                break
            }
            left--
            right++
        }
        return left + 1, right - 1
    }

    for i := 0; i < len(s); i++ {
        // 奇数长度：以 s[i] 为中心
        left, right := extend(s, i, i)
        if right-left > maxRight-minLeft {
            maxRight, minLeft = right, left
        }

        // 偶数长度：以 s[i] 和 s[i+1] 之间为中心
        left, right = extend(s, i, i+1)
        if right-left > maxRight-minLeft {
            maxRight, minLeft = right, left
        }
    }

    return s[minLeft : maxRight+1]
}
```

## 五、extend 函数详解

```go
var extend = func(s string, left, right int) (int, int) {
    for left >= 0 && right < len(s) {
        if s[left] != s[right] {
            break
        }
        left--
        right++
    }
    return left + 1, right - 1
}
```

扩展过程：

```
s = "babad", extend(2, 2)（奇数，中心 a）

初始: left=2, right=2 → s[2]=a, 相等
  left→1, right→3 → s[1]=b, s[3]=b, 相等
  left→0, right→4 → s[0]=b, s[4]=d, 不等 → break

循环结束后 left=-1, right=5
但回文边界是 left+1=0, right-1=4? 不对
等等：break 时 left=-1, right=4（不相等那次没扩展）
返回 0, 3 → s[0:4] = "baba"? 不对

再仔细看：
循环体先判断相等，再 left-- right++
break 时 s[left] != s[right]，这次不算

left=-1, right=4 时 break
所以有效的回文边界是 left+1=0, right-1=3
s[0:4] = "baba" 也不对...

让我重新走：
left=2, right=2: s[2]==s[2] ✓, left=1, right=3
left=1, right=3: s[1]==s[3] (b==b) ✓, left=0, right=4
left=0, right=4: s[0]!=s[4] (b!=d) ✗, break

left=0, right=4 时 break
返回 left+1=1, right-1=3
s[1:4] = "bab" ✓!
```

关键：**循环退出时 `left` 和 `right` 指向的是第一对不匹配的位置**（或越界），所以要 `+1` 和 `-1` 回退到最后一对匹配的位置。

## 六、完整流程图解

以 `"cbbd"` 为例：

```
i=0: s[0]='c'
  extend(0,0): c ✓ → left=-1 → 返回 (0,0)，长度1
  extend(0,1): c≠b → 返回 (1,0)，长度0（left>right，无效）
  最长: (0,0)

i=1: s[1]='b'
  extend(1,1): b ✓ → left=0,right=2 → c≠b → 返回 (1,1)，长度1
  extend(1,2): b=b ✓ → left=0,right=3 → c≠d → 返回 (1,2)，长度2 ← 更新
  最长: (1,2)

i=2: s[2]='b'
  extend(2,2): b ✓ → 返回 (2,2)，长度1
  extend(2,3): b≠d → 返回 (3,2)，长度0
  最长不变

i=3: s[3]='d'
  extend(3,3): d ✓ → 返回 (3,3)，长度1
  extend(3,4): 越界 → 返回 (4,3)，长度0
  最长不变

最终: s[1:3] = "bb" ✓
```

## 七、返回值为什么要 +1？

```go
return s[minLeft : maxRight+1]
```

Go 的切片是**左闭右开** `[a, b)`。`extend` 返回的 `minLeft` 和 `maxRight` 是闭区间边界，所以右端要 +1。

```
回文 "bab" 在 s 中的位置: 1~3（闭区间）
Go 切片: s[1:4]  → 左闭右开，4 = 3+1
```

---

## 八、为什么不用 DP？

| 方法 | 时间 | 空间 | 特点 |
|------|------|------|------|
| 中心扩展 | O(n²) | O(1) | 简单直观，面试首选 |
| DP | O(n²) | O(n²) | 空间大，写起来也不短 |
| Manacher | O(n) | O(n) | 最优但复杂，面试一般不要求 |

中心扩展和 DP 时间一样，但空间 O(1) vs O(n²)，中心扩展完胜。

## 九、复杂度分析

| 维度 | 值 |
|------|------|
| 时间 | O(n²)，n 个中心，每个最多扩展 n/2 次 |
| 空间 | O(1)，只用几个变量 |

## 十、容易错的点

### 1. extend 返回要 +1/-1 回退

```go
// ✗ 错：直接返回 left, right
return left, right

// ✓ 对：退出时 left/right 已经越界或不匹配，要回退
return left + 1, right - 1
```

### 2. 偶数长度扩展从 (i, i+1) 开始

```go
// ✗ 错：偶数也从 (i, i) 开始，就只有奇数回文了
left, right = extend(s, i, i)

// ✓ 对：偶数长度必须传两个相邻位置
left, right = extend(s, i, i+1)
```

漏掉偶数扩展就找不到 `"bb"` 这种回文。

### 3. 更新最长时用差值比较，不是长度

```go
// ✗ 错：每次要算长度，多一步
if right-left+1 > maxLen {

// ✓ 对：直接比较差值，等价且简洁
if right-left > maxRight-minLeft {
```

`right-left` 大等价于 `right-left+1` 大，+1 抵消了。

### 4. Go 切片右端 +1

```go
return s[minLeft : maxRight+1]  // 不是 maxRight
```

## 十一、面试表达

> 最长回文子串用中心扩展法。遍历每个位置，以该位置为奇数中心、以该位置和下一个位置之间为偶数中心，分别向外扩展。扩展函数就是双指针从中心往两边走，遇到不等就停，返回边界时要回退一步（因为退出时已经不匹配了）。每次扩展完更新最长边界。时间 O(n²)，空间 O(1)。
