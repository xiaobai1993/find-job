# 392. 判断子序列

> LeetCode 链接：https://leetcode.cn/problems/is-subsequence/

## 题目
给定字符串 s 和 t，判断 s 是否是 t 的子序列（按顺序删除某些字符后得到）。

## 最易理解的方法：双指针

**核心思路：**
用两个指针分别扫描 s 和 t，t 的字符匹配 s 时才移动 s 的指针。
若 s 的指针走到末尾，说明 s 是 t 的子序列。

```
s="ace", t="abcde"

i=0(a), j=0(a): 匹配 i=1
i=1(c), j=1(b): 不匹配 j=2
i=1(c), j=2(c): 匹配 i=2
i=2(e), j=3(d): 不匹配 j=4
i=2(e), j=4(e): 匹配 i=3

i==len(s) → true
```

## Go 实现

```go
func isSubsequence(s string, t string) bool {
    i, j := 0, 0
    for i < len(s) && j < len(t) {
        if s[i] == t[j] {
            i++
        }
        j++
    }
    return i == len(s)
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 双指针：t的字符匹配s时才推进s的指针；s走完则是子序列。
