# 1047. 删除字符串中的所有相邻重复项

> LeetCode 链接：https://leetcode.cn/problems/remove-all-adjacent-duplicates-in-string/

## 题目
重复执行：选择相邻且相同的两个字母删除，直到无法删除为止，返回结果。

## 最易理解的方法：栈模拟

**核心思路：**
用栈，若当前字符与栈顶相同则弹出（消除），否则压入。

```
s = "abbaca"

a→栈[a]
b→栈[a,b]
b==b→弹出→栈[a]
a==a→弹出→栈[]
c→栈[c]
a→栈[c,a]

结果: "ca"
```

## Go 实现

```go
func removeDuplicates(s string) string {
    stack := []byte{}
    for i := 0; i < len(s); i++ {
        if len(stack) > 0 && stack[len(stack)-1] == s[i] {
            stack = stack[:len(stack)-1]
        } else {
            stack = append(stack, s[i])
        }
    }
    return string(stack)
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> 栈模拟：当前字符==栈顶则弹出（消除），否则压入；最终栈即为结果。
