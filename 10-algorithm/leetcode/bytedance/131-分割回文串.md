# 131. 分割回文串

> LeetCode 链接：https://leetcode.cn/problems/palindrome-partitioning/

## 题目
给定字符串 s，将 s 分割成若干子串，使每个子串都是回文串，返回所有可能的方案。

## 最易理解的方法：回溯 + 预处理 DP

**核心思路：**
1. 预处理：用 DP 计算 `isPalin[i][j]` 表示 `s[i..j]` 是否是回文
2. 回溯：从 start 开始枚举所有可能的回文前缀，递归处理剩余部分

```
s = "aab"

start=0:
  [0,0]="a"回文 → start=1
    [1,1]="a"回文 → start=2
      [2,2]="b"回文 → 收集["a","a","b"]
    [1,2]="ab"非回文
  [0,1]="aa"回文 → start=2
    [2,2]="b"回文 → 收集["aa","b"]
  [0,2]="aab"非回文
```

## Go 实现

```go
func partition(s string) [][]string {
    n := len(s)
    // 预处理回文
    dp := make([][]bool, n)
    for i := range dp {
        dp[i] = make([]bool, n)
        dp[i][i] = true
    }
    for length := 2; length <= n; length++ {
        for i := 0; i <= n-length; i++ {
            j := i + length - 1
            if s[i] == s[j] {
                if length == 2 || dp[i+1][j-1] {
                    dp[i][j] = true
                }
            }
        }
    }
    var res [][]string
    var path []string
    var backtrack func(start int)
    backtrack = func(start int) {
        if start == n {
            tmp := make([]string, len(path))
            copy(tmp, path)
            res = append(res, tmp)
            return
        }
        for end := start; end < n; end++ {
            if dp[start][end] {
                path = append(path, s[start:end+1])
                backtrack(end + 1)
                path = path[:len(path)-1]
            }
        }
    }
    backtrack(0)
    return res
}
```

## 复杂度
- 时间：O(n × 2^n)
- 空间：O(n²)

## 记忆口诀
> DP预处理所有子串是否回文；回溯枚举回文前缀，递归剩余部分；到末尾时收集结果。
