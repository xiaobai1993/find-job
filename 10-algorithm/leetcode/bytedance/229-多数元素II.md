# 229. 多数元素 II

> LeetCode 链接：https://leetcode.cn/problems/majority-element-ii/

## 题目
给定整数数组，找出其中所有出现次数超过 n/3 的元素。

## 最易理解的方法：Boyer-Moore 投票（两个候选人）

**核心思路：**
超过 n/3 的元素最多2个。维护两个候选 + 计数，遍历后再验证。

```
nums = [3,2,3]

candidate1=3,cnt1=1
candidate2=2,cnt2=1
3==candidate1 → cnt1=2

验证: 3出现2次 > 3/3=1 ✓
结果: [3]
```

## Go 实现

```go
func majorityElement(nums []int) []int {
    c1, c2, cnt1, cnt2 := 0, 1, 0, 0
    for _, n := range nums {
        if n == c1 {
            cnt1++
        } else if n == c2 {
            cnt2++
        } else if cnt1 == 0 {
            c1, cnt1 = n, 1
        } else if cnt2 == 0 {
            c2, cnt2 = n, 1
        } else {
            cnt1--
            cnt2--
        }
    }
    cnt1, cnt2 = 0, 0
    for _, n := range nums {
        if n == c1 { cnt1++ } else if n == c2 { cnt2++ }
    }
    var res []int
    if cnt1 > len(nums)/3 { res = append(res, c1) }
    if cnt2 > len(nums)/3 { res = append(res, c2) }
    return res
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 两个候选人投票；不同于任一候选则两者各减1；最后验证计数 > n/3。
