# 347. 前 K 个高频元素

> LeetCode 链接：https://leetcode.cn/problems/top-k-frequent-elements/

## 题目
给定整数数组 `nums` 和整数 `k`，返回出现频率前 k 高的元素。

## 最易理解的方法：哈希表 + 小根堆（大小为k）

**核心思路：**
先统计每个元素频次，然后用**大小为 k 的小根堆**维护前 k 个高频元素。遍历频次时，将元素入堆；若堆大小超过 k，弹出堆中频次最小的（小根堆堆顶）。最终堆中剩下的就是频次前 k 的元素。

```
nums = [1,1,1,2,2,3], k = 2
频次: {1:3, 2:2, 3:1}

小根堆(按频次):
入(1,3): [(1,3)]
入(2,2): [(2,2),(1,3)]  → 堆大小=2=k
入(3,1): [(3,1),(1,3),(2,2)] → 超k，弹(3,1) → [(2,2),(1,3)]

结果: [1, 2]
```

## Go 实现

```go
import "container/heap"

func topKFrequent(nums []int, k int) []int {
    freq := make(map[int]int)
    for _, n := range nums {
        freq[n]++
    }
    // 小根堆，按频次排序
    h := &MinHeapByFreq{}
    for num, cnt := range freq {
        heap.Push(h, [2]int{num, cnt})
        if h.Len() > k {
            heap.Pop(h)
        }
    }
    res := make([]int, k)
    for i := 0; i < k; i++ {
        res[i] = heap.Pop(h).([2]int)[0]
    }
    return res
}

type MinHeapByFreq [][2]int
func (h MinHeapByFreq) Len() int           { return len(h) }
func (h MinHeapByFreq) Less(i, j int) bool { return h[i][1] < h[j][1] }
func (h MinHeapByFreq) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }
func (h *MinHeapByFreq) Push(x interface{}) { *h = append(*h, x.([2]int)) }
func (h *MinHeapByFreq) Pop() interface{} {
    old := *h; n := len(old); x := old[n-1]; *h = old[:n-1]; return x
}
```

## 复杂度
- 时间：O(n log k)
- 空间：O(n)

## 记忆口诀
> 哈希计频；小根堆维护k个高频元素（超k则弹出堆中最小频次的）；结尾堆中即答案。
