# 350. 两个数组的交集 II

> LeetCode 链接：https://leetcode.cn/problems/intersection-of-two-arrays-ii/

## 题目
给定两个整数数组，返回它们的交集（结果中每个元素出现的次数与两数组中出现次数的最小值相同）。

## 最易理解的方法：哈希表计数

**核心思路：**
统计 nums1 中每个数的频率，遍历 nums2，存在且频率>0时加入结果并递减。

```
nums1=[1,2,2,1], nums2=[2,2]

cnt: {1:2, 2:2}
遍历nums2: 2→cnt[2]=2>0 → 加入，cnt[2]=1
           2→cnt[2]=1>0 → 加入，cnt[2]=0
结果: [2,2]
```

## Go 实现

```go
func intersect(nums1 []int, nums2 []int) []int {
    cnt := make(map[int]int)
    for _, n := range nums1 { cnt[n]++ }
    var res []int
    for _, n := range nums2 {
        if cnt[n] > 0 {
            res = append(res, n)
            cnt[n]--
        }
    }
    return res
}
```

## 复杂度
- 时间：O(m+n)
- 空间：O(m)

## 记忆口诀
> 统计nums1频率；遍历nums2，有频率则加入结果并--；允许重复出现。
