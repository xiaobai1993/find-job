# 337. 打家劫舍 III

> LeetCode 链接：https://leetcode.cn/problems/house-robber-iii/

## 题目
小偷在树形结构中偷窃，相连的节点不能同时被偷，求最大收益。

## 最易理解的方法：树形 DP（后序遍历）

**核心思路：**
对每个节点返回两个值 `[不偷该节点的最大收益, 偷该节点的最大收益]`：
- 偷当前节点：左子不偷 + 右子不偷 + 当前值
- 不偷当前节点：max(左偷,左不偷) + max(右偷,右不偷)

```
    3
   / \
  2   3
   \    \
    3    1

后序遍历:
节点3(叶): [0,3]
节点1(叶): [0,1]
节点2: 不偷=max(0,3)=3; 偷=2+0=2 → [3,2]
节点3: 不偷=max(0,1)=1; 偷=3+0=3 → [1,3]
根3: 不偷=max(3,2)+max(1,3)=3+3=6; 偷=3+0+0=3 → [6,3]

答案=max(6,3)=7
```

## Go 实现

```go
func rob(root *TreeNode) int {
    var dfs func(node *TreeNode) (int, int) // (不偷, 偷)
    dfs = func(node *TreeNode) (int, int) {
        if node == nil {
            return 0, 0
        }
        lNo, lYes := dfs(node.Left)
        rNo, rYes := dfs(node.Right)
        // 不偷当前：子节点可偷可不偷，取最大
        no := max(lNo, lYes) + max(rNo, rYes)
        // 偷当前：子节点不能偷
        yes := node.Val + lNo + rNo
        return no, yes
    }
    no, yes := dfs(root)
    return max(no, yes)
}

func max(a, b int) int {
    if a > b { return a }
    return b
}
```

## 复杂度
- 时间：O(n)
- 空间：O(h)

## 记忆口诀
> 后序DFS返回(不偷,偷)两个值；不偷=子节点取max之和；偷=当前值+左不偷+右不偷。
