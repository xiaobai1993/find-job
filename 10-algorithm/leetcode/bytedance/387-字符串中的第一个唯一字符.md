# 387. 字符串中的第一个唯一字符

> LeetCode 链接：https://leetcode.cn/problems/first-unique-character-in-a-string/

## 题目
给定字符串，找到其中第一个不重复的字符并返回它的索引，不存在则返回 -1。

## 最易理解的方法：两遍哈希计数

**核心思路：**
第一遍：统计每个字母出现次数。
第二遍：找第一个出现次数为 1 的字母。

```
s = "leetcode"

count: l:1, e:3, t:1, c:1, o:1, d:1

第二遍: l(1次)→位置0 → 返回0
```

## Go 实现

```go
func firstUniqChar(s string) int {
    count := [26]int{}
    for _, c := range s {
        count[c-'a']++
    }
    for i, c := range s {
        if count[c-'a'] == 1 {
            return i
        }
    }
    return -1
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 两遍：先计频，再找第一个频率为1的字符的位置。
