# 300. 最长上升子序列

> LeetCode 链接：https://leetcode.cn/problems/longest-increasing-subsequence/

## 题目
给定整数数组，找到最长严格递增子序列的长度（子序列不要求连续）。

## 最易理解的方法：动态规划 O(n²)

**核心思路：**
`dp[i]` = 以 `nums[i]` 结尾的最长递增子序列长度。对每个 `i`，遍历 `j < i`，若 `nums[j] < nums[i]`，则 `dp[i] = max(dp[i], dp[j]+1)`。

```
nums = [10, 9, 2, 5, 3, 7, 101, 18]
dp   = [ 1, 1, 1, 2, 2, 3,   4,  4]

dp[5]=3: nums[5]=7 > nums[2]=2(dp[2]=1), nums[3]=5(dp[3]=2)
         dp[5] = max(1+1, 2+1) = 3
```

## Go 实现

```go
func lengthOfLIS(nums []int) int {
    n := len(nums)
    dp := make([]int, n)
    for i := range dp {
        dp[i] = 1 // 至少包含自己
    }
    ans := 1
    for i := 1; i < n; i++ {
        for j := 0; j < i; j++ {
            if nums[j] < nums[i] {
                if dp[j]+1 > dp[i] {
                    dp[i] = dp[j] + 1
                }
            }
        }
        if dp[i] > ans {
            ans = dp[i]
        }
    }
    return ans
}
```

## 进阶方法：贪心 + 二分 O(n log n)

维护一个数组 `tails`，`tails[i]` 是长度为 `i+1` 的递增子序列的最小末尾值。对每个 `num`，二分找到插入位置。

```go
func lengthOfLIS(nums []int) int {
    tails := []int{}
    for _, num := range nums {
        lo, hi := 0, len(tails)
        for lo < hi {
            mid := (lo + hi) / 2
            if tails[mid] < num {
                lo = mid + 1
            } else {
                hi = mid
            }
        }
        if lo == len(tails) {
            tails = append(tails, num) // 延长
        } else {
            tails[lo] = num // 替换（保持最小末尾）
        }
    }
    return len(tails)
}
```

## 复杂度
- DP：时间 O(n²)，空间 O(n)
- 贪心+二分：时间 O(n log n)，空间 O(n)
