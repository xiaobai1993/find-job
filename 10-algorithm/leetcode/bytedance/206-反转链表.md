# 206. 反转链表

> LeetCode 链接：https://leetcode.cn/problems/reverse-linked-list/

## 题目
将一个单链表反转，返回反转后的链表头节点。

## 最易理解的方法：迭代三指针

**核心思路：**
用三个指针 `prev`、`curr`、`next` 逐一反转节点指向。每次把 `curr.Next` 改为指向 `prev`，然后三个指针整体右移一步，直到 `curr` 为空。

```
初始：  nil    1 -> 2 -> 3 -> nil
       prev  curr

步骤1： nil <- 1    2 -> 3 -> nil
              prev curr

步骤2： nil <- 1 <- 2    3 -> nil
                   prev curr

最终返回 prev
```

**算法步骤：**
1. `prev = nil`，`curr = head`
2. 循环：保存 `next = curr.Next`，`curr.Next = prev`，`prev = curr`，`curr = next`
3. 返回 `prev`

## Go 实现

```go
func reverseList(head *ListNode) *ListNode {
    var prev *ListNode
    curr := head
    for curr != nil {
        next := curr.Next  // 保存后继
        curr.Next = prev   // 反转指向
        prev = curr        // prev 前进
        curr = next        // curr 前进
    }
    return prev
}
```

## 递归写法（面试加分）

```go
func reverseList(head *ListNode) *ListNode {
    if head == nil || head.Next == nil {
        return head
    }
    newHead := reverseList(head.Next) // 递归反转后面
    head.Next.Next = head             // 后面的节点指回来
    head.Next = nil                   // 断开原来的指向
    return newHead
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)（迭代），O(n)（递归）

## 记忆口诀
> prev/curr/next 三指针；curr.Next 指 prev；三指针同步右移。
