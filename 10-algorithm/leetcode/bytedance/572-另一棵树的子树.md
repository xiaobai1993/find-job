# 572. 另一棵树的子树

> LeetCode 链接：https://leetcode.cn/problems/subtree-of-another-tree/

## 题目
给定两棵二叉树 root 和 subRoot，判断 subRoot 是否是 root 的子树（subRoot 与 root 的某个子树结构和值完全相同）。

## 最易理解的方法：DFS + isSameTree

**核心思路：**
遍历 root 的每个节点，判断以该节点为根的子树是否与 subRoot 相同。

```
root:
    3
   / \
  4   5
 / \
1   2

subRoot:
  4
 / \
1   2

以节点4为根的子树 = subRoot ✓ → true
```

## Go 实现

```go
func isSubtree(root *TreeNode, subRoot *TreeNode) bool {
    if root == nil {
        return false
    }
    if isSameTree(root, subRoot) {
        return true
    }
    return isSubtree(root.Left, subRoot) || isSubtree(root.Right, subRoot)
}

func isSameTree(p, q *TreeNode) bool {
    if p == nil && q == nil {
        return true
    }
    if p == nil || q == nil {
        return false
    }
    return p.Val == q.Val && isSameTree(p.Left, q.Left) && isSameTree(p.Right, q.Right)
}
```

## 复杂度
- 时间：O(m × n)，m 和 n 分别为两棵树的节点数
- 空间：O(max(h1, h2))

## 记忆口诀
> 对每个节点判断是否与subRoot相同；相同则true；否则递归检查左右子树。
