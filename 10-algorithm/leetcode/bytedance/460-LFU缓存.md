# 460. LFU 缓存

> LeetCode 链接：https://leetcode.cn/problems/lfu-cache/

## 题目
设计并实现最不经常使用（LFU）缓存：get 返回键对应值，put 更新/插入键值对。缓存满时淘汰使用频次最低的键（频次相同淘汰最久未使用的）。

## 最易理解的方法：双哈希表 + 双向链表（O(1)）

**核心思路：**
- `keyMap`：key → (value, freq)
- `freqMap`：freq → 有序双向链表（同频率按LRU顺序，链表头最近使用）
- `minFreq`：当前最低频率（用于淘汰）

每次 get/put 时：从 freqMap[oldFreq] 移出该节点，加入 freqMap[oldFreq+1] 的头部；若 freqMap[minFreq] 为空则 minFreq++。put 新 key 时 minFreq 重置为 1。

```go
type LFUCache struct {
    cap, minFreq int
    keyMap  map[int]*Node           // key → 节点
    freqMap map[int]*DoubleList     // freq → 双向链表
}

type Node struct {
    key, val, freq int
    prev, next *Node
}

type DoubleList struct {
    head, tail *Node
    size       int
}
```

## Go 实现

```go
type LFUCache struct {
    cap, minFreq int
    keys  map[int]*Node
    freqs map[int]*list.List
    nodes map[int]*list.Element
}

func Constructor(capacity int) LFUCache {
    return LFUCache{
        cap:   capacity,
        keys:  make(map[int]*Node),
        freqs: make(map[int]*list.List),
        nodes: make(map[int]*list.Element),
    }
}

type Node struct{ key, val, freq int }

func (c *LFUCache) Get(key int) int {
    if node, ok := c.keys[key]; ok {
        c.increment(key, node)
        return node.val
    }
    return -1
}

func (c *LFUCache) Put(key int, value int) {
    if c.cap == 0 {
        return
    }
    if node, ok := c.keys[key]; ok {
        node.val = value
        c.increment(key, node)
        return
    }
    if len(c.keys) >= c.cap {
        // 淘汰 minFreq 链表中最后一个
        lst := c.freqs[c.minFreq]
        back := lst.Back()
        n := back.Value.(*Node)
        lst.Remove(back)
        delete(c.keys, n.key)
        delete(c.nodes, n.key)
    }
    node := &Node{key, value, 1}
    c.keys[key] = node
    if c.freqs[1] == nil {
        c.freqs[1] = list.New()
    }
    el := c.freqs[1].PushFront(node)
    c.nodes[key] = el
    c.minFreq = 1
}

func (c *LFUCache) increment(key int, node *Node) {
    oldFreq := node.freq
    c.freqs[oldFreq].Remove(c.nodes[key])
    if c.freqs[oldFreq].Len() == 0 && oldFreq == c.minFreq {
        c.minFreq++
    }
    node.freq++
    if c.freqs[node.freq] == nil {
        c.freqs[node.freq] = list.New()
    }
    el := c.freqs[node.freq].PushFront(node)
    c.nodes[key] = el
}
```

## 复杂度
- 时间：O(1) 所有操作
- 空间：O(capacity)

## 记忆口诀
> 双哈希表：key→节点，freq→链表；操作时从旧freq链表移出，加入新freq链表头；minFreq随操作更新。
