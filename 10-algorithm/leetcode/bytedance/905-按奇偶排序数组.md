# 905. 按奇偶排序数组

> LeetCode 链接：https://leetcode.cn/problems/sort-array-by-parity/

## 题目
给定整数数组，将所有偶数移到数组前面，奇数移到后面（顺序任意）。

## 最易理解的方法：双指针原地交换

**核心思路：**
左指针找奇数，右指针找偶数，交换位置，向中间收缩。

```
nums = [3,1,2,4]

l=0(3奇数), r=3(4偶数) → swap → [4,1,2,3]
l=1(1奇数), r=2(2偶数) → swap → [4,2,1,3]
l>=r → 结束
```

## Go 实现

```go
func sortArrayByParity(nums []int) []int {
    l, r := 0, len(nums)-1
    for l < r {
        for l < r && nums[l]%2 == 0 { l++ }
        for l < r && nums[r]%2 == 1 { r-- }
        if l < r {
            nums[l], nums[r] = nums[r], nums[l]
            l++; r--
        }
    }
    return nums
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 双指针：左找奇右找偶，相遇则停；找到后交换，向内收缩。
