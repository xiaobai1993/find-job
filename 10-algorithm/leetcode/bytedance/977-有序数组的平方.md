# 977. 有序数组的平方

> LeetCode 链接：https://leetcode.cn/problems/squares-of-a-sorted-array/

## 题目
给定按升序排列的整数数组（包含负数），返回每个数字平方后排好序的新数组。

## 最易理解的方法：双指针（从两端向中间）

**核心思路：**
两端的平方值最大，双指针从两端向中间，将较大的平方值从结果数组末尾填入。

```
nums = [-4,-1,0,3,10]

l=0(-4²=16), r=4(10²=100)
100>16 → res[4]=100, r=3
64>16  → res[3]=64,  r=2
9>16?  → 16>9 → res[2]=16, l=1
9>1    → res[1]=9,  r=1
1      → res[0]=1

结果: [0,1,9,16,100]
```

## Go 实现

```go
func sortedSquares(nums []int) []int {
    n := len(nums)
    res := make([]int, n)
    l, r, k := 0, n-1, n-1
    for l <= r {
        lsq, rsq := nums[l]*nums[l], nums[r]*nums[r]
        if lsq > rsq {
            res[k] = lsq
            l++
        } else {
            res[k] = rsq
            r--
        }
        k--
    }
    return res
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> 双指针从两端；较大平方填到结果末尾；指针向中间收缩；O(n)一次完成。
