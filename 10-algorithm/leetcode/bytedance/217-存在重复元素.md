# 217. 存在重复元素

> LeetCode 链接：https://leetcode.cn/problems/contains-duplicate/

## 题目
给定整数数组，判断是否有任何值出现至少两次。

## 最易理解的方法：哈希集合

```go
func containsDuplicate(nums []int) bool {
    seen := make(map[int]bool)
    for _, n := range nums {
        if seen[n] {
            return true
        }
        seen[n] = true
    }
    return false
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> 哈希集合；遇到已存在的值立即返回true；遍历完返回false。
