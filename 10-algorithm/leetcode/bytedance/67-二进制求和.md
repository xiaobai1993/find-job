# 67. 二进制求和

> LeetCode 链接：https://leetcode.cn/problems/add-binary/

## 题目
给定两个二进制字符串 a 和 b，返回它们的和（也是二进制字符串）。

## 最易理解的方法：从末位模拟进位

**核心思路：**
类似十进制加法，从末位开始逐位相加（0或1），维护进位 carry，最后翻转结果。

```
a="11", b="1"

i=1,j=0: 1+1+0=2 → 位=0,carry=1
i=0: 1+0+1=2 → 位=0,carry=1
carry=1: 补1

结果翻转: "100"
```

## Go 实现

```go
func addBinary(a string, b string) string {
    i, j := len(a)-1, len(b)-1
    carry := 0
    res := []byte{}
    for i >= 0 || j >= 0 || carry > 0 {
        sum := carry
        if i >= 0 {
            sum += int(a[i] - '0')
            i--
        }
        if j >= 0 {
            sum += int(b[j] - '0')
            j--
        }
        res = append(res, byte(sum%2)+'0')
        carry = sum / 2
    }
    // 翻转
    for lo, hi := 0, len(res)-1; lo < hi; lo, hi = lo+1, hi-1 {
        res[lo], res[hi] = res[hi], res[lo]
    }
    return string(res)
}
```

## 复杂度
- 时间：O(max(m,n))
- 空间：O(max(m,n))

## 记忆口诀
> 从末位到开头逐位相加；sum%2是当前位，sum/2是进位；最后翻转结果。
