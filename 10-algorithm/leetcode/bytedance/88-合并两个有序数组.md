# 88. 合并两个有序数组

> LeetCode 链接：https://leetcode.cn/problems/merge-sorted-array/

## 题目
给定两个有序数组 `nums1`（长度 m+n，前 m 个有效）和 `nums2`（长度 n），将 `nums2` 合并到 `nums1` 中。

## 最易理解的方法：从后向前双指针

**核心思路：**
从后往前比较，把较大的放到 nums1 末尾。这样不会覆盖 nums1 中还未比较的元素。

```
nums1 = [1,2,3,_,_,_], m=3
nums2 = [2,5,6],       n=3

p1=2(值3), p2=2(值6), p=5
6>3 → nums1[5]=6, p2=1, p=4
5>3 → nums1[4]=5, p2=0, p=3
3>2 → nums1[3]=3, p1=1, p=2
2≤2 → nums1[2]=2, p2=-1, 停止
剩余 nums1[0..1] 已在原位

结果: [1,2,2,3,5,6]
```

## Go 实现

```go
func merge(nums1 []int, m int, nums2 []int, n int) {
    p1, p2, p := m-1, n-1, m+n-1
    for p1 >= 0 && p2 >= 0 {
        if nums1[p1] > nums2[p2] {
            nums1[p] = nums1[p1]
            p1--
        } else {
            nums1[p] = nums2[p2]
            p2--
        }
        p--
    }
    // nums2 还有剩余（nums1 剩余已在原位无需处理）
    for p2 >= 0 {
        nums1[p] = nums2[p2]
        p2--
        p--
    }
}
```

## 复杂度
- 时间：O(m+n)
- 空间：O(1)

## 记忆口诀
> 从后向前：两指针比较，大的填到末尾；nums2 有剩余则继续填，nums1 剩余已在原位。
