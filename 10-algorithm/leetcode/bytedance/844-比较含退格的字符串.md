# 844. 比较含退格的字符串

> LeetCode 链接：https://leetcode.cn/problems/backspace-string-compare/

## 题目
给定字符串 s 和 t（'#' 表示退格），判断它们是否相等。要求 O(n) 时间 O(1) 空间。

## 最易理解的方法：从末尾向前双指针

**核心思路：**
从末尾向前扫描，遇到 '#' 跳过下一个有效字符，对比两个字符串的有效字符是否匹配。

```
s="ab#c", t="ad#c"

从末尾扫:
s: c,b被#退格→a,c; 有效序列: "ac"
t: c,d被#退格→a,c; 有效序列: "ac"
→ 相等
```

## Go 实现

```go
func backspaceCompare(s string, t string) bool {
    i, j := len(s)-1, len(t)-1
    skipS, skipT := 0, 0
    for i >= 0 || j >= 0 {
        for i >= 0 {
            if s[i] == '#' { skipS++; i-- } else if skipS > 0 { skipS--; i-- } else { break }
        }
        for j >= 0 {
            if t[j] == '#' { skipT++; j-- } else if skipT > 0 { skipT--; j-- } else { break }
        }
        if i >= 0 && j >= 0 && s[i] != t[j] { return false }
        if (i >= 0) != (j >= 0) { return false }
        i--; j--
    }
    return true
}
```

## 复杂度
- 时间：O(m+n)
- 空间：O(1)

## 记忆口诀
> 从末尾向前扫描；遇#则skip++跳过有效字符；双串同时对比有效字符。
