# 151. 翻转字符串里的单词

> LeetCode 链接：https://leetcode.cn/problems/reverse-words-in-a-string/

## 题目
给定字符串，翻转字符串中的单词（多余空格去除，单词间用单空格分隔）。

## 最易理解的方法：Split + 逆序拼接

**核心思路：**
按空格分割，过滤空字符串，然后逆序拼接。

```
"  the sky is  blue  "

分割去空: ["the","sky","is","blue"]
逆序: ["blue","is","sky","the"]
拼接: "blue is sky the"
```

## Go 实现

```go
import "strings"

func reverseWords(s string) string {
    words := strings.Fields(s) // 自动按空白分割并过滤空字符串
    lo, hi := 0, len(words)-1
    for lo < hi {
        words[lo], words[hi] = words[hi], words[lo]
        lo++
        hi--
    }
    return strings.Join(words, " ")
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> strings.Fields分割（自动处理多余空格）；原地翻转单词切片；Join用单空格拼接。
