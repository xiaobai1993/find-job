# 896. 单调数列

> LeetCode 链接：https://leetcode.cn/problems/monotonic-array/

## 题目
判断数组是否单调（单调递增或单调递减）。

## 最易理解的方法：一次遍历记录方向

**核心思路：**
遍历时记录是否出现了增大和减小的情况，若两者同时出现则非单调。

```
[1,2,2,3]: 只增(含相等) → 单调递增 → true
[1,2,3,2]: 先增后减 → false
```

## Go 实现

```go
func isMonotonic(nums []int) bool {
    inc, dec := true, true
    for i := 1; i < len(nums); i++ {
        if nums[i] > nums[i-1] { dec = false }
        if nums[i] < nums[i-1] { inc = false }
    }
    return inc || dec
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 维护inc和dec两个flag；有增则dec=false，有减则inc=false；最终inc||dec。
