# 148. 排序链表

> LeetCode 链接：https://leetcode.cn/problems/sort-list/

## 题目
对链表进行排序，要求 O(n log n) 时间复杂度。

## 最易理解的方法：归并排序（分治）

**核心思路：**
1. 找中点（快慢指针），从中点断开成两个链表
2. 递归排序两个子链表
3. 合并两个有序链表

```
4 -> 2 -> 1 -> 3

找中点断开：  4->2   1->3
递归排序：    2->4   1->3
合并：        1->2->3->4
```

**算法步骤：**
1. 递归终止：链表为空或只有一个节点
2. 快慢指针找中点：`slow/fast`，断开 `slow.Next = nil`
3. 递归 `sortList(head)` 和 `sortList(mid)`
4. 合并两个有序链表

## Go 实现

```go
func sortList(head *ListNode) *ListNode {
    if head == nil || head.Next == nil {
        return head
    }
    // 快慢指针找中点
    slow, fast := head, head.Next
    for fast != nil && fast.Next != nil {
        slow = slow.Next
        fast = fast.Next.Next
    }
    mid := slow.Next
    slow.Next = nil // 断开
    // 递归排序
    left := sortList(head)
    right := sortList(mid)
    // 合并
    return mergeTwoLists(left, right)
}

func mergeTwoLists(l1, l2 *ListNode) *ListNode {
    dummy := &ListNode{}
    curr := dummy
    for l1 != nil && l2 != nil {
        if l1.Val <= l2.Val {
            curr.Next = l1
            l1 = l1.Next
        } else {
            curr.Next = l2
            l2 = l2.Next
        }
        curr = curr.Next
    }
    if l1 != nil {
        curr.Next = l1
    } else {
        curr.Next = l2
    }
    return dummy.Next
}
```

## 复杂度
- 时间：O(n log n)
- 空间：O(log n)（递归栈）

## 记忆口诀
> 快慢指针找中点断开；递归排序左右；合并两个有序链表。
