# 209. 长度最小的子数组

> LeetCode 链接：https://leetcode.cn/problems/minimum-size-subarray-sum/

## 题目
给定正整数数组 `nums` 和正整数 `target`，找出满足 **总和 ≥ target** 的长度最小的连续子数组，返回其长度；若不存在返回 0。

## 最易理解的方法：滑动窗口

**核心思路：**
右指针不断向右扩展（扩大窗口，增加总和），当窗口总和 ≥ target 时，记录窗口长度，然后左指针右移（收缩窗口）。这样能找到所有满足条件的最短窗口。

```
nums = [2,3,1,2,4,3], target = 7

left=0:
right=0: sum=2
right=1: sum=5
right=2: sum=6
right=3: sum=8 ≥ 7 → len=4, left=1, sum=6
right=4: sum=10 ≥ 7 → len=4, left=2, sum=7 ≥ 7 → len=3
         left=3, sum=6
right=5: sum=9 ≥ 7 → len=3, left=4, sum=7 ≥ 7 → len=2
         left=5, sum=3

最短长度 = 2 (子数组[4,3])
```

## Go 实现

```go
func minSubArrayLen(target int, nums []int) int {
    left, sum := 0, 0
    ans := len(nums) + 1
    for right := 0; right < len(nums); right++ {
        sum += nums[right]
        for sum >= target {
            l := right - left + 1
            if l < ans {
                ans = l
            }
            sum -= nums[left]
            left++
        }
    }
    if ans == len(nums)+1 {
        return 0
    }
    return ans
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 滑动窗口；right扩张加元素；sum>=target时记录长度并left收缩；两层循环合计O(n)。
