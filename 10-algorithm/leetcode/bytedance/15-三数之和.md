# 15. 三数之和

题目链接：`https://leetcode.cn/problems/3sum/`

---

## 一、题目描述

给一个整数数组，找出所有三元组 `[a, b, c]`，使得 `a + b + c = 0`。结果不能有重复的三元组。

**示例：**

```
输入: nums = [-1,0,1,2,-1,-4]
输出: [[-1,-1,2],[-1,0,1]]

解释:
  (-1) + (-1) + 2 = 0
  (-1) + 0 + 1 = 0
  注意 [-1,0,1] 和 [0,1,-1] 是同一组，只出现一次

输入: nums = [0,1,1]
输出: []

输入: nums = [0,0,0]
输出: [[0,0,0]]
```

---

## 二、暴力法的困境

最直觉的想法：三重循环枚举所有组合。

```
问题1: O(n³)，肯定超时
问题2: 去重困难 — [-1,0,1] 和 [0,1,-1] 怎么判断是同一组？
```

去重的思路：先排序，保证每组里的数按从小到大排列，这样 [-1,0,1] 和 [0,1,-1] 就变成同一个 [-1,0,1] 了。

排序之后，自然引出一个优化：**排序 + 双指针**。

---

## 三、核心思路：排序 + 固定一个 + 双指针

排序后，问题变成：**固定第一个数 a，然后在剩余部分用双指针找 b 和 c 使得 b + c = -a**。

这和"两数之和"一模一样——有序数组上，左指针从左、右指针从右，和太大就右指针左移，和太小就左指针右移。

```
排序: [-4, -1, -1, 0, 1, 2]

固定 a = -4 (下标0)
  剩余部分找 b+c = 4
  left=1(-1), right=5(2) → -1+2=1 < 4 → left++
  left=2(-1), right=5(2) → -1+2=1 < 4 → left++
  left=3(0),  right=5(2) → 0+2=2 < 4  → left++
  left=4(1),  right=5(2) → 1+2=3 < 4  → left++
  left==right，结束

固定 a = -1 (下标1)
  剩余部分找 b+c = 1
  left=2(-1), right=5(2) → -1+2=1 = 1 ✓ 找到 [-1,-1,2]
  left=3(0),  right=4(1) → 0+1=1 = 1  ✓ 找到 [-1,0,1]

固定 a = -1 (下标2) → 跳过！和前一个相同，避免重复

固定 a = 0 (下标3)
  剩余部分找 b+c = 0
  left=4(1), right=5(2) → 1+2=3 > 0 → right--
  left==right，结束

结果: [[-1,-1,2],[-1,0,1]]
```

---

## 四、去重是这题最恶心的部分

排序解决了"同一组不同排列"的问题，但还有另一种重复：数组中有相同元素，可能枚举出完全相同的三元组。

```
[-1, -1, 0, 1]
            ↑
固定第一个 -1 → 找到 [-1, 0, 1]
固定第二个 -1 → 又找到 [-1, 0, 1]  ← 重复！
```

需要在三个位置去重：

| 去重位置 | 条件 | 说明 |
|----------|------|------|
| 固定 a 时 | `i > 0 && nums[i] == nums[i-1]` 跳过 | 相同的 a 不再固定 |
| 找到一组后，left 去重 | `nums[left] == nums[left-1]` 跳过 | 相同的 b 不再配 |
| 找到一组后，right 去重 | `nums[right] == nums[right+1]` 跳过 | 相同的 c 不再配 |

**关键：去重是在找到答案之后做的，不是在移动指针之前。**

---

## 五、Go 完整代码

```go
func threeSum(nums []int) [][]int {
    sort.Ints(nums)
    var res [][]int
    n := len(nums)

    for i := 0; i < n-2; i++ {
        // 去重1：相同的 a 跳过
        if i > 0 && nums[i] == nums[i-1] {
            continue
        }

        // 剪枝：a > 0 则 b+c > 0，不可能等于 -a < 0
        if nums[i] > 0 {
            break
        }

        left, right := i+1, n-1
        for left < right {
            sum := nums[i] + nums[left] + nums[right]
            if sum == 0 {
                res = append(res, []int{nums[i], nums[left], nums[right]})
                left++
                right--

                // 去重2：相同的 b 跳过
                for left < right && nums[left] == nums[left-1] {
                    left++
                }
                // 去重3：相同的 c 跳过
                for left < right && nums[right] == nums[right+1] {
                    right--
                }
            } else if sum < 0 {
                left++
            } else {
                right--
            }
        }
    }

    return res
}
```

## 六、逐行理解

```go
sort.Ints(nums)                    // 必须先排序！排序是整个解法的基础

for i := 0; i < n-2; i++ {        // i 固定 a，只需到 n-3（留两个给 b、c）

    // 去重1：i 和前一个相同就跳过
    if i > 0 && nums[i] == nums[i-1] { continue }

    // 剪枝：a 已经 > 0，后面都 > 0，不可能加起来 = 0
    if nums[i] > 0 { break }

    left, right := i+1, n-1        // 双指针在 [i+1, n-1] 范围内

    for left < right {
        sum := nums[i] + nums[left] + nums[right]

        if sum == 0 {
            // 找到一组
            res = append(res, []int{nums[i], nums[left], nums[right]})
            left++                 // 找到后两边都要移动
            right--                // 只移一边会错过组合

            // 去重2：跳过相同的 b
            for left < right && nums[left] == nums[left-1] { left++ }
            // 去重3：跳过相同的 c
            for left < right && nums[right] == nums[right+1] { right-- }

        } else if sum < 0 {
            left++                 // 和太小，左指针右移
        } else {
            right--                // 和太大，右指针左移
        }
    }
}
```

## 七、去重图解

```
nums = [-2, -1, -1, -1, 0, 1, 2, 2]
                 ↑i
          ↑left              ↑right

假设 i=1, nums[i]=-1
找到 [-1, -1, 2]

left++: nums[left] 还是 -1（和前一个相同）
  → 去重跳过，left 继续右移到 0

right--: nums[right] 还是 2（和后一个相同）
  → 去重跳过，right 继续左移

这样就不会再产生 [-1, -1, 2]
```

## 八、三个去重为什么是和前/后一个比？

```go
// a 的去重：和前一个比
if i > 0 && nums[i] == nums[i-1] { continue }

// b 的去重：和前一个比（left 已经右移过了，看上一个位置）
for left < right && nums[left] == nums[left-1] { left++ }

// c 的去重：和后一个比（right 已经左移过了，看下一个位置）
for left < right && nums[right] == nums[right+1] { right++ }
```

为什么不是和下一个比？

- **a 的去重**：`nums[i] == nums[i-1]` — 和前一个比，保证相同的 a 只在第一次出现时固定
- **b 的去重**：left 已经 `++` 了，所以 `nums[left-1]` 是刚刚用过的 b，如果相同就跳过
- **c 的去重**：right 已经 `--` 了，所以 `nums[right+1]` 是刚刚用过的 c，如果相同就跳过

**一句话：都是和"刚刚用过"的那个比，相同就跳过。**

## 九、复杂度分析

- **时间**：O(n²)。排序 O(n log n)，外层循环 O(n)，内层双指针 O(n)，总体 O(n²)
- **空间**：O(log n)，排序的栈空间（不算结果数组）

## 十、容易错的点

### 1. 排序是必须的

不排序就没法用双指针，也没法去重。这是整个解法的前提。

### 2. 去重用 `==` 不是 `!=`

```go
// ✓ 跳过相同的
if i > 0 && nums[i] == nums[i-1] { continue }

// ✗ 错误写法
if i > 0 && nums[i] != nums[i-1] { continue }  // 这会跳过所有不重复的
```

### 3. 找到答案后 left 和 right 都要移动

```go
if sum == 0 {
    res = append(res, ...)
    left++     // 必须移
    right--    // 必须移
    // 如果只移一个，sum 不变，死循环或错过组合
}
```

### 4. 剪枝用 break 不是 continue

```go
if nums[i] > 0 { break }   // 后面的 a 更大，直接结束

// 不是 continue，因为 a 排序后递增，后面的 a 也 > 0
```

### 5. i 的范围是 n-2 不是 n-1

```go
for i := 0; i < n-2; i++ {  // 留两个位置给 b 和 c
```

### 6. 去重循环要有 left < right 守卫

```go
for left < right && nums[left] == nums[left-1] { left++ }
//     ^^^^^^^^^^ 防止越界
```

## 十一、面试表达

> 三数之和，先排序，然后固定第一个数 a，在剩余部分用双指针找 b + c = -a。排序后可以用双指针：和太小左指针右移，和太大右指针左移。去重分三处：固定 a 时跳过相同的值；找到答案后，b 和 c 也要跳过相同的值。剪枝：如果 a > 0 就直接结束，因为后面都 > 0 加起来不可能为 0。时间 O(n²)，空间 O(log n)。
