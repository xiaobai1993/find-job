# 111. 二叉树的最小深度

> LeetCode 链接：https://leetcode.cn/problems/minimum-depth-of-binary-tree/

## 题目
给定二叉树，找到其最小深度（从根节点到最近叶子节点的路径的节点数）。

## 最易理解的方法：BFS（层序遍历）

**核心思路：**
BFS 逐层遍历，遇到第一个叶子节点（无左右子节点）时返回当前层数。
（注意：只有一侧子树时不是叶节点，不能用 min(左深度,右深度)）

```
    3
   / \
  9  20
     / \
    15   7

BFS: level1=[3], level2=[9,20],
9是叶节点 → 最小深度=2
```

## Go 实现

```go
func minDepth(root *TreeNode) int {
    if root == nil {
        return 0
    }
    queue := []*TreeNode{root}
    depth := 0
    for len(queue) > 0 {
        depth++
        n := len(queue)
        for i := 0; i < n; i++ {
            node := queue[i]
            // 找到叶节点
            if node.Left == nil && node.Right == nil {
                return depth
            }
            if node.Left != nil {
                queue = append(queue, node.Left)
            }
            if node.Right != nil {
                queue = append(queue, node.Right)
            }
        }
        queue = queue[n:]
    }
    return depth
}
```

## 复杂度
- 时间：O(n)（最坏情况）
- 空间：O(n)

## 记忆口诀
> BFS遇叶节点立即返回当前深度；注意必须是叶节点（左右均空）才能返回。
