# 301. 删除无效的括号

> LeetCode 链接：https://leetcode.cn/problems/remove-invalid-parentheses/

## 题目
给定包含括号和字母的字符串，删除最少数量的无效括号，返回所有可能的结果。

## 最易理解的方法：BFS（按层枚举删除）

**核心思路：**
BFS 按层枚举：第一层删除1个字符，第二层删除2个字符...
找到第一层有合法括号字符串时，收集所有该层的合法结果就是答案（最少删除数）。

```
"()())()"

第0层: "()())()" 非法
第1层: 删一个字符后的所有字符串中找合法的:
  "()()" ✓
  "())()" (非法)
  "()()" (重复)
  "()())" (非法)
  "(())" ✓
  ...

答案: ["()()", "(())"]
```

## Go 实现

```go
func removeInvalidParentheses(s string) []string {
    isValid := func(str string) bool {
        count := 0
        for _, c := range str {
            if c == '(' {
                count++
            } else if c == ')' {
                count--
                if count < 0 {
                    return false
                }
            }
        }
        return count == 0
    }
    visited := map[string]bool{s: true}
    queue := []string{s}
    var res []string
    found := false
    for len(queue) > 0 {
        n := len(queue)
        for i := 0; i < n; i++ {
            cur := queue[i]
            if isValid(cur) {
                res = append(res, cur)
                found = true
            }
            if found {
                continue
            }
            for j := 0; j < len(cur); j++ {
                if cur[j] != '(' && cur[j] != ')' {
                    continue
                }
                next := cur[:j] + cur[j+1:]
                if !visited[next] {
                    visited[next] = true
                    queue = append(queue, next)
                }
            }
        }
        if found {
            return res
        }
        queue = queue[n:]
    }
    return res
}
```

## 复杂度
- 时间：O(n × 2^n)（最坏）
- 空间：O(2^n)

## 记忆口诀
> BFS按层删除；第一次找到合法结果的那层就是最少删除；visited防重复。
