# 961. 在长度 2N 的数组中找出重复 N 次的元素

> LeetCode 链接：https://leetcode.cn/problems/n-repeated-element-in-size-2n-array/

## 题目
长度为 2N 的数组中，有 N+1 个不同的元素，其中有一个元素重复了 N 次，找出该元素。

## 最易理解的方法：哈希集合

**核心思路：**
遍历数组，将元素加入集合，第一次重复出现的就是答案。

```
nums = [5,1,5,2,5,3,5,4], N=4

遍历: 5→set, 1→set, 5 已在set → 返回5
```

## Go 实现

```go
func repeatedNTimes(nums []int) int {
    seen := make(map[int]bool)
    for _, n := range nums {
        if seen[n] { return n }
        seen[n] = true
    }
    return -1
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> 哈希集合记录；第一次重复出现的即为答案（重复N次的元素必然是第一个重复的）。
