# 34. 在排序数组中查找元素的第一个和最后一个位置

> LeetCode 链接：https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array/

## 题目
给定升序整数数组 `nums` 和目标值 `target`，找出 target 的第一个和最后一个位置；若不存在返回 `[-1,-1]`。时间复杂度 O(log n)。

## 最易理解的方法：两次二分查找

**核心思路：**
分别二分查找**左边界**和**右边界**：
- 左边界：找第一个 `>= target` 的位置
- 右边界：找最后一个 `<= target` 的位置（等价于找第一个 `> target` 的位置 - 1）

## Go 实现

```go
func searchRange(nums []int, target int) []int {
    left := lowerBound(nums, target)
    if left == len(nums) || nums[left] != target {
        return []int{-1, -1}
    }
    right := lowerBound(nums, target+1) - 1
    return []int{left, right}
}

// 返回第一个 >= target 的下标
func lowerBound(nums []int, target int) int {
    lo, hi := 0, len(nums)
    for lo < hi {
        mid := (lo + hi) / 2
        if nums[mid] < target {
            lo = mid + 1
        } else {
            hi = mid
        }
    }
    return lo
}
```

## 复杂度
- 时间：O(log n)
- 空间：O(1)

## 记忆口诀
> 两次二分：左边界找第一个>=target；右边界找第一个>target再减1；如果nums[left]!=target则不存在。
