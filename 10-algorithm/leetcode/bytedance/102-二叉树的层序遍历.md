# 102. 二叉树的层序遍历

> LeetCode 链接：https://leetcode.cn/problems/binary-tree-level-order-traversal/

## 题目
给定一个二叉树的根节点，返回其节点值的**层序遍历**（即逐层从左到右访问所有节点）。

## 最易理解的方法：BFS 队列

**核心思路：**
用队列做 BFS。关键技巧：**在处理每一层之前，先记录队列当前长度 n**，然后只处理这 n 个节点（它们是当前层的所有节点），处理时把下一层节点加入队列。

```
树：
    3
   / \
  9   20
     /  \
    15    7

第1次循环：n=1，处理[3]    → 下一层[9,20]
第2次循环：n=2，处理[9,20] → 下一层[15,7]
第3次循环：n=2，处理[15,7] → 无子节点
```

## Go 实现

```go
func levelOrder(root *TreeNode) [][]int {
    if root == nil {
        return nil
    }
    var res [][]int
    queue := []*TreeNode{root}
    for len(queue) > 0 {
        n := len(queue) // 当前层节点数
        level := make([]int, 0, n)
        for i := 0; i < n; i++ {
            node := queue[i]
            level = append(level, node.Val)
            if node.Left != nil {
                queue = append(queue, node.Left)
            }
            if node.Right != nil {
                queue = append(queue, node.Right)
            }
        }
        res = append(res, level)
        queue = queue[n:] // 移除已处理的当前层
    }
    return res
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> BFS队列；每轮先记 n=len(queue)，循环处理 n 个节点即一层；子节点入队。
