# 279. 完全平方数

> LeetCode 链接：https://leetcode.cn/problems/perfect-squares/

## 题目
给定整数 n，返回和为 n 的完全平方数（1,4,9,16,...）的最少数量。

## 最易理解的方法：完全背包 DP

**核心思路：**
`dp[i]` 表示组成 i 所需的最少完全平方数。
对每个 j（j² ≤ i）：`dp[i] = min(dp[i], dp[i-j²] + 1)`

```
n=12

完全平方数: 1,4,9

dp[0]=0, dp[1]=1, dp[2]=2, dp[3]=3
dp[4]=1 (4=2²)
dp[5]=2 (4+1)
...
dp[12]=3 (4+4+4)

答案=3
```

## Go 实现

```go
func numSquares(n int) int {
    dp := make([]int, n+1)
    for i := 1; i <= n; i++ {
        dp[i] = i // 最多用i个1²
        for j := 1; j*j <= i; j++ {
            if dp[i-j*j]+1 < dp[i] {
                dp[i] = dp[i-j*j] + 1
            }
        }
    }
    return dp[n]
}
```

## 复杂度
- 时间：O(n × √n)
- 空间：O(n)

## 记忆口诀
> 完全背包：dp[i]=min(dp[i-j²]+1)，j²≤i；初始化dp[i]=i（全用1²）。
