# 860. 柠檬水找零

> LeetCode 链接：https://leetcode.cn/problems/lemonade-change/

## 题目
柠檬水5美元，顾客用5/10/20元支付，判断是否能给每位顾客正确找零。

## 最易理解的方法：贪心找零

**核心思路：**
维护5元和10元的数量。收到20元时优先用10+5找零（保留更多小额钞票），不够则失败。

```
bills=[5,5,5,10,20]

收5: five=1
收5: five=2
收5: five=3
收10: five=2,ten=1 (找5元)
收20: ten=0,five=1 (找10+5)

全部成功 → true
```

## Go 实现

```go
func lemonadeChange(bills []int) bool {
    five, ten := 0, 0
    for _, bill := range bills {
        switch bill {
        case 5:
            five++
        case 10:
            if five == 0 { return false }
            five--; ten++
        case 20:
            if ten > 0 && five > 0 {
                ten--; five--
            } else if five >= 3 {
                five -= 3
            } else {
                return false
            }
        }
    }
    return true
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 统计5和10元；收20时优先用10+5找零（保留小额）；不够则false。
