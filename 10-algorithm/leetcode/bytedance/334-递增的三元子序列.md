# 334. 递增的三元子序列

> LeetCode 链接：https://leetcode.cn/problems/increasing-triplet-subsequence/

## 题目
给定整数数组，判断是否存在长度为 3 的递增子序列（i < j < k，nums[i] < nums[j] < nums[k]）。

## 最易理解的方法：贪心双变量

**核心思路：**
维护两个变量：`first`（最小值）和 `second`（在 first 后面的次小值）。
遍历每个数：
- 若 <= first：更新 first
- 若 <= second：更新 second
- 否则：找到第三个更大的值，返回 true

```
nums=[2,1,5,0,4,6]

first=2, second=∞
1: 1<2 → first=1
5: 5>second=∞→5>first=1 → second=5
0: 0<first=1 → first=0
4: 4<second=5 → second=4
6: 6>second=4 → true (存在 0<4<6 或类似的递增三元组)
```

## Go 实现

```go
import "math"

func increasingTriplet(nums []int) bool {
    first, second := math.MaxInt64, math.MaxInt64
    for _, n := range nums {
        if n <= first {
            first = n
        } else if n <= second {
            second = n
        } else {
            return true
        }
    }
    return false
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 贪心：维护first（最小）和second（次小）；遇到>second的第三个数即返回true。
