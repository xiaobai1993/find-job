# 946. 验证栈序列

> LeetCode 链接：https://leetcode.cn/problems/validate-stack-sequences/

## 题目
给定 pushed 和 popped 两个序列，判断是否可能是一个空栈的 push 和 pop 操作序列。

## 最易理解的方法：模拟栈操作

**核心思路：**
模拟：依次将 pushed 中的元素入栈，每入一个就检查栈顶是否等于 popped 中待弹出的元素，是则弹出。

```
pushed=[1,2,3,4,5], popped=[4,5,3,2,1]

push 1→[1]     pop? 1≠4
push 2→[1,2]   pop? 2≠4
push 3→[1,2,3] pop? 3≠4
push 4→[1,2,3,4] pop? 4==4 → 弹出 → [1,2,3], j=1
                  5==? 3≠5
push 5→[1,2,3,5] pop? 5==5 → 弹出 → [1,2,3], j=2
                  3==3 → 弹出 ... → 最终栈空 → true
```

## Go 实现

```go
func validateStackSequences(pushed []int, popped []int) bool {
    stack := []int{}
    j := 0
    for _, v := range pushed {
        stack = append(stack, v)
        for len(stack) > 0 && stack[len(stack)-1] == popped[j] {
            stack = stack[:len(stack)-1]
            j++
        }
    }
    return len(stack) == 0
}
```

## 复杂度
- 时间：O(n)
- 空间：O(n)

## 记忆口诀
> 模拟入栈；每次入栈后持续检查栈顶==待弹出元素则弹出；最终栈空则有效。
