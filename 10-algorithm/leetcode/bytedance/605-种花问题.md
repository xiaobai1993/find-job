# 605. 种花问题

> LeetCode 链接：https://leetcode.cn/problems/can-place-flowers/

## 题目
花坛数组（0空1有花），相邻位置不能同时种花，判断能否再种 n 朵。

## 最易理解的方法：贪心扫描

**核心思路：**
遍历花坛，当前位置为0且前后也为0（或是边界）时就种花，尽早种以腾出空间。

```
flowerbed=[1,0,0,0,1], n=1

位置1: 左=1 → 跳过
位置2: 左=0,右=0 → 种花，flowerbed变[1,0,1,0,1]
位置3: 左=1 → 跳过

种了1朵 >= n=1 → true
```

## Go 实现

```go
func canPlaceFlowers(flowerbed []int, n int) bool {
    for i := 0; i < len(flowerbed) && n > 0; i++ {
        if flowerbed[i] == 0 {
            left := i == 0 || flowerbed[i-1] == 0
            right := i == len(flowerbed)-1 || flowerbed[i+1] == 0
            if left && right {
                flowerbed[i] = 1
                n--
            }
        }
    }
    return n <= 0
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 贪心：当前为0且左右均为0（或边界）则种花；种后标记为1防止影响下一格。
