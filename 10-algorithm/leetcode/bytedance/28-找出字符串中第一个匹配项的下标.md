# 28. 找出字符串中第一个匹配项的下标

> LeetCode 链接：https://leetcode.cn/problems/find-the-index-of-the-first-occurrence-in-a-string/

## 题目
给定字符串 haystack 和 needle，在 haystack 中找到 needle 第一次出现的下标（不存在返回 -1）。

## 方法一：KMP 算法（O(m+n)）

**核心思路：**
预处理 needle 的部分匹配表（failure function）`lps[i]` = `needle[0..i]` 的最长相等前后缀长度。
匹配失败时，利用 lps 跳过不必要的比较。

```
needle = "aabaa"
lps = [0,1,0,1,2]

匹配 "aabaabaab":
失配时利用lps跳转，而不是每次退回到起点
```

## Go 实现

```go
func strStr(haystack string, needle string) int {
    n, m := len(haystack), len(needle)
    if m == 0 {
        return 0
    }
    // 构建 lps 数组
    lps := make([]int, m)
    length, i := 0, 1
    for i < m {
        if needle[i] == needle[length] {
            length++
            lps[i] = length
            i++
        } else if length > 0 {
            length = lps[length-1]
        } else {
            lps[i] = 0
            i++
        }
    }
    // KMP 匹配
    j := 0 // needle 指针
    for i := 0; i < n; {
        if haystack[i] == needle[j] {
            i++
            j++
        }
        if j == m {
            return i - j
        } else if i < n && haystack[i] != needle[j] {
            if j > 0 {
                j = lps[j-1]
            } else {
                i++
            }
        }
    }
    return -1
}
```

## 复杂度
- 时间：O(m+n)
- 空间：O(m)

## 记忆口诀
> KMP：先建lps（最长相等前后缀）；匹配失败时j=lps[j-1]回退而非从0；找到返回i-j。
