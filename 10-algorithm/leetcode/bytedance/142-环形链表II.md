# 142. 环形链表 II

> LeetCode 链接：https://leetcode.cn/problems/linked-list-cycle-ii/

## 题目
给定链表，若链表中存在环，返回入环的第一个节点，否则返回 nil。

## 最易理解的方法：Floyd 判圈 + 数学推导

**核心思路：**
第一步：快慢指针找相遇点（同 141 题）。第二步：**将慢指针重置回 head，快指针保持在相遇点，两者都每次走 1 步，再次相遇处即为环的入口**。

**数学原理：**
设链表头到环入口距离为 `a`，环入口到相遇点为 `b`，环长为 `c`。相遇时：slow 走了 `a+b`，fast 走了 `a+b+c`（多走一圈）。所以 `2(a+b) = a+b+c`，推出 `a = c-b`，即**从 head 到入口的距离 = 从相遇点继续走到入口的距离**。

```
head→[1→2→3→4→5]
              ↑___↓ (环入口=3)

a=距离(head→3)=2
fast 和 slow 相遇于 5

重置 slow=head，fast=5
slow: head→1→2→3
fast:    5→3
同时到达 3 → 入口！
```

## Go 实现

```go
func detectCycle(head *ListNode) *ListNode {
    slow, fast := head, head
    // 第一步：找相遇点
    for fast != nil && fast.Next != nil {
        slow = slow.Next
        fast = fast.Next.Next
        if slow == fast {
            // 第二步：找环入口
            slow = head
            for slow != fast {
                slow = slow.Next
                fast = fast.Next
            }
            return slow
        }
    }
    return nil
}
```

## 复杂度
- 时间：O(n)
- 空间：O(1)

## 记忆口诀
> 快慢指针找相遇点；然后一个回 head，另一个从相遇点，同速走，再次相遇即入口（a = c-b）。
