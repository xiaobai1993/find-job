# 841. 钥匙和房间

> LeetCode 链接：https://leetcode.cn/problems/keys-and-rooms/

## 题目
n 个房间（0到n-1），0号房间可以进入，其他需要钥匙。rooms[i] 是房间i里的钥匙，判断能否进入所有房间。

## 最易理解的方法：DFS/BFS 可达性

**核心思路：**
从房间0出发 DFS，将获得的钥匙加入队列，最终判断是否访问了所有房间。

```
rooms = [[1],[2],[3],[]]

从0出发: 获得钥匙1 → 进入1: 获得钥匙2 → 进入2: 获得钥匙3 → 进入3: 无新钥匙
访问了[0,1,2,3] → true
```

## Go 实现

```go
func canVisitAllRooms(rooms [][]int) bool {
    visited := make([]bool, len(rooms))
    var dfs func(room int)
    dfs = func(room int) {
        visited[room] = true
        for _, key := range rooms[room] {
            if !visited[key] {
                dfs(key)
            }
        }
    }
    dfs(0)
    for _, v := range visited {
        if !v { return false }
    }
    return true
}
```

## 复杂度
- 时间：O(n+m)（m为钥匙总数）
- 空间：O(n)

## 记忆口诀
> 从0号房间DFS；收集钥匙进入未访问的房间；最终检查所有房间是否被访问。
