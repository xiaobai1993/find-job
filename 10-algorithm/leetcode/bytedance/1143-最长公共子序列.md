# 1143. 最长公共子序列

> LeetCode 链接：https://leetcode.cn/problems/longest-common-subsequence/

## 题目
给定两个字符串 `text1` 和 `text2`，返回两个字符串的最长公共子序列的长度（子序列不要求连续）。

## 最易理解的方法：动态规划

**核心思路：**
`dp[i][j]` 表示 `text1[0:i]` 和 `text2[0:j]` 的最长公共子序列长度。
- 若 `text1[i-1] == text2[j-1]`：`dp[i][j] = dp[i-1][j-1] + 1`
- 否则：`dp[i][j] = max(dp[i-1][j], dp[i][j-1])`

```
text1="abcde", text2="ace"

    ""  a  c  e
""   0  0  0  0
a    0  1  1  1
b    0  1  1  1
c    0  1  2  2
d    0  1  2  2
e    0  1  2  3  ← LCS长度=3
```

## Go 实现

```go
func longestCommonSubsequence(text1 string, text2 string) int {
    m, n := len(text1), len(text2)
    dp := make([][]int, m+1)
    for i := range dp {
        dp[i] = make([]int, n+1)
    }
    for i := 1; i <= m; i++ {
        for j := 1; j <= n; j++ {
            if text1[i-1] == text2[j-1] {
                dp[i][j] = dp[i-1][j-1] + 1
            } else {
                if dp[i-1][j] > dp[i][j-1] {
                    dp[i][j] = dp[i-1][j]
                } else {
                    dp[i][j] = dp[i][j-1]
                }
            }
        }
    }
    return dp[m][n]
}
```

## 复杂度
- 时间：O(m × n)
- 空间：O(m × n)，可滚动数组优化为 O(n)

## 记忆口诀
> 字符相同=斜上角+1；不同=上方和左方取最大；LCS 是二维DP经典。
