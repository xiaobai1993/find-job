# 785. 判断二分图

> LeetCode 链接：https://leetcode.cn/problems/is-graph-bipartite/

## 题目
给定无向图（邻接表），判断是否为二分图（可以用两种颜色给节点着色，使得相邻节点颜色不同）。

## 最易理解的方法：BFS/DFS 染色

**核心思路：**
用 0/1 两色 BFS 染色，相邻节点必须不同色，若发现冲突则不是二分图。

```
graph = [[1,3],[0,2],[1,3],[0,2]]

BFS从0出发:
0→颜色0; 邻居1,3→颜色1
1→颜色1; 邻居2→颜色0, 0已着色一致
3→颜色1; 邻居2→颜色0, 0已着色一致

无冲突 → 二分图
```

## Go 实现

```go
func isBipartite(graph [][]int) bool {
    color := make([]int, len(graph))
    for i := range color { color[i] = -1 }
    for i := 0; i < len(graph); i++ {
        if color[i] != -1 { continue }
        queue := []int{i}
        color[i] = 0
        for len(queue) > 0 {
            cur := queue[0]
            queue = queue[1:]
            for _, nb := range graph[cur] {
                if color[nb] == -1 {
                    color[nb] = 1 - color[cur]
                    queue = append(queue, nb)
                } else if color[nb] == color[cur] {
                    return false
                }
            }
        }
    }
    return true
}
```

## 复杂度
- 时间：O(V+E)
- 空间：O(V)

## 记忆口诀
> BFS染色；未着色节点染反色；已着色且同色则非二分图。
