# 295. 数据流的中位数

> LeetCode 链接：https://leetcode.cn/problems/find-median-from-data-stream/

## 题目
设计数据结构，支持：`addNum(num)` 向数据流添加整数；`findMedian()` 返回目前所有数据的中位数。

## 最易理解的方法：两个堆（大根堆 + 小根堆）

**核心思路：**
- **大根堆 `maxHeap`**：存较小的一半（堆顶是较小一半的最大值）
- **小根堆 `minHeap`**：存较大的一半（堆顶是较大一半的最小值）
- 保持大根堆元素数量 ≥ 小根堆（差不超过1）

中位数：若两堆大小相同，取两堆顶平均值；否则取大根堆顶。

```
addNum 步骤：
1. 先放入大根堆（维护：先放大根堆，若比小根堆顶大则先移到小根堆再取一个回大根堆）
2. 平衡两堆大小（大根堆最多比小根堆多1个）

addNums: 1, 2, 3
maxHeap:[1], minHeap:[]    → median=1
maxHeap:[1], minHeap:[2]   → median=(1+2)/2=1.5
maxHeap:[2,1], minHeap:[3] → median=2
```

## Go 实现

```go
import "container/heap"

type MedianFinder struct {
    maxH MaxHeap // 大根堆，存较小一半
    minH MinHeap // 小根堆，存较大一半
}

func Constructor() MedianFinder { return MedianFinder{} }

func (mf *MedianFinder) AddNum(num int) {
    heap.Push(&mf.maxH, num)
    // 将大根堆最大值推入小根堆
    heap.Push(&mf.minH, heap.Pop(&mf.maxH))
    // 保持大根堆 >= 小根堆
    if mf.maxH.Len() < mf.minH.Len() {
        heap.Push(&mf.maxH, heap.Pop(&mf.minH))
    }
}

func (mf *MedianFinder) FindMedian() float64 {
    if mf.maxH.Len() > mf.minH.Len() {
        return float64(mf.maxH[0])
    }
    return float64(mf.maxH[0]+mf.minH[0]) / 2.0
}

type MaxHeap []int
func (h MaxHeap) Len() int           { return len(h) }
func (h MaxHeap) Less(i, j int) bool { return h[i] > h[j] }
func (h MaxHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }
func (h *MaxHeap) Push(x interface{}) { *h = append(*h, x.(int)) }
func (h *MaxHeap) Pop() interface{} {
    old := *h; n := len(old); x := old[n-1]; *h = old[:n-1]; return x
}

type MinHeap []int
func (h MinHeap) Len() int           { return len(h) }
func (h MinHeap) Less(i, j int) bool { return h[i] < h[j] }
func (h MinHeap) Swap(i, j int)      { h[i], h[j] = h[j], h[i] }
func (h *MinHeap) Push(x interface{}) { *h = append(*h, x.(int)) }
func (h *MinHeap) Pop() interface{} {
    old := *h; n := len(old); x := old[n-1]; *h = old[:n-1]; return x
}
```

## 复杂度
- 时间：addNum O(log n)，findMedian O(1)
- 空间：O(n)

## 记忆口诀
> 大根堆存小半，小根堆存大半；中位数看两堆顶；每次加数后平衡两堆大小（大根堆不少于小根堆）。
