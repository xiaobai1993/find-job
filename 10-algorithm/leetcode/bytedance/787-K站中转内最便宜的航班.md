# 787. K 站中转内最便宜的航班

> LeetCode 链接：https://leetcode.cn/problems/cheapest-flights-within-k-stops/

## 题目
n 个城市、给定航班（起点、终点、价格），求从 src 到 dst 最多 k 站中转（k+1 条边）的最低费用，不可达返回 -1。

## 最易理解的方法：Bellman-Ford（限 k+1 轮松弛）

**核心思路：**
Bellman-Ford 限制只做 k+1 轮松弛，每轮基于上一轮的结果更新（防止一轮内多次松弛）。

```
src=0, dst=2, k=1
flights: 0→1(100), 1→2(100), 0→2(500)

第1轮: dist[1]=100, dist[2]=500
第2轮: dist[2]=min(500,100+100)=200

结果: 200
```

## Go 实现

```go
import "math"

func findCheapestPrice(n int, flights [][]int, src int, dst int, k int) int {
    dist := make([]int, n)
    for i := range dist { dist[i] = math.MaxInt32 }
    dist[src] = 0
    for i := 0; i <= k; i++ {
        tmp := append([]int{}, dist...)
        for _, f := range flights {
            u, v, w := f[0], f[1], f[2]
            if dist[u] != math.MaxInt32 && dist[u]+w < tmp[v] {
                tmp[v] = dist[u] + w
            }
        }
        dist = tmp
    }
    if dist[dst] == math.MaxInt32 { return -1 }
    return dist[dst]
}
```

## 复杂度
- 时间：O(k×E)
- 空间：O(n)

## 记忆口诀
> Bellman-Ford限k+1轮；每轮基于上轮dist更新(用tmp防止链式传播)；dst不可达返-1。
