# 33. 搜索旋转排序数组

题目链接：`https://leetcode.cn/problems/search-in-rotated-sorted-array/description/`

---

## 一、题目描述

升序数组在某个点旋转了，比如 `[0,1,2,4,5,6,7]` 在 4 处旋转变成 `[4,5,6,7,0,1,2]`。

给旋转后的数组和 target，返回 target 的下标，找不到返回 -1。要求 O(log n)。

**示例：**

```
输入: nums = [4,5,6,7,0,1,2], target = 0
输出: 4

输入: nums = [4,5,6,7,0,1,2], target = 3
输出: -1

输入: nums = [1], target = 0
输出: -1
```

---

## 二、核心思路：二分 + 判断哪半边有序

数组虽然旋转了，但**从 mid 切一刀，必定有一半是有序的**。这是解题的关键性质。

```
[4, 5, 6, 7, 0, 1, 2]
       ↑ mid

左半 [4,5,6,7] → 有序
右半 [0,1,2]  → 也有序（但不包含左半的所有值）

实际上：任意从 mid 切开，左半或右半至少一个完全有序
```

所以策略是：**每次二分，先判断哪半边有序，然后看 target 在不在有序那半边，在就搜那半，不在就搜另一半。**

---

## 三、怎么判断哪半边有序？

看 `nums[left]` 和 `nums[mid]` 的关系：

```
情况1：nums[left] <= nums[mid] → 左半有序

  [4, 5, 6, 7, 0, 1, 2]
   l        m        r
   4 <= 7 → 左半 [4,5,6,7] 有序 ✓

情况2：nums[left] > nums[mid] → 右半有序

  [5, 6, 0, 1, 2, 3, 4]
   l        m        r
   5 > 1 → 右半 [1,2,3,4] 有序 ✓
```

**一句话：`nums[left] <= nums[mid]` → 左有序，否则右有序。**

---

## 四、target 在不在有序那半边？

有序那半边的范围是确定的，直接比较：

```
左半有序时：范围 [nums[left], nums[mid]]
  target 在这个范围 → 搜左边 (right = mid - 1)
  target 不在       → 搜右边 (left = mid + 1)

右半有序时：范围 [nums[mid], nums[right]]
  target 在这个范围 → 搜右边 (left = mid + 1)
  target 不在       → 搜左边 (right = mid - 1)
```

## 五、完整流程图解

### 例1：`nums = [4,5,6,7,0,1,2], target = 0`

```
第1轮: left=0, right=6, mid=3
       nums = [4, 5, 6, 7, 0, 1, 2]
               l        m        r
       nums[left]=4 <= nums[mid]=7 → 左半有序
       target=0 在 [4,7] 内？ 不在 → 搜右边
       left = mid+1 = 4

第2轮: left=4, right=6, mid=5
       nums = [4, 5, 6, 7, 0, 1, 2]
                             l  m  r
       nums[left]=0 <= nums[mid]=1 → 左半有序
       target=0 在 [0,1] 内？ 在 → 搜左边
       right = mid-1 = 4

第3轮: left=4, right=4, mid=4
       nums[mid]=0 == target → 返回 4 ✓
```

### 例2：`nums = [5,6,0,1,2,3,4], target = 6`

```
第1轮: left=0, right=6, mid=3
       nums = [5, 6, 0, 1, 2, 3, 4]
               l        m        r
       nums[left]=5 > nums[mid]=1 → 右半有序
       target=6 在 [1,4] 内？ 不在 → 搜左边
       right = mid-1 = 2

第2轮: left=0, right=2, mid=1
       nums = [5, 6, 0]
               l  m  r
       nums[left]=5 <= nums[mid]=6 → 左半有序
       target=6 在 [5,6] 内？ 在 → 搜左边
       right = mid-1 = 0

第3轮: left=0, right=0, mid=0
       nums[mid]=5 != 6, 5 < 6 → left=1

left > right → 返回 -1 ✓
```

## 六、Go 完整代码

```go
func search(nums []int, target int) int {
    left, right := 0, len(nums)-1

    for left <= right {
        mid := left + (right-left)/2

        if nums[mid] == target {
            return mid
        }

        if nums[left] <= nums[mid] {
            // 左半有序
            if nums[left] <= target && target < nums[mid] {
                right = mid - 1 // target 在左半
            } else {
                left = mid + 1  // target 在右半
            }
        } else {
            // 右半有序
            if nums[mid] < target && target <= nums[right] {
                left = mid + 1  // target 在右半
            } else {
                right = mid - 1 // target 在左半
            }
        }
    }

    return -1
}
```

## 七、逐行理解

```go
left, right := 0, len(nums)-1    // 标准二分初始化

for left <= right {               // 标准二分循环条件
    mid := left + (right-left)/2  // 防溢出

    if nums[mid] == target { return mid }  // 找到了

    // ---- 以下是与普通二分唯一不同的地方 ----

    if nums[left] <= nums[mid] {
        //      左半 [left..mid] 有序
        //      判断 target 是否在有序区间内
        if nums[left] <= target && target < nums[mid] {
            right = mid - 1  // 在有序区间，放心搜
        } else {
            left = mid + 1   // 不在，去另一半
        }
    } else {
        //      右半 [mid..right] 有序
        if nums[mid] < target && target <= nums[right] {
            left = mid + 1   // 在有序区间，放心搜
        } else {
            right = mid - 1  // 不在，去另一半
        }
    }
}

return -1  // 没找到
```

## 八、和普通二分的对比

| | 普通二分 | 旋转数组二分 |
|--|----------|--------------|
| 判断条件 | 直接比 target 和 nums[mid] | 先判断哪半边有序，再判断 target 在哪半 |
| 核心区别 | 整个数组有序 | 只有一半有序 |
| 收缩方式 | target < mid → 左，target > mid → 右 | 有序半边能确定 target 在不在，不在就去另一半 |

本质就是：**普通二分能直接判断 target 在 mid 左还是右，旋转数组需要先确定哪半有序，才能做判断。**

## 九、复杂度分析

- **时间**：O(log n)，标准二分
- **空间**：O(1)

## 十、容易错的点

### 1. 判断有序用 `<=` 不是 `<`

```go
if nums[left] <= nums[mid]  // 注意是 <=
```

当 `left == mid` 时（只剩两个元素），`nums[left] == nums[mid]`，这种情况也算左半有序。

### 2. 判断 target 在有序区间内，边界要写对

```
左半有序时：nums[left] <= target && target < nums[mid]
                                    ^注意是 <，不是 <=
                                   因为 nums[mid] 已经确认不是 target

右半有序时：nums[mid] < target && target <= nums[right]
                                  ^注意是 <=
```

可以这样记：**mid 那边是开区间（已经检查过了），另一端是闭区间。**

### 3. 没有重复元素才能这么做

题目保证无重复。如果有重复，`nums[left] == nums[mid]` 时无法判断哪半有序，需要单独处理（见 LeetCode 81）。

### 4. 单元素数组

```
nums = [1], target = 0
left=0, right=0, mid=0
nums[mid]=1 != 0
nums[left]=1 <= nums[mid]=1 → 左半有序
target=0 在 [1,1] 内？ 不在 → left=1
left > right → return -1 ✓
```

## 十一、面试表达

> 旋转排序数组找 target，用二分。关键性质：从 mid 切开，至少有一半是有序的。判断哪半有序看 `nums[left]` 和 `nums[mid]` 的大小关系：`nums[left] <= nums[mid]` 说明左半有序，否则右半有序。确定有序半边后，看 target 在不在这个有序范围内，在就搜有序那边，不在就搜另一边。时间 O(log n)，空间 O(1)。
