# 329. 矩阵中的最长递增路径

> LeetCode 链接：https://leetcode.cn/problems/longest-increasing-path-in-a-matrix/

## 题目
给定 m×n 整数矩阵，找到最长递增路径的长度（可以上下左右移动，不能重复访问）。

## 最易理解的方法：DFS + 记忆化

**核心思路：**
从每个格子出发 DFS，找以该格子为起点的最长路径。
用 memo[i][j] 缓存结果避免重复计算（天然无环，因为路径严格递增）。

```
矩阵:
9 9 4
6 6 8
2 1 1

从2出发: 2→6→9 = 长度3
从1出发: 1→2→6→9 = 长度4
答案 = 4
```

## Go 实现

```go
func longestIncreasingPath(matrix [][]int) int {
    m, n := len(matrix), len(matrix[0])
    memo := make([][]int, m)
    for i := range memo {
        memo[i] = make([]int, n)
    }
    dirs := [][2]int{{0,1},{0,-1},{1,0},{-1,0}}
    var dfs func(i, j int) int
    dfs = func(i, j int) int {
        if memo[i][j] != 0 {
            return memo[i][j]
        }
        memo[i][j] = 1
        for _, d := range dirs {
            ni, nj := i+d[0], j+d[1]
            if ni >= 0 && ni < m && nj >= 0 && nj < n && matrix[ni][nj] > matrix[i][j] {
                if val := 1 + dfs(ni, nj); val > memo[i][j] {
                    memo[i][j] = val
                }
            }
        }
        return memo[i][j]
    }
    res := 0
    for i := 0; i < m; i++ {
        for j := 0; j < n; j++ {
            if v := dfs(i, j); v > res {
                res = v
            }
        }
    }
    return res
}
```

## 复杂度
- 时间：O(m×n)（每个格子只计算一次）
- 空间：O(m×n)

## 记忆口诀
> DFS+记忆化；因为严格递增所以无环，memo安全；从每个格子出发取最大值。
