# 740. 删除并获得点数

> LeetCode 链接：https://leetcode.cn/problems/delete-and-earn/

## 题目
给定数组，选取 nums[i] 可以获得 nums[i] 点数，但必须删除所有等于 nums[i]-1 和 nums[i]+1 的元素。求能获得的最大点数。

## 最易理解的方法：转化为打家劫舍问题

**核心思路：**
相当于：选了 x 就不能选 x±1（和打家劫舍一样）。
用 sum[x] = x × count(x) 建桶数组，然后做 DP（打家劫舍）。

```
nums = [3,4,2]

sum: [0,0,2,3,4,0]  (2出现1次×2, 3出现1次×3, 4出现1次×4)

dp打家劫舍:
dp[0]=0, dp[1]=0, dp[2]=2, dp[3]=max(3,2)=3, dp[4]=max(4,3+4)=7

结果: 6 (选2+4)
```

## Go 实现

```go
func deleteAndEarn(nums []int) int {
    maxVal := 0
    for _, n := range nums {
        if n > maxVal { maxVal = n }
    }
    sum := make([]int, maxVal+1)
    for _, n := range nums { sum[n] += n }
    // 打家劫舍
    if maxVal == 0 { return 0 }
    if maxVal == 1 { return sum[1] }
    prev, curr := sum[0], max3(sum[0], sum[1])
    for i := 2; i <= maxVal; i++ {
        prev, curr = curr, max3(curr, prev+sum[i])
    }
    return curr
}

func max3(a, b int) int {
    if a > b { return a }
    return b
}
```

## 复杂度
- 时间：O(n + max)
- 空间：O(max)

## 记忆口诀
> 建sum桶(sum[x]=x×频率)；再做打家劫舍DP（选了x不能选x±1）。
